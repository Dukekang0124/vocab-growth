# 词汇生长 Vocabulary Growth — App (v2)

> 把 OB「英语自学建设系统」(Hermes) 验证过的词汇生长方法论，变成可自助使用的 Web 应用。
> 核心闭环：**学（词群语块卡）→ 复（分层抢救+遗忘深度）→ 用（开口练：4 种练法+即时评分）**
> 在线地址：https://dukekang0124.github.io/vocab-growth/

## 本地运行（零依赖）

```bash
node server.js          # 默认 http://127.0.0.1:8430
node server.js 9000     # 自定义端口
```

或直接双击 `index.html`（纯静态，file:// 也能跑；语音用浏览器 TTS）。

## v2 新增：开口练（对标 OB 英语开口练）

原「造句工坊」升级为「🎤 开口练」，提交即评分，四种练法：

| 练法 | 玩法 | 反馈 |
|:--|:--|:--|
| ✍️ 造句 | 中译英写一句 | 四维评分 + 纠错 + 老外版本对照 |
| 📝 句型填空 | 从地道例句挖空补全 | 自动判对错，正确 ≥70 分 |
| 🎯 关键词造句 | 3 个词串进一句话 | 漏词扣分并提示 |
| 🎤 开口说 | 看中文开口说，浏览器语音识别转文字 | 与老外版本比对打分（零成本，无需 API key；微信内置浏览器自动降级提示换 Chrome/Edge） |

配套三套系统：

- **即时评分**（`js/speak-workshop.js`）：语法 / 完整 / 自然 / 词汇 四维进度条 + A~E 等级评语 + 「这样改更好」纠错 + 「做得好的」亮点 + 老外版本（可点击听发音）
- **难度分级**（`js/difficulty-level.js`）：A1/A2/B1/B2 四档，按最近 5 次练习均分自动定级，每档给不同的造句提示（入门「先把话说出来」→ 高级「表达看法并给理由」），并按难度筛选候选词
- **激励机制**（`js/gamification.js`）：积分（顶栏 ⭐ 实时显示）+ 5 级等级（开口新手→口语大师）+ 8 枚徽章自动解锁；「📚 词汇 → 🏆 成就」页展示徽章墙、升级进度、最近练习记录

## 方法论映射（为什么这么设计）

| 原系统方法论 | App 实现 |
|:--|:--|
| 识别≠生产 | 全部产出型题型：说词/造句/开口说，无选择题 |
| 词群学习法 | 8 个故事词群（海洋探险/高山之旅…） |
| 简单英语解释法 | 每词 simple 字段（小孩能懂的释义） |
| 分层抢救六层提示 | 复习页逐层解锁（硬想30s→词性→词义→首字母→长度+场景→答案） |
| 遗忘是数据 | 🟢🟡🔴 遗忘深度驱动排程（隔2天/1天/每天） |
| 三库自动流转 | 🔴自动进薄弱清单；连续2次🟢自动移出 |
| 当天用掉 | 首页「今天用掉」清单 |
| 新词上限铁律 | 待复习>30 锁定新词添加 |
| 语块优先/库存积累 | 说法库：你想说X→老外会说Y（自测模式+跟读） |
| 敢说先于说对 | 开口练评语只鼓励不打击（E 级也给下一步动作），敢开口就有积分 |
| 即时反馈 | 提交即出四维评分与纠错，不等语伴、不等老师 |
| 循序渐进 | 难度分级 + 自动定级，同一批词随水平升级练法 |
| 证据驱动 | 只统计真实发生的学习行为（复习/开口练/用掉），积分只从练习来 |
