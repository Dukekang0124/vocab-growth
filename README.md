# 词汇生长 Vocabulary Growth — App

> 把 OB「英语自学建设系统」(Hermes) 验证过的词汇生长方法论，变成可自助使用的 Web 应用。
> 核心闭环：**学（词群语块卡）→ 复（分层抢救+遗忘深度）→ 用（造句+老外版本+当天用掉）**

## 本地运行（零依赖）

```bash
node server.js          # 默认 http://127.0.0.1:8430
node server.js 9000     # 自定义端口
```

或直接双击 `index.html`（纯静态，file:// 也能跑；语音用浏览器 TTS）。

## 目录结构

```
vocab-growth-app/
├── index.html            页面骨架（6 tab）
├── css/style.css         样式（移动优先响应式）
├── js/
│   ├── data.js           种子数据：68词(8词群) + 13语块 + 真实状态（OB 真实资产）
│   ├── srs.js            SRS-lite 调度引擎（纯函数，可单测）
│   ├── store.js          状态管理（localStorage，storage 适配器注入可测）
│   └── app.js            UI 渲染与交互 + TTS
├── assets/audio/         40 个 OB 真实美音 mp3（488KB）
├── server.js             零依赖静态服务器
└── test/                 Node 单元测试（node --test）
```

## 方法论映射（为什么这么设计）

| 原系统方法论 | App 实现 |
|:--|:--|
| 识别≠生产 | 全部产出型题型：说词/造句，无选择题 |
| 词群学习法 | 8 个故事词群（海洋探险/高山之旅…） |
| 简单英语解释法 | 每词 simple 字段（小孩能懂的释义） |
| 分层抢救六层提示 | 复习页逐层解锁（硬想30s→词性→词义→首字母→长度+场景→答案） |
| 遗忘是数据 | 🟢🟡🔴 遗忘深度驱动排程（隔2天/1天/每天） |
| 三库自动流转 | 🔴自动进薄弱清单；连续2次🟢自动移出 |
| 当天用掉 | 首页「今天用掉」清单 |
| 新词上限铁律 | 待复习>30 锁定新词添加 |
| 语块优先/库存积累 | 说法库：你想说X→老外会说Y（自测模式+跟读） |
| 证据驱动 | 只统计真实发生的学习行为（复习/造句/用掉） |
