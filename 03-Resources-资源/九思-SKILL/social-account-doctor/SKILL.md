# social-account-doctor — 找对标 / 拆爆款 / 套自己

> 不挖钩子建仓库，不写诊断报告。直接对着具体爆款 → 输出**下一条笔记初稿**（标题 + 封面大字 + 首段 + CTA）。

## 闭环图

```
[我的账号 / 选题方向]
       │
       ▼ ① find  (多模态识别本质 → 矩阵搜→ 相似度过滤)
[5-10 个真对标爆款]
       │
       ▼ 人工勾选 3-5 条 ✋
[选定对标]
       │
       ▼ ② crack
[每条 4 维钩子拆解（视觉/文字/口播/剧情）+ 综合权重 + 骨架 + 封面 + 标签]
       │
       ▼ ③ adapt
[3 标题 + 3 封面大字 + 1 段首段 + 1 个 CTA]  → 可发
```

## 输入路由

| 用户说什么 | 走哪个命令 |
|---|---|
| "找对标" / "我这号有什么对标" | **find** |
| "拆这条爆款" / "这条为什么爆" | **crack**（单条） |
| "对着这条仿写" / "下一条该怎么写" | **crack + adapt** |
| "我想发 XX 主题，有什么参考" | **find + crack + adapt**（全闭环） |

## 1. find — 找对标

### Step 1: 多模态识别本质（5维）
- 载体形态：口播/图文/Vlog/剧情/混剪？
- 情绪锚点：焦虑/共鸣/愤怒/好奇/温暖？
- 审美风格：粗糙真实/精致高级/搞笑夸张？
- 内容结构：痛点→方法→案例 / 反常识→解释→行动？
- 反差点：这条内容跟同类最大的不同是什么？

输出：形容词三元组 + 一句话账号定位

### Step 2: 矩阵搜索
按 5 维本质 + 关键词矩阵搜索，找出 5-10 个候选对标

### Step 3: 相似度过滤
按内容形态/情绪锚点/审美风格/受众重叠度四个维度打分

### Step 4: 人工勾选
让用户从 5-10 个候选中勾选 3-5 条

### Step 5: 输出对标画像
账号名/粉丝量/内容母题/代表作品/钩子模式/可借鉴+不要照抄

## 2. crack — 拆爆款

对每条选定对标，输出：
```
钩子（4 维拆解）：
├ 视觉钩：封面/首帧/画面张力的钩子是什么
├ 文字钩：标题/字幕/文案的钩子是什么
├ 口播钩：开头第一句话/核心金句的钩子是什么
├ 剧情钩：情绪曲线/反转/悬念的钩子是什么
└ 综合权重：视觉 ×0.3 + 口播 ×0.4 + 文字 ×0.2 + 剧情 ×0.1

骨架（可填空模板）：
├ 开头：[什么场景/什么痛点]
├ 转折：[什么反常识/什么反转]
├ 方法：[什么步骤/什么资源]
└ 结尾：[什么CTA/什么金句]

封面公式：[什么大字/什么配色/什么构图]
标签策略：[什么主标签/什么副标签]
```

## 3. adapt — 套自己

基于 crack 结果 + 自己的素材/定位，输出：

```
## 标题候选（3个，每个标注命中哪个标题公式 + 抄了什么对标 + 改了什么）
  1. 「[文案]」 — 公式 N + 对标「XXX」+ 改了 XX
  2. 「[文案]」 — 公式 N + 对标「XXX」+ 改了 XX
  3. 「[文案]」 — 公式 N + 对标「XXX」+ 改了 XX

## 封面大字（3个方案）
  方案A：「[大字]」— 参考对标「XXX」
  方案B：「[大字]」— 参考对标「XXX」
  方案C：「[大字]」— 参考对标「XXX」

## 首段（1段）
  [完整首段文案]

## CTA（1个）
  [完整CTA文案]
```

## 铁律

1. 对标必须真实，不能编造
2. 拆解必须具体到帧/秒/句，不能笼统说"开头好"
3. adapt 的每一行都要能溯源到对标公式（抄了什么）和素材条目（用了什么）
4. 封面大字优先从素材的"候选金句"里选
5. 素材覆盖不到、只能走通用话术的位置，必须标记 ⚪ 推断
