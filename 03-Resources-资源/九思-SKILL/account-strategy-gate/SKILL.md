# account-strategy-gate — 账号战略会诊 + 场景外拓闸门

> 把「22-账号深度诊断 / 23-三大平台风向与认知拓展定论 / 24-单场景立住判定标准」三份知识过程化成一条决策流。不写诊断报告、不出单条初稿——直接跑闸门、给战略结论。

## 决策流图

```
[账号现状数据 + 外拓意图]
       │
       ▼ ① 数据对齐（把数据落进四关表）
[四关闸门：逐关算差距]
       │
       ▼ ② 判定立住 / 未立住
[四关全绿 且 连续4周稳定？]
       │
       ├─ 是 → ③ 外拓路由（去哪 + 怎么切）
       └─ 否 → ④ 补关动作（回到 22号根因给具体改法）
```

## 输入（两类，缺了先要齐）

| 输入 | 谁提供 | 说明 |
|:--|:--|:--|
| 账号现状数据 | 康哥补后台截图 / Hermes 周更脚本 | 粉丝、日均吸粉、近30天破3万条数、完播率、2秒跳出、条均评论 |
| 外拓意图 | 康哥一句话 | 「我能外拓了吗」「第二场景该不该开」「离立住差多少」 |

**能力边界（不装懂）**：数据必须来自官方后台 / Hermes 脚本 / 康哥截图，缺哪项就标记「待补」，绝不编数据。

## 四关闸门（判定线以 24号为准）

| 关 | 名称 | 判定线 | 数据从哪来 |
|:--|:--|:--|:--|
| ① | 爆款复制 | 近30天 **≥3 条**播放破 3 万 | 创作者中心 / 周报 |
| ② | 增长造血 | 日均净增粉 **≥30** | 粉丝曲线 / 周报 |
| ③ | 留存及格 | 完播率中位 **≥10%** 且 2秒跳出 **<40%** | 单条视频数据详情 |
| ④ | 粘性信号 | 条均评论 **≥5** + 个人态评论（「跟着你学」「我也是这样」「就服你」） | 评论区 |

## 放行规则（三条铁律）

1. **四关全绿、且连续 4 周稳定** → 开第二场景。
2. **任一关连续 2 周红** → 守单场景，回 22号根因（补中段钩、争点前置）改结构后重测。
3. **完播 10% 是「脱崩区」闸门线，不是终点**——过了再 10% → 20% → 40% 逐级上调；健康值 >40% 是「老师人设」终值，别加在闸门里。

## 外拓路由（只在已立住时启用，来自 23号）

| 平台 | 打法 |
|:--|:--|
| 抖音主号 | 死守英语场景，认知只做「场景锚定」（认知不脱英语场景） |
| 视频号 | 认知外拓主场（原创声明 +50%、中年用户群、知识赛道公私域加权） |
| 小红书 | 认知「方法论化」，埋搜索关键词吃搜索长尾（新 CES 评论×4/关注×8） |

场景锚定法：认知不独立成片，锚进「学东西」的场景——❌「你不是拖延」→ ✅「35岁想翻身，怎么用学英语这件小事破局」。

## 口径铁律（防混用）

- 收藏率 = **藏÷赞**（健康值 >60%）
- 藏播比 = **藏÷播**（当前 1-2%）
- 完播闸门线 10% ≠ 健康终值 40%，两件事

2. 不跳级：四关没全绿，一步都不外拓。
