# 段永平投资方法论（Duan Yongping Investing）

> 来源：《大道段永平投资问答录》（中信出版社 2025）
> 段永平：步步高/OPPO/vivo 创始人，经典案例网易（近百倍）、苹果、茅台。

## 免责声明

本 skill 不构成投资建议、不荐股、不预测股价、不给买卖建议。只提供分析框架，最终判断由使用者自己做。引用原书观点仅作方法论参考。

## 决策三维漏斗（按优先级，第一层不过直接放弃）

| 优先级 | 维度 | 核心问题 |
|---|---|---|
| 🥇 第一 | 商业模式 | 赚钱方式好不好？护城河宽不宽？ |
| 🥇 并列第一 | 企业文化 | 做对的事情吗？有利润之上的追求吗？ |
| 🥉 第三 | 合理价格 | 现在买下整家公司，10 年后划算吗？ |

## Workflow

### Step 1: 商业模式检查（第一过滤器）

- [ ] 护城河 = 能长期维持的差异化？
- [ ] 定价权测试：提价 10% 客户会流失吗？
- [ ] 坏信号：同质化 / 价格战 / 重资产 / 毛利率持续下降？

### Step 2: 企业文化检查（段永平最独特贡献）

- [ ] 好信号：利润之上的追求、消费者导向、本分
- [ ] 坏信号：利润至上、言行不一致
- [ ] 三维结构：使命 → 愿景 → 核心价值观 是否清晰一致？

### Step 3: 价格合理性（毛估估，非公式）

用当前市值买整家公司，算 10 年总现金流，年化满意吗？定性 > 定量。

### Step 4: 能力圈自检

- [ ] 知道能力圈边界比能力圈多大更重要
- [ ] 不懂不碰是理性，装懂比不懂更危险

### Step 5: 输出模板（一张纸检查清单）

```
【公司评估：___】
□ 商业模式好？ → 不过关 → 放弃，多便宜都不买
□ 企业文化好？ → 不过关 → 放弃
□ 价格合理？ → 划算 → 可买入
结论：买 / 不买 / 观望

【卖出检查】
只在三种情况卖：
1. 基本面变坏  2. 有更好机会（机会成本）  3. 价格离谱高
```

## 三个卖出理由（唯一认可）

1. 公司基本面变坏
2. 有更好的机会（机会成本）
3. 价格离谱地高

**不卖的理由**（识别并警告）：涨多了卖、别人卖我也卖、做波段、落袋为安、因为成本低。

## Important Notes

- 安全边际 = 理解度，不是股价短期波动；跌 30% 判断不变才有安全边际。
- 估值是"功夫"不是公式。
- 本分 + 平常心：做对的事、把事情做对；回到事物本源。
- A 股生存：✅ 适合价值投资；❌ 不做空、不用杠杆/融资、不抄底（抄底是投机）、不因"长期持有"而持有烂公司、避开价值陷阱。
