# 简单财富之路（Simple Path to Wealth）

> 来源：J.L. Collins《The Simple Path to Wealth》（2016）
> 核心公式：**花得比赚的少 → 投资盈余 → 远离债务**

## 免责声明

本 skill 不构成投资建议、不荐股、不预测。只提供财务自由的目标测算与资产配置框架，具体数字是原书/研究数据，需按个人情况调整。最终决策由使用者自己做。

## FIRE 核心公式

```
财务独立 = 25 × 年支出（4% 法则）
```

| 年支出 | 所需资产（4%） | 所需资产（3.5% 保守） |
|---|---|---|
| 7万（极简） | 175万 | 200万 |
| 12万 | 300万 | 343万 |
| 15万 | 375万 | 428万 |
| 20万 | 500万 | 571万 |

> 中国通胀率较高（3-5%），建议采用 3-3.5% 安全提款率。

## Workflow

### Step 1: 算目标（年支出 × 25）

问：你的年必要支出是多少？→ 目标资产 = 年支出 × 25（保守 × 28.6）

### Step 2: 三工具投资法

| 工具 | 作用 | 中国版 |
|---|---|---|
| 股票指数基金 | 财富增值 + 通胀对冲 | 沪深300 + 中证500 ETF |
| 债券指数基金 | 平滑波动 + 通缩对冲 | 国债 ETF/纯债基金 |
| 现金 | 日常 + 应急 | 余额宝/短债 |

**两阶段策略**：财富积累期 100% 股票；财富保全期 75% 股票 + 20% 债券 + 5% 现金。

### Step 3: 算储蓄率与时间

| 储蓄率 | 约需工作年数 |
|---|---|
| 10% | ~42 年 |
| 25% | ~24 年 |
| 50% | ~11.5 年 |
| 70% | ~7 年 |

### Step 4: 熊市应对（7 信条）

1. 崩盘是正常的 2. 市场总会恢复 3. 市场永远向上 4. 熊市是财富积累者的礼物 5. 别听媒体 6. 不要试图择时 7. 坚持定投

### Step 5: 输出模板

```
【FIRE 测算】
- 年支出：___ 万
- 目标资产：___ 万（4% 法则） / ___ 万（3.5% 保守）
- 当前储蓄率：___% → 约需 ___ 年

【配置建议】
- 积累期：100% 股票指数（或按年龄法则调整）
- 保全期：75% 股票 + 20% 债券 + 5% 现金
- 紧急备用金：6-12 个月生活费
```

## Important Notes

- Trinity Study：4% 提款率 + 50/50 股债 + 通胀调整 → 96% 成功率存活 30 年。
- 储蓄率比收益率更重要——提高储蓄率比追求高回报更可控。
- 待业/收入不稳：先留 12 个月现金缓冲，配置偏保守，收入恢复后再调高股票占比。
