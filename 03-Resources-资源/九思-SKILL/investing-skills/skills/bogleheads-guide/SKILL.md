# 博格头投资指南（Bogleheads Guide）

> 来源：《The Bogleheads' Guide to Investing》第二版（Larimore / Lindauer / LeBoeuf）
> 核心哲学：投资的"常识悖论"——日常生活中有效的原则（请专家、一分钱一分货、危机就行动、过去预示未来）在投资中恰恰有害。

## 免责声明

本 skill 不构成投资建议、不荐股、不做买卖决策。只提供资产配置与行为纪律框架，最终决策由使用者自己做。税务/法律条款以当地现行法规为准。

## 十大原则（先过一遍再谈配置）

1. 选择健康财务生活方式（月存 ≥ 10%）
2. 尽早开始、定期投资
3. 买你所知
4. 用 TIPS 保卫购买力
5. 算清需要存多少钱
6. 指数基金做核心仓位
7. 资产配置是基石（93.6% 的回报波动由此决定）
8. 成本至关重要
9. 最大化税收效率
10. 分散化

## Workflow

### Step 1: 资产配置三要素（缺一不可）

| 要素 | 核心问题 | 决策依据 |
|---|---|---|
| 目标 | 这笔钱用来做什么？ | 买房/教育/退休 |
| 时间框架 | 什么时候需要用钱？ | 股票只适合 5 年+ |
| 风险承受力 | 熊市来了你会卖吗？ | "睡眠测试"——跌了睡不着就降股票 |

### Step 2: 年龄-债券法则

```
债券比例 ≈ 年龄
```

| 年龄 | 股票% | 债券% | 最大年亏损参考 |
|---|---|---|---|
| 30 | 70 | 30 | -26.6% |
| 40 | 60 | 40 | -26.6% |
| 50 | 50 | 50 | -18.4% |
| 60 | 40 | 60 | -18.4% |
| 70 | 30 | 70 | -10.1% |

### Step 3: 投资前准备（顺序不能乱）

1. 还清信用卡和高息债务
2. 建立紧急备用金（3-12 个月生活费）
3. 净值思维（资产 − 负债）

### Step 4: 选指数基金（量化阈值）

- [ ] 免佣金
- [ ] 费用率 ≤ 0.5%（越低越好）
- [ ] 被动管理、低换手率

### Step 5: 输出模板

```
【配置方案】
- 目标：___ / 时间框架：___年 / 风险承受：能/不能扛 -X% 波动
- 股债比例：___ / ___（年龄法则：债券≈___%）
- 国际股票：20%-40%（可选）
- 紧急备用金：___ 个月

【待办清单】
□ 高息债务是否清零？
□ 紧急备用金是否到位？
□ 费用率是否达标？
```

## 行为纪律（7 大陷阱，识别即警告）

近期偏差 / 过度自信 / 损失厌恶 / 分析瘫痪 / 禀赋效应 / 心理账户 / 锚定效应

## Important Notes

- 费用率是预测基金未来表现**最可靠的唯一指标**。
- 1% 费用差 → 复利 20 年 → 回报差 18%。
- 待业/收入不稳时，用保守偏平衡配置（40-50% 债券），收入恢复后再调整。
- 退休后遵守 4% 法则：通胀调整提款 ≤ 初始资产的 4%。
