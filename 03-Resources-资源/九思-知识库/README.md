## 与 Hermes 的关系

九思 与 Hermes **协同统一管理（2026-08-26 起，原「独立性铁律」已撤销）**：两者在同一 PARA 骨架下共存，用 `九思-` / `Hermes-` 前缀区分归属。

- 合作关系、相互独立身份，必要时协作。

## 沉淀规则

- **实时沉淀（最高优先级）**：每次交流后，九思 **务必实时**把关键内容（对话结论、新建机制、SKILL、脚本、方案）写成 Markdown 笔记，按 PARA 分类落到对应 `九思-` 文件夹，实时更新、不得遗漏。
- 命名建议：`YYYY-MM-DD-主题.md`
- 跨会话的长期约定、偏好，沉淀到 `00-约定与偏好.md`。
- 经验资产化：可复用的经验/坑/流程，固化成 skill（`[[03-Resources-资源/九思-SKILL]]`）+ 文档（`[[03-Resources-资源/九思-知识库]]`）。
