## 三、缺陷记录（开发过程中发现并修复）

| # | 缺陷 | 根因 | 修复 |
|:--|:--|:--|:--|
| D1 | 自定义新词 `getWord()` 查不到（学习/复习流程会跳过新词） | `getWords()` 合并自定义词时未映射 `id` 字段 | store.js 自定义词映射补 `id: w.w` |
| D2 | 复习 5 词完成后汇总页被新一轮直接覆盖，看不到汇总 | 会话复位条件 `!rs \|\| rs.finished` 误触发 | 改为 `!rs` 时才新建会话，`idx>=queue.length` 时展示汇总 |
| D3 | 含撇号例句（I'm curious…）的内联 onclick 会产生 JS 语法错误 | HTML 实体 `&#39;` 解码后提前闭合 JS 字符串 | 改为 id 寻址（speakExById/speakChunkById），消除内联文本转义 |
| D4 | 删除自定义语块不持久化（刷新后复活） | delChunk 直接改内存未调用 save | store 新增 removeCustomChunk(id) 落盘 |
| D5 | 单测 T1-06 场景断言数组顺序与 sort() 默认序不一致 | 断言写法问题（非产品缺陷） | 改为集合包含断言 |

以上缺陷修复后全量回归：35 单测 + 关键 GUI 路径复测全部通过。
