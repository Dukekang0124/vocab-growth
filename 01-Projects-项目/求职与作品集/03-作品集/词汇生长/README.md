# 词汇生长 Vocabulary Growth

> 把 OB「英语自学建设系统」(Hermes) 验证过的词汇生长方法论，变成可自助使用的 Web 应用。
> **不背单词，让单词长出来**——学（词群语块卡）→ 复（分层抢救+遗忘深度）→ 用（造句+老外版本+当天用掉）

---

## 核心定位

**一句话定位**：零基础重学英语的开口工具，把「想说的欲望+敢说的勇气」转化为可执行的 Web App。

**目标用户**：零基础重学英语、想开口说的成年人（来自原系统真实用户画像）。

**核心闭环**：
```
学（词群语块卡）→ 复（分层抢救+遗忘深度）→ 用（造句+老外版本+当天用掉）
```

---

## 四不原则

- ❌ 不做选择题为主的识别训练（识别≠生产）
- ❌ 不做写作模块（主攻开口说）
- ❌ 不做"先输入后开口"路径
- ❌ 不追求大而全课程

## 技术栈

| 层级 | 技术选型 | 原因 |
|:--|:--|:--|
| 前端框架 | **零框架纯静态**（index.html + script 标签） | 零构建、零月费、双击即用、GitHub Pages 直发 |

| 测试 | **Node --test**（35 单测）+ **ZCode 内置浏览器**（18 GUI 用例） | 全覆盖、可重复、可回放 |

## 快速开始

### 本地体验（零依赖）

```bash
cd vocab-growth-app
node server.js          # 默认 http://127.0.0.1:8430
node server.js 9000     # 自定义端口
```

或直接双击 `index.html`（file:// 协议可用，TTS 会用浏览器自带）。

### 云端部署（5 分钟）

```bash
# 1. 将 vocab-growth-app 整目录上传到 GitHub 仓库
# 2. 在仓库设置中启用 GitHub Pages（分支：main / 文件夹：/）
# 3. 等待 1-2 分钟，访问 https://<你的用户名>.github.io/vocab-growth-app/
```

详见 [[DEPLOY]]（Cloudflare Pages / GitHub Pages 双方案）。

## 方法论映射

| 原系统方法论 | 产品化实现 |
|:--|:--|
| 识别≠生产 | 全部产出型题型：说词/造句，无选择题 |
| 词群学习法 | 8 个故事词群，卡片带故事锚点 |
| 简单英语解释法 | 每词 simple 字段（小孩能懂的释义） |
| 分层抢救六层提示 | 复习页逐层解锁（硬想30s→词性→词义→首字母→长度+场景→答案） |
| 预忘深度三级 | 🟢🟡🔴 遗忘深度驱动排程（🟢隔天2天/🟡1天/🔴每天） |
| 三库纸面规则自动化 | 🔴自动进薄弱清单；连续2次🟢自动移出 |
| 当天用掉 | 首页「今天用掉」清单 + 勾选统计 |
| 新词上限铁律 | 待复习>30 锁定（用户亲立规矩强制执行） |
| 语块优先/库存积累 | 说法库：你想说X→老外会说Y（自测模式+跟读） |
| 证据驱动 | 指标只统计真实行为（复习/造句/用掉才触发 streak） |
