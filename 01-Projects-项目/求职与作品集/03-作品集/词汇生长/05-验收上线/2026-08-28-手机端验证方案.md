# 词汇生长 · 手机端验证方案

> 目标：确认产品能在主流手机浏览器（iOS Safari、Android Chrome）中正常打开并运行，验证播放功能与电脑端差异
> **关键验证点**：对比电脑端"能打开但播放无声音"的问题是否在手机端同样存在
> 执行日期：2026-08-28 | 测试对象：vocab-growth-app（本地服务器 http://127.0.0.1:8430）

---

## 一、验证目标

1. **页面加载**：主流手机浏览器能否正常加载 `http://127.0.0.1:8430`，页面布局是否正常（375px 响应式）
2. **核心功能**：复习/造句/词群/说法库等 6 个标签页能否正常切换与操作
3. **播放功能**：点击发音按钮是否有声音输出，**重点对比电脑端"能打开但播放无声音"的问题是否在手机端同样存在**
4. **行为差异**：记录手机端与电脑端的体验差异（如 TTS 调用、音频播放、触摸交互）
5. **浏览器兼容性**：验证 iOS Safari、Android Chrome、Android Chrome 12 的差异

## 七、常见问题与解决

| 问题 | 可能原因 | 解决方案 |
|:--|:--|:--|
| 手机无法访问 `127.0.0.1` | `127.0.0.1` 仅限本机访问 | 使用局域网 IP（如 `192.168.x.x`） |
| 页面加载缓慢 | Wi-Fi 信号弱或服务器负载高 | 检查电脑端服务器负载，使用有线网络 |
| 播放无声音 | 浏览器不支持 `speechSynthesis` 或音频文件缺失 | 检查浏览器兼容性，确认 mp3 文件存在 |
| 布局错位 | 触摸事件与鼠标事件未正确处理 | 检查 CSS 媒体查询，确认 `viewport` 标签正确 |

## 十、测试执行指引

### 10.1 如何在手机上访问

1. **获取本机 IP**：
   ```powershell
   ipconfig | Select-String "IPv4"
   ```
2. **手机浏览器输入**：
   ```
   http://192.168.1.100:8430
   ```
3. **如需 HTTPS**：
   - 可使用 ngrok 临时暴露：`ngrok http 8430`，获取公网地址（仅测试用）

### 10.2 如何截图

- **iOS Safari**：电源键 + 音量+ 键（截图自动保存到相册）
- **Android Chrome**：电源键 + 音量- 键
- **电脑端 Chrome DevTools**：F12 → 设备工具栏 → 点击截图图标

### 10.3 如何验证声音

- 播放时观察音量图标（浏览器音量条是否跳动）
- 对比 OB mp3 与 TTS 的音质差异
- 如无声音，检查浏览器是否支持 `speechSynthesis`
