## 📋 总体检查清单

### 第一阶段：微信白名单配置（1-3 步完成）

- [ ] **第 1 步：登录微信公众平台**
  - [ ] 访问 https://mp.weixin.qq.com/
  - [ ] 使用管理员账号登录
  - [ ] 进入"设置" → "功能设置"

- [ ] **第 2 步：配置业务域名**
  - [ ] 找到"业务域名"配置项
  - [ ] 填写域名（无需 https://）
    - GitHub Pages：`yourname.github.io`
    - 自定义域名：`vocab.growth.app`
  - [ ] 点击"保存"

- [ ] **第 3 步：下载验证文件**
  - [ ] 微信会提供 `MP_verify_xxxxx.txt` 文件
  - [ ] 下载该文件
  - [ ] 上传到 GitHub Pages 根目录
    - 或上传到自定义域名的根目录
  - [ ] 等待 10-30 分钟生效

## 🚨 常见问题与解决

### 微信白名单配置问题

**Q: 微信白名单配置后多久生效？**
A: 需等待 10-30 分钟生效。

**Q: 为什么显示"域名未在白名单中"？**
A: 白名单配置后需 10-30 分钟生效，请等待后再测试。

**Q: 验证文件上传后多久生效？**
A: 上传后需等待 10-30 分钟生效，请耐心等待。

---

### 抖音跳转问题

**Q: 为什么抖音不支持通过链接打开群聊？**
A: 抖音本身不支持通过链接打开应用内页面，仅支持外链跳转。

**Q: 如何通过抖音引流？**
A: 建议通过抖音短视频引流，而非直接分享链接到群聊。

---

### 小红书跳转问题

**Q: 小红书对外链有限制怎么办？**
A: 确保链接符合平台规则，添加引导语："点击链接查看完整内容"。

---

### 数据持久化问题

**Q: 换设备后数据丢失怎么办？**
A:
- 短期：定期导出 JSON 备份（我的词汇 → 数据管理 → 导出备份）
- 中期：开发数据备份/恢复功能
- 长期：开发后端 API + 数据库（跨设备同步）
