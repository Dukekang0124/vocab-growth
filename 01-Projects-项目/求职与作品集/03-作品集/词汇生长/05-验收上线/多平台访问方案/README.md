# 词汇生长 · 多平台访问与跳转功能方案

> 目标：完善产品在微信、抖音、小红书等主流平台的访问与跳转能力
> **核心问题**：从微信、抖音、小红书等平台如何直接打开产品？
> **方案定位**：静态网页 + 微信白名单 + 外部跳转
> 创建：2026-08-28

---

## 一、现状分析

### 1.1 当前产品架构

```
词汇生长 v1.0
├── 技术栈：HTML + CSS + JavaScript（零后端）
├── 部署方式：GitHub Pages / Cloudflare Pages（静态托管）
├── 数据存储：浏览器 localStorage（本地）
└── 访问方式：仅支持电脑端浏览器
```

### 1.2 核心限制

| 限制项 | 说明 | 影响 |
|:--|:--|:--|
| **静态网页** | 无后端 API | 无法识别用户身份、无法记录学习进度 |
| **数据本地化** | localStorage 仅存本机 | 换设备/浏览器数据丢失 |
| **微信白名单** | 需配置业务域名 | 未配置前无法在微信打开 |
| **抖音链接** | 不支持应用内打开 | 仅支持外链跳转 |

## 二、多平台访问方案

### 2.1 电脑端网页版访问（✅ 已支持）

**场景**：用户在电脑浏览器中直接访问产品链接

**访问路径**：
```
1. 用户复制产品链接（如 https://yourname.github.io/vocab-growth-app/）
2. 在电脑 Chrome/Edge/Firefox/Safari 中打开链接
3. 页面自动加载，显示今日统计与功能入口
```

**技术实现**：
- ✅ 已完成：静态 HTML + CSS + JavaScript
- ✅ 已完成：响应式设计（支持 1280px+ 分辨率）
- ✅ 已完成：localStorage 数据持久化

**适用人群**：电脑用户、英语学习者（习惯用电脑学习）

### 2.2 微信聊天页内点击链接打开（🟡 需配置）

**场景**：用户在微信聊天中点击产品链接，唤起微信内置浏览器打开

**访问路径**：
```
1. 用户在微信聊天中复制产品链接
2. 点击链接 → 唤起微信内置浏览器
3. 显示产品页面（需配置微信白名单）
```

**前置条件**：
- ✅ **必须配置微信白名单**（详见"五、微信白名单配置"）
- ✅ **链接必须使用 HTTPS 协议**
- ✅ **域名必须在微信公众平台配置业务域名**

**技术实现**：
```html
<!-- index.html 已支持 hash 路由 -->
<link rel="stylesheet" href="css/style.css">
<script src="js/app.js"></script>

<!-- Hash 路由支持 -->
window.addEventListener('hashchange', VG_APP.handleHashChange);
window.addEventListener('load', VG_APP.init);
```

**配置步骤**（3 步）：
1. 登录微信公众平台：https://mp.weixin.qq.com/
2. 配置业务域名：设置 → 功能设置 → 业务域名 → 添加域名
3. 下载验证文件 `MP_verify_xxxxx.txt` → 上传到 GitHub Pages 根目录

**适用人群**：微信用户、想通过微信分享链接给朋友

**注意事项**：
- ⚠️ 白名单配置后需 10-30 分钟生效
- ⚠️ 微信版本 ≥ 7.0.0 才能正常打开链接
- ⚠️ 建议先在个人对话中测试，再群聊测试

### 2.6 是否需要开发独立 APP？（❌ 不需要）

**结论**：**不需要开发独立 APP**

**理由**：

| 对比项 | 网页版（当前方案） | 独立 APP | 推荐 |
|:--|:--|:--|:--|
| **开发成本** | ¥0（零后端） | ¥5,000-50,000（iOS/Android） | 网页版 ✅ |
| **维护成本** | ¥0（静态托管） | ¥2,000-20,000/年（服务器+更新） | 网页版 ✅ |
| **用户获取** | 任意平台分享链接 | 需上架应用商店（审核周期长） | 网页版 ✅ |
| **数据同步** | 无法跨设备同步 | 需后端 + 数据库 | 网页版 ✅ |
| **功能完整性** | 100%（已验证 53/53 通过） | 需重新开发测试 | 网页版 ✅ |
| **更新速度** | 实时更新（Git 推送） | 需重新上架（审核周期 1-7 天） | 网页版 ✅ |
| **用户门槛** | 无需安装，点击即用 | 需下载安装（用户流失率高） | 网页版 ✅ |

**推荐方案**：
- **短期（0-3 个月）**：继续使用网页版，通过微信白名单、抖音引流、小红书笔记推广
- **中期（3-12 个月）**：如果用户量 > 10,000，再考虑开发轻量级 PWA（渐进式 Web 应用）
- **长期（12 个月+）**：如果用户量 > 100,000，再考虑开发独立 APP

## 五、微信白名单配置（3 步完成）

### 5.1 配置步骤

**步骤 1：登录微信公众平台**
```
1. 访问：https://mp.weixin.qq.com/
2. 使用管理员账号登录
3. 进入"设置" → "功能设置"
```

**步骤 2：配置业务域名**
```
1. 找到"业务域名"配置项
2. 填写域名（无需 https://）
   - GitHub Pages：yourname.github.io
   - 自定义域名：vocab.growth.app
3. 点击"保存"
```

**步骤 3：下载验证文件**
```
1. 微信会提供 MP_verify_xxxxx.txt 文件
2. 下载该文件
3. 上传到你的 GitHub Pages 根目录
   - 或上传到自定义域名的根目录
4. 等待 10-30 分钟生效
```

### 5.2 验证白名单

配置完成后，使用检测工具验证：

```javascript
const testLink = 'https://yourname.github.io/vocab-growth-app/';
const result = LinkCompatibilityChecker.checkPlatformSupport(
  testLink,
  'wechat'
);
console.log('支持:', result.supported);  // 应该为 true
```

```
抖音个人主页 → 添加外链 → 用户点击外链按钮 → 跳转到产品页面
```

**方式三：私信引流**

### 10.1 Hash 路由实现

```javascript
// js/app.js
VG_APP.go = function(hash) {
  // 清除当前 hash
  window.location.hash = hash;

  // 更新导航状态
  document.querySelectorAll('.nav-btn').forEach(btn => {
    btn.classList.remove('active');
    if (btn.dataset.tab === hash.replace('#', '')) {
      btn.classList.add('active');
    }
  });

  // 渲染对应页面
  VG_APP.renderPage(hash);
};

window.addEventListener('hashchange', VG_APP.handleHashChange);
window.addEventListener('load', VG_APP.init);
```

## 十一、常见问题

### Q1: 为什么抖音不支持通过链接打开群聊？

**原因**：抖音本身不支持通过链接打开应用内页面，仅支持外链跳转。

**解决**：使用抖音短视频引流，而非直接分享链接到群聊。

### Q2: 微信白名单配置后多久生效？

**原因**：微信白名单配置后需 10-30 分钟生效。

**解决**：等待 30 分钟后再测试。

### Q3: 数据仅存本机，换设备怎么办？

**原因**：当前使用 localStorage 持久化，数据仅存本机浏览器。

**解决**：
- 短期：定期导出 JSON 备份（我的词汇 → 数据管理 → 导出备份）
- 中期：开发数据备份/恢复功能
- 长期：开发后端 API + 数据库（跨设备同步）

### Q4: 是否需要开发独立 APP？

**原因**：网页版已满足 100% 功能需求，开发 APP 成本高、维护成本高。

**解决**：继续使用网页版，通过微信白名单、抖音引流、小红书笔记推广。

### Q5: 如何让用户更方便地访问产品？

**解决**：
- 短期：生成二维码，用户扫码即可访问
- 中期：添加 PWA 支持，用户可安装到桌面
- 长期：开发数据备份/恢复功能，方便用户迁移数据
