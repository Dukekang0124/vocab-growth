## 🔄 跨平台数据同步问题

```
┌─────────────────────────────────────────────────────────────┐
│                    数据持久化说明                            │
└─────────────────────────────────────────────────────────────┘

当前数据存储方式：localStorage（浏览器本地存储）

【数据存储位置】
- 电脑浏览器：电脑浏览器的 localStorage
- 手机浏览器：手机浏览器的 localStorage
- 微信浏览器：微信浏览器的 localStorage

【数据不共享】
- ❌ 电脑浏览器数据 ≠ 手机浏览器数据
- ❌ 微信浏览器数据 ≠ Chrome 浏览器数据
- ❌ 换设备/浏览器后数据丢失

【数据备份方法】
1. 导出 JSON 备份（我的词汇 → 数据管理 → 导出备份）
2. 备份文件保存在本地
3. 换设备后导入备份文件（我的词汇 → 数据管理 → 导入备份）

【长期解决方案】
- 中期：开发数据备份/恢复功能（JSON 导出/导入）
- 长期：开发后端 API + 数据库（跨设备同步）
```

| **抖音跳转外部** | ✅ 已支持 | 无 | 本地 | ⭐⭐⭐⭐ |
| **小红书跳转外部** | ✅ 已支持 | 无 | 本地 | ⭐⭐⭐⭐ |
