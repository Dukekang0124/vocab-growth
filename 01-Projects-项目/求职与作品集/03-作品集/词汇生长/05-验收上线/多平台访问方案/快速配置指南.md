# 多平台访问 · 快速配置指南

> 5 分钟完成微信白名单配置，让产品在微信中正常打开

---

## 🚀 一键配置（3 步完成）

### 第 1 步：登录微信公众平台

```
1. 访问：https://mp.weixin.qq.com/
2. 使用管理员账号登录
3. 左侧导航 → 设置 → 功能设置
```

### 第 2 步：配置业务域名

```
1. 找到"业务域名"配置项
2. 填写域名（无需 https://）
   - GitHub Pages：yourname.github.io
   - 自定义域名：vocab.growth.app
3. 点击"保存"
```

### 第 3 步：下载验证文件

```
1. 微信会提供 MP_verify_xxxxx.txt 文件
2. 下载该文件
3. 上传到你的 GitHub Pages 根目录
   - 或上传到自定义域名的根目录
4. 等待 10-30 分钟生效
```

## ❓ 常见问题

**Q: 微信白名单配置后多久生效？**
A: 需等待 10-30 分钟生效。

**Q: 为什么抖音不支持通过链接打开群聊？**
A: 抖音本身不支持通过链接打开应用内页面，仅支持外链跳转。

**Q: 数据仅存本机，换设备怎么办？**
A: 短期：定期导出 JSON 备份；中期：开发数据备份/恢复功能。

**Q: 是否需要开发独立 APP？**
A: 不需要，网页版已满足 100% 功能需求，开发 APP 成本高、维护成本高。
