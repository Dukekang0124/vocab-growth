## 💻 控制台使用（开发者）

```javascript
// 1. 加载检测模块
const LinkCompatibilityChecker = window.LinkCompatibilityChecker;

// 2. 生成测试链接
const testLink = LinkCompatibilityChecker.generateTestLink();
console.log('测试链接:', testLink);

// 3. 检查微信支持
const wechatResult = LinkCompatibilityChecker.checkPlatformSupport(
  testLink,
  'wechat'
);
console.log('微信支持:', wechatResult.supported);

// 4. 批量检查所有平台
const allResults = LinkCompatibilityChecker.checkAllPlatforms(testLink);
console.log('支持率:', LinkCompatibilityChecker.getSupportSummary(testLink).supportRate + '%');
```

## 🔧 微信白名单配置（3 步）

1. **登录微信公众平台**
   - https://mp.weixin.qq.com/

2. **配置业务域名**
   - 左侧导航 → 设置 → 功能设置 → 业务域名
   - 添加域名：`yourname.github.io`

3. **下载验证文件**
   - 下载 `MP_verify_xxxxx.txt`
   - 上传到 GitHub Pages 根目录
   - 等待 10-30 分钟生效

## ❓ 常见问题

**Q: 为什么抖音聊天群不支持？**
A: 抖音本身不支持通过链接打开应用内页面，仅支持外链跳转。建议通过抖音短视频引流。

**Q: 检测显示"域名未在白名单中"怎么办？**
A: 需要在微信公众平台配置业务域名（参考上方配置步骤）。

**Q: 如何检测当前页面是否在微信中打开？**
A: `LinkCompatibilityChecker.isRunningOnPlatform('wechat')`
