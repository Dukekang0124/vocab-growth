## 二、资源占用分析

### 2.1 本地环境资源占用

#### 2.1.1 代码运行时资源占用

| 资源类型 | 占用量 | 说明 |
|:--|:--|:--|:--|
| **CPU** | 0.1% - 0.5%（空闲时） | node server.js |
| **CPU** | 1% - 5%（访问时） | node server.js + 浏览器 |
| **内存** | ~20MB | node server.js |
| **内存** | ~100MB - 200MB | 浏览器（单标签页） |
| **存储** | ~500MB | 代码 + 音频文件 |
| **网络** | 0（本地测试） | 无流量产生 |

**资源占用表现**：
- **CPU 占用**：node server.js 仅用于处理 HTTP 请求，空闲时几乎无 CPU 占用
- **内存占用**：node server.js 仅用于处理 HTTP 请求，内存占用极小
- **存储占用**：代码 + 音频文件固定占用，不随时间增长
- **网络占用**：本地测试不产生网络流量

#### 2.1.2 浏览器访问时资源占用

| 资源类型 | 占用量 | 说明 |
|:--|:--|:--|:--|
| **CPU** | 1% - 5%（空闲时） | 浏览器渲染 + JavaScript 执行 |
| **CPU** | 5% - 15%（操作时） | 浏览器渲染 + JavaScript 执行 + TTS |
| **内存** | ~100MB - 200MB | 浏览器（单标签页） |
| **内存** | ~200MB - 500MB | 浏览器（多个标签页） |
| **存储** | 0（纯静态） | 无额外缓存 |
| **网络** | 10MB - 50MB/次 | 下载 index.html + CSS + JS + 音频 |

**资源占用表现**：
- **CPU 占用**：浏览器渲染 HTML/CSS/JavaScript，操作时（如造句、发音）CPU 占用增加
- **内存占用**：浏览器渲染页面，多标签页时内存占用增加
- **存储占用**：纯静态页面，无额外缓存
- **网络占用**：每次访问下载页面资源，音频文件（40 个 mp3）占用较大

#### 2.1.3 资源释放方式

**代码运行时资源释放**：
```bash
# 1. 停止 node server.js
Ctrl + C

# 2. 验证资源释放
# Windows（任务管理器）：
# - 检查 node.exe 进程是否消失
# - 检查 CPU 占用是否恢复到 0%

# Linux/Mac：
ps aux | grep node
# 如果没有输出，说明进程已停止
```

**浏览器资源释放**：
- **关闭标签页**：浏览器自动释放资源（内存、CPU）
- **关闭浏览器**：浏览器完全释放资源（内存、CPU、存储）
- **清除缓存**：手动清除浏览器缓存（不影响代码运行）

#### 2.3.2 请求处理时资源释放

**Cloudflare Workers 请求处理流程**：
```
1. 用户发起请求（登录/注册/同步）
   ↓
2. Cloudflare Workers 接收请求（~1ms CPU 时间）
   ↓
3. Cloudflare KV 读取/写入数据（~0.1ms KV 时间）
   ↓
4. 返回响应给用户（~1ms CPU 时间）
   ↓
5. 请求处理完成，资源立即释放
```

**资源释放方式**：
- **无后台进程**：Cloudflare Workers 按需触发，无服务器进程
- **请求处理完成**：每次请求处理完成后，资源立即释放
- **存储释放**：KV 数据永久存储，不随时间释放（除非手动删除）
