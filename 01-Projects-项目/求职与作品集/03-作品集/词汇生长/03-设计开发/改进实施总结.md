### 1.2 代码实现

#### 1. 评分模块（speak-workshop.js）
**实现功能**：
- ✅ 语法评分算法（时态、主谓一致、冠词）
- ✅ 词汇评分算法（多样性、复杂度）
- ✅ 自然度评分算法（句式变化、连接词、地道表达）
- ✅ 完整度评分算法（内容完整性、逻辑连贯性）
- ✅ 总分计算与反馈生成
- ✅ 语法纠正建议

**核心算法**：
```javascript
// 语法评分：基于规则引擎
- 时态错误检测（was/were/has/have等）
- 主谓一致错误检测（I go/goes, He go/goes）
- 冠词错误检测（I am/are, He is/are）

// 词汇评分：基于多样性计算
- 词汇多样性 = 不重复词数 / 总词数
- 词汇复杂度 = 高级词汇占比 × 100
- 平均词长计算

// 自然度评分：基于句式分析
- 连接词使用统计
- 句式复杂度评估
- 地道表达匹配

// 完整度评分：基于内容分析
- 主语、谓语、标点检查
- 与参考表达的相关性
- 内容完整性评估
```

**评分示例**：
```
用户句子："I go to school."
语法评分：100分（正确）
词汇评分：80分（词汇简单）
自然度评分：85分（表达自然）
完整度评分：90分（表达完整）
总分：89分（B级）
```

**难度定义**：
```javascript
A1（入门级）：5词以内，500词汇量，30秒限制
A2（初级）：5-10词，500-1500词汇量，45秒限制
B1（中级）：10-20词，1500-3000词汇量，60秒限制
B2（高级）：20-50词，3000-5000词汇量，90秒限制
```

**自动检测逻辑**：
```javascript
// 基于历史表现（5次以上）
avgScore >= 80 → B2
avgScore >= 70 → B1
avgScore >= 60 → A2
else → A1

// 基于词汇量
wordCount >= 2000 → B1
wordCount >= 500 → A2
else → A1
```

## 五、技术难点与解决方案

### 5.1 评分算法准确性

**问题**：如何准确评分造句的语法、词汇、自然度？

**解决方案**：
- **语法评分**：基于规则引擎 + NLP语法检查
- **词汇评分**：基于词汇表匹配 + 多样性计算
- **自然度评分**：基于句式分析 + 地道表达匹配
- **完整度评分**：基于内容完整性分析

**改进方向**：
- 收集更多用户造句数据
- 训练机器学习模型
- 优化规则引擎
- 引入更多语法规则

### 5.2 ASR集成

**问题**：如何实现发音评测？

**解决方案**：
- **短期**：使用TTS模拟评分（基于波形相似度）
- **中期**：集成第三方ASR API（科大讯飞、阿里云、百度）
- **长期**：自研ASR评分算法

**成本估算**：
- 科大讯飞ASR：约¥0.03/分钟
- 阿里云ASR：约¥0.02/分钟
- 百度ASR：约¥0.015/分钟

### 5.3 个性化推荐

**问题**：如何根据用户表现推荐合适的练习？

**解决方案**：
- 基于历史表现（正确率、用时、重复错误）
- 基于错题分析（针对性推荐）
- 基于兴趣偏好（用户选择）
- A/B测试优化推荐算法

**推荐算法**：
```javascript
function recommendPractice(user) {
  const history = user.practiceHistory;
  const wrongWords = user.wrongWords;

  // 1. 基于错题推荐
  if (wrongWords.length > 0) {
    return {
      mode: 'keywords',
      words: wrongWords.slice(0, 3),
      reason: '针对性练习'
    };
  }

  // 2. 基于表现推荐
  const avgScore = calculateAvgScore(history);
  if (avgScore < 60) {
    return {
      mode: 'sentence',
      difficulty: 'A1',
      reason: '需要巩固基础'
    };
  }

  // 3. 基于兴趣推荐
  return {
    mode: 'dialogue',
    scenario: user.preferredScenario,
    reason: '兴趣导向'
  };
}
```
