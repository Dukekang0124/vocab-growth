## 1. 产品概述

**产品名**：词汇生长 Vocabulary Growth
**一句话定位**：不背单词，让单词长出来——把 Hermes 验证过的「词汇生长系统 v3」从笔记+Agent对话，变成一个可自助使用的 Web 应用。
**目标用户**：零基础重学英语、想开口说的成年人（画像来自原系统真实用户）。
**核心闭环**：学（词群语块卡）→ 复（分层抢救+遗忘深度）→ 用（造句+老外版本+当天用掉）。

**四不原则**：不做选择题为主的识别训练；不做写作模块；不做"先输入后开口"路径；不追求大而全课程。

## 2. 信息架构

单页应用（SPA），底部/侧边 6 个主标签：

```
词汇生长 App

├── ③ 复习（Review）          分层抢救流程
```

## 3. 核心算法规格：SRS-lite 调度引擎（js/srs.js）

不引入标准 SM-2，忠实数字化原系统规则（"遗忘深度映射复习强度"）：

### 3.1 遗忘深度模型

复习一个词时记录「第几层提示才想起」：

| 想起层级 | 遗忘深度 | 语义 | 下次复习间隔 |
|:--|:--|:--|:--|
| 0-1层（硬想/词性即想起） | 🟢 浅 | 记得牢 | 隔天起算 2 天 |
| 2-3层（词义/首字母想起） | 🟡 中 | 有点模糊 | 当天再复习 + 隔天 1 天 |
| 4层+/看答案（长度/半句/答案） | 🔴 深 | 快忘了 | 进薄弱清单，每天复习直至连续2次🟢 |

### 3.2 队列生成（每日）

```
今日复习队列 = 到期词（nextReview <= today）
排序优先级：未造句(⬜) > 薄弱(🔴在清单) > 其余按 nextReview 升序
每次会话取 5 词（继承"抽5个旧词"规则）
```

### 3.3 状态流转状态机

```
复习标记🟢 → greenStreak+1；连续2次🟢 且在薄弱清单 → 自动移出，可标"已会用"
复习标记🔴 → 自动进薄弱词清单（inWeak=true, weakSince=today）
🟡 → greenStreak 归零，间隔1天
新词建档 → depth=未测, nextReview=明天（睡眠巩固：新词隔天首复习）
造句完成 → sentenceStatus=✅（不改变复习排程）
```

### 3.4 新词上限铁律

```
待复习数 = 今日到期词数
if 待复习数 > 30 → 新词添加锁定，UI 提示「先消化再进食：待复习 N 词 > 30」
```

## 4. 数据模型

### 4.1 实体（js/data.js 种子 + localStorage 运行态合并）

```js
word = {
  id: 'curious',            // 唯一ID（=word文本）
  word: 'curious', ipa: '/ˈkjʊriəs/', pos: 'adj.',
  simple: 'wanting to know more about something',  // 简单英语释义（小孩能懂）
  zh: '好奇的',
  chunk: 'I'm curious about ...',   // 句型骨架/语块
  example: { en: "I'm curious—what's your next plan?", zh: '我好奇你下一步怎么打算' },
  note: '间接疑问句语序需巩固',      // 原系统真实备注（部分词有）
  audio: 'curious.mp3',      // OB真实音频（40词有，其余TTS）
  groupId: 'ocean',
  // —— 运行态（种子含真实初始值）——
  sentenceStatus: 'done'|'pending',
  depth: 'untested'|0|2|4,   // 遗忘深度
  greenStreak: 0, inWeak: false, weakSince: null,
  firstLearned: '2026-08-04',
  lastReview: null, nextReview: '2026-08-30',
  usedToday: false           // 今天用掉
}
group = { id:'ocean', name:'海洋探险', story:'一段深海潜水的探险故事…', order:1 }
chunk = { id, scene:'好奇提问', zh:'我好奇你下一步怎么打算', en:"I'm curious—what's your next plan?", custom:false }
```

### 4.2 localStorage Schema（key: `vocab_growth_v1`）

```js
state = {
  version: 1,
  words: { [id]: word运行态覆盖 },   // 只存运行态，种子静态数据不重复存
  customWords: [word],               // 用户新增词（全量）
  customChunks: [chunk],
  sentenceRecords: [{date, wordId, userSentence, refEn, status}],
  growthLog: [{date, totalWords}],   // 曲线数据点
  milestones: [{date, text, n}],
  streak: { last ActiveDate, days },
  speed: 1.0, freeLimit: 2           // B类预留：免费词群数、unlocked
}
```

### 4.3 种子数据（真实 OB 资产）

- **68 词**（8 词群）——主动词汇库 66 词全量迁移 + strict/fabulous 2 词从 OB 音频资产恢复（8/9 脚本事故前已学），保留真实状态（4词✅已造句、5词有深度标记、himalayas/mechanic 在薄弱清单）
- **13 语块**（4 场景）——完整迁移地道说法库
- **40 个美音 mp3**（488KB）——原系统 audio/ 目录全量
- **2 条造句记录**、真实里程碑（8/7 达 60 词）
- **词群划分**（按原词群学习法重组）：海洋探险7 / 高山之旅5 / 在路上9 / 职业故事6 / 日常物件7 / 情绪心态6 / 聊天高频13 / 世界与观点13 = 66

## 5. 交互规格（关键流程）

### 5.1 分层抢救（复习页核心交互）

```
[中文提示卡] 好奇的 · "想打听别人下一步计划时的心情"
   ↓ 用户尝试想起英文…
[① 先硬想 30秒] → 点击开始倒计时（可随时点"想起来了"）
[② 给词性]   adj. 形容词
[③ 给词义]   wanting to know more
[④ 给首字母]  c _ _ _ _ _ _ _
[⑤ 给长度+场景半句]  7个字母 · I'm c______ about your plan
[⑥ 看答案]   curious /ˈkjʊriəs/ 🔊
   ↓
[第几层想起的？] 🟢0-1层 🟡2-3层 🔴4层+/没想起
   ↓ 自动流转 + 下一词 / 去「造句工坊」用掉它
```

### 5.2 造句工坊

```
[词: curious] 中文场景：你想打听语伴下一步的计划
[textarea 用户造句] → [提交]
   ↓
[老外会说] "I'm curious—what's your next plan?" 🔊
[地道搭配] be curious about sth / curious + 疑问词从句（陈述语序）
[勾选] ✅ 已会说对 / ⬜ 记录待巩固 → 沉淀进造句记录 + 说法库来源
```

### 5.3 今天用掉

当日新学/复习词进入「今天用掉」清单，勾选后记入统计；当日未用掉的词次日仍在（不惩罚，只提示——继承"不惩罚遗忘"立场）。

## 6. 技术架构

```
vocab-growth-app/
├── index.html            页面骨架（6个 tab 容器）
├── css/style.css         全部样式（响应式，移动优先）
├── js/data.js            种子数据（纯数据，Node 可测）
├── js/srs.js             SRS-lite 引擎（纯函数，Node 可测）
├── js/store.js           状态管理（storage 适配器注入，Node 可测）
├── js/app.js             UI 渲染与交互（含 TTS 封装）
├── assets/audio/*.mp3    40个OB真实美音
├── server.js             零依赖静态服务器（Node，上线用）
└── test/                 Node 单元测试（node:test）
    ├── test-data.js      数据完整性（68词/8群/13块/字段校验/音频映射）
    ├── test-srs.js       调度引擎（深度映射/流转状态机/队列/铁律）
    └── test-store.js     状态管理（持久化/导入导出/统计）
```

**选型理由**（对标姊妹项目"工具选型判断力"）：
- 零框架零构建：经典 script 标签加载，双击 index.html 即用、GitHub Pages/任意静态托管直发、离线可用。
- 纯函数分层：data/srs/store 三个模块不碰 DOM，Node 直接单测——弥补姊妹项目"无测试"短板。
- TTS 用 `speechSynthesis`（零成本），有 OB 真实 mp3 的词优先播 mp3（保真），无 mp3 的回退 TTS。
- 图表手写 SVG 折线（累计词量），不引图表库。
- 无后端无账号：localStorage + JSON 导出/导入（B5 评估结论：不做账号体系）。

## 7. UI 设计

- **视觉**：清新绿主色（#2E7D32 生长感）+ 深度徽章色（🟢#43A047/🟡#F9A825/🔴#E53935）；圆角卡片、大字号词卡、进度色条。
- **布局**：桌面左侧导航 + 内容区；移动端底部 tab。词卡核心操作单手可达（发音/下一层/标记）。
- **反馈**：所有状态变化即时toast；流转事件（进薄弱/移出薄弱/里程碑）弹横幅强化"数据在生长"的感知。
