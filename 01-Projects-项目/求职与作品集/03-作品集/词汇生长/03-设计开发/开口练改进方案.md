# 词汇生长开口练改进方案

## 一、改进目标

对标OB英语开口练的核心功能，提升当前项目的开口练体验，重点实现：
1. 实时反馈机制（造句评分）
2. 难度分级系统
3. 激励机制（积分、等级、徽章）
4. 练习模式扩展

## 二、核心改进模块

### 2.1 造句评分模块（speak-workshop.js）

#### 功能设计
```javascript
// 评分维度
{
  grammar: {
    score: 0-100,
    errors: [],
    suggestions: []
  },
  vocabulary: {
    score: 0-100,
    diversity: 0-100,
    complexity: 0-100
  },
  naturalness: {
    score: 0-100,
    highlights: [],
    improvements: []
  },
  completeness: {
    score: 0-100,
    missing: [],
    summary: ""
  }
}

// 总分计算
totalScore = (grammar + vocabulary + naturalness + completeness) / 4
```

#### 评分算法
1. **语法评分**：
   - 规则引擎检查
   - 时态、主谓一致、语序
   - 基础语法错误检测

2. **词汇评分**：
   - 词汇多样性（不重复词数/总词数）
   - 词汇复杂度（平均词长、高级词汇占比）
   - 词汇匹配度（与参考表达的相关性）

3. **自然度评分**：
   - 句式变化（简单句/复合句比例）
   - 连接词使用
   - 地道表达匹配

4. **完整度评分**：
   - 内容完整性
   - 逻辑连贯性
   - 话题覆盖

#### 自动难度检测
```javascript
function autoDetectDifficulty() {
  const stats = store.getStats();
  const history = store.getPracticeHistory();

  // 基于历史表现
  if (history.length >= 5) {
    const avgScore = history.reduce((sum, h) => sum + h.score, 0) / history.length;

    if (avgScore >= 80) return 'B2';
    if (avgScore >= 70) return 'B1';
    if (avgScore >= 60) return 'A2';
    return 'A1';
  }

  // 基于词汇量
  const wordCount = store.getWords().length;
  if (wordCount >= 2000) return 'B1';
  if (wordCount >= 500) return 'A2';
  return 'A1';
}
```

```javascript
function renderRepetitionMode(word) {
  return `
    <div class="repetition-mode">
      <div class="instruction">
        <p>请模仿录音：</p>
        <p>"${word.en}"</p>
      </div>

      <div class="audio-player">
        <button onclick="playNativeAudio('${word.id}')">
          🔊 听示范
        </button>
        <div class="waveform"></div>
      </div>

      <div class="record-section">
        <button id="recordBtn" onclick="startRecording()">
          🎤 开始录音
        </button>
        <div class="record-time">00:00</div>
      </div>

      <div class="feedback-section" id="repetitionFeedback">
        <!-- 反馈内容 -->
      </div>
    </div>
  `;
}

function startRecording() {
  // 使用Web Audio API录音
  const mediaRecorder = new MediaRecorder(navigator.mediaDevices.getUserMedia({ audio: true }));

  mediaRecorder.ondataavailable = (event) => {
    const audioBlob = event.data;
    analyzeAudio(audioBlob);
  };

  mediaRecorder.start();

  // 计时器
  let seconds = 0;
  const timer = setInterval(() => {
    seconds++;
    document.getElementById('record-time').textContent =
      formatTime(seconds);
  }, 1000);

  // 录音结束
  mediaRecorder.onstop = () => {
    clearInterval(timer);
  };
}

function analyzeAudio(audioBlob) {
  // 发送音频到评分API
  const formData = new FormData();
  formData.append('audio', audioBlob);
  formData.append('reference', currentWord.en);

  fetch('/api/analyze-audio', {
    method: 'POST',
    body: formData
  })
  .then(response => response.json())
  .then(data => {
    showRepetitionFeedback(data);
  });
}
```

## 五、技术难点与解决方案

### 难点1：评分算法准确性
**问题**：如何准确评分造句的语法、词汇、自然度？

**解决方案**：
- 语法评分：基于规则引擎 + NLP语法检查
- 词汇评分：基于词汇表匹配 + 多样性计算
- 自然度评分：基于句式分析 + 地道表达匹配
- 完整度评分：基于内容完整性分析

### 难点2：ASR集成
**问题**：如何实现发音评测？

**解决方案**：
- 短期：使用TTS模拟评分（基于波形相似度）
- 中期：集成第三方ASR API（科大讯飞、阿里云、百度）
- 长期：自研ASR评分算法

### 难点3：个性化推荐
**问题**：如何根据用户表现推荐合适的练习？

**解决方案**：
- 基于历史表现（正确率、用时、重复错误）
- 基于错题分析（针对性推荐）
- 基于兴趣偏好（用户选择）
- A/B测试优化推荐算法
