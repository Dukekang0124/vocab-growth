## 一、iOS Safari（iPhone 自带浏览器）

### TTS 出声
- [ ] 打开 App，进入「每日练习」任意一个场景
- [ ] 点句子右边的 ▶ 播放按钮 → **能听到英文朗读**（有道/百度/Web Speech 任一音源出声即可）
- [ ] 点「慢速」按钮 → 速度明显变慢且出声
- [ ] 盲说区点「听发音」→ 出声
- [ ] 把手机**静音开关打开**（侧边静音键）后重试 → Safari 下也应出声（iOS 对 `<audio>` 不受静音键影响，但若走 Web Speech 可能受系统控制，需实测）

### 录音 + 评分
- [ ] 点句子下的「录音」按钮 → 浏览器弹出**麦克风授权**，点「允许」
- [ ] 说一句英文，停止 → **波形动画出现**且能回放自己声音
- [ ] 停止后是否出现评分？（iOS Safari 支持 `webkitSpeechRecognition` 概率中等）
  - 有评分 → 看 accuracy/fluency 数字是否合理
  - **无评分**（常见）→ 应看到「无评分环境」提示 + 自评星星兜底，**不报错、不白屏**

### 新手引导 / {{name}} / 音标 / 持久化
- [ ] 首次进入弹出 4 步新手引导，可「下一步 / 跳过」，关掉后不再弹（localStorage 记住）
- [ ] 「关于」页把昵称改成自己的名字 → 回到练习，句子里的 `{{name}}` 变成该名字
- [ ] 每个英文句子下方显示**美式音标**（如 `/hˈaɪ ˈaɪm ˈælʌks/`）
- [ ] 录一次音/自评一次 → 进入「进度」页，能看到分数趋势柱状图，且**刷新页面后仍在**

## 二、安卓微信（X5 内核）

### TTS 出声
- [ ] 微信里打开链接，进入「每日练习」
- [ ] 点 ▶ 播放 → **能出声**（X5 下 Web Speech 常不可用，应自动回退到有道/百度 TTS）
- [ ] 点「慢速」「听发音」均出声

### 录音 + 评分（重点缺口）
- [ ] 点「录音」→ 微信是否弹麦克风授权？
- [ ] 录完回放 → **能否听到自己声音**？（X5 的 MediaRecorder 兼容性最差，最可能是卡点）
- [ ] 停止后评分：
  - X5 **通常能录音但无语音识别** → 应看到「无评分环境」预警 + 自评星星，绝不白屏
  - 这是**预期行为**：盲说模式不依赖录音，微信里完整可用

### 盲说模式（微信里的核心路径）
- [ ] 不录音、不评分，纯盲说：点「我想试试」→ 英文变 ■ 遮罩 → 自己说 → 「我想起来了/想不起来」→ 揭示对照
- [ ] 盲说模式下「打卡」按钮**始终可见** → 听读或录音任一达标即可打卡，streak 能累加
