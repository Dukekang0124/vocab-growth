# PRD · 英语开口练 v1.0

> 产品需求文档 | 2026-08-28 | 作者：苏不倦

## 一、产品概述

### 1.1 产品定位
面向31-40岁零基础成人的英语开口练习工具，每天3-5句场景化练习，微信直接使用，无需下载。

### 1.2 核心目标
- **用户目标**：能开口说出完整的英语句子，获得成就感
- **业务目标**：低成本验证需求，收集用户反馈，为求职提供作品集
- **内测目标**：50-100名种子用户，验证核心体验和付费意愿

### 1.3 核心闭环
```
每日场景 → 听标准发音 → 跟读录音 → 自动评分/对照 → 打卡记录 → 连续激励
```

## 三、交互设计

### 3.1 信息架构
```
底部Tab导航
├── 挑战（首页）：每日场景 + 录音
├── 词卡：300词分类浏览
├── 对话：20个场景选择
├── 跟读：50句列表
└── 进度：统计 + 日历 + 成就 + 反馈
```

### 3.2 关键交互

**TTS播放**：
- 点击"播放"→ 有道TTS加载MP3 → 播放
- 点击"慢速"→ playbackRate=0.7
- 播放中再次点击 → 停止

**录音**：
- 点击"开始录音"→ 微信弹授权 → 录音中（波形动画）→ 再点停止
- 停止后自动尝试语音识别评分（Chrome）或显示对照提示（微信）

**打卡**：
- 完成当日录音 → 自动打卡 → 连续天数+1
- 日历显示打卡记录

### 3.3 视觉规范

- 暗色主题（护眼，适合晚间学习）
- 主色调：靛蓝/紫色系
- 字体：系统字体栈
- 最小触控区域：44px
- 基准宽度：375px（移动端优先）

| 维度 | 要求 |

## 六、后续迭代方向（v1.1+）

1. **内容扩充**：场景对话增至30+，跟读增至100句
2. **语音评分升级**：接入专业发音评测API（如讯飞）
3. **付费上线**：接入面包多等第三方支付
4. **用户系统**：微信登录+云端同步
5. **社交分享**：打卡海报生成+分享
6. **内容更新机制**：每周新增场景
