# 出包执行单 · 英语开口练 APK（本机跑，卡住就回来报）

> 照着打勾，一步一个产物。卡在哪步，把报错原样发我。

## 第 0 步 · 前置检查（一次性）

- [ ] 本机有 Node 18+（`node -v`）
- [ ] 本机有 JDK 17（`java -version` 显示 17.x；没有 → `scoop install openjdk17`）
- [ ] 本机有 Android SDK + 环境变量 `ANDROID_HOME`（没有 → 装 Android Studio，勾选 SDK Platform 35 + Command-line Tools）
- [ ] 记下两个环境变量：`JAVA_HOME`、`ANDROID_HOME` 都指向正确目录

## 第 1 步 · 初始化 Capacitor 工程（一次性）

```bash
cd "D:\写作工具\知识管理\01-Projects-项目\求职与作品集\03-作品集\英语开口练"
npm init -y
npm i @capacitor/core @capacitor/cli @capacitor/android
npx cap init "英语开口练" com.kaikou.english --webdir app
```
- [ ] 用仓库里已有的 `capacitor.config.json` 覆盖生成的（appId 已配好）
- [ ] 看到根目录出现 `android/` 文件夹

## 第 2 步 · 生成安卓工程（一次性）

```bash
npx cap add android
```
- [ ] `android/` 里有 `AndroidManifest.xml` 和 `build.gradle`

## 第 3 步 · 把网页塞进壳（每次改 web 后都要跑）

```bash
powershell -ExecutionPolicy Bypass -File android-build/sync-web.ps1
npx cap sync android
```
- [ ] 输出 `✅ 已同步网页到原生壳`

## 第 4 步 · 确认权限声明

打开 `android/app/src/main/AndroidManifest.xml`，确认有三行：
- [ ] `RECORD_AUDIO`（麦克风）
- [ ] `INTERNET`（TTS CDN）
- [ ] `ACCESS_NETWORK_STATE`

缺哪行补哪行（放 `<manifest>` 内、`<application>` 外）。

## 第 5 步 · 生成签名密钥（⚠️ 只做一次，必须备份）

```bash
keytool -genkey -v -keystore kaikou-release.keystore -alias kaikou -keyalg RSA -keysize 2048 -validity 10000
```
- [ ] 记住密码和 alias
- [ ] **把 `kaikou-release.keystore` 备份到加密云盘/移动硬盘**（丢了 = 无法同身份更新）

## 第 6 步 · 出 release 包

```bash
npx cap build android --release
```
- [ ] 产物出现在 `android/app/build/outputs/apk/release/app-release.apk`

## 第 7 步 · 分发

- [ ] 把 `app-release.apk` 复制到仓库根目录（`english-speaking-app/` 与 `english-speaking-app-github/` 各一份，后者提交）
- [ ] 改 `download.html` 里 APK 按钮 href：`href="/app-release.apk"`
- [ ] 提交 + 交给豆包 push（沿用交接流程）

## 第 8 步 · 更新机制（以后每次改 web）

- [ ] `index.html` 里 `APP_VERSION` 和 `version.json` 里 `version` 同步 +1（如 `1.4.1` → `1.4.2`）
- [ ] 重跑第 3 步 + 第 6 步，出新 APK

---

## 常见卡点速查

| 现象 | 原因 | 解法 |
|---|---|---|
| `npx cap build` 报找不到 SDK | `ANDROID_HOME` 没配 | 配 `ANDROID_HOME` 指向 SDK 目录，重启终端 |
| Gradle 下载巨慢 | 首次拉依赖 | 挂代理或耐心等，只发生一次 |
| 安装时提示"未知来源" | 自签名 APK 未过商店 | 用户设置里允许"未知来源"一次即可（正常现象） |
| 手机上 TTS 没声但网页版有声 | WebView 禁了 Web Speech TTS | 属已知限制，主音源 CDN 联网时正常；离线用盲说模式 |
