## 一、问卷题纲（内测结束 / 使用 3 天后推送）

**Q1. 你有多大意愿把"英语开口练"推荐给想练口语的朋友？（0–10 分）**
- 0 = 完全不会，10 = 一定会 → 用于算 NPS（9–10 推荐者，7–8 中立，0–6 贬损）

**Q2. 如果正式版定价 29.9 元，你是否愿意付费解锁全部内容？**
- A. 愿意现在就买 / B. 愿意，但等更完善 / C. 不确定 / D. 不愿意（原因见 Q4）

**Q3. 你最希望我们优先改进哪 3 项？（多选，≤3）**
- 发音打分反馈 / AI 对话陪练 / 更多场景例句 / 真人示范更自然 / 学习进度追踪 / 界面更友好 / 降低开口心理压力 / 其他（填空）

**Q4. 你在使用过程中"卡在哪"或"为什么放弃"？（开放题）**
- 自由填写，这是挖掘真实痛点的核心来源

**Q5. 一句话描述：这个产品帮你"开口"了吗？**
- 验证核心价值主张是否成立

> 投放建议：用微信/腾讯文档问卷，内测群内推送；配合 1 元红包或早鸟卡提高回收率。

## 二、埋点清单（轻量可选 · 尊重"未验证不投开发"）

**原则**：优先用问卷 + 手动观察；埋点仅为辅助，且只加"最小必要事件"，不为埋点改大量代码。
若加，建议在现有 `index.html` 关键节点插 1 行 `track(event, params)`（可先 console.log 或落 localStorage，验证后再接 Workers KV）。

| 事件名 | 触发时机 | 参数 |
|---|---|---|
| `page_view` | 页面加载 | `src`（渠道：douyin/xhs/wechat/私域） |
| `repeat_start` | 点击某句"开始跟读" | `sentence_id` |
| `repeat_finish` | 完成一次跟读（含录音回放结束） | `sentence_id`, `has_record`（是否录了音） |
| `record_trigger` | 点击麦克风录音 | — |
| `unlock` | 卡密解锁成功 | `code_batch`（来源批次） |

**采集方式（零成本档）**：
- 初期：`localStorage` 计数 + 用户主动填问卷，不接后端；
- 验证后（P1）：`track()` 上报到 Workers KV（已在 `cloudflare-workers/src/index.js` 预留 `/api/progress` 接口）。
