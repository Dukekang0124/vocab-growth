# 英语开口练 · 产品优化 PRD

> 聚焦核心 MVP，兼顾演示价值与合规底线 · 2026-08-27 · 形态：规划文档（不改代码）
> 产品代码在豆包工作台开发，本文为规划层产出，落地需回豆包端实现。

## 0. 文档说明

基于当前 aiforce.cloud 部署版评估 + 优化方向，制定聚焦核心 MVP 的可执行规划。（2026-08-27 复核说明：经全流程实测与源码审计，本节及全文的现状描述已同步为已验证事实，未验证的推断已标注。）

**8 个优化方向 → 落地分层**：

- 明确用户水平/场景 → 待做（现版无分级自测）
- 阶梯路径+即时反馈 → 部分（即时反馈已用「回放对比」实现；ASR 评分属 V2）
- 真人语音示范+跟读对比 → 已落地（TTS 标准音+慢速+录音 AB 对比；真人音源后期替换）
- 句型库+情境模板 → 雏形（301 词卡例句 + 20 场景对话覆盖主干）
- 智能对话陪练 → 选择式已落地（20 场景）；自由表达接大模型属 V2
- 激励+进度追踪 → 已落地（连续天数 + 8 徽章 + 打卡日历 + 通关标记）
- 降门槛交互 → 大部分落地（大字大录音钮）；新手引导一句文案待补
- 离线+多端同步 → P2（现状 localStorage 本机有效）

## 1. 现状复盘

| 维度 | 当前版本 | 目标版本 |
|---|---|---|
| 产品形态 | 单页应用 5 Tab：挑战/词卡/对话/跟读/进度 + 额度制付费墙 | 收银台与合规补齐即为可售完整版；阶梯地图、自由对话留迭代 |
| 核心交互 | 录音→自动回放对比→回放成功才可打卡（强制开口）；无 ASR 评分（V2） | 增量：发音评分 + 逐词纠错（讯飞评测选型） |
| 用户体系 | 匿名 localStorage（key=english_speaking_app_v1）+ 解锁码交付权益 | 维持匿名决策；跨设备同步延后至有实证需求 |
| 付费节奏 | 免费额度：词卡前 50 / 对话前 3 关 / 跟读前 5 句，触墙弹 ¥29.9 一次买断 | 弹窗修复裁切 + 增补 ¥99 锚价与「7 天全额退」承诺 |
| 激励 | 连续天数置顶 + 打卡日历 + 8 枚徽章 + 场景通关√ | 增量：断签温和挽留、打卡战绩复制分享 |
| 定位一致 | 「开口」与功能一致：听→读→录→比 | 对外叙事收紧为同一句话；AI 自由对话作为 V2 增量叙事 |

> 关键判断（复核后修订）：口语灵魂闭环已用「示范→自录→回放对比」方式闭合并强制开口打卡，不构成生死线风险；当前真正的阻断项是**收银台细节（弹窗裁切 / 无复制微信号按钮 / 抖音内长按二维码失效）**与**备案资质滞后**。「账号缺失导致付费无法交付」的判断已被解锁码交付方案化解。

## 2. 目标用户与场景定位

### 2.1 用户分层

| 层级 | 画像 | 核心诉求 |
|---|---|---|
| 核心·初学者 | 31-45 岁成人（苏不倦粉丝主力 31-40），0 基础/荒废多年 | 不怕错的练习环境、看得见的进步、被引导的第一次开口 |
| 核心·重返者 | 有基础但「不敢说」 | 场景化实用句、发音自信、真实对话演练 |
| 扩展·备考/商务 | 雅思/托福/职场 | 考试模板、商务情境（P1） |

### 2.2 场景矩阵

| 场景 | 优先级 | 说明 |
|---|---|---|
| 日常对话 | MVP | 自我介绍/闲聊/兴趣，最刚需高频——30 每日轮换场景已覆盖主干 |
| 出行旅游 | MVP | 点餐/问路/酒店/就医，情境强——对话场景库已含机场/酒店/看医生等 |
| 商务 | P1 | 会议/邮件/谈判 |
| 考试 | P1 | 雅思/托福口语模板 |

> MVP 聚焦「日常 + 出行」；商务/考试归 P1，避免范围失控。（现有 20 个对话场景与该矩阵吻合。）

## 3. MVP 四大模块详设

### M1 阶梯式口语练习路径（MVP）

- **分级**：【待做】显式 L1-L4 与入口自测；现版以每日场景按天轮换 + 20 场景构成隐式难度
- **内容**：【已落地】30 每日场景×3-5 句、301 词卡、20 场景对话、50 跟读句
- **解锁节奏**：【已落地】额度制替代章节制：每日挑战全免费 + 词卡前 50 / 对话前 3 关 / 跟读前 5 句，其余 ¥29.9 一次性解锁
- **路径地图 UI**：【待做】横向进度条 + 当前 Level 高亮 + 「下一站」指引
- **验收点**：新用户进入 5 秒内明白「我在哪、下一步去哪」（现版首屏即今日挑战，接近达标）

### M2 即时发音 + 语法反馈机制（MVP）

流程（现版）：点句子 → 听 TTS 示范（正常/慢速）→ 录音 → 自动回放对比；评分组件为 V2 增量。

- **评分维度**：【V2】准确度 / 流利度 / 完整度，综合 0-100（讯飞语音评测选型）
- **反馈 UI**：【部分落地】录音中波纹动效已有；得分环 + 逐词红绿标（红=需改进）随评分组件 V2 接入
- **真人示范 + 跟读对比**：【已落地】TTS 示范音轨与用户录音回放对比；后期换康哥真人录音
- **语法轻提示**：【V2】识别明显错误（时态/单复数/冠词），「小贴士」呈现不打击
- **验收点**：「录完即听自己 vs 标准音」现版已达成；「录一句 3 秒内出分」为 V2 验收目标

### M3 智能对话陪练（MVP）

- **模式切换**：【落地形态不同】对话已是独立 Tab（无需跟读/AI 双模切换）
- **情境角色**：【已落地】20 个情境含咖啡师/路人/酒店前台/面试官等
- **多轮对话**：【选择式已落地】用户从选项中选 B 角色回应，答对进入下一轮；自由表达接豆包大模型属 V2
- **安全兜底**：【选择式天然满足】答错展示正确答案并解释，不卡死不冷场
- **验收点**：选择式「完成 3 轮以上情境对话且不中断」已达标；自由对话指标留 V2

### M4 学习激励与进度追踪（MVP）

- **连胜 Streak**：【已落地】连续天数置顶展示；断签温和提醒【待做】
- **徽章**：【已落地】8 枚（坚持一周/坚持一月/词汇破百/词汇大师/对话新手/对话达人/开口十次/口语狂人）
- **看板正反馈**：【已落地】首次录音即出现「完成今日打卡」按钮，打卡成功有 toast 正反馈；庆祝动效可选做
- **学习日历**：【已落地】月视图打卡日历
- **验收点**：第一次录音即获正反馈，愿意第二天回来（机制已在位，靠埋点数据验证）

## 4. 降低开口心理门槛

- 首屏行动召唤：【基本满足】首屏即今日挑战 + 大录音钮；缺一行新手引导「先点▶听一遍，再点🎙跟着说」
- 无评判氛围：【符合】对话答错给正确答案与解释，不用「错误」话术打压
- 错误友好：【符合】纠错以提示/toast 呈现；麦克风被拒提示可再友好一点
- 匿名可试：【已满足】全程无需注册登录即可体验免费额度内全部内容
- 小步快跑：【已满足】每次 3-5 句、约 3 分钟一局

## 5. 合规底线（P0，上线前必做）

| 项 | 要求 | 风险 |
|---|---|---|
| ICP 备案 | 腾讯云大陆节点+自有域名备案，当天提交 | 🔴 阻断：不备案无法访问 |
| 经营资质 | 长期需个体户主体；现阶段个人小额收款普遍做法过渡 | 🟠 中期：月流水平稳后尽快转正 |
| 隐私+麦克风 | 一页纸隐私说明挂关于页，明确音频仅本地处理不上传 | 🔴 阻断：违规收集个人信息之嫌 |
| 权益交付 | 既定决策不做账号：解锁码人工发码交付付费权益 | 🟡 已化解原「无法交付付费」风险；需明示清缓存凭码恢复 |
| 支付闭环 | 个人收款码弹窗+发码流程已跑通；剩余：弹窗裁切、复制微信号按钮、长按失效降级 | 🔴 上线阻断（收银台三件套） |
| 核心交互实测 | 模拟环境端到端已完成；iOS 微信内嵌 TTS 实机为最后一块 | 🟡 投流前必测 |

> 合规周期长（1-4 周），现在就启动。与《上线前评估自查清单》P0 一致，可合并执行。

## 6. 求职展示建议

- **叙事线**：用户痛点（不敢开口/怕错/无反馈）→ 做减法（额度制免费体验 + 强制开口打卡）→ 守底线（备案/隐私前置）→ 验证（真机矩阵、漏斗指标）
- **可演示点**：5 Tab 模块实拍、标准音/慢速/自录回放对比、20 场景通关√、打卡日历与 8 徽章墙、¥29.9 弹窗权益对比表
- **关键话术**：为什么先用「回放对比」而非 AI 评分（学习科学 + 成本克制）、为什么额度制而非逐句付费墙、为什么坚持匿名 localStorage + 解锁码而不做账号
- **呈现**：本 PRD + 《产品商业化评估与改造方案》（终版商业口径）+ demo 录屏，组成作品集「产品规划」模块

## 7. 落地路线图

### P0 — 上线前必须（收银台 + 底座）
- 收银台三件套：复制微信号按钮 / 长按识别降级文案 / 弹窗裁切修复
- 解锁码一单一码化（SHA-256 哈希 + 发货台账）
- 统计埋点接入（pw_view / copy_wechat / unlock_ok 等）
- 关于页接线（导航加第 6 Tab 或入口卡片）
- ICP 备案提交 + 自有域名 + HTTPS
- iOS 微信内嵌等真机兼容矩阵测试

### P1 — 上线 2 周内
- 免费额度调优实验（对话 3→5 关 / 跟读 5→8 句，单变量推进）
- 弹窗文案升级：¥99 锚价 + 7 天全额退承诺 + 无二次收费声明
- TTS voice 固定（锁定 en 语音）+ iOS 静默失败检测
- 付费后体验闭环（解锁直达对话页）+ 清缓存丢单恢复提示
- 301 词与 50 句内容英文人工审校

### P2 — 迭代优化
- ASR 发音评分 + 逐词纠错（讯飞评测）
- 自由表达 AI 对话陪练（豆包大模型接入）
- 显式阶梯地图（L1-L4）/ 断签挽留 / 战绩分享海报
- 跨设备同步与离线 PWA 重新评估
- 商务/考试场景扩展包；内容月更后测试 ¥39.9 定价

## 8. 成功指标 / 验收标准
