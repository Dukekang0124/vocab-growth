# 英语开口练 · 上线前评估与自查清单

> 评估对象：aiforce.cloud 部署版 · 定价 29.9 元 · 状态：未上线 · 计划部署腾讯云 · 评估日期：2026-08-27
> 注：本产品为康哥求职作品集，例句含「苏不倦」人设。

## 一句话结论

这是一款「300词就能开口」的零基础成人开口练习器。经深度复核（全流程实测 + index.html 源码审计）：**五个功能模块全部真实可用**——每日挑战 30 场景按天轮换、301 词卡标记掌握、20 个选择式场景对话、50 句跟读（TTS 标准音 + 慢速 + 录音回放对比）、打卡日历 + 8 枚成就徽章；免费额度真实生效（词卡前 50 / 对话前 3 关 / 跟读前 5 句）。真正的风险不在功能闭环，而在：①付费墙可被源码绕过且整站内容内嵌单文件、另存网页即可白嫖；②收款走个人码人工发码，抖音内置浏览器长按识别大概率失效；③移动端付费弹窗「解锁」按钮被裁切；④ ICP 备案与统计埋点未启动。结论：修完收银台三处漏水即可上线收费；账号体系按既定决策不做（localStorage + 解锁码交付权益）。

## 二、用户体验问题

- **卖点与功能一致**：「300词就能开口」与实际「先听、再开口说简单句」对得上；早期误判的功能错位系仅看首屏所致，进入各 Tab 后可证伪。
- **首屏行动召唤基本到位**：进入即是今日挑战卡片与明显录音钮；改进空间在新手第一次访问的一句引导文案（如「先点▶听一遍，再点🎙跟着说」）。
- **付费节奏合理但呈现有 bug**：并非逐句打扰，而是额度触墙后的一次性弹窗；但移动端弹窗底部「输入解锁码＋解锁」行被横向裁切，必须在上线前修复。
- **数据看板正反馈总体在线**：打卡成功、场景通关均有即时 toast 与视觉标记；首次进入的全 0 态可加一句低门槛鼓励话术。
- **亮点（要保留）**：极简聚焦、中英对照、慢速播放对大龄用户友好、「录了才允许打卡」的强制开口机制、深色暖橙品牌感——这是差异化优势。

## 三、上线前必须准备（合规 & 技术 · 按优先级）

### P0 — 不解决不能上线

- [x] **[实测] 核心交互端到端复核**：录音入口/回放对比/打卡联动/付费墙触发全链路验证可用（残余风险见下方条目）
- [ ] **[合规] ICP 备案**：腾讯云大陆节点 + 自有域名必须备案（约 1-2 周），当天提交
- [ ] **[合规] 经营性备案/资质**：长期合规需个体工商户主体；现阶段个人小额收款属普遍做法，列入月流水稳定后必办
- [ ] **[合规] 隐私政策 + 麦克风授权告知**：收集语音属个人信息，做一页纸隐私说明挂关于页，录音前告知用途
- [ ] **[技术] 收银台修复三件套**：「复制微信号」按钮（execCommand 兜底）/ 长按识别失效时的截图扫一扫降级文案 / 弹窗裁切 CSS 修复
- [ ] **[技术] 解锁码一单一码化**：替换明文 kaikou99 为 SHA-256 哈希一单一码（兼作发货台账），详见《产品商业化评估与改造方案》P0-2

### P1 — 上线两周内补齐

- [ ] [技术] 统计埋点接入（pw_view / copy_wechat / unlock_ok / checkin 等 7 个事件）
- [ ] [产品] 关于页接线：view-about 板块已建成但导航无入口，增长与信任页面当前不可达
- [ ] [产品] iOS 微信内嵌浏览器 TTS 静默失败检测 + 「用浏览器打开」引导话术

- [ ] [内容] 301 词条与 50 句跟读英文表达的人工通读审校（至今无人做过，教育产品内容错误是致命项）

## 四、具体优化建议（可执行）

1. **核心闭环已闭合并经实测确认**：保持「标准音→自录→回放对比」不打分的设计别在上线前抢改，ASR 评分是 V2 支撑涨价的增量，不是上线前提。
2. **叙事收紧不摇摆**：对外表述统一为「开口练：听→读→录→比」，避免用户拿「AI 对话陪练」的期待来对标产生落差。
3. **免费钩子已生效且略偏紧**：现为 50 词/3 对话/5 句，建议放宽至对话 5 关/跟读 8 句再观察转化（一次只动一个变量）。
4. **首屏激活小增强**：首次访问在今日挑战卡下加一行引导「先点▶听一遍，再点🎙跟着说」，配合强制打卡形成第一轮成就感。
5. **合规前置别拖**：备案提交走腾讯云流程（今天启动）；隐私政策与用户协议先上一页纸版本。
6. **数据归用户的既定实现**：不引登录，用解锁码交付权益；在解锁弹窗明示「清缓存后凭码随时恢复」的自救路径。
7. **保留差异化并放大**：营销素材直接拍真实取证——「出国点咖啡敢开口」「教娃秀一句」，而不是功能罗列。
