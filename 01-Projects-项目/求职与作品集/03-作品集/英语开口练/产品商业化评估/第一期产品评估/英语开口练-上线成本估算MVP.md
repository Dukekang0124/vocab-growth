# 英语开口练 · 上线成本估算（MVP 最小验证版）

> 原则：**最小化验证、按需投入**。在用户明确表现出付费意愿之前，严格控制前期支出。

## 一句话结论

MVP 验证期（验证「有没有人愿意点开、愿意输激活码、愿意付费」）的**硬性现金支出 ≈ ¥10–14 / 首年**（仅域名），外加 **1–2 小时**操作时间。其余全部在 Cloudflare / GitHub 免费额度内，**零月费**。真正产生持续费用的 ASR 语音识别、对话大模型、Workers 付费档，都放在「验证出付费意愿之后」再投入。

---

## 三档成本速览

| 档位 | 做什么 | 首年现金 | 工时 | 验证目标 |
|---|---|---|---|---|
| **极致MVP** | GitHub Pages + .xyz + Cloudflare 代理；继续硬编码 `kaikou99`，**不部署后端** | ¥10–14 | 1–2h | 有人点开？有人输码？从哪来？ |
| **标准MVP**（推荐） | 上述 + Cloudflare Workers 云卡密校验 + 防盗刷 | ¥10–14 | 2–3h | 同上 + 卡密是否被分享 |
| **验证后运营** | 接 ASR 打分 + 对话陪练 + 进度云同步 | ¥150–200/月 | 3–5天 | 付费留存、功能价值 |

> 标准MVP 与 极致MVP 现金支出相同——Workers + KV 免费额度内（10万请求/天、10万KV读/天）都是 **¥0**。建议直接上标准MVP，防盗刷价值远大于这 1 小时。

## 必须 vs 可暂缓

- ✅ **必须**：域名 + Cloudflare 代理（唯一硬性现金）；GitHub Pages（已就绪）；卡密云校验（¥0，强烈建议同批做）
- ⏸ **可暂缓**：ASR 打分（当前版本本就无 ASR，先验证有人用）；AI 对话陪练（最贵最重）；进度云同步/账号（本地存储够用）；多店铺自动发卡（手工即可）
- ❌ **砍掉**：腾讯云国内备案 + 服务器（卡密模式免备案，国内服务器多余）

---

## 隐藏费用 / 被忽略的坑

1. **域名续费溢价**：.xyz 首年 ¥1 促销，续费 **¥109/年**。长期预算按续费价算。
2. **ASR 按量不可控**：用户量上来后 ASR 是主要变成本（≈¥150/月级）。开启前设调用上限。
3. **平台佣金**：小红书/抖音橱窗/微信小店抽成 1%–10%，29.9 到手约 ¥27–29.6。
4. **时间机会成本（最大隐性）**：没验证付费意愿前就投 P1/P2/P3 开发才是真浪费。
5. **SSL 证书**：Cloudflare 免费提供，无需购买。
6. **备案**：卡密模式免备案，省 7–20 天 + 服务器费。

---

## 🔧 价格更正（重要）

此前规划文档写的「火山引擎 ASR ¥0.0012/次」**有误**。官方定价：小模型流式语音识别 **¥0.0584/分钟**（首 18000 分钟阶梯）。一条 10 秒跟读 ≈ **¥0.01/次**。豆包大模型价格无误（lite 输入¥0.6/百万tok、输出¥3.6/百万tok）。

## 推荐执行路径（带决策触发点）

1. **第 0 步（今天，¥10–14 + 2h）**：买 .xyz → CF 代理 → 部署 Workers 卡密（沿用 `cloudflare-workers/` 下已写好的代码）。上线「能打开、能输码、能跟读 TTS」的真实版本。
2. **验证窗口（2–4 周）**：观察访问量、激活码输入率、渠道来源。**不投任何开发资源。**
3. **触发①**：有人询单/付费 → 上 ASR 打分。
4. **触发②**：付费留存达标 → 上对话陪练 + 进度云同步。
5. **触发③**：日发卡 > 20 张 → 上自动发卡 webhook。

> 心法：**每个功能在「被需求倒逼」时才做**，不是「我觉得该有」时做。这是把前期支出压到最低的关键。
