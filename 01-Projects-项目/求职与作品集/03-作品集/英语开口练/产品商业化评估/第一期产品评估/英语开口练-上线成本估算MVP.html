英语开口练 · 上线成本估算

基于「MVP 最小验证 · 按需投入」原则　|　生成日期：2026-08-27　|　定位：第一期产品评估

一句话结论：MVP 验证期（验证「有没有人愿意点开、愿意输激活码、愿意付费」）的硬性现金支出 ≈ ¥10–14 / 首年（仅域名），外加你自己的 1–2 小时操作时间。其余全部在 Cloudflare / GitHub 免费额度内，零月费。真正产生持续费用的 ASR 语音识别、对话大模型、Workers 付费档，都放在「验证出付费意愿之后」再投入。

① 三档成本速览（从最小到完整）

档位做什么首年现金你的工时验证目标
极致MVP GitHub Pages + .xyz域名 + Cloudflare代理；继续用硬编码 kaikou99，不部署后端 ¥10–14 1–2h 有人点开？有人输码？从哪来？
标准MVP 在极致MVP基础上 + Cloudflare Workers 云卡密校验 + 防盗刷（设备绑定/IP限速） ¥10–14 2–3h 同上 + 卡密是否被广泛分享
验证后运营 接 ASR 打分 + 对话陪练 + 进度云同步（按需开启，按量付费） ¥150–200/月 3–5天开发 付费留存、功能价值
「标准MVP」与「极致MVP」现金支出相同——因为 Cloudflare Workers + KV 在免费额度内（10万请求/天、10万KV读/天）都是 ¥0。区别只在你多花 1 小时部署。建议直接上标准MVP，防盗刷价值远大于这 1 小时。

③ 必须 vs 可暂缓（按「最小化验证」原则）

事项分类理由
域名 ¥10–14 + Cloudflare 代理必须解决国内/微信访问不稳定，是「真实用户能打开」的前提。唯一硬性现金支出。
GitHub Pages 部署必须已就绪，0 成本。
卡密云校验（Workers）建议¥0，但防盗刷、防分享，提升付费转化可信度。强烈建议与域名同批做。
ASR 跟读打分可暂缓当前版本本就无 ASR，先验证「有人用」再补。补了反而增加¥150/月变成本。
AI 对话陪练可暂缓最贵、开发最重。是「验证付费意愿后」的第二阶段功能。
进度云同步 / 账号体系可暂缓MVP 用本地存储即可，账号是规模化后的事。
多店铺自动发卡可暂缓早期手工发卡（你已有小红书/抖音/微信小店），量起来再自动化。
腾讯云国内备案 + 服务器砍掉卡密模式经第三方店铺收款，完全免备案。国内服务器是过度支出。

④ 隐藏费用 / 被忽略的坑

  • 域名续费溢价：.xyz 首年常 ¥1 促销，但续费标准价 ¥109/年。做长期预算请按续费价算，别被首年低价误导。
  • ASR 按量不可控：用户量上来后 ASR 是主要变成本（≈¥150/月级）。务必在开启前设「每日/每用户调用上限」。
  • 平台佣金：小红书/抖音橱窗/微信小店抽成约 1%–10%，是营收分成不是前置成本，但影响净收入（29.9 到手可能 ¥27–29.6）。
  • 时间机会成本（最大隐性支出）：在没有验证付费意愿前就投入 P1/P2/P3 开发，是真正的浪费。先把极致/标准 MVP 跑出去收反馈。
  • SSL 证书：Cloudflare 免费提供，无需单独购买（避免被推销 ¥数百/年的证书）。
  • 备案成本：卡密模式免备案，省下 7–20 天时间 + 可能的服务器费。若未来要接微信支付直连，才需备案。

⑤ 对之前「全栈补齐」方案的回调

此前的规划按「全栈补齐（ASR+对话+进度+Workers+多店铺自动化）」展开，在你本次明确「MVP 最小验证、严控投入」后，做如下收敛：

原方案项判定调整
Workers 云卡密保留¥0，防盗刷价值高，与域名同批上。
ASR 打分（P1）后移验证付费意愿后再做，避免 ¥150/月 空转。
对话陪练（P2）后移第二阶段功能，非验证必需。
进度云同步 KV后移MVP 用本地存储，账号规模化后再云化。
多店铺自动发卡 webhook（P3）砍掉手工发卡即可，自动化是规模化后期的效率投资。
腾讯云备案 + 国内服务器砍掉卡密模式免备案，国内服务器多余。

⑥ 🔧 价格更正（重要）

此前规划文档中写的「火山引擎 ASR ¥0.0012/次」有误。核实官方定价：小模型流式语音识别 ¥0.0584/分钟（首 18000 分钟阶梯）。一条 10 秒跟读 ≈ ¥0.01/次。请以此为准做预算。豆包大模型价格无误（lite 档输入¥0.6/百万tok、输出¥3.6/百万tok）。

⑦ 推荐执行路径（带决策触发点）

  • 第 0 步（今天，¥10–14 + 2h）：买 .xyz → Cloudflare 代理 → 部署 Workers 卡密（沿用已写好的 index.js + wrangler.toml + DEPLOY.md）。上线一个「能打开、能输码、能跟读 TTS」的真实可用版本。
  • 验证窗口（2–4 周）：观察——访问量、激活码输入率、哪个渠道带来用户、是否有人主动问「怎么买」。不投任何开发资源。
  • 触发升级①：若有人主动询单/付费 → 上 ASR 打分（P1），让用户「开口有反馈」提升留存。
  • 触发升级②：若付费留存 > 预期 → 上对话陪练（P2）+ 进度云同步。
  • 触发升级③：若日发卡 > 20 张 → 上自动发卡 webhook（P3），解放你手工。
核心心法：每个功能都在「被需求倒逼」时才做，而不是在「我觉得该有」时做。这是把前期支出压到最低的关键。
