## 一、背景与原则

本产品当前为单文件 H5（跟读 + Web Speech TTS + 本地录音回放），定价 29.9，尚未公开收费。

**产品推进总原则（用户拍板，2026-08-27）：**
- 先面向少量真人（≤100）做灰度内测，收集真实反馈；
- **仅当反馈整体积极、验证产品具备价值后**，才投入资源做功能/架构系统化；
- 未经真实用户数据支撑，禁止大规模开发与资源投入；
- 每一步推进都须有可量化阈值背书，未达则迭代 MVP 或 pivot。

**成本纪律（来自成本测算）：**
- MVP 验证期硬现金 ≈ ¥10–14/首年（仅 .xyz 域名）+ 1–2 小时工时；
- ASR 按量（≈¥0.01/次）是头号成本杀手，接入前必设调用上限；
- 不接 ASR 的纯跟读 MVP 才盈利，接 ASR 的完整版在 100 人规模年亏 ¥1,839（见成本估算）。

## 二、灰度 MVP 范围（现在就能上，¥10/年）

| 模块 | 是否包含 | 说明 |
|---|---|---|
| 跟读例句 + 分类场景 | ✅ | 现有 H5 核心，直接可用 |
| Web Speech TTS 真人示范 | ✅ | 浏览器内置，零成本、国内可达 |
| 本地录音 + 回放 | ✅ | 现有能力，纯本地，无上传 |
| 卡密解锁（kaikou99 兜底 / Workers 云卡密） | ✅ | 付费入口，零备案 |
| 发音 ASR 打分 | ❌ 不接 | P1 才做，成本杀手，验证前不动 |
| AI 对话陪练 | ❌ 不接 | P2，依赖大模型 API |
| 进度云同步 / 账号体系 | ❌ 不接 | 验证后做 |
| ICP 备案 / 公众号 / 小程序 | ❌ 不接 | 会逼回备案+营业执照，推翻免备案优势 |

**交付形态**：保持单文件 HTML、零构建步骤，部署在 GitHub Pages + 自定义 .xyz 域名 + Cloudflare 代理（国内/微信可达性优于裸 GitHub Pages）。

## 三、招募计划（≤100 内测）

| 渠道 | 用法 | 备注 |
|---|---|---|
| 抖音（苏不倦） | 口播 + 老外聊天录屏引流，评论区/主页放内测报名 | 已有账号，零成本 |
| 小红书 | 图文笔记"自学者给自学者发地图"，文末引导内测 | 已有账号 |
| 微信橱窗 / 微信小店 | 上架"内测体验卡"（免费或 ¥9.9 早鸟），发卡密 | 已有，0.6% 手续费、免备案 |
| 私域（微信群/朋友圈） | 直接邀请，发 H5 链接 + 卡密 | 最快触达 |

**引流话术要点**：强调"免费/早鸟内测""帮一个普通人也敢开口说英语的产品提建议"，降低门槛、提高反馈真诚度。
**节奏**：首周放 30–50 人，观察后再放量到 100，避免一次性涌入无法深度跟进。

## 四、验证周期

- **建议 2–4 周静默观察**，期间不投任何开发资源（仅答疑、催填问卷）。
- 每周拉一次数据看板（模板见[[01-Projects-项目/求职与作品集/03-作品集/英语开口练/产品商业化评估/第一期产品评估/英语开口练-内测反馈收集表]]）。
- 第 2 周末做第一次 Go/No-Go 评估；第 4 周末做最终评估。

| 类别 | 指标 | 采集方式 |
|---|---|---|
| 行为 | 打开率（访问/受邀） | H5 访问日志 / 问卷回填 |

| 主观 | NPS（0–10 推荐意愿） | 问卷 |
| 主观 | 痛点 TOP3 | 问卷多选 + 开放题 |

## 六、Go / No-Go 闸门（量化阈值，可改）

**满足以下全部条件 → 投 P1（接 ASR 打分 + 启动系统化）：**
- 周活 ≥ 30 / 100（即 ≥30% 受邀用户持续使用）
- 跟读完成率 ≥ 40%
- 且（NPS ≥ 0 **或** 付费 ≥ 3 / 100）

**未达任一硬条件 → 不进 P1**，执行二选一：
- 迭代 MVP（修反馈 TOP3 痛点后复测），或
- Pivot（重新定义核心价值，如从"跟读"转向"对话陪练"再验证）。

> 阈值可根据首批数据校准；原则是"先有数据、再调门槛"，而非凭感觉放行。

---

## 七、No-Go 红线（验证前绝对不做）

- ❌ 不碰 ICP 备案、不买国内服务器
- ❌ 不接公众号 / 小程序做付费入口（认证 600/年 + 营业执照 + 备案，见微信生态费用核查）
- ❌ 不接 ASR / 对话大模型（成本杀手，且未验证需求）
- ❌ 不招人、不外包、不为开发付钱
- ❌ 不做多端同步 / 账号体系 / 复杂后台

---

## 八、P1 触发后的下一步（仅作预告，不现在做）

1. **接 ASR 打分**：火山引擎流式（≈¥0.0584/分钟，10 秒跟读≈¥0.01/次），接前必设每用户每日调用上限 + 结果缓存，控成本（详见成本估算）。
2. **收款路径升级**：微信小店已够用；若付费率稳，再评估公众号/小程序（届时 0.6% 微信支付才划算）。
3. **系统化**：进度云同步（Workers KV）、激励看板、阶梯路径，按反馈优先级排期。
