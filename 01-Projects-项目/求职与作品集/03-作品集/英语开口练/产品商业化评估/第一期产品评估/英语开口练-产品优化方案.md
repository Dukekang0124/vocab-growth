# 英语开口练 · 产品优化方案（帮用户开口说英语）

> 北极星指标：**用户能够用英语开口说**（康哥定）
> 定位：带 35 岁零基础成年人，开口说出第一句、再到能聊 3-5 个回合的 AI 口语陪练。

## 二、场景决策（关键）

| 场景 | 课程阶段 | 采纳 |
|:--|:--|:--|
| 日常对话（问候/自我介绍/点餐/问路/天气） | 从零到入门 + 从入门到初级（01/02） | ✅ **MVP 核心** |
| 商务英语 | 从初级到中级（03） | ⏳ 后续阶段 |
| 考试口语 | 中级到高级（04） | ⏳ 后续阶段 |

**V1.0–V1.5 只做「日常对话」**：苏不倦定位是零基础开口，商务/考试是 03/04 阶段，MVP 不越级。（现版 20 个对话场景与 30 个每日场景均落在日常+出行区间，符合该约束。）

## 三、8 个功能模块规格

### M1 用户水平分级 + 学习场景体系
- 目标：进来先定位水平，再进对场景。
- 做：3 道自测题（读字母 / 自我介绍 / 点餐问路）→ 判定起点 → 分流到「从零到入门」或「从入门到初级」场景包。【待做——现版以每日场景轮换构成隐式难度】
- 验收：新用户 30 秒内完成分级并进入对的场景。

### M2 阶梯式练习路径 + 即时反馈（生死线）
- 目标：开口 → 反馈 → 修正 → 再开口。
- 做：阶梯 = `发音热身(音标/单词) → 整句跟读 → 场景对话 → 自由表达`；即时反馈 = 扣子接 ASR + 发音评测（打分 + 逐词标红 + 大模型语法纠错）。【即时反馈已用回放对比实现；ASR 打分为 V2】
- 验收：录一句，能看到总分 + 哪个词读错 + 怎么改。（现版验收替代口径：录完能立刻听标准音对比自己的录音）

### M3 真人语音示范 + 跟读对比
- 做：TTS 标准音（后期换康哥真人录音）→ 用户录音 → 逐句 AB 对比。【已落地，含慢速播放】
- 验收：每个跟读句能「听示范 → 录 → 回放对比」。✅ 已达标

### M4 常用句型库 + 情境对话模板
- 做：301 词升级为「高频句型库」（`I want to __ / Can I __? / My name is __`），每个句型挂 3-5 个情境模板。【雏形已有：词卡例句 + 对话选项即模板；填空句型卡待做】
- 验收：每场景有「句型卡 + 可填空对话模板」。

### M5 智能对话陪练（自由表达）
- 做：豆包大模型对话 + 角色扮演（点咖啡店员/问路路人），用户自由开口 → AI 接话 + 温柔纠错。【角色与情境已有 20 个场景；大模型自由对话 V2 接入】
- 验收：能和 AI 角色完成 3-5 回合自由对话。（现版已达选择式 5-6 轮对话验收）

### M6 学习激励 + 进度追踪
- 做：账号持久化 + 打卡奖励（连续 3 天解锁新场景）+ 301 词进度条。【本机版已落地：连续天数/日历/8徽章/通关√；账号按决策不做，跨设备同步待实证需求】
- 验收：进度跨设备不丢；断签有挽留、连续有正反馈。（现版本机达标：清缓存丢数据为已知代价，用解锁码恢复权益）

### M7 界面交互降开口心理门槛
- 做：① 首句不评分（敢说优先）② 一句话一行大字 + 大录音按钮 ③ 移动端全流程优化。【①②③均符合现状：全程无评分压迫、大字大钮、390px 实测良好】
- 验收：新用户 10 秒内录下第一句，移动端全流程可用。（剩余障碍＝首次访问引导一句话 + 付费弹窗裁切修复）

### M8 离线 + 多端同步
- 做：词卡/示范音静态缓存（PWA）+ 云端数据库同步。【维持不做，P2 再评估】
- 验收：弱网可看词卡；手机 PC 进度一致。

## 五、分期路线图

- 验收（修订后）：能录→能听对比→能解锁付费→进度不丢、手机可用。剩余动作＝收银台三件套 + 备案 HTTPS + 统计埋点。

### V1.5 · 开口核心能力（决定产品值多少钱）

## 六、定价决策

- **定位「AI 纠音陪练」→ ¥39.9**（修正 29.9 游离子，魔力数字 9 + 高于 9.9 仍小额）。【最新口径：移至 V2 测试位——ASR 评分上线且内容月更三个月后再执行】
- 若最终只做到"跟读+词卡"无纠音/陪练 → 降回 ¥9.9 对齐 L2。【已废弃：回放对比 + 20 场景体系 + 打卡徽章的组合差异化支撑得住 29.9】
- 真人示范音源：先 TTS，后期换康哥真人录音（更有辨识度）。
- **终版结论：维持 ¥29.9**——配 ¥99 锚价、7 天全额退承诺、「无二次收费」声明；本产品是私域训练营的信任敲门砖，不是唯一利润来源（详见《产品商业化评估与改造方案》）。

## 七、验证步骤

**V1.0 完成后（上线前）**
1. 真人录 3 句 → 有打分 + 逐词纠音。【修订：现版验收=回放对比可听；评分项随 V2】
2. 点「解锁」→ 能付款 → 付款后解锁。【模拟端到端已验至扫码环节；真实转账→发码→输码待首单实测】
3. 登录 → 打卡 +1 → 换设备进度还在。【改为：清缓存 → 凭解锁码恢复权限】
4. 手机（iOS/安卓微信内嵌）→ 录音、词卡、付费全流程可用。【真机矩阵待测】

**V1.5 完成后（核心能力）**
5. 找真零基础用户，走完分级→跟读→对比→句型→陪练，3 天内完成第一次"自由开口"。

**上线后（小流量）**
6. 抖音埋链接，追踪打开率→录音尝试率→解锁点击率→付款数→次日留存。（前置：统计埋点接入）
7. 收 3-5 个真实用户完整路径反馈，逐环找断点。
