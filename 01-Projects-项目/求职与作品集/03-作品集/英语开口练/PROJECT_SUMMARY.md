## 三、核心经验沉淀

### 3.1 微信Web开发必知

1. **不要假设Web Speech API可用** — 微信X5内核不支持，必须准备国内TTS方案
2. **录音每次需授权是正常的** — 微信安全策略，不要浪费时间尝试绕过
3. **个人收款码无法在微信网页内长按识别** — 这是微信的反钓鱼策略，不是bug
4. **微信支付JSAPI需要营业执照** — 个人开发者走第三方平台（面包多等）
5. **Cloudflare Pages在微信内可访问** — GitHub Pages不稳定，Netlify被hCaptcha拖慢

### 3.2 单文件应用开发经验

1. 数据数组集中管理，便于内容扩充
2. 所有浏览器API必须有降级方案
3. CSS变量统一主题，修改方便
4. SVG图标内联，减少请求
5. localStorage做状态持久化，无需后端
6. 单文件适合<10个功能模块的产品，超过后考虑拆分

### 3.3 部署经验

1. Cloudflare Pages直传有中文路径bug，走GitHub连接更可靠
2. GitHub连接时Repository access要选对仓库，不刷新就手动刷新
3. 国内访问Cloudflare Pages速度可接受（CDN节点在亚太）
4. 纯静态站不需要Build command，输出目录设为 `/`
5. 验证时加 `?v=时间戳` 绕过CDN缓存

### 3.4 产品经验

1. **先跑通核心闭环再做付费** — TTS+录音是核心，支付是后话
2. **内测免费降低门槛** — 收集反馈比收29.9元更有价值
3. **微信是主战场** — 所有功能必须在微信内置浏览器中可用
4. **作品集产品要可体验** — 一个能扫码打开的链接 > 十页PPT
