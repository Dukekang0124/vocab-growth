# 英语开口练 Web App — MVP功能规划

> 规划日期：2026-08-27
> 项目定位：康哥AI转型求职核心作品集 + 苏不倦英语自媒体引流工具
> 技术路线：纯HTML+CSS+JS单页应用，浏览器原生API，0后端0服务器
> 交付物：可运行的HTML文件，doubao-app-builder生成

---

## 一、产品定位

### 一句话定位
**"300词就能开口"——给31-40岁零基础成人的英语开口练习工具。**

### 不是什么
- ❌ 不是又一个背单词APP（不做海量词库、不做拼写测试）
- ❌ 不是语法学习工具（不教语法规则）
- ❌ 不是课程平台（不卖课、不做长视频）

### 是什么
- ✅ 开口练习器——给你场景和句子，让你马上说出来
- ✅ 发音反馈——标准发音播放+录音回放，自己对比
- ✅ 进度激励——打卡连续天数，低门槛高成就感
- ✅ 方法论入口——苏不倦四阶段路线图，学完引流微信

### 目标用户
- 31-40岁成人（苏不倦抖音核心粉丝群）
- 零基础或弱基础，学过多次都放弃
- 痛点：不敢开口、怕说错、不知道从哪开始
- 需求：每天10分钟，能看到自己在进步

## 二、MVP核心功能（6个模块）

### 模块1：每日开口挑战（首页核心）

**功能描述**：
- 每天一个生活场景（如：自我介绍、点咖啡、问路、超市购物）
- 展示3-5句该场景最常用的简单英语句子（控制在300核心词范围内）
- 每句配中文翻译
- 点击句子→浏览器TTS播放标准发音
- 用户点击"我来说"→录音→回放自己的发音
- 完成当天挑战→打卡+1

**设计要点**：
- 首屏只显示今天的挑战，不做复杂导航
- 句子大字体，手机端友好
- 录音按钮醒目，降低开口心理门槛
- 场景库预置30个，按天轮换（足够1个月）

**数据来源**：从四阶段课程中提炼高频场景句，优先第一阶段内容。

---

### 模块2：300核心词卡

**功能描述**：
- 精选300个最高频英语核心词（名词/动词/形容词/功能词）
- 卡片式展示：英文单词+音标+中文释义+1个简单例句
- 点击单词→TTS发音
- 左右滑动切换卡片
- 标记"已掌握"→从待复习队列移除
- 底部进度条：已掌握 X / 300

**设计要点**：
- 不是背单词APP，词卡只做"眼熟+会读"，不考拼写
- 300词是苏不倦核心理念的具象化——"这些就够你开口了"
- 例句必须来自真实场景，且只用到已学过的词

**数据来源**：基于牛津3000核心词筛选最常用前300，结合四阶段课程用词。

---

### 模块3：场景对话练习

**功能描述**：
- 选择一个生活场景→进入对话模式
- 屏幕显示A角色说的话（播放发音）
- 用户从2-3个选项中选择B角色的回应
- 选对→继续下一轮对话；选错→提示正确答案并解释
- 完成整个场景对话→获得"场景通关"标记

**设计要点**：
- 选择题形式，不要求用户打字输入（降低门槛）
- 对话简短，每个场景5-8轮
- 场景与每日挑战联动，但更完整
- 预置10个核心场景：自我介绍、点餐、购物、问路、时间日期、天气、打电话、酒店入住、机场、工作面试

---

### 模块4：发音跟读训练

**功能描述**：
- 精选20个最容易读错的高频句子
- 播放标准发音（可调节语速：正常/慢速）
- 用户录音跟读
- 回放对比：先播标准音→再播自己的录音
- 不做AI评分（技术复杂且MVP不需要），靠用户自己听对比

**设计要点**：
- "自己听出来"比"机器打分"更有学习效果
- 慢速播放功能对零基础至关重要
- 句子选自四阶段课程中的关键句

---

### 模块5：学习进度与打卡

**功能描述**：
- 打卡日历：显示本月每天是否完成挑战
- 连续打卡天数（核心激励数字，大字展示）
- 总练习天数、已掌握词数、已通关场景数
- 简单的成就徽章：连续7天/30天、掌握100词/300词、通关5场景/10场景
- 数据存在localStorage，不上传服务器

**设计要点**：
- 连续天数是最核心的激励，放在最显眼位置
- 成就系统简单，不要做复杂的等级体系
- 所有数据本地存储，隐私友好，0后端成本

---

### 模块6：苏不倦方法论与引流

**功能描述**：
- "关于"页面：苏不倦个人介绍+核心理念
- 四阶段路线图概览：从零到入门→入门到初级→初级到中级→中级到高级
- 每个阶段一句话说明+目标能力
- 底部CTA："想系统学习？加微信发送「英语」获取免费避坑指南"
- 微信二维码图片

**设计要点**：
- 这是作品集的"产品思维"体现——免费工具引流→私域转化
- 也是求职面试时讲"用户增长"的案例素材
- 二维码用已有素材（微信二维码.jpg）

## 三、技术实现方案

### 技术栈
| 层面 | 选型 | 理由 |
|:--|:--|:--|
| 结构 | HTML5 单文件 | 交付简单，双击即运行 |
| 样式 | 原生CSS + CSS变量 | 0依赖，深色主题，响应式 |
| 交互 | 原生JavaScript (ES6+) | 0框架，加载快 |
| 发音 | Web Speech API (SpeechSynthesis) | 浏览器原生，0成本，支持中英文 |
| 录音 | MediaRecorder API | 浏览器原生，录音回放 |
| 存储 | localStorage | 0后端，打卡/进度数据本地存 |
| 图标 | 内联SVG | 0外部依赖 |

### 页面结构（单页应用，Tab切换）
```
┌─────────────────────────┐
│  顶部：Logo + 连续打卡天数  │
├─────────────────────────┤
│                         │
│   内容区（5个Tab切换）     │
│   ┌─ 每日挑战 ─┐         │
│   │  300词卡   │         │
│   │  场景对话   │         │
│   │  发音跟读   │         │
│   │  关于/引流  │         │
│   └───────────┘         │
│                         │
├─────────────────────────┤
│  底部Tab导航栏（5个图标）  │
└─────────────────────────┘
```

### 视觉风格
- 深色主题（与作品集网站.html一致）
- 主色调：暖橙色/琥珀色（苏不倦品牌感，温暖不冰冷）
- 字体：系统无衬线，大字号优先
- 圆角卡片设计，手机端友好
- 动效：简洁的淡入/滑动，不做花哨动画

### 数据预置（硬编码在JS中）
- 30个每日挑战场景 × 3-5句 = ~120句
- 300核心词卡（词+音标+释义+例句）
- 10个场景对话（每个5-8轮）
- 20个发音跟读音频句子
- 四阶段路线图内容

## 四、MVP边界（不做什么）

| 不做 | 原因 | 后续版本考虑 |
|:--|:--|:--|
| 用户注册/登录 | 0后端，localStorage够用 | V2加微信授权登录 |
| AI发音评分 | 技术复杂，MVP靠自听对比 | V2接入语音识别API |
| 社交/排行榜 | 需要后端，且非核心 | V3考虑 |
| 付费/会员 | MVP是引流品，不收费 | 验证后加课程入口 |
| 海量词库 | 300词是理念，不是限制 | V2按等级扩展 |
| 离线PWA | 增加复杂度 | V2加Service Worker |
| 多语言界面 | 目标用户是中国人 | 不需要 |

## 六、开发步骤

1. **内容准备**：从四阶段课程提炼场景句、300词表、对话脚本（本规划已定义范围）
2. **UI设计**：确定配色、布局、组件样式（doubao-app-builder生成）
3. **核心功能开发**：每日挑战+TTS发音+录音回放（最核心）
4. **扩展模块**：词卡+场景对话+发音跟读
5. **进度系统**：打卡日历+localStorage存储+成就
6. **引流页面**：关于+四阶段路线图+微信二维码
7. **测试优化**：多浏览器测试+手机端适配+性能优化
8. **交付**：HTML文件+使用说明+PRD文档
