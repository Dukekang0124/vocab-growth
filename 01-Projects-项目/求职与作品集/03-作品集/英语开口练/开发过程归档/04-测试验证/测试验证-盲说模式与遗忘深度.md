## 一、G1 盲说遮罩（生产模式核心）

```
初始英文可见        : 是
初始有「我想试试」  : 是
点「我想试试」后遮住: 是 ✓   （英文变 ■■■）
遮罩时播放被禁用    : 是 ✓   （pointer-events:none）
```

遮罩生效且播放禁用，确保用户无法「偷看/偷听」答案，必须先自己产出。

## 二、G2 分层抢救（一次只给一层）

```
点 1 次提示 → 第 1 层：这是一个问句，一共 4 个词。
点 2 次提示 → 第 2 层：意思就是：你好！你好吗？
点 3 次提示 → 第 3 层：第一个词是 Hello
```

提示逐层累积显示，且全部由句子**自动计算生成**（词性/词义/首字母/词长/半句/全句），无需额外内容维护。

## 五、修复过程中发现并解决的问题

| 问题 | 处理 |
|---|---|
| 替换 state 字段留下残留 `};` | 删除残留行，grep 确认结构唯一 |
