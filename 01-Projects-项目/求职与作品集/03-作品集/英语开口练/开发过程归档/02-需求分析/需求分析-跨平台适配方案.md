### 降级策略（必须实现）

| 检测项 | 缺失时的行为 |
|---|---|
| `navigator.mediaDevices.getUserMedia` 不可用 | 隐藏"录音跟读"按钮，改为"听音跟读"（播放标准音 → 用户自评），并提示"当前环境不支持录音" |
| `MediaRecorder` 不可用 | 同上 |
| `SpeechRecognition` 不可用 | 打分改为**手动自评**（准确度 / 流利度两个滑杆或星级），并注明"自评模式" |
| 处于微信 / 抖音 / 小红书内嵌环境 | 顶部显示轻量引导条："在浏览器打开可获得完整录音打分体验"，提供【复制链接】按钮 |

**核心原则**：任何环境下页面都能打开、能听、能学、能记录进度 —— 录音打分是增强项，不是阻断项。

## 二、用户规模指标（分档）

> ⚠️ **需康哥确认目标档位**。以下按"抖音/小红书内容引流 → 点击链接打开"的漏斗估算。

| 指标 | L1 起步期 | L2 成长期（设计基准） | L3 爆发期 |
|---|---|---|---|
| 日活跃用户（DAU） | 100 – 500 | **1,000 – 5,000** | 10,000 – 50,000 |
| 日打开次数（PV） | 300 – 1,500 | **3,000 – 15,000** | 30,000 – 150,000 |
| 峰值并发在线 | 10 – 30 | **100 – 500** | 1,000 – 3,000 |
| 峰值 QPS（按 5 分钟峰值均摊） | 1 – 3 | **10 – 50** | 100 – 300 |
| 日流量（按优化后 200KB/次） | 60 – 300 MB | **0.6 – 3 GB** | 6 – 30 GB |

**漏斗假设**：单条视频/笔记曝光 1–10 万 → 链接点击率 1–3% → 打开后留存 30%。若康哥当前粉丝量级与此不符，请告知实际数字，我按实际值重算。

**承载评估**：当前为 Cloudflare Pages 静态托管（全球 CDN、免费版无硬性并发上限、带宽公平使用）。
- L1 / L2 档：**当前架构完全够用，零成本**。
- L3 档：静态资源仍可承载，但需关注（a）`*.pages.dev` 域名在国内的访问稳定性；（b）Cloudflare 免费版无 SLA。

## 三、性能与稳定性要求

### 3.1 加载速度（按 L2 档，移动端 4G）

| 指标 | 当前实测/估算 | 目标值 | 说明 |
|---|---|---|---|
| 首屏传输体积 | ~670 KB | **≤ 200 KB** | 图片外置/懒加载、字体异步后可达 |
| 首字节时间 TTFB | 200 – 800 ms（国内访问 pages.dev 波动大） | ≤ 500 ms | 依赖 CDN 节点，必要时换自定义域名 |
| FCP（首次内容绘制） | 2 – 4 s（估） | **≤ 1.5 s** | WiFi / 良好 4G |
| TTI（可交互时间） | 3 – 6 s（估） | **≤ 2.5 s** | WiFi / 良好 4G |
| 弱网（Fast 3G）TTI | 8 s+ | **≤ 5 s** | 保证弱网不劝退 |
| Lighthouse 移动端性能分 | 待实测（估 50–65） | **≥ 85** | Chrome DevTools 实测 |

### 3.2 并发承载（按 L2 档峰值 500 并发 / 50 QPS）

| 指标 | 目标值 |
|---|---|
| 500 并发下请求成功率 | ≥ 99.9% |
| 500 并发下 P95 响应时间 | ≤ 1 s（静态资源，CDN 边缘命中） |
| 错误率（5xx） | ≤ 0.1% |
| 服务可用性（月度） | ≥ 99.9%（Cloudflare 免费版无 SLA，实际通常更高） |
| 压测方式 | 用 `k6` 或 `wrk` 对 pages.dev 发起 500 并发持续 5 分钟 |

### 3.3 稳定性与容错

| 项 | 要求 |
|---|---|
| 能力探测失败 | 必须降级而非白屏/报错；任何 API 缺失都不阻断页面渲染 |
| 音频加载失败 | 逐音源回退，全失败后给明确环境提示（已实现，需覆盖全平台文案） |
| 弱网/断网 | 已加载页面可离线使用核心浏览功能（后续可加 Service Worker） |
| 数据丢失 | `localStorage` 学习进度不因刷新/关闭丢失（已实现，需验证微信内不被清理） |

## 四、改造清单（按优先级）

| 优先级 | 任务 | 预期收益 |
|---|---|---|
| **P0** | 能力探测 + 降级模式（录音不可用时切"听音跟读 + 手动自评"） | 解决 iOS 微信 / 抖音 / 小红书核心功能失效 |
| **P0** | 首屏瘦身：470KB base64 图片外置为独立文件并懒加载 | 首屏 670KB → ≤200KB |
| **P0** | 字体改造：移除 `miaoda.feishu.cn` 外部依赖，改系统字体栈或内联子集 | 消除阻塞渲染的外部请求 |
| **P1** | 平台引导：微信/抖音/小红书内显示"在浏览器打开"引导条 + 复制链接 | 把受限用户导到完整体验 |
| **P1** | 真机实测：微信( iOS+Android)、抖音、小红书、PC 三浏览器 | 验证降级策略与录音实测能力 |
| **P2** | 加 `manifest.json` + `apple-mobile-web-app` 支持添加到主屏幕 | 提升回访率 |
| **P2** | 评估自定义域名（已备案）替换 `*.pages.dev` | 改善国内访问速度与稳定性 |
| **P3** | Service Worker 离线缓存 | 弱网/二次访问秒开 |
