# 部署指南 · 英语开口练

> 适用于Cloudflare Pages + GitHub自动部署方案

## 一、架构说明

```
本地修改 index.html → 推送到GitHub → Cloudflare Pages自动构建 → 全球CDN分发
```

- **代码仓库**：https://github.com/Dukekang0124/english-speaking-app
- **线上地址**：https://english-speaking-app-e37.pages.dev
- **部署方式**：Git连接，main分支推送即部署
- **构建配置**：无构建步骤，纯静态文件，输出目录 `/`

## 二、首次部署流程（已完成，供参考）

### 2.1 准备GitHub仓库
1. 在GitHub创建Public仓库 `english-speaking-app`
2. 上传 `index.html` 到仓库根目录

### 2.2 注册Cloudflare
1. 访问 https://dash.cloudflare.com/ 注册
2. 完成个人认证（邮箱验证即可，无需实名认证）

### 2.3 连接GitHub
1. Cloudflare控制台 → Workers & Pages → Create → Pages → Connect to Git
2. 选择GitHub，安装"Cloudflare Pages"GitHub App
3. Repository access选择"Only select repositories"→ 选择 `english-speaking-app`
4. 如果仓库列表不刷新，手动刷新页面

### 2.4 构建设置
| 配置项 | 值 |
|--------|-----|
| Project name | english-speaking-app |
| Production branch | main |
| Framework preset | None |
| Build command | （留空） |
| Build output directory | / |
| Root directory | （留空） |

### 2.5 部署
点击"Save and Deploy"，等待1-2分钟构建完成。

## 三、日常更新流程

### 方法A：通过浏览器上传（推荐，无需Git环境）

1. 打开 https://github.com/Dukekang0124/english-speaking-app/upload/main
2. 拖拽修改后的 `index.html` 到上传区
3. 填写Commit message（如"v1.1 修复xxx"）
4. 点击"Commit changes"
5. 等待1-2分钟，Cloudflare自动部署完成
6. 访问线上地址验证（加 `?v=版本号` 绕过缓存）

### 方法B：通过Git命令行（需科学上网或配置代理）

```powershell
# 进入GitHub仓库本地目录
cd "D:\写作工具\知识管理\01-Projects-项目\求职与作品集\03-作品集\英语开口练\english-speaking-app-github"

# 复制最新代码
Copy-Item "..\english-speaking-app\index.html" "index.html" -Force

# 提交并推送
git add .
git commit -m "v1.1 变更描述"
git push origin main
```

**注意**：Git连接GitHub可能需要配置代理或科学上网。如遇连接问题，使用方法A。

### 方法C：Cloudflare Pages直传（不推荐）
- 拖拽上传文件夹有中文路径bug，可能导致空文件名
- 仅在GitHub不可用时作为备选

## 四、部署验证清单

每次部署后必须验证：

- [ ] 线上地址可访问（加 `?v=时间戳` 绕过缓存）
- [ ] 首页每日挑战正常加载
- [ ] 点击"播放"有发音（有道TTS）
- [ ] 点击"慢速"播放变慢
- [ ] 词卡/对话/跟读Tab可切换
- [ ] 进度页显示内测反馈卡片
- [ ] 微信内打开测试（发链接到微信文件传输助手）

## 五、Cloudflare Workers部署（卡密验证，预留）

内测期不需要。正式付费时部署：

```powershell
cd "cloudflare-workers"
npm install -g wrangler
wrangler login
wrangler deploy
```

详见 `cloudflare-workers/DEPLOY.md`。

部署后在 `index.html` 中设置：
```javascript
const API_BASE = 'https://your-worker.your-subdomain.workers.dev';
```

## 六、自定义域名（可选）

如需绑定自有域名（如 `speak.yourdomain.com`）：
1. Cloudflare Pages项目 → Custom domains → Set up a custom domain
2. 按提示添加DNS记录
3. 等待SSL证书签发（自动）
4. 国内使用建议备案域名+国内CDN
