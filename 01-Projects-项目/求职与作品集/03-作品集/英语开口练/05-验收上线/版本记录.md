### 可行性评估结论（先有结论再有动作）
- **技术可行（FEASIBLE）**：单文件 HTML、零外部 JS 依赖、状态全在 `localStorage` → 可零业务改写打进 APK。
- **三个必须正视的限制**：① Android 系统 WebView 禁用 Web Speech TTS（主音源有道/Baidu CDN `<audio>` 照常出声，离线兜底失效）；② 应用**当前零推送功能**（"保留推送"无从谈起，要做属新增且需后端）；③ 原本无 service worker / 无离线缓存。
- **功能存活判定**：打包后**保留现有全部功能**（日常句/盲说/打卡/评分/音标/对话/录音），唯一"损失"是 Capacitor 壳下 Web Speech 离线兜底（影响极小）。

### 分发方案（康哥拍板 A+D）
- **A 自签名 APK 官网直下**为主实体交付：零审核、随时发版、微信里可分享安装页链接。
- **D PWA 添加到主屏幕**为轻量入口：安卓 Chrome 一键安装，连包都不用下；更新随站点自动生效。
- B（国内商店 TWA）/ C（Google Play，国内无 GMS 不可达）留作第二阶段；**推送本期不做**。

### 本次落地（web 侧，commit `ad9cd76`）
- **PWA 清单**：`manifest.webmanifest`（standalone/深底主题色/三图标），head 加 `link rel=manifest` + `mobile-web-app-capable`
- **离线壳**：`sw.js` 同源 network-first 缓存（在线即最新、离线可开），外源 TTS CDN 不缓存；init 的 `DOMContentLoaded` 安全路径内注册，失败不影响主流程
- **图标**：`icon-192.png` / `icon-512.png`（沙箱无 PIL，用 Python `struct`+`zlib` 标准库手写 PNG 编码器生成，零依赖）
- **版本更新机制**：`APP_VERSION='1.4.1'` + `version.json`，启动比对不符弹「有新版本」横幅跳落地页
- **下载落地页**：`download.html`（PWA 安装指引 + APK 直链占位 + 微信"在浏览器打开"提示 + 盲说离线卖点）
- **缓存策略**：`_headers` 给 `sw.js`/`version.json` 加 `no-cache`，避免更新滞后

### APK 出包脚手架（留档，需康哥本机执行）
- `APK打包指南.md`：前置环境 → cap init/add android → sync-web → 权限声明 → keytool 签名 → `cap build --release` → 分发 → 更新机制 → TWA/商店第二阶段
- `capacitor.config.json`（appId `com.kaikou.english`）、`android-build/sync-web.ps1`（同步最新网页进原生壳并去 PWA manifest 链接）、`android-build/assetlinks.json`（TWA 校验模板）
- **keystore 必须离线备份**：丢失 = 无法以同一身份发更新

### 验证
- `index.html` 内联脚本 `node --check` → SYNTAX_OK；图标 PNG 192/512 尺寸合法；manifest/version.json JSON 合法；sw.js 含 install/fetch 监听
- **补丁实测**：在 `78d9080` 上 `git apply` → `index.html` MD5 与目标逐字节一致（MATCH_OK），7 个新增文件齐全；工作树已还原干净

### 已知限制

## v1.3-beta（2026-08-29）— 对标词汇生长·生产模式改造

> commit `bbcb195`，由豆包 agent 推送（九思沙箱无 GitHub 写权限，走打包交接）。线上已验证生效。

### 核心改造（对标 OB「词汇生长」三环教学法）
- **G1 盲说遮罩（生产模式）**：每日句点「我想试试」→ 英文变 `■■■` 遮罩 + 该句播放/慢速按钮禁用，用户看中文先自己产出英文，再揭示对照。
  - **最大价值：不依赖录音/语音识别，微信等降级环境也能完整使用**（唯一在所有端跑通的核心练习）
- **G2 分层抢救七层提示**：连点「再给一层提示」逐层累积——①问句·词数 → ②句意 → ③首词 → ④各词长度 → ⑤前半句 → ⑥完整句。**全部由句子自动计算生成，无需人工维护内容**
- **G3 遗忘深度 + 复习队列**：`sentenceStats[key]={last,rescue,depth,due,times,greenStreak}`；`rescue`=用到第几层才想起（0=自己想起/6=直接看答案）；深度分档绿0-1层隔天/黄2-3层当天/红4+层当天；复习区 `.filter(d=>d.sceneIdx!==currentIdx)` 排除当日场景、红色优先排序

### 副标题更新
「遮住英文先自己说，卡住再要提示 —— 不用录音也能练」

### 同期已上线的阶段一止血（commit `f09dbcf`）一并包含
- 听读打卡解耦：听完 4 句也能打卡（微信无录音环境不再永久卡 0）
- 打分词序敏感：倒着念/只念首尾明显降分，漏词红色标注，逐词纠错
- 无评分环境：自动探测录音+识别能力，降级时给 1-5 星自评兜底

- G1/G2/G3 三项功能真机命中 ✅
