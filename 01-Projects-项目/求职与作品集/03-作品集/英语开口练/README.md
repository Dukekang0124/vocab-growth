# 英语开口练 · 项目总览

> 300词就能开口的成人英语自学Web App，面向31-40岁零基础人群，每日3-5句场景化开口练习。

## 项目定位

- **产品名**：英语开口练
- **Slogan**：300词就能开口
- **目标用户**：31-40岁英语零基础/久未接触的成人
- **核心价值**：每天一个场景，3-5句话，开口就赢了
- **项目性质**：求职作品集 + 可商业化产品
- **开发者**：苏不倦（闵苏康）

## 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端 | 纯HTML/CSS/JS单文件 | 无框架、无构建、零依赖 |
| TTS发音 | 有道TTS（dict.youdao.com） | 微信内置浏览器可用，免费 |
| 录音 | MediaRecorder API | 浏览器原生，微信需每次授权 |
| 语音识别 | webkitSpeechRecognition | 降级评分，微信不支持 |
| 数据存储 | localStorage | 纯本地，无需后端 |
| 部署 | Cloudflare Pages + GitHub | 免费、自动部署、全球CDN |
| 后端（预留） | Cloudflare Workers | 卡密验证，内测期未启用 |

## 开发规范（所有开发任务必须遵循）

### 1. 先查后做

开工前必须检查：
- OB目录中已有的历史资料、代码、文档
- 当前线上版本的状态
- 相关的评估文档和决策记录

### 2. 五阶段流程

每个功能/迭代必须按以下阶段推进，每阶段产出归档到对应文件夹：

| 阶段 | 文件夹 | 必产出 |
|------|--------|--------|
| 需求调研 | `01-需求调研/` | 需求来源、用户痛点、参考资料 |
| 需求分析 | `02-需求分析/` | PRD或功能说明、优先级、验收标准 |
| 设计开发 | `03-设计开发/` | 技术方案、代码变更、关键问题记录 |
| 测试验证 | `04-测试验证/` | 测试用例、兼容性记录、Bug清单 |
| 验收上线 | `05-验收上线/` | 上线检查、部署记录、版本号 |

### 3. 代码规范

- **单文件原则**：前端保持 `index.html` 单文件，不引入构建工具和npm依赖
- **中文注释**：关键函数和复杂逻辑必须有中文注释
- **数据与逻辑分离**：内容数据（WORDS、DAILY_SCENES等）集中管理
- **降级兼容**：所有浏览器API必须有降级方案（TTS→有道TTS→Web Speech→提示；录音→MediaRecorder→提示）
- **移动端优先**：所有UI以375px宽度为基准设计，touch-friendly
- **微信兼容**：核心功能必须在微信内置浏览器（X5内核）中可用

### 4. 部署规范

- 代码修改在 `english-speaking-app/index.html` 中进行
- 测试通过后复制到 `english-speaking-app-github/index.html`
- 通过GitHub提交触发Cloudflare Pages自动部署
- 提交信息格式：`[版本] 变更描述`（如 `v1.1 修复TTS+内测免费版`）
- 部署后必须验证线上版本

### 5. 版本管理

- 版本号：v主版本.次版本（如v1.0, v1.1）
- 每次上线在 `05-验收上线/版本记录.md` 中记录
- 重大修改前备份 `index.html.bak-YYYY-MM-DD`

### 6. 关键技术约束（踩坑沉淀）

| 约束 | 原因 | 解决方案 |
|------|------|----------|
| 微信不支持Web Speech API | X5内核限制 | 多源TTS降级：有道美音→有道英音→百度TTS→Web Speech |
| 微信录音每次需授权 | 微信安全策略 | 无法绕过，UI上引导用户 |
| 微信不支持SpeechRecognition | X5内核限制 | 录音仍可用，评分功能降级为自行对照 |
| 个人主体无法接入微信支付JSAPI | 需要营业执照 | 内测期免费；正式期用第三方平台（面包多等） |
| 微信内长按无法识别收款码 | 微信安全限制 | 内测期免费；正式期用外部支付平台 |
| GitHub Pages国内不稳定 | DNS污染/CDN节点 | 用Cloudflare Pages替代 |
| Cloudflare Pages直传有bug | 空文件名问题 | 通过GitHub仓库连接部署 |
| 纯静态站无后端 | 单文件架构 | 用Cloudflare Workers做轻后端（卡密验证） |
