# 别等"学会了"再动手——先做起来，AI会教你

> 九思 | 2026-08-08 | 第五篇文章
> 写给：总觉得"还没准备好"而一直没开始的人

---

你有没有这种感觉：

**收藏了几百个教程，报了课，关注了几十个博主——但真要你动手做点什么，你心里那个声音就冒出来：**

"再等等，我还没学会。"

我太懂这个声音了。因为我以前也是这样。

直到有一天我想明白一件事：**你永远等不到"学会"的那天。**

不是吓你，是事实——因为AI时代，**东西永远在变**。你今天学的，下个月可能就过时了。你要是抱着"先学会再用"，那你永远在"学"，永远用不上。

## 我发现的真相：先做，比先学有用得多

以前我学东西是这么干的：

报课 → 做笔记 → 收藏 → 想着"学完再用" → **然后没有然后了**。

现在我是这么干的：

遇到一个事 → 直接上手做 → 卡住了 → 问AI/查资料 → 解决 → **这个技能，我会了**。

**区别在哪？**

![先学后做 vs 先做后学](02-已发布/封面图/005-compare.png)

| 先学后做 | 先做后学 |
|:--|:--|
| 学一堆"可能有用"的 | 学"正在用到"的 |
| 记不住（没场景）| 忘不掉（用了就记住了）|
| 一直"准备中" | 一直在"前进" |
| 越学越焦虑 | 越做越有底 |

**不是夸张——用"先做后学"，你学一个东西的速度，是"先学后做"的几倍。** 因为你学的每一个点，都是你正在遇到的问题，你非记住不可。

## AI时代，这件事更容易了

以前"先做后学"有门槛：你卡住了，得翻书、问人、百度——**有时候卡一下午，人就没耐心了**。

现在不一样：

你卡住了 → 打开AI → 问它"这个怎么弄" → 它一步步教你 → **你马上接着做**。

**AI就是你的"随叫随到老师"，而且是那种不嫌你笨、问一百遍也不烦的。** 所以你完全不用担心"不会"，因为**你不会的，当场就能问**。

## 3个动作，今天就能开始

![3个动作](02-已发布/封面图/005-steps.png)

### 1. 挑一件"破事"干
不是大事，是那种你一直拖着的小事：写个简历、做个PPT、拍条视频、整理手机照片。

**越破越好——因为它不需要"准备好"才能干。**

### 2. 卡住就问AI
别自己憋着。卡住的那一秒，打开AI，问它。

问的时候说清楚：**"我在做XX，遇到XX问题，帮我解决"**——它基本都能给你答案。

### 3. 干完，记录一下
不用写长文，一句话：**"今天我干了XX，学会了XX。"**

就这一句——攒一个月回头看，你会吓一跳：**原来我做了这么多**。

## 最后一句

**别等准备好了再出发——你永远准备不好，但你可以现在就出发。**

而且，你不需要"确定能成功"，你只需要确定：**今天做的这件事，对未来的我有价值。**

这个价值，AI时代会被放大——因为你先做，AI就教你；你越做，你越快。

**你今天想干的那件"破事"，是什么？评论区说出来，逼自己一把。**
