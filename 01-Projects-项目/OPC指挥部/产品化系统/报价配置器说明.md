# 报价配置器（可交互HTML案例）

> 2026-08-05 ⑥号打造 → 移交④号产品化系统。
> 能力来源：interactive-html-data Skill（数据→可交互HTML：报价器/沙盘/看板）。

## 这是什么

**课程报价配置器**——学员拖动参数（人数/时长/陪练次数）→ 实时生成定制报价。
比静态价格表专业，让"报价"变成可交互体验。

## 当前功能

| 参数 | 逻辑 |
|:--|:--|
| 学习人数（1-10）| 单价阶梯：1-2人¥97 / 3-4人¥89 / 5人+¥79 |
| 学习时长（1-12月）| 总价=单价×人数×时长；≥6个月 9折 |
| 陪练次数（0-7次/周）| 展示（暂未计入价格，可扩展）|

三套餐：入门版¥9.9 / 进阶版¥97（推荐）/ 私教版¥297

## 怎么用

1. 浏览器直接打开 `报价配置器.html`（零依赖）
2. 发给学员/客户演示（拖动参数实时报价）
3. 或导出PNG当配图
