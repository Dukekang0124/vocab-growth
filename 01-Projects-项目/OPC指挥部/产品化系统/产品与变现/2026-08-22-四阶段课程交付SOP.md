## 二、每级交付卡

### L1 · 免费层交付卡（可执行版）

**目的**：不是"发资料"，是"筛选 + 加微信 + 埋钩子"。

| 要素 | 标准动作 |
|------|---------|
| **交付物** | 引流品（避坑指南/每日最低执行/听力材料排期/共鸣开头）→ 完整四阶段路线图 PDF（01-04） |
| **交付动作** | ① 视频/简介引导"评论区扣1"或"进粉丝群" → ② 群公告放引流品 → ③ 群内引导"加微信领完整版路线图" → ④ 加微后 5 分钟内发 PDF + 一句破冰 |
| **验收标准** | ✅ 用户收到 PDF 并回复"收到" ✅ 用户加到了微信（从"群友"变"好友"） ✅ 识别出用户水平（从哪阶段开始） |
| **下一步引导** | 按用户水平分层：零基础 → 推 ¥9.9 音标计划；已入门 → 预告 97 思维课（先不急推） |
| **话术模板** | 「完整版路线图发你啦。你目前是零基础吗？如果是，建议先从音标开始——我整理了个 14 天计划，帮你把音标真正学完，9 块 9 奶茶钱，学完不满意随时退。」 |

### L2 · ¥9.9 交付卡（可执行版）

**目的**：验证付费 + 建立"付过费"用户池（后续升单池）。

| 要素 | 标准动作 |
|------|---------|
| **交付物** | 14天赖世雄音标学习计划 PDF（v1.1） |
| **交付动作** | ① 确认收款（微信直收，拒收口令「音标」触发） → ② 收款后 5 分钟内发 PDF → ③ 确认收到 + 一句使用提醒（"Day1 是热身，先录音对比字母"） → ④ 记入收入追踪 |
| **验收标准** | ✅ 收款到账 ✅ 用户确认收到 ✅ 当日记入收入追踪 ✅ 买家标签（音标计划/日期/来源渠道） |
| **下一步引导** | 学完 14 天后跟进一次（"音标练得怎么样？"）→ 有需求的引 97 思维课预告；不硬推 |
| **话术模板** | 「收到，计划发你啦！Day 1 是字母热身，记得先录音对比，14 天后再听会吓一跳。有任何问题微信找我——我不是客服，我是走过这条路的人。」 |

### L3 · ¥97 交付卡（待启用版）

**触发条件**（对齐发布路线图，不跳级）：¥9.9 稳定月销 ≥10 份 → 才开发 ¥97 内容 → 预售验证 → 首发。

| 要素 | 标准动作（预设） |
|------|---------|
| **交付物** | 初级英语思维课（视频/讲义 + 作业 + 答疑） |
| **交付动作** | 预售收款 → 开班建群 → 按课表交付 → 每周答疑 → 结营 |
| **验收标准** | 学员完课率、作业提交率、结营反馈 |
| **下一步引导** | 结营后推 ¥297 体系课（用"原价¥597"锚定） |

### L4 · ¥297 交付卡（待启用版）

| 要素 | 标准动作（预设） |

## 三、售后与红线

| 场景 | 标准动作 |
|------|---------|
| **退款** | ¥9.9 无条件退（"不满意随时退"是销售话术的一部分，必须兑现）；退完记入收入追踪 |
| **盗版/转发** | 产品文档内已有温和提醒（"别直接发 PDF，喜欢请支持正版"）；不追责不纠缠 |
| **用户问问题** | 当天回复；答不上来记入"买家反馈池"（下一版迭代素材） |
| **白嫖党** | 免费层正常服务；付费层不催不追，保持体面 |
| **红线** | ① 不承诺效果（"学完就会英语"绝对不说）② 不贬低竞品教材（赖世雄是好书，我们卖的是"带你学完"）③ 不跳级推产品（没买 9.9 不硬推 97） |
