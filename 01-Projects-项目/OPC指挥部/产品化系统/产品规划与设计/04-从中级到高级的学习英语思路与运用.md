# 从中级到高级：苏不倦的英语学习路线图 · 第四阶段

> 你已经能说英语了。现在，让英语成为你的一部分。
> 这个阶段，英语不再是"学习对象"，而是"生活工具"。
> 我是苏不倦。我会告诉你，怎么从"能说英语"变成"用英语生活、工作、创作"。

---

## 写在前面：恭喜，你已经赢了

如果你真的走到了这个阶段——能跟老外持续聊天、能听懂常速英语、能读一般文章——我想先说一句：你已经超过了中国 95% 的英语学习者。

但接下来，没人能教你了。

为什么？因为到了这个水平，你要学的不再是"英语"，而是"用英语去学你想学的任何东西"。英文对你来说，应该像中文一样——是获取信息的工具，不是一门课。

这个阶段的核心转变：**从"学英语"变成"用英语"。**

### ⏱️ 预计时间

**12-24 周以上。** 到了这个阶段，"时间"不再是一个有意义的衡量标准。你不是在"学"英语，你是在"用"英语生活。有些人用了半年，有些人用了一辈子。关键是——**你不再觉得这是"学习"，它就是你生活的一部分。**

### 📖 怎么用这本指南

这不再是"按步骤执行"的指南，而是一份**参考地图**：
1. **先读三个核心转变**——它们比任何具体方法都重要
2. **从"输入方案"中挑 1-2 个你真正感兴趣的开始**——选你喜欢的，别选"应该学的"
3. **从"输出方案"中挑 1 个立刻开始做**——哪怕今天只发一条英文朋友圈
4. **维持系统是底线**——再忙也保住每天的 15 分钟

## 第四阶段：从中级到高级（能对话 → 能自由表达）

### 你现在在哪？

- 词汇量 2500-3500，日常沟通无障碍
- 能听懂常速对话和播客
- 能深度对话 10+ 回合
- 基本摆脱了"翻译思维"

### 这个阶段结束的时候，你能做到什么？

| 能力 | 目标 |
|------|------|
| 听力 | 能无字幕看美剧、电影、新闻、讲座 |
| 口语 | 能即兴表达复杂观点，参与辩论和演讲 |
| 阅读 | 能读原版书、专业文献、深度长文 |
| 写作 | 能写有结构的文章、工作报告、长内容 |
| 词汇量 | 从 3500 涨到 5000-8000 |

## 核心转变一：扔掉"学习材料"

到了这个阶段，你不需要任何"为英语学习者准备"的东西了。

不需要 English Pod。不需要"每日英语听力"上的分级内容。不需要"适合 B2 学习者的播客"。

**真实世界的内容，就是你的教材。**

选材标准来了个 180 度大转弯：

| 之前 | 现在 |
|------|------|
| "这个适合我的级别吗？" | "我对这个话题感兴趣吗？" |
| 挑"学习材料" | 挑"想看的内容" |
| 为了学英语而看 | 为了获取信息/娱乐而看，英语只是顺便 |

想了解 AI？直接看英语的 AI 视频和文章。喜欢心理学？找英语的心理学播客。对创业感兴趣？看英语的商业访谈。

**当你不再觉得"我在学英语"，而只是"我在看我想看的东西"——你就真的突破了。**

---

## 核心转变二：用输出来倒逼输入

这个阶段最有效的方法，我自己的亲身经历证明——**不是学到能创作，而是通过创作来学。**

什么意思？

你想做一个英语短视频？那你得写脚本。写脚本的时候你会发现——这个词我不会说，那个表达我不确定。然后你去查、去学、去问。**因为有明确的目的，你学的东西永远不会忘。**

这就是"输出倒逼输入"：

```
你想拍英语视频 → 你得写脚本 → 发现表达不够 → 精准输入 → 学了马上用 → 再也忘不掉
```

### 你可以做的输出型练习

| 方式 | 怎么开始 |
|------|------|
| **英语短视频** | 用手机录一段 1-2 分钟的英语视频，分享你的观点。不需要专业设备，手机就行 |
| **英文日记/博客** | 每周写一篇英文文章，分享你的思考。写完让 AI 帮你改语法 |
| **英语社交媒体** | 在 HelloTalk 的 Moments、小红书英语社区、B站专栏发英文内容，用英语跟人互动 |
| **用英语做工作** | 主动申请工作中能用英语的任务——写英文邮件、看英文文档、跟外国同事开会 |

我拍英语短视频这件事，逼着我写了几百篇英语脚本。每一篇都在倒逼我提升词汇量、句式、表达逻辑。一年下来，我的口语进步比之前三年都大。

## 核心转变三：建立"维持系统"

在中国学英语，最大的敌人不是学不会，是**学完就忘。**

你不可能一辈子每天都花两小时学英语。你有工作、有生活、有其他事情要做。所以到了这个阶段，你需要一个"维持系统"——用最少的精力，保持英语不退步。

| 维度 | 最低维持量 | 怎么做 |
|------|------|------|
| 听力 | 每天 15 分钟 | 通勤/做家务/运动的时候听感兴趣的英语播客 |
| 口语 | 每天说几句 | 自言自语、HelloTalk 聊天、录英语视频都行，关键是**每天都用嘴说英语** |
| 阅读 | 每周 1-2 篇 | 看英文新闻（BBC/CGTN）、英语公众号文章、知乎英语专栏，找你本来就关心的话题 |

维持的秘诀不是"每天学很久"，而是"每天都接触一点"。就像健身——你不可能每天练三小时，但每天做 20 个俯卧撑，肌肉就不会退化。

哪怕你今天忙到飞起，就听了 5 分钟播客、用英语自言自语了 3 句话——你也赢了。因为你没有中断。

## 输入方案：真实材料

### 听力

| 资源 | 说明 |
|------|------|
| **老爸老妈浪漫史（How I Met Your Mother）** | 美式日常口语，语速正常，幽默好笑。适合这个阶段练耳朵 |
| **你感兴趣的任何英语播客** | 科技、商业、心理学、真实犯罪、喜剧……找你真的想听的 |
| **B站英语博主/英语区** | 搜"英语vlog""英语博主""English with"——不为了学英语，就为了看内容，国内直接用 |
| **TED 演讲** | 当你想听点有深度的东西，顺便练英语 |
| **美剧/电影（无字幕）** | 这是终极挑战。先开英文字幕，再慢慢去掉 |

**精听 vs 泛听的比例可以反过来：**

```
初级→中级阶段：精听 70% + 泛听 30%
中级→高级阶段：精听 30% + 泛听 70%
```

到了这个水平，大部分输入应该是"享受型"的——你听/看是因为你想，不是因为"我在学英语"。

### 我的建议：从一本书开始

如果你到了这个阶段，不知道从哪入手——我的建议是：**找一本你真正想读的英语原版书。**

不要找"适合英语学习者的"，不要找"经典名著"（那些语言太老了）。找一本你本来就想看中文版的非虚构书——商业、心理、科技、自我提升都行。比如 Atomic Habits、The Psychology of Money、Show Your Work。

每天读 10 页。不查字典——猜。读完一章再回头看生词。

**读完第一本原版书的成就感，比我通过任何英语考试都大。** 它证明了一件事：英语不再是你的障碍，而是你的工具。

### 我怎么知道自己还在进步？

B1→B2 的进步是最难感知的。你不会有"哇我今天突然听懂了"的那种顿悟。但你回头看会发现：

- 三个月前你还需要字幕的地方，现在不需要了
- 半年前你查过的单词，现在已经会用了
- 去年你不敢开口的话题，现在能聊了

**建议做法：每 4 周录一段自己的英语视频。** 不用发出去，就自己看。一个月一个月对比，你会发现进步比你想象的大得多。这也是我自己一直在做的事情。

### 阅读资源

| 资源 | 说明 |
|------|------|
| **原版非虚构书** | 挑你感兴趣的领域：商业、心理、科技、自我提升。第一本原版书是最难的，读完第一本，后面就顺了 |
| **英语新闻** | BBC、The Guardian、AP News。每天刷 5 分钟就行 |
| **深度英文文章** | BBC Future、The Conversation（国内可直接访问），B站专栏也有不少英语长文 |
| **你工作/专业领域的英文资料** | AI 论文、行业报告、英文产品文档——既提升英语，又提升专业能力 |

## 避坑：高手也会犯的错

| ❌ 别这样做 | ✅ 应该这样做 |
|------|------|
| 还在找"学习材料"，不敢碰真实内容 | 真实世界就是你的教材。关掉"每日英语听力"，打开 B站英语区和播客 |
| 只看只听不输出 | 输出倒逼输入。写、说、拍视频——选一个开始 |
| 追求"完美发音"或"零口音" | 清晰 > 完美。你的思想比你那一点点口音重要一万倍 |
| 断了一天就觉得"完了，我放弃了" | 断一天没关系，别断一周。维持系统就是给你兜底的 |
| 还在用"学英语"的心态 | 英语是工具，不是学科。你在用英语生活，不是在学英语 |

## 什么时候算"毕业"？

这不是考试，但你可以用下面几条来检验自己：

- [ ] 能无字幕看美剧/电影，理解 80% 以上
- [ ] 能即兴用英语表达一个复杂观点，不需要提前准备
- [ ] 能用英语做一次工作汇报或公开分享
- [ ] 能读懂自己专业领域的英语文献
- [ ] 英语不再让你感到紧张——它就是你的另一个表达方式
- [ ] 你开始用英语帮助别人了（拍视频、写文章、教朋友）

到了这里，英语已经不是一门外语了。**它是你的第二语言。**

**英语不是目的。英语是你通往更大世界的那扇门。**

你想认识更多有趣的人？用英语。
你想获取第一手的信息和知识？用英语。
你想让自己的职业生涯多一条路？用英语。

英语只是一把钥匙。真正重要的，是钥匙打开的门后面，那些你还没见过的风景。

别把英语当成一座山来爬。把它当成一双鞋——穿上它，去你想去的任何地方。

**往前走，别回头。**
