# 英语学习网站 vs APP 成本分析（⑪号窗口产出）

> 来源：2026-08-09 ⑪号窗口对话分析，供④号产品化窗口参考
> 背景：苏不倦英语学习产品化决策——做网站还是APP？
> 结论：**网站成本远低于APP，应网站起步验证，再决定要不要APP**

## 全维度成本对比（国内，2026）

| 维度 | 网站（Web） | APP |
|:--|:--|:--|
| **开发** | AI辅助可做，静态站几乎零成本；交互式几千元 | 跨平台（Flutter/RN）也要几万-几十万；原生更贵 |
| **服务器/域名** | 域名 ~50元/年 + 轻量服务器 100-500元/年 | 同左（APP也要后端）+ 更多 |
| **发布门槛** | ICP备案（免费，2-4周） | **软著（1000-3000元）+ 商店审核 + iOS开发者账号 99美元/年** |
| **维护** | 低（改内容即可） | 高（版本更新/商店政策/兼容性） |
| **技术门槛** | 非程序员+AI可做静态站 | 非程序员基本做不了（即使AI辅助） |
| **首年总成本** | **~500-2000元** | **~3万-50万**（含软著/账号/开发） |

## 关键判断（为什么网站适合苏不倦）

1. **需求是内容变现，不是工具产品** → 内容型产品网站天然适合
2. **最小市场验证原则**（2026-08-09确立）→ 网站2周可上线验证，APP至少3-6个月
3. **用户非程序员** → 网站（AI辅助）可掌控，APP完全依赖别人

## 推荐路径（从轻到重）

```
第1步：静态网站/落地页（几百元，2周）
   → 方法论文档 + 免费PDF引流 + 付费课程入口
   → 验证：访问？下载？付费？
第2步：简单交互（AI辅助，几千元）
   → 词汇测试/打卡功能（⑪号词汇库是现成题库！）
   → 验证：用户真的用吗？
第3步（验证通过后）才考虑 APP 或小程序
```

## 现成资产（⑪号可贡献）

- 主动词汇库（66词+持续增长）→ 词汇测试题库
- 地道说法库 → 场景学习素材
- 已验证方法论（12条+）→ 内容产品
- 词汇生长系统v3 → 产品核心逻辑

## 决策建议

- **不投入APP**（成本高、门槛高、验证慢）
- **从网页/落地页起步**（低成本验证内容需求）
- 验证通过 → 再考虑小程序（比APP便宜，微信生态契合知识付费）
