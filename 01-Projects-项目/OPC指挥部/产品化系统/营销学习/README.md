## 🆕 最小可验证（2026-08-08 用户确立）

**学的每个方法论，必须拿到用户真实反馈才算验证通过**：
- 学完→提炼→应用到苏不倦账号（视频/文章/产品）→**看真实用户反应**
- 哪怕只有1个人评论/提问/收藏——这就是反馈，记录到 `03-应用验证/`
- 判断标准：**没有用户反馈 = 这个方法论没验证过 = 不算学会了**
- 用户问的问题/评论的质疑 → 是最值钱的信号（哪里没讲清楚、用户真在意什么）

**应用验证记录模板**：
```
方法：XX书/XX博主 → XX方法论
应用到：哪条视频/哪篇文章/哪个产品
用户反馈：评论原文/私信/提问（至少1条）
验证结论：✅方向对 / 🟡要调整 / ❌不适合我们
回灌：方法论升级 or 弃用
```
