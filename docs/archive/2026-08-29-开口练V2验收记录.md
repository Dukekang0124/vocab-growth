- `node --test test/test-data.js test/test-srs.js test/test-store.js` → **35/35 通过**（无回归）

  - `I went diving last summer and I saw a dolphin.`（对照老外版本）→ 95 分 A 级，0 语法错误

### 过程中发现并修复的 bug
1. **复数词掩码失败**：maskWord 用全词匹配，`dolphin` 盖不住 `dolphins` → 改为词干正则 `\bdolphin\w*`，判分同步接受词干变形（`wsStem`）
2. **关键词变形重复**：候选关键词同时出现 dolphin 和 dolphins → 按 `indexOf` 前缀关系去重
3. **脚本加载时序**：新模块曾引用 `VG_STORE.state`（工厂模块无此属性）→ 统一改为惰性解析 `VG_APP._store`；`init()` 延后一拍执行，保证首次渲染时模块能拿到 store 实例

## 三、已知限制（非缺陷）

- 开口说的语音识别依赖 Web Speech API：Chrome/Edge 最佳；微信内置浏览器、Firefox 不支持 → 按钮禁用并引导换浏览器，其余三种练法不受影响
- 评分引擎是规则引擎，能抓确定性语法错误与表达习惯，不能理解语义；后续可接 LLM 提升纠错质量（预留 `speak-workshop` 纯函数边界，替换实现即可）
- 徽章条件依赖本机数据（连续天数、造句数），换设备/清缓存会重新累计（与现有 streak 机制一致）
