## 🚀 上线步骤

### 1. 部署到 GitHub Pages
```bash
# 克隆仓库
git clone https://github.com/your-username/vocab-growth.git
cd vocab-growth

# 推送到 GitHub
git push origin main
```

### 2. 配置 GitHub Pages
1. 进入 GitHub 仓库设置
2. 选择 "Pages" 选项
3. 选择 "main" 分支
4. 选择 "/docs" 或根目录
5. 等待部署完成

### 3. 配置微信白名单（可选）
1. 登录微信公众平台
2. 进入 "设置" → "公众号设置"
3. 添加新的域名到白名单
4. 等待审核（通常1-3个工作日）

### 4. 配置 DNS（如果使用自定义域名）
1. 添加 CNAME 记录指向 GitHub Pages
2. 等待 DNS 生效（通常24-48小时）

### 5. 测试上线版本
```bash
# 测试部署版本
curl -I https://your-username.github.io/vocab-growth/

# 测试跨平台功能
curl -I https://your-username.github.io/vocab-growth/js/cross-platform.js
```

## 📋 应急预案

### 1. 服务器故障
- **预案**：GitHub Pages 自动备份，无需担心服务器故障
- **恢复时间**：立即恢复
- **影响范围**：全球用户

### 2. 域名问题
- **预案**：备用域名（vocab-growth.github.io）
- **恢复时间**：DNS 生效时间
- **影响范围**：域名访问用户

### 3. 数据丢失
- **预案**：用户数据保存在 localStorage，自动备份
- **恢复时间**：用户重新加载数据
- **影响范围**：单个用户

### 4. 兼容性问题
- **预案**：跨平台适配模块自动检测和提示
- **恢复时间**：实时
- **影响范围**：特定平台用户
