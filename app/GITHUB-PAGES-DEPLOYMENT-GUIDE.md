## 🚀 部署步骤详解

### 第一步：创建 GitHub 仓库

#### 1.1 登录 GitHub
访问 https://github.com 并登录你的账号

#### 1.2 创建新仓库
1. 点击右上角的 `+` 图标，选择 `New repository`
2. 填写仓库信息：
   - **Repository name**: `vocab-growth-app`（推荐）
   - **Description**: `词汇生长 Vocabulary Growth - 不背单词，让单词长出来`
   - **Public/Private**: 选择 `Public`（GitHub Pages 免费需要公开仓库）
   - **Initialize this repository**: **不要勾选**任何选项
3. 点击 `Create repository`

#### 1.3 获取仓库地址
创建成功后，你会看到类似以下的仓库地址：
```
https://github.com/你的用户名/vocab-growth-app.git
```

---

### 第二步：上传代码到 GitHub

#### 2.1 打开项目目录
在终端中导航到项目根目录：
```bash
cd /path/to/vocab-growth-app
```

#### 2.2 初始化 Git 仓库（如果还没有）
```bash
git init
```

#### 2.3 添加所有文件到暂存区
```bash
git add .
```

#### 2.4 创建首次提交
```bash
git commit -m "feat: 词汇生长 MVP v1.0 - 完整功能实现"
```

#### 2.5 连接到远程仓库
```bash
git remote add origin https://github.com/你的用户名/vocab-growth-app.git
```

#### 2.6 推送代码到 GitHub
```bash
git branch -M main
git push -u origin main
```

**如果遇到认证问题**：
- GitHub 现在要求使用个人访问令牌（Personal Access Token）
- 访问 https://github.com/settings/tokens 生成新令牌
- 在推送时使用令牌替代密码

---

### 第三步：配置 GitHub Pages

#### 3.1 进入仓库设置
1. 在仓库页面点击 `Settings` 标签
2. 在左侧菜单中找到 `Pages` 选项

#### 3.2 配置 GitHub Pages
1. 在 `Source` 部分：
   - **Branch**: 选择 `main`
   - **Folder**: 选择 `/` (根目录)
2. 点击 `Save`

#### 3.3 等待部署完成
- GitHub Pages 会在 1-2 分钟内完成部署
- 你可以在 `Pages` 设置页面看到部署状态
- 部署成功后，会显示你的网站地址

#### 3.4 获取网站地址
你的网站地址将是：
```
https://你的用户名.github.io/vocab-growth-app/
```

### 第五步：域名优化（可选）

#### 5.1 绑定自定义域名
如果你有自己的域名，可以绑定到 GitHub Pages：

1. 在 GitHub Pages 设置中，点击 `Custom domain`
2. 输入你的域名（如 `vocab.growth.app`）
3. 点击 `Save`

#### 5.2 配置 DNS
在你的域名 DNS 设置中添加：
```
类型: CNAME
名称: www（或子域名）
值: 你的用户名.github.io
```

#### 5.3 启用 HTTPS
1. 在 GitHub Pages 设置中勾选 `Enforce HTTPS`
2. 等待 SSL 证书生成（可能需要几分钟到几小时）

## 🔧 常见问题解决

### ❓ 问题1：推送代码时认证失败
**解决方案**：
```bash
# 使用个人访问令牌替代密码
# 令牌生成地址：https://github.com/settings/tokens
git push -u origin main
# 用户名：GitHub 用户名
# 密码：个人访问令牌（不是 GitHub 密码）
```

### ❓ 问题2：GitHub Pages 404 错误
**可能原因**：
1. 仓库名称不正确
2. `index.html` 文件缺失
3. 分支名称配置错误

**解决方案**：
1. 确认仓库名称与 URL 一致
2. 检查 `index.html` 是否在仓库根目录
3. 在 GitHub Pages 设置中确认分支为 `main`

### ❓ 问题3：音频文件无法播放
**解决方案**：
1. 检查 `assets/audio/` 目录是否包含所有 40 个 mp3 文件
2. 检查文件大小是否正常（每个约 9-12KB）
3. 确认浏览器支持 TTS（作为后备方案）

### ❓ 问题4：部署后样式错乱
**解决方案**：
1. 清除浏览器缓存
2. 检查 `css/style.css` 文件是否正确上传
3. 查看浏览器控制台是否有 CSS 加载错误

### ❓ 问题5：微信内无法访问
**解决方案**：
1. 确认域名在微信白名单中（检查 `js/wechat-whitelist.js`）
2. 使用浏览器打开而不是微信内置浏览器
3. 或者等待微信审核白名单申请
