## 一、AI工具使用习惯

**日常工具矩阵：**
- **DeepSeek** — 最频繁，日常拆解/思考
- **千问** — 工程/写代码
- **Claude Code** — 80%主力开发环境
- **Claude** — 20%辅助
- **GPT-4.7 / DeepSeek V4 Pro** — 奢侈级，顶级项目才用

**核心主张：少研究模型，多构建系统。**

**入门路径：** Qclaw（零门槛）→ Claude Code + DeepSeek（进阶）→ 自建知识系统（终极形态）

## 二、每日三块工作法（90分钟生产引擎）

| 模块 | 时间 | 动作 |
|:--|:--|:--|
| 模块一 | 30min | **深度理解一个概念** — 多AI交叉验证，不看屏幕用自己的话写出来 |
| 模块二 | 30min | **思考与我的连接** — 禁止再学新内容，只做连接 |
| 模块三 | 30min | **融入系统并固化** — 提取原子→放入原子库→产生可执行技能 |

## 三、假性掌握陷阱

> "学不会=赚不到钱"——会就不可能用不出来。

**多巴胺陷阱：** 学习→看懂→快感→停止——本质和打游戏没区别。

**正确闭环：** 理解→连接→固化→运行→产出→复盘→迭代

## 四、知识系统构建

### 原子库
**1520条**最小知识单元（乐高积木式），可自由组合。

**完整流水线：**
```
RSS抓取 → 浮墨碎片 → 跨域对撞 → 灵感锻造 
         → 洞见 → 孵化池 → 驻留助卡 
         → 蒸馏 → 转换 → 出品
```

### 决策日志
记录时间/事件/原因/结果，用于复盘。

### 模型深挖工作流
1. 从原子库拉取模型完整解释
2. AI帮剥离到核心逻辑（一两句话的抽象）
3. 自己尝试给出2-3个领域的应用场景；卡住了AI补充
4. 产出"模型迁移日志"

---

## 五、读书方法：从"画书"到拆书

**拆书流程：**
```
拆知识块 → 全网融合 → 标注关键点 → 主题阅读AI化
```

**拆解模板：**
1. 作者核心观点
2. 我以前怎么做
3. 我现在怎么做
4. 反直觉冲击
5. 可执行下一步

以《价值心法》为例完整演示。

---

## 六、信息差（信息不对称）完整拆解

- 基于 Akerlof 柠檬市场理论
- 跨领域应用：内容创作 / 投资交易 / 产品设计 / 职场组织
- "我现在干的事情，他们会在一年、两年、三年之后才会去做——这就是信息差"

书籍、论文或海外趋势，你翻译转述就创造了内容价值。但一旦同行都读了这本书，信息差就消失了。所以需要不断从一手货源获得信息差。
