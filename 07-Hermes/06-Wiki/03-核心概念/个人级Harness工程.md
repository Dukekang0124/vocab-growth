# 个人级Harness工程

> **碰撞产物**：李伯杰《AI Agent设计原理》的 Harness 公式 × 九思OS 12窗口系统的交叉验证。
> 结论：**九思OS 就是一个人独享的 Harness 工程实例**——组织级框架在个人尺度上的完整落地。

## 核心公式

```
生产级Agent = LLM + 上下文 + 工具 + 约束 + 验证 + 纠正
                     └────── Harness（工程外壳）──────┘
```

## 九思OS对照表

| Harness组件 | 书里的定义 | 九思OS的实现 |
|:--|:--|:--|
| 约束 | 限定做什么/不做什么 | SOUL.md（独立思考铁律/时间认知铁律/操作模式铁律）+ 12窗口边界 + 全窗口执行令 |
| 验证 | 检查做对没有 | 收尾四查（沉淀/固化/合并/最后一环）+ oral-script-review 27维 + change-impact-check |
| 纠正 | 做错如何补正 | darwin-skill 棘轮机制 + 沉淀自觉（4触发→立即写Skill）+ 回归门 |

## 为什么个人也能用 Harness

书里的前提是组织级（多Agent协作），但 Harness 的本质是**「让模型可靠做事」的工程外壳**——个人使用同样需要：

- 没有 Harness 的个人 = 一个强大的模型+脆弱的记忆（脱缰野马）
- 有 Harness 的个人 = 12窗口分工 + 知识库 + 自动化 = 可靠执行系统
