# 进化七步法

> 2026-08-02 用户元认知提炼（problem-evolution Skill 的 wiki 版）

## 核心流程

```
遇到问题 → 发散思维 → 建立初步构想 → 形成解决方案
→ 沉淀为方法论/Skill → 重复使用 → 进一步进化
```

## 为什么有效

这是"从解决一个问题"到"学会解决一类问题"的跃迁——**元能力**。

| 步骤 | 要点 | 今日案例 |
|:--|:--|:--|
| 遇到问题 | 先诊断根因，不急着治标 | 压缩中断→查磁盘→查锁→找到竞态 |
| 发散思维 | 允许天马行空，先收集方向 | "能不能扩容？"→软扩容→高维构想 |
| 初步构想 | 串成框架：现状vs目标vs差距 | 五步闭环 |
| 解决方案 | 小步落地，先做闭环入口 | 沉淀机制先建 |
| 沉淀为方法论 | 证据链铁律 | Skill+蓝图+文档 |
| 重复使用 | 能自动化就不靠提醒 | cron每日自动跑 |
| 进一步进化 | 闭环本身也被监控 | 回归门 |

## 应用判断

- 反复出现的问题 / 用户有方向感的构想 / 需要系统性解决 / 值得复用
