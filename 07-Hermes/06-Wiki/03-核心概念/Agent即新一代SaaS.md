# Agent即新一代SaaS

**定义**: Agent卖的是工作本身，不是软件

**来源**: [[02-Areas-资产/战略参谋-自我迭代系统/AI学习与创作系统/Builder思维/AI_Agent就是新一代SaaS]]

**为什么重要**: 范式转移：过去SaaS卖一套软件让团队进去点按钮，现在Agent产品卖一份原本由人完成的工作。产品策略：找一个每天重复、老板愿意付钱、结果能验收的小工作。验收标准从「功能有没有」变成「活干没干完」。运营指标从DAU/留存变成替客户省了多少人工。
