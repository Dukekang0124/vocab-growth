## 使用现成框架（胡子哥同款）

### 三环迭代系统 v3.0

```
⚡ 触发 → 验证 → 演进
```

**第一环·入口触发：** 入盒四规则
- 不认同 / 讲不清楚 / 困惑 / 旧认知被动摇

**第二环·验证加工：**
- 灵感引擎（7刃切割）→ 门禁四问 → 挖矿（8条规则）→ 输出

**第三环·认知演进：**
- 每篇末尾加"上期回顾"

### 7刃切割法
悖论刀 / 杠杆刀 / 溯源刀 / 反转刀 / 类比刀 / 笨拙刀 / 尺度刀

### 知识卡片四铁律
原子性 / 可行动 / 可证伪 / 诚实性 — L1~L3 等级

### Skill 清单
灵感炼金炉 v3.0、挖矿、灵感对撞机、内容炼金、口播

## 自定义构建（小秦的方法）

**融合方案：** PARA + 卡片笔记（Zettelkasten）+ Obsidian 双向链接

**核心理论：** 知识周转率闭环系统

| 指标 | 说明 |
|:--|:--|
| 周转率 ≥ 60% | 知识在流动而非积灰 |
| 库存逐月递减 | 知识越用越少反而好 |
| 清理率每月 5-10% | 定期删除过时知识 |

**MOC 导航系统：** 每个文件夹放 wiki 文件汇总，省 token。
**个人画像：** 放 Wiki 目录让 AI 了解你的风格。
