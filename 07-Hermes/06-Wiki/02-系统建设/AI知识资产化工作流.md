# 🤖 AI+PARA 知识资产化全工作流

> 来源：小秦同学 | 6页
> 录入：2026-07-17 | 核心：用AI把书变成个人洞见卡

---

## 总览：终极进化

**核心三步骤：**

```
全景扫描 → 深度内化 → 资产淬炼
```

**工具链：**
- NotebookLM — 扫描+原文引用
- Gemini/Claude/ChatGPT — 深度内化
- 知识沉淀 → PARA 的 Resources/02_洞见卡

---

## 步骤1-2：全景扫描

### 步骤1：获取电子书
优先 PDF 格式，方便 NotebookLM 做原文定位。

### 步骤2：全景知识地图
用 NotebookLM 生成，完整提示词包含：角色定位、工作目标、行为准则、输出结构。

**知识地图输出格式：**
- 核心板块 → 知识点 → 术语定义 / 价值导航 / 内部织网 / 原文定位

**挑选"最值得吃透的概念"的标准：**
- 最刺痛你的
- 能立刻用的
- 最反直觉的

---

## 步骤3：深度内化 → 原子行动卡片

切换工具到 Gemini/Claude/ChatGPT。

### 原子卡片生成器提示词结构
```
工作目标 → 硬性约束（拒绝学术黑话、杜绝鸡汤、强制关联现实）
         → 输出结构（核心洞见 / What / Why / How）
```

### 人工"注入灵魂"
- 改标题
- 写真实痛感

### 本步完成标志
- 得到 1 张"原子行动卡片"，包含 What/Why/How
- 卡片里至少有 1 句你的真实经历（痛感）+ 1 个可执行的微动作

---

## 步骤4：资产沉淀 → 洞见卡（个人原则）

**核心目标：** 去掉原书语境与作者语气，把知识变成"你自己的铁律"。

### 工具建议
不要用 NotebookLM 做这步（太忠于原著）。用 Gemini/Claude/ChatGPT 做"抛光与去语境"。

### 动作1：先填4个素材（人类区）
1. **核心概念** — 干瘪名词
2. **我的大白话顿悟** — 翻译成你自己的话
3. **我踩过的血坑** — 真实经历
4. **我给自己定的铁律** — 未来做法

### 动作2：发送"洞见卡淬炼师"提示词

输出结构：
```
### 💡 洞见：[提炼一句极具断言感、反直觉的狠话作为标题]

1. 我的认知重塑
   - 大众误以为...但我现在的认知是...
   
2. 达摩克利斯之剑
   - 如果我以后再犯，代价会有多惨

3. 绝对铁律
   - 以后一旦触发【条件】，必须执行【决策】
```

### 动作3：归档入库
- 人工终审 → 永久入库 → 打标签（按知识属性，不按书名）

## 常见问题

| 问题 | 解答 |
|:--|:--|
| NotebookLM 输出太长？ | 用提示词防截断机制，让它先输出3个板块 |
| 挑不出概念？ | 先挑"最刺痛你"的那条 |
| 做完卡片没感觉？ | 缺的不是AI，是你没写真实代价 |
