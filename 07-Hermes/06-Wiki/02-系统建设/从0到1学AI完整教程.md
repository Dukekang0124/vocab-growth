## 二、AI 到底是什么？身体 vs 大脑

### 核心隐喻：装配你的专属机甲

| | 身体（智能体框架） | 大脑（大模型 API） |
|:--|:--|:--|
| 作用 | 负责执行、操作电脑 | 决定 AI 有多聪明 |
| 代表 | Hermes / Claude Code / QClaw | DeepSeek / GPT / Claude |
| 状态 | 空壳，无法单独运作 | 需接入才能动起来 |

> 没有脑子的身体就是一堆废铁。

### API 接入三要素
1. **Base URL（访问地址）** — 告诉智能体去哪找模型
2. **API Key（密钥）** — 专属通行证，通常只显示一次
3. **Model Name（模型名称）** — 大小写、多一个空格都跑不起来

## 五、知识加工方法论：从灵感到卡片

### 四道筛选（入口防守）
1. 这个观念我不认同 → 引发思考
2. 我以为懂了但讲不清楚 → 发现漏洞
3. 这个现象让我困惑 → 需要挖深
4. 我的认知被动摇了 → 需要重建

### 加工流水线
```
灵感进来 → 七刃切割(7个维度解构) 
          → 挖矿压缩(提炼精华) 
          → 知识卡片(4K格式) 
          → 归位(PARA)
```

### 复利的力量
1 张知识卡片 → 50 张卡片 → AI 自动牵线搭桥，发现跨领域的知识盲点与暗纹连接。

每天一张卡片。30、40、50 张的时候，系统雏形就有了。
