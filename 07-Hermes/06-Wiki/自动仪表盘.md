# 📊 自动仪表盘

> Dataview 驱动 · 实时更新，无需手动维护

## 🆕 待发布脚本

```dataview
LIST 
FROM "02-Areas/短视频创作脚本"
WHERE contains(file.name, "（待发布）")
SORT file.ctime DESC
```

## ✅ 已完成的创作

```dataview
TABLE file.ctime AS "创建时间"
FROM "04-Archive/已完成的创作类目"
SORT file.ctime DESC
LIMIT 20
```

## 📝 本周日记

```dataview
LIST 
FROM "自我迭代系统/每日随记"
WHERE file.day >= date(today) - dur(7 days)
SORT file.day DESC
```

## 📈 知识库统计

```dataview
TABLE length(rows) AS "篇数"
FROM ""
GROUP BY "📁 " + file.folder AS "目录"
SORT length(rows) DESC
```
