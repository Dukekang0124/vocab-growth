## 三、我的工作流程

### 内容创作流程
```
灵感/选题 → QuickAdd捕获（00-inbox）
    ↓
写脚本 → Templater自动套口播模板（创作与待发布/）
    ↓
AI审稿（13+维，只诊断不代写，结尾不给文案）
    ↓
修改 → 拍摄 → 发布
    ↓
归档 → 04-Archive/已完成的创作类目
```

### 求职流程
```
刷BOSS/猎聘 → 三必问（五险一金入职交？双休？远程？）
    ↓
符合条件的 → 投递 → 记录追踪表
    ↓
面试 → 复盘 → 优化
```

### 英语学习流程
```
多邻国（基础）→ 每日英语听力（输入）→ ListenLeap
→ HelloTalk/Tandem（口语输出）→ 牛津书虫（沉浸阅读）
```

## 四、内容风格偏好

**说话风格：**
- 结论先行，第一句话扔判断
- 口语化、短句（≤25字）
- 用词偏好：说句大实话/我跟你说/你还别说/干脆/反正就是
- 不用：每天分享/保证见效/7天流利/最好/100%/结尾CTA

**审稿原则：**
1. 先分析为什么不好，再给修改建议，不跳步
2. 结尾只诊断不做处方（用户结尾比AI建议版好）
3. 每次审稿后→用户改→对比差异→更新Skill→下次更准

**内容原则：**
- 不虚构数据（不用90%等未验证数字）
- 不在脚本结尾加收藏/点赞/关注引导
- 不承诺发布频率（不日更）
- 好内容自带收藏冲动
