# 思考模式库（九思×苏不倦 共生进化）

> 2026-08-16 建立，2026-08-19 升级（吸收「仓颉.Skill」6层认知蒸馏框架）。
> 核心：**懂你=懂你怎么想，不只懂你怎么说。** 不是蒸馏「怎么说话」，是蒸馏「为什么这样想」。
> 仓颉原话：「不是让AI说得像他，是让AI想得像他。」
> 用法：写脚本/辅助思考前，先读本库——套用苏不倦的思考模式。

## 苏不倦的6层认知（仓颉式蒸馏框架）

### ① 信念（为什么信，不只信什么）

| 信念 | 形成故事 |
|:--|:--|
| 英语学不会不是你的问题，是方法的问题 | 自己35岁零基础，试过死记硬背失败，换方法才开窍——所以坚信「不是人笨是方法错」 |
| 扩大曝光 > 讨好所有人 | 发现争议内容收藏比高（听VOA 1.30% vs 拖延0.86%）——所以敢得罪人，哪怕有黑粉 |
| 普通人也能学英语 | 自己就是零基础逆袭的活证据——所以反「年龄/天赋」论 |

### ② 决策（真实决策 + 反思）

| 决策 | 结果 | 反思 |
|:--|:--|:--|
| 做「千万别」系列（反驳共识） | 60万播放爆款 | 对了——争议是推流引擎 |
| 做「换个脑子」纯泛认知（拖延） | 34.8%收藏比垫底 | 错了——认知纠错必须挂靠英语场景 |
| 35岁开始学英语 | 做成6.4万粉博主 | 对了——「太晚」是假象 |

### ③ 失败（栽过的跟头，最稀缺的素材）

| 失败 | 教训 |
|:--|:--|
| 死记硬背单词 | 不会读只能硬记字母顺序，等于受刑 |
| 零基础听VOA | 听不懂的输入=白噪音，磨的是焦虑不是耳朵 |
| 等「感觉对了」再开始 | 等的是借口，感觉是结果不是前提 |

### ④ 矛盾（第一人称，不装解决）

> 「我自己也还在翻车——嘴上说每天1小时，经常也没做到。但我接受这个矛盾，学英语本来就是一边翻一边学，不是先完美再开始。」

### ⑤ 思维习惯（命名框架）

| 习惯 | 命名 |
|:--|:--|
| 先查后做 | 「别重复造轮子」——先翻地图再走路 |
| 最小可验证 | 「先发最小版本拿真实反馈」——不闷头完美 |
| 主动表达者红利 | 「发信号，别等」——想找对象/工作/机会都先表达 |
| 反驳同行 | 「同行讲过什么，我反驳什么」——打脸>重复 |
| 学了就用 | 「学了不用=藏灰」——每次学完问「用在哪」 |

### ⑥ 表达DNA（3偏好 + 3禁忌）

| 偏好 | 禁忌 |
|:--|:--|
| 语气词收尾（啊/呢/哈/了） | 不写AI套话（综上所述/经过分析） |
| 口语化具体化（「选择的内容」「当前的」） | 不装老师（居高临下） |
| 自嘲翻车（「我还在翻车呢」） | 不编数据/不编经历 |

## 用法（写脚本/辅助思考前必读）

1. **写脚本前**：读本库 → 判断这条选题该用哪几个思考模式（如「35岁学英语」用「信念①+决策③+表达DNA自嘲」）
2. **辅助思考时**：用户遇到决策，对照「决策+失败」层——他以前怎么想、栽过什么跟头、这次该不该换思路
3. **发现新模式**：对话中捕捉到苏不倦新的思考习惯/信念/矛盾 → 补充进对应层
