## 六、选型铁律（与省钱机制联动）

1. **默认全 Flash**（轻活），**重活才切 Pro**（model-router 5问：动脑/长文/决策/影响/创造，≥3重→Pro）。
2. **错峰**：耗 token 的重活压到 21 点后（平峰价），避开工作日 9-12/14-18 高峰（2倍价）。
3. **白嫖优先于付费**：能用 agnes/glm/opencode 白嫖的就别用 deepseek 付费。
4. **用完即回**：切 Pro 干完活切回 Flash 基线。

## 七、锁区/故障判定铁律

- **判断模型能不能用，看 API 实测，不看控制台列表**——智谱控制台会显示已下线模型（glm-4.5-flash 显示但返回空），opencode 会显示锁区模型（muse-spark 显示但 RegionError）。
- **RegionError = 永久锁区**，放弃；**502/FreeUsageLimit = 临时过载/限流**，间歇可用或错峰重试。

### 三条关键结论

1. **deepseek 双雄仍是天花板**——但付费。agnes-2.5-flash 是免费里唯一接近 deepseek 的，白嫖首选。
2. **nemotron-3-ultra-free 是深度黑马**——「你拖延的不是任务，是任务带来的负面情绪」是全榜最有洞察的一句，但 Nvidia 服务间歇 502，要看运气。
3. **reasoning 模型（pro/alpha/x-preview/hy3）烧 token 严重**——思考 3000-4600 字才出正文，免费的无所谓、付费的（agnes-pro）慎重。laguna/nemotron-3.5 中文夹英文，不适合中文创作。
