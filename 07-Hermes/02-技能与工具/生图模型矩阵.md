## 调用方法（接口速查）

### Seedream 5.0（火山方舟，主力）
```python
POST https://ark.cn-beijing.volces.com/api/v3/images/generations
Headers: Authorization: Bearer ark-41781275-...
Body: {
  "model": "doubao-seedream-5-0-260128",
  "prompt": "描述+保持参考图形象",
  "image": "data:image/png;base64,{参考图b64}",  # 参考图（角色一致性）
  "response_format": "b64_json",
  "size": "2k",  # 或3k/4k/WIDTHxHEIGHT（不支持1k）
  "watermark": True
}
# 返回 data[0].b64_json → base64解码保存
```

### 通义万相（阿里）
```python
POST https://dashscope.aliyuncs.com/api/v1/services/aigc/text2image/image-synthesis
Headers: Authorization: Bearer sk-ws-... + X-DashScope-Async: enable  # 关键！
Body: {"model": "wanx2.1-t2i-turbo", "input": {"prompt": "..."}, "parameters": {"size": "1024*1024", "n": 1}}
# 拿 task_id → 轮询 GET /api/v1/tasks/{task_id} 直到 SUCCEEDED
# URL下载403（防盗链），需带referer或换SDK
```

### CogView-3-flash（智谱）
```python
POST https://open.bigmodel.cn/api/paas/v4/images/generations
Headers: Authorization: Bearer ZAI_API_KEY
Body: {"model": "cogview-3-flash", "prompt": "...", "size": "1024x1024", "reference_image": "b64"}
# cogview-4限流时用3-flash
```

### Kolors（硅基流动，免费）
```python
POST https://api.siliconflow.cn/v1/images/generations
Headers: Authorization: Bearer sk-grvdzjgs...
Body: {"model": "Kwai-Kolors/Kolors", "prompt": "...", "image_size": "1024x1024", "batch_size": 1}
# 返回 images[0].url（S3临时URL，1小时有效，完整URL才能下载）
```

### ComfyUI（本地）
```bash
cd D:\软件\ComfyUI\ComfyUI_Windows_portable\ComfyUI && unset PYTHONPATH && python_standalone\python.exe -s main.py --windows-standalone-build
# 浏览器 http://127.0.0.1:8188，API POST /prompt
```

## 选型原则

1. **封面角色一致性** → Seedream 5.0（0.22元/张，值）
2. **日常快速图** → CogView-3-flash / Kolors（免费）
3. **本地大图/批量** → ComfyUI（免费）
4. **质量要求高** → 通义万相
5. **Seedream Pro**（角色更强）→ 充值后可用

## 收费结论（月成本估算）

- 封面设计：每月约5-10张 → Seedream 0.22×10 = **约2-3元/月**
- 日常测试：免费模型（CogView/Kolors）→ **0元**
- **总生图成本极低**（几块钱/月）
