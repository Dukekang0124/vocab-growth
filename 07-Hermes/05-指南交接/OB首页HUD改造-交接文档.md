## 待⑤号继续的

2. **重启 OB**（Ctrl+P → Reload app without saving）让插件和 CSS 生效
3. **验证首页渲染**：Track 进度条是否数据驱动（DataviewJS 从复盘笔记算收藏比）、折线图是否显示

## 注意事项

- 用户重度使用 OB，**改造要稳**，别破坏现有 vault 结构
- 所有数据必须在 OB vault 内（不在浏览器/外部系统），这是选 OB 一体化而不是 Cockpit 的根本原因
- 小红书/视频号禁自动化铁律不变（内容管线只是管理，不碰平台）
- 复盘数据录入后，首页 Track 进度/折线图应自动更新（数据驱动）
- 原 Creator Cockpit 项目在 `D:\软件\creator-cockpit-app`（体验用，可保留作参考，不维护）
- Node.js v24.18.1 装在 `D:\软件\nodejs\`（Cockpit 体验用，OB 改造不需要它）
