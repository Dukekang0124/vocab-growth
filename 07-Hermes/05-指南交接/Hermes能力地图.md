> 目的：让你一眼看清「12个窗口分别能做什么、每个窗口有哪些核心 Skill」。

## 上下文容量速查 🆕

| 项 | 值 | 说明 |
|:--|:--|:--|
| 模型硬上限 | **100万 tokens**（pro/flash 同）| DeepSeek API 限制，不能改配置扩容 |
| 压缩触发线 | **65万 tokens**（0.65，已调优）| 会话到 65万 触发自动压缩（Summarizing thread）|
| 压缩后保留 | 约 22万 tokens（35%）| 继续用，循环 |
| 保护最近 | 50 条消息 | 压缩时最近 50 条不压缩 |
| 为什么不能扩 | 上下文=模型服务端限制 | memory 是本地可扩，上下文是 API 硬限制 |
| 软扩容途径 | Memory+OB+session_search+Skill | 外部记忆≈无限，需要时按需检索 |

> 参考：一本书约 10万 tokens，100万 ≈ 10本书。真正"忘"的原因不是窗口不够，是没沉淀到 Memory/OB。
