# 跨窗口 Skill 共享机制

> 所有 Skill 存在 `~/.hermes/skills/`，10 个窗口共享同一套能力库。

## 沉淀流程

日常对话中发现「这个方法可以用三次以上」→ 跟我说「记下来」→ 我生成 Skill → 所有窗口即时可用。

## 应用场景

| 窗口 | 可沉淀成 Skill 的模式 |
|------|------|
| ① 自媒体系统 | 选题判断标准、爆款脚本结构、标题优化模式 |
| ② 生存与发展作战室 | 岗位筛选条件、简历关键词匹配、面试话术 |
| ③ 一人公司指挥部 | 定价模型、变现路径判断、客户分类 |
| ④ 产品化系统 | 课程结构模板、用户调研框架 |
| ⑤ 知识库系统 | 分类规则、标签体系、笔记模板 |
| ⑥ 系统配置 | Skill审计流程、清理策略、模型切换规则 |
| ⑦ 复盘系统 | 周报模板、复盘分析框架 |
| ⑧ 自我迭代系统 | 决策检查清单、习惯跟踪方法 |
| ⑨ 总长 | 审计 checklist、跨窗口一致性检查 |
| ⑩ AI学习与创作系统 | AI工具评测框架、Prompt模式 |

## 规则

- 任意窗口沉淀的 Skill，其他窗口直接使用（`skill_view`）
- 跨窗口 Skill 命名加领域前缀，避免冲突
- ⑥号窗口定期做 Skill 去重和清理
