## 互联四步法

任何窗口对接高维进化系统，走这四步：

### 1. 写状态日志

格式：`| 日期 | 窗口号 | **🔗高维进化系统互联互通**：{具体做了什么} |`

### 2. 追加观察池

找到当前窗口产出的可复用价值，按四类分类写入 `skill-factory-观察池.md`：
- ①重复工作流 → 等⑥号周日提炼
- ②失败模式 → 更新 Skill Pitfalls
- ③知识生长点 → 进概念库
- ④用户新方向 → 月复盘讨论

### 3. 更新核心 Skill 接口

选当前窗口最核心的 Skill，加「高维进化系统接口」章节：
- 6类产出分流规则（市场简报/扫描/投喂/新Skill/重复流/纠正）
- 沉淀自觉4触发条件

### 4. 更新 README 互联章节

在窗口主目录的 README 加互联图，画出五步闭环在窗口的落地路径。
