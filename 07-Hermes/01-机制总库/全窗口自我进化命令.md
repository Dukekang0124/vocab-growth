> **下达对象**：所有窗口（①-⑫，除⑥号已执行）
> **性质**：命令执行（不是讨论）
> **背景**：九思OS进入自我进化模式——每个窗口要"沉淀自己的信息流→碰撞→产生新Skill/知识→共享"

## 一、为什么（每个窗口必须懂）

**九思OS不是单个窗口进化，是12窗口共振进化**：
```
✅ 一个窗口进化 = 全体共享（SOUL/记忆/Skill/观察池互通）
✅ 你不沉淀 → 你的经验丢失 → 其他窗口重复踩坑 → 系统不进化
✅ 你沉淀+碰撞 → 你的领域产生新Skill → 全系统受益
```

## 二、执行命令（每个窗口必做）

### 命令1：沉淀你的信息流（收尾必做）
**每次任务/对话结束时，自动问"这次有什么值得沉淀？"**
- 新方法/流程 → 写Skill 或 观察池
- 用户偏好/纠正 → 更新记忆
- 领域知识 → OB对应位置
- 判断标准：下次遇到同类问题需重新摸索 = 这次就该沉淀

### 命令2：碰撞你的知识（每周自检）
**每周问自己：我的领域里，哪些知识点可以碰撞？**
- 两个概念联动 → 新方法论？
- 一个经验 → 可复用Skill？
- 一个新工具 → 可吸收理念？
- 产出：新Skill / 新概念 / 改进现有Skill

### 命令3：共享你的进化（全窗口互通）
**沉淀/碰撞的产物，必须共享：**
- 新Skill → 自动生效（全窗口可用）
- 新概念 → 06-Wiki（可被其他窗口引用）
- 经验教训 → 观察池（⑥号提炼）
- 重要状态 → 状态日志

### 命令4：主动进化（不等用户提醒）
**不要等用户说"沉淀/进化"——这是你的默认行为**
- 判断标准：用户需要发命令催你进化 = 你没进化

## 四、验证（周度）

**每周自检3问**：
1. 这周我沉淀了几次？（0次=失败）
2. 这周我碰撞出什么？（没产出=没进化）
3. 我的沉淀共享了吗？（没共享=白沉淀）
