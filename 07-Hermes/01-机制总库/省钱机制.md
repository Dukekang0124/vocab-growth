## 二、执行命令（每个窗口必做）

### 命令1：先查后做（最重要）

**每个窗口接任务时，先做第0.0步：**

```
接任务 → 先问"这内容OB/Session/Skill里有吗？"
  → 有 → 引用知识库（缓存命中=便宜120倍）
  → 没有 → 才动手（未命中）→ 干完必须沉淀
```

**具体查**：①OB知识库（06-Wiki/概念库/素材库）②session_search（过去会话）③能力共享中心（已有能力）

### 命令2：沉淀优先

**每次内容/经验/成果 → 必须进OB，放对位置：**

| 类型 | 位置 |
|:--|:--|
| 系统机制 | 07-Hermes/ |
| 经验/踩坑 | 07-Hermes/skill-factory-观察池.md |
| 变更 | 07-Hermes/变更台账.md |
| 项目成果 | 01-Projects/OPC指挥部/<对应系统>/ |
| 知识概念 | 06-Wiki/03-核心概念/ |

**为什么**：沉淀=把未命中变命中（一次写N次读，长期净省）；不沉淀=每次重新造（未命中=贵）

### 命令3：少开新会话

**不频繁 /new**——新会话=全未命中=最贵。
- 用长会话+压缩（已调0.65/0.35/50，会话耐用）
- 能继续的会话继续，不轻易重开

### 命令4：全Flash基线 + 重活切Pro

**所有窗口默认 Flash**（省基线）：
- **轻活**（查词/格式/提醒/扫描）→ Flash（默认，不用切）
- **重活**（深度分析/创作/战略）→ 才切 Pro（/model deepseek-v4-pro）
- 判断：model-router 5问（动脑/长文/决策/影响/创造，≥3重→Pro）

**绝不**：轻活用Pro（浪费12.4倍差价）、重活用Flash（质量降）

### 命令5：错峰（自动化）

**耗token的自动化，安排在21点后（平峰价）**：
- 白天9-18点=2倍价（峰谷定价已生效）
- 已改：AI信息/AI Builder/生态/财富/市场/周选题等8个cron→21点
- **各窗口新建cron时**：默认21点后，不排白天高峰
