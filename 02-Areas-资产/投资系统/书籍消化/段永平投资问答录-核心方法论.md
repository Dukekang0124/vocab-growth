# 段永平投资问答录——核心方法论

> **段永平**：步步高/OPPO/vivo创始人，2001年转型投资。经典案例：网易（近百倍）、苹果、茅台。核心理念源于巴菲特，但更强调**企业文化**和**本分+平常心**。

---

## 一、决策三维漏斗（按优先级）

| 优先级 | 维度 | 核心问题 |
|-------|------|---------|
| 🥇第一 | 商业模式 | 这家公司赚钱的方式好不好？护城河宽不宽？ |
| 🥇并列第一 | 企业文化 | 这帮人做对的事情吗？有利润之上的追求吗？ |
| 🥉第三 | 合理价格 | 现在买下整家公司，10年后划算吗？ |

## 二、七大核心原则

### 1. 买股票就是买公司（基石）
- 股票 = 部分所有权，不是筹码
- 如果公司不上市，你还愿意买吗？
- 买入理由必须和未来现金流有关，而非K线/消息/政策

### 2. 商业模式 = 最核心的过滤器
- **好模式**：利润和净现金流都杠杠的，有护城河
- **护城河**：「能够长期维持的差异化」
- **定价权测试**：提价10%，客户会流失吗？
- **坏模式信号**：产品同质化、价格战、重资产投入、毛利率持续下降

### 3. 企业文化（段永平最独特的贡献）
- 三维结构：使命→愿景→核心价值观
- 好文化信号：利润之上的追求、消费者导向、本分、选人先看价值观
- 坏文化信号：利润至上、言行不一致、诚信被淡化
- ✅**A股特别重要**：很多公司商业模式好但文化有问题

### 4. 能力圈
- 「知道自己能力圈的边界，比能力圈有多大更重要」
- 不懂不碰，不是保守，是理性
- 建立能力圈需要多年专注跟踪

### 5. 安全边际 = 理解度
- 「安全边际是对公司的理解度，不是股价短期的价格波动」
- 对好公司，一点点价格差别10年后看都不是事
- 如果股价跌30%你的判断不变，那才有安全边际

### 6. 估值是"功夫"，不是公式
- 芒格没见过巴菲特按计算器估值
- **毛估估法**：用当前市值买整家公司，算10年总现金流，年化回报满意吗？
- 定性分析 > 定量分析

### 7. 本分 + 平常心
- **本分** = 做对的事情，把事情做对（有不为清单）
- **平常心** = 回到事物本源，排除诱惑
- 赚本分钱，睡得好，活得长

## 三、买入前一张纸检查清单

```
□ 商业模式好？（护城河宽不宽？差异化强不强？）
   → 不过关 → 放弃，多便宜都不买
□ 企业文化好？（有利润之上的追求吗？）
   → 不过关 → 放弃，好模式也维持不久
□ 价格合理？（10年后回头看划算吗？）
   → 划算 → 可买入
```

## 四、三个卖出理由（段永平认可的）
1. 公司基本面变坏（商业模式或文化变质）
2. 有更好的机会（机会成本比较）
3. 价格离谱地高

**不卖的理由**：涨多了卖、别人卖我也卖、做波段、落袋为安、因为成本低

---

## 五、经典案例对照

| 标的 | 判断依据 | 结果 |
|-----|---------|------|
| **网易** | 现金流好，游戏潜力大 | 近百倍 |
| **苹果** | 生态圈模式+消费者导向文化 | 长期重仓 |
| **茅台** | 极致差异化+轻资产+强定价权 | 长期重仓 |
| **GE** | 买入看文化→卖出因文化变质 | 反思：对新模式重视不够 |
| **万科/创维** | 后来认为商业模式不够好 | 卖出，承认错误 |

## 六、A股生存指南（段永平版）

1. ✅ A股适合价值投资
2. ❌ 不要做空、不要用杠杆/融资
3. ❌ 不要抄底（抄底是投机）
4. ❌ 不要因"长期持有"而持有烂公司
5. ❌ 避开价值陷阱（便宜但未来现金流不行）
6. ✅ 商业模式第一，哪怕在A股
