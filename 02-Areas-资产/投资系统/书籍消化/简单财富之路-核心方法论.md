# 简单财富之路——核心方法论

> **核心公式**：花得比赚的少 → 投资盈余 → 远离债务

## 📊 FIRE核心公式

**财务独立 = 25 × 年支出**

| 年支出 | 所需资产（4%法则） | 所需资产（3.5%保守） |
|--------|------------------|-------------------|
| 7万（极简） | 175万 | 200万 |
| 12万 | 300万 | 343万 |
| 15万 | 375万 | 428万 |
| 20万 | 500万 | 571万 |

> 注意：中国通胀率较高（通常3-5%），建议采用**3-3.5%安全提款率**

## 📈 三工具投资法

| 工具 | 作用 | 美国版 | 中国版 |
|------|------|--------|--------|
| 股票指数基金 | 财富增值 + 通胀对冲 | VTSAX (0.05%) | 沪深300+中证500ETF |
| 债券指数基金 | 平滑波动 + 通缩对冲 | VBTLX | 国债ETF/纯债基金 |
| 现金 | 日常 + 应急 | 银行/货币基金 | 余额宝/短债 |

### 两阶段策略

- **财富积累期**（有收入时）：100%股票指数基金
- **财富保全期**（靠资产生活时）：75%股票 + 20%债券 + 5%现金

## 🛡️ 4%法则详解

Trinity Study（1998）结论：4%提款率 + 50/50股债 + 通胀调整 → 96%成功率存活30年

**关键发现**：100%股票组合在4%提款率下，30年后资产中位数剩余 $10,075,000（初始$1,000,000）

> 股票不仅帮你积累财富，还在你花钱时继续保护你的资产

## 🌪️ 熊市应对七信条

1. 崩盘是正常的
2. 市场总会恢复
3. 市场永远向上（120年历史证据）
4. 熊市是财富积累者的礼物
5. 别听媒体
6. 不要试图择时
7. 坚持定投

| 10% | ~42年 |
| 25% | ~24年 |
| 50% | ~11.5年 |
| 70% | ~7年 |

## 🚀 用户当前适配（存款50万待业中）

1. **紧急备用金**：6-12个月生活费 → 6-12万放货币基金
2. **当前组合**：60%股票 + 30%债券 + 10%现金（待业阶段偏保守）
3. **收入恢复后**：逐步调整到80-100%股票
4. **目标**：每月存至少50%收入投入指数基金
