# 投资决策检查清单

> 每次想操作（买/卖/调仓）前，先过一遍。不代做决策，帮你避坑。

---

## 🛑 买入前检查

### 第一关：我懂吗？

- [ ] 这个标的靠什么赚钱？一句话能说清吗？
- [ ] 说不清 → **跳过**。只投自己能理解的。
- [ ] 我是因为"别人都在买"还是"我真看懂了"？

### 第二关：它好吗？（段永平三维）

- [ ] **商业模式**：护城河宽吗？差异化强吗？毛利率稳定吗？
- [ ] **企业文化**：管理层诚信吗？是消费者导向还是利润至上？
- [ ] **价格**：用当前市值买下整家公司，10年后划算吗？

### 第三关：我会死吗？

- [ ] 这笔钱 3-5 年内不需要动用？
- [ ] 如果跌 30%，我会恐慌卖出还是加仓？
- [ ] 没有用杠杆/借钱？
- [ ] 买入后不影响紧急备用金？

### 第四关：我是在投机吗？

- [ ] 不是"抄底"心理？（抄底 = 投机）
- [ ] 不是因为"已经跌了很多所以便宜"？（价值陷阱）
- [ ] 不是因为"怕错过"？（FOMO 是最贵的情绪）

---

## 🚨 卖出前检查

**只有三种情况应该卖出：**
1. 基本面变了（商业模式/企业文化变坏）
2. 有更好得多的机会（机会成本）
3. 价格离谱地高（未来10年现金流折现都追不上）

**以下不是卖出的理由：**
- ❌ 跌了害怕 → 恐慌是别人的，价值是自己的
- ❌ 涨了想落袋 → 好公司的时间价值远超波段收益
- ❌ 别人都在卖 → 别人玩的是不同的游戏
- ❌ 想抄底再买回来 → 没人能精准择时

---

## 📋 调仓前检查

- [ ] 为什么要调？是策略调整还是情绪驱动？
- [ ] 调仓手续费是多少？（ETF 联接通常 0.1%-0.5%）
- [ ] 调仓后的配置是否符合年龄法则（债券 ≈ 年龄%）？
- [ ] 行业 ETF 占比是否超过股票仓位的 10%？
- [ ] 调仓后能安心睡觉吗？（睡眠测试）

## 🧠 情绪自检

| 你现在感觉 | 可能的问题 | 应该做什么 |
|:--|:--|:--|
| "再不买就来不及了" | FOMO | 等 48 小时再决定 |
| "完了全完了" | 恐慌 | 关掉软件，过一周再看 |
| "这次不一样" | 过度自信 | 历史上每次都一样 |
| "我就做个短线" | 自我欺骗 | 回到买入前检查第一关 |
| "反正已经亏了，不管了" | 损失厌恶 | 重新评估基本面是否变了 |
