# 财富增长思维训练

> ⑫号投资辅助系统 · 财富增长思维专项训练
> 不是看盘，是训练思维方式——决策框架、行为心理、长期主义

## 核心目标

提升财富增长思维，不是追求短期收益，而是建立：
1. **识别好决策的能力** — 投资/商业/职业中都能用
2. **情绪免疫力** — 市场波动时不恐慌、不被 FOMO 驱使
3. **长期视角** — 用 10 年尺度思考问题

## 自动化规则

**每周三上午 10 点**，cron 自动扫描：
1. 搜索以上信息源的最近更新
2. 每条一句话判断：值不值读？🟢 = 值得 / 🟡 = 还行 / 🔴 = 跳过
3. 🟢 的写摘要到 `每周扫描/`，标注来源+日期

**用户投喂**：发链接/截图/文章 → 按 investment-analysis-protocol 标准分析 → 提炼关键洞见 → 入库到 `你投喂的/` → 特别好的升级到 `提炼入库/`
