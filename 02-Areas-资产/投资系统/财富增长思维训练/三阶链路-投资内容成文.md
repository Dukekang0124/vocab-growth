> 日期：2026-08-08

## ⭐ 最小可验证铁律（2026-08-08 用户确立）

> 用户原话：「以后我们不断输出什么，沉淀什么，要加一条最小可验证——那就市场验证，哪怕只有一个用户看过，尤其是用过，拿到用户真实反馈很重要，也是验证值得不值得做下去的重要因素。」

**任何沉淀/输出，最终要用市场验证来检验。** 不是写完发布就完事：
- 1 个用户看过/用过 = 有效验证（不是"没数据=没意义"）
- 用户真实反馈（阅读/评论/使用/提问）= 检验值不值得做下去的重要因素
- 没有市场验证的沉淀 = 自我假设，可能自嗨
- 验证结果 → 反向决定：继续做/调整/放弃

### 最小可验证在⑫号的落地

| 环节 | 最小验证动作 | 判断 |
|:--|:--|:--|
| 文章发布 | ≥1人阅读/评论/收藏 | 有反馈=有效；0反馈=换表达/换选题 |
| 方法论输出 | 用户实际使用/提问 | 用得上=有效；纯理论=需落地化 |
| 投喂内容分析 | 用户认可/追问 | 有价值=继续；无感=调整方向 |
| 书单/学习计划 | 用户开始读第一本 | 启动了=有效；收藏不读=门槛太高 |

**判断标准：一个用户（哪怕只有苏不倦自己）用过后给的真实反馈，就是方向修正的依据。**

## 三阶链路（⑫号版）

```
第一阶：自主沉淀（基础）—— 本窗口每次交流自动沉淀
  ├─ 投资分析 → OB 投资系统/公司分析/
  ├─ 学习投喂 → 财富增长思维训练/你投喂的/ + 提炼入库/
  ├─ 新方法论 → guru-evaluator评估 → Skill / 观察池
  ├─ 用户纠正 → 记忆
  └─ 判断标准：下次遇同类问题需重新摸索 = 这次就该沉淀

第二阶：打磨沉淀（进化）—— 沉淀的内容打磨成可复用资产
  ├─ 已固化：guru-evaluator Skill / Nischa财富系统总纲 / 中文投资学习路径 / 搞钱书单筛选法
  ├─ 每周碰撞：两个投资概念联动 → 新方法论？（如 Nischa框架×博格指数=收入分配→定投闭环）
  └─ 判断标准：沉淀≠终点，打磨成能复用的东西才算进化

第三阶：自主成文（输出）—— 打磨后的资产写成文章，市场验证
  ├─ 每固化一个投资方法论/Skill → 判断能否成文
  ├─ 能写：方法论型（普适、脱敏）→ 写文章 → 用户发布 → 数据反馈
  ├─ 不能写：私人型（持仓/金额/个人投资决策）→ 只沉淀不成文
  └─ 判断标准：有沉淀+有打磨+有成文+有反馈 = 完整进化环

第四阶：最小可验证（反馈）—— 输出后用市场反馈检验方向 🆕
  ├─ ≥1个用户看过/用过 = 有效验证
  ├─ 真实反馈（阅读/评论/使用/提问）→ 决定继续/调整/放弃
  ├─ 无反馈 ≠ 没意义，是信号：换表达/换选题/换渠道
  └─ 判断标准：验证结果反向优化第一二三阶（循环进化）
```

## 哪些不能成文（私人型 🔴）

| 内容 | 原因 |
|:--|:--|
| 苏不倦具体持仓/金额 | 隐私+风险 |
| 个人投资决策分析 | 涉个人信息 |
| 具体标的研究（个股/ETF分析） | 可能被当荐股 |

## ⑫号成文流程（调用 jiusi-article-writing）

1. 选资产：从"能成文"清单挑一个
2. 脱敏：去掉苏不倦/南昌/具体路径/账号标识
3. 小白视角：不是投资教程，是"我学到了什么+你也能用"
4. 写稿（九思口吻）：痛点开头→方法→例子→行动→落款
5. 自检（写前6问+改稿自检）
6. 封面+配图（按 jiusi-article-writing 流程）
7. 交用户发布 → 数据反馈 → 优化表达 → 反向优化沉淀

## 触发规则

- 每固化一个投资方法论 Skill → 自动判断能否成文（不等用户提醒）
- 用户说"这个写成文章" → 直接走第三阶
- 用户投喂投资内容消化后 → 判断能否成文（方法论型→建议成文）

## 收尾自问（⑫号每次对话）

1. 这次交流我沉淀了吗？→ 落OB/观察池/记忆
2. 沉淀的值得打磨吗？→ 能否升级Skill/方法论
3. 打磨的能成文吗？→ 方法论型→进选题池；私人型→只沉淀
