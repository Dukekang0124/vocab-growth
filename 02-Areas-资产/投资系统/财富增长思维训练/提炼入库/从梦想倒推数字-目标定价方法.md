## 一、这个方法解决什么问题

博格指数投资教你怎么投，FIRE 教你怎么算退休目标——但**没人教你怎么从"我想出国/我想创业/我想不用打工"这些模糊梦想，变成每月该存多少的具体数字。**

Nischa 的框架就是补这个缺的。

## 二、核心公式链

```
梦想 → 定价 → 盈余 → 月存 → 自动化 → 定期审视
```

### 第一步：算盈余（Margin）

```
盈余 = 月总收入 − 必要开支
```

- 必要开支控制在月收入的 **50%-60%**
- 盈余 = 你能用来追目标的钱
- 如果盈余 ≤ 0 → 先减开支或提收入，没盈余就没资格谈目标

> 待业期变体：盈余 = 月存款消耗的负数。目标不是积累，是**减缓消耗**。

### 第二步：为梦想定价

把每个模糊目标变成**精确到千位**的数字：

| 目标类型 | 定价公式 | 示例 |
|:--|:--|:--|
| 大额消费 | 总价 × 首付比 + 冗余（5%-10%） | 买房：房价 × 20% + 税费装修 |
| 过渡期缓冲 | 月开支 × 缓冲月数 | 裸辞/创业：月支 × 12-18个月 |
| 财务独立 | 年开支 × 25（4%法则） | 年花12万 → 目标300万 |
| 能力投资 | 课程费用 + 时间机会成本 | 学技能/考证：学费 + N个月减少的收入 |

**定价原则**：
- 用**现在的购买力**算，不要赌未来工资涨
- 宁高不低——没花完比不够花好
- 多个目标排优先级，不需要同时追

### 第三步：倒推每月必存

```
每月必存 = 目标金额 ÷ 目标月份数
```

**实操**：
1. 排出所有目标的优先级
2. 先追最短期的（通常 1-2 年的），同时兼顾最长期的（退休）
3. 月存总额 ≤ 每月盈余 → OK
4. 月存总额 > 每月盈余 → 要么延长期限，要么砍目标

> 📚 **原版关键约束**：Alex 的盈余 $2,800，但买房（$2,000/月）+ 转型缓冲（$1,458/月）= $3,458 > $2,800。**不可能同时追。** Nischa 原话："it's eventually impossible to pay for everything at the same time." 必须分阶段排优先级——这是整个框架最容易被跳过的一步，也是最重要的一步。

### 第四步：大额消费前问机会成本

**豁免线**：单笔 < 净资产的 **0.01%** → 不纠结，享受。

**超出豁免线的**，问自己三句话：
1. 这笔钱如果不花，能让我离哪个目标近多少？
2. 我选择现在享受，放弃的是什么？
3. 5 年后的我会感谢现在的我选了哪边？

## 三、跟现有 Skill 的衔接

```
Nischa 框架（本方法）
  ↓ 算出每月要存多少
博格指数投资 → 这笔钱放哪里、怎么投
  ↓ 知道怎么投了
FIRE/4%法则 → 投到什么时候可以停
  ↓ 过程中
金钱心理学 → 管住手，不被 FOMO 带偏
```

**一个动作串联四个 Skill**：

> 每月收入到账 → 先抽 X 元到投资账户（Nischa 定价+博格定投） → 剩下的才消费（机会成本思维） → 每年检查目标进度（FIRE 法则） → 管住不追涨杀跌（金钱心理学）

## 四、苏不倦当前可直接用的场景

### 场景1："自媒体收入要达到多少我才不用找工作"

| 变量 | 数字 |
|:--|:--|
| 月必要开支 | 假设 ¥5,000 |
| 安全边际（1.5倍） | ¥7,500 |
| 需要月均稳定自媒体收入 | ≥ **¥7,500** |

倒推：如果当前粉丝 5,500，需要多少粉丝/多少客单价才能稳定月入 7,500？

### 场景2："出国（马来西亚/泰国）需要多少钱"

| 项目 | 估算 |
|:--|:--|
| MM2H 签证费/证明金 | ¥5-10万 |
| 搬家+前3个月生活 | ¥5-8万 |
| 总计缓冲金 | **¥10-18万** |

跟现有存款 50 万的对比 → 够。但前提是**已经有远程收入**，否则存款只出不进。

### 场景3："最坏情况下我还能撑多久"

| 变量 | 数字 |
|:--|:--|
| 当前存款 | ~¥50万 |
| 月开支 | ¥5,000-8,000 |
| 可撑月数 | **62-100个月（5-8年）** |

💡 这个数字很关键——你不是在"快没钱了"的压力下找工作，你有充分的时间挑对的。
