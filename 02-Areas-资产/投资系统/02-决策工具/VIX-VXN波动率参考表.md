# VIX/VXN 波动率参考表

> 用途：判断市场恐慌/乐观状态，辅助定投/抄底节奏

## VIX（标普500恐慌指数）警戒线

```
VIX < 13   → 极度自满（可能憋大招，但别猜顶）
VIX 14-18 → 正常区间（按计划定投，别择时）
VIX 20-25 → 开始紧张（停止加仓，观察）
VIX 25-30 → 恐慌区边缘（准备弹药，分批小买）
VIX > 30  → 恐慌区（历史经验：情绪底，可分批加大买入）
⚠️ VIX单日暴涨>15% → 警惕突发风险（先看发生了什么再动手）
```

## VXN（纳指100恐慌指数）警戒线

VXN 通常比 VIX 高 5-8 个点（科技股波动率溢价）：

```
VXN < 15   → 极度自满
VXN 15-25 → 正常区间（科技股常态）
VXN 25-30 → 开始紧张
VXN 30-40 → 恐慌区边缘
VXN > 40  → 恐慌区（科技股情绪底）
```

## 使用原则

1. **VIX 是情绪体温计，不是买卖信号**——用来理解市场状态，不单独触发交易
2. **抄底逻辑 = 恐慌时买入（VIX>25）**，不是便宜时买入（VIX<15）
3. **定投不需要等恐慌**——按节奏慢慢买，恐慌线是"加码弹药"的触发
4. **防守逻辑 = 突发暴涨（单日>15%）先看发生了什么**，不机械操作
5. **别拿它择时**——博格："波动是费用不是罚款"
