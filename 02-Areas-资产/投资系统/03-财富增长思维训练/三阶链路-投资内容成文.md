# 三阶链路 — 投资内容成文方法论

> 对齐 jiusi-article-writing「自主进化三阶链路」
> ⑫号专属：投资领域内容如何走"沉淀→打磨→成文→市场验证"

## ⭐ 最小可验证铁律（2026-08-08 用户确立）

> 用户原话：以后我们不断输出什么、沉淀什么，要加一条最小可验证——那就市场验证，哪怕只有一个用户看过/用过，拿到用户真实反馈很重要。

- 1 个用户看过/用过 = 有效验证（不是"没数据=没意义"）
- 真实反馈 = 检验值不值得做下去的重要因素
- 没有市场验证的沉淀 = 自我假设，可能自嗨
- 验证结果 → 反向决定：继续做 / 调整 / 放弃

## 四阶链路

```
第一阶：自主沉淀（基础）—— 每次交流自动沉淀
第二阶：打磨沉淀（进化）—— 沉淀打磨成可复用资产
第三阶：自主成文（输出）—— 方法论型写文章，市场验证
第四阶：最小可验证（反馈）—— ≥1 个用户看过/用过 = 有效验证
```

## 哪些能成文（方法论型 ✅）

| 已沉淀资产 | 成文方向 |
|---|---|
| Nischa 4步财务规划法 | 《工资到账30分钟，决定你10年后的钱包》 |
| 还债vs投资三维模型 | 《欠着钱，该先还债还是先投资？》 |
| 中文投资学习路径 | 《普通人学理财，该从哪听起？》 |
| 搞钱书单筛选法 | 《这9本理财书别读了，先查这个》 |

## 哪些不能成文（私人型 🔴）

- 苏不倦具体持仓/金额（隐私+风险）
- 个人投资决策分析（涉个人信息）
- 具体标的研究（可能被当荐股）

## 成文流程

选资产 → 脱敏（去苏不倦/南昌/账号标识）→ 小白视角 → 写稿（痛点开头→方法→例子→行动）→ 自检 → 封面配图 → 发布 → 数据反馈 → 反向优化

## 收尾自问（每次对话）

1. 这次交流我沉淀了吗？→ 落 OB/观察池/记忆
2. 沉淀的值得打磨吗？→ 能否升级 Skill/方法论
3. 打磨的能成文吗？→ 方法论型进选题池；私人型只沉淀
