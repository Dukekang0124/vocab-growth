# 中文投资学习路径 — 从入门到实战的播客路线

> 提炼自：6 档中文财经播客投喂（Rich 推荐清单）

## 为什么需要这个

英文方法论（博格/FIRE/段永平/Nischa）逻辑严谨但缺中文语境"体感"。这 6 档播客补的是：同样的投资原则，用 A 股案例、人民币、中国家庭场景讲出来。

## 三层学习路径

```
第一层：启蒙（建立金钱观 + 基本知识）
  知行小酒馆 → 大方谈钱
第二层：框架（理解周期 + 产业 + 家庭财富）
  面基 → 起朱楼宴宾客
第三层：实战（看别人怎么决策 + 怎么认错）
  三点下班 → 听懂涨声
```

## 每层怎么用

### 第一层：启蒙
| 播客 | 先听什么 | 配合 Skill |
|---|---|---|
| 知行小酒馆 | E204《我人生中的第一个10万》 | Nischa 工资分钱法、金钱心理学 |
| 大方谈钱 | 基金分类/选基/持有 | 博格指数投资（中文实操版） |

### 第二层：框架
| 播客 | 先听什么 | 配合 Skill |
|---|---|---|
| 面基 | E120 周期 + E152 | 博格头指南长期视角 |
| 起朱楼宴宾客 | 第175期公募基金持仓分析 | 段永平"不懂不碰" |

### 第三层：实战
| 播客 | 先听什么 | 配合 Skill |
|---|---|---|
| 三点下班 | S3E24 风险→多元投资 | 金钱心理学"管住手" |
| 听懂涨声 | 二手房那期 | Nischa 机会成本审视 |

## 6 档播客定位速查

| 播客 | 定位 | 判断 |
|---|---|---|
| 知行小酒馆 | 财商启蒙+生活温度 | 🟢 必听 |
| 大方谈钱 | 基金入门+实操 | 🟡 可听 |
| 面基 | 宏观周期+投资框架 | 🟢 必听 |
| 起朱楼宴宾客 | 家庭财富+产业认知 | 🟢 必听 |
| 听懂涨声 | 家庭资产+房产决策 | 🟡 可听 |
| 三点下班 | 投资实战+真实复盘 | 🟢 必听 |

## 对康哥最该优先听的两档

- **面基**：基金经理访谈，补充博格指数投资缺少的"市场温度感"
- **三点下班**：真实亏损复盘，最好的金钱心理学教材
