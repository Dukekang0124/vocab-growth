# 搞钱书单 — 精选精读推荐

> 筛选原则：避开已有 Skill 覆盖的书，只选有真实增量、值得深度阅读的

|---|---|
| 金钱心理学 | psychology-of-money ✅ |
| 穷查理宝典 | munger-mental-models ✅ |

## 二、值得精读的（按优先级）

### 🥇 Tier 1：必读（补现有体系最大盲区）
| 书 | 作者 | 补什么 |
|---|---|---|
| 《投资最重要的事》 | 霍华德·马克斯 | 第二层思维 + 风险认知（现有 Skill 没讲"怎么识别风险"） |
| 《聪明的投资者》 | 格雷厄姆 | 价值投资源头——安全边际、市场先生 |
| 《周期》 | 霍华德·马克斯 | 市场周期规律 |

### 🥈 Tier 2：高价值（反直觉，改变金钱观）
| 书 | 作者 | 补什么 |
|---|---|---|
| 《Die with Zero》 | Bill Perkins | 花钱观颠覆——让钱在人生各阶段产生最大效用 |
| 《稀缺》 | 穆来纳森 | 贫穷心理学——缺的不只是钱是"带宽" |

### 🥉 Tier 3：可选（中文语境/实操）
| 书 | 作者 | 补什么 |
|---|---|---|
| 《投资中最简单的事》 | 邱国鹭 | A股语境价值投资 |
| 《邻家的百万富翁》 | 斯坦利/丹科 | 节俭+积累实证 |
| 《How Not to Invest》 | Barry Ritholtz | 反面清单思维 |

## 三、阅读顺序建议

```
第一阶段（财商+思维）：Die with Zero → 稀缺
第二阶段（价值投资）：聪明的投资者 → 投资最重要的事
第三阶段（周期+实战）：周期 → 投资中最简单的事
可选：邻家的百万富翁 / How Not to Invest
```
