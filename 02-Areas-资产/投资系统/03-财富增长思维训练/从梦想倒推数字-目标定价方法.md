# 从梦想倒推数字 — 目标定价方法

> 提炼自：Nischa "Your Ultimate Financial Plan in 10 minutes"
> 核心公式链：梦想 → 定价 → 盈余 → 月存 → 自动化 → 定期审视

## 这个方法解决什么问题

博格教你怎么投，FIRE 教你怎么算退休目标，但**没人教你怎么从"我想出国/创业/不用打工"这些模糊梦想，变成每月该存多少的具体数字**。Nischa 补的就是这个缺。

## 核心公式链

### 第一步：算盈余（Margin）
```
盈余 = 月总收入 − 必要开支
```
- 必要开支控制在月收入的 50%-60%
- 盈余 ≤ 0 → 先减开支或提收入
- 待业期变体：盈余 = 月存款消耗的负数，目标是减缓消耗

### 第二步：为梦想定价

| 目标类型 | 定价公式 | 示例 |
|---|---|---|
| 大额消费 | 总价 × 首付比 + 冗余（5%-10%） | 买房：房价 × 20% + 税费装修 |
| 过渡期缓冲 | 月开支 × 缓冲月数 | 裸辞/创业：月支 × 12-18 个月 |
| 财务独立 | 年开支 × 25（4%法则） | 年花 12 万 → 目标 300 万 |
| 能力投资 | 课程费用 + 时间机会成本 | 学技能：学费 + N 个月减少收入 |

定价原则：用现在购买力算、宁高不低、多目标排优先级。

### 第三步：倒推每月必存
```
每月必存 = 目标金额 ÷ 目标月份数
```
- 先追最短期的，同时兼顾最长期的
- 月存总额 ≤ 每月盈余 → OK；否则延长期限或砍目标

### 第四步：大额消费前问机会成本
- 豁免线：单笔 < 净资产的 0.01% → 不纠结，享受
- 超出豁免线问三句：不花能离目标近多少？现在享受放弃什么？5 年后的我会感谢哪边？

## 康哥当前可直接用的场景

### 场景1：自媒体收入要达到多少才能不找工作
- 月必要开支假设 ¥5,000，安全边际 1.5 倍 → ¥7,500
- 需要月均稳定自媒体收入 ≥ ¥7,500

### 场景2：出国（马来西亚/泰国）需要多少钱
- MM2H 签证费/证明金 ¥5-10 万 + 搬家前 3 个月生活 ¥5-8 万 → 总计 ¥10-18 万
- 前提：已有远程收入，否则存款只出不进

### 场景3：最坏情况下还能撑多久
- 存款 ~¥50 万，月开支 ¥5,000-8,000 → 可撑 62-100 个月（5-8 年）
- 关键洞察：你不是在"快没钱了"的压力下找工作，你有充分时间挑对的
