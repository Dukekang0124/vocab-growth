## 总路线图

```
【主线】逻辑+表达（深度，必修）→ 产出走 B层桥接（过「英语动作桥接」才出口播）
  ① 超越感觉（批判性思维经典）→ ✅ 已消化（9 skills + 口播选题钩子库）
  ② 学会提问（有五维检查法地基）→ 下一本
  ③ 认知重建书单（超预测/侦察兵心态/反脆弱…）
  ↓ 保证：想得清、说得出、判断准

【英文书线】英语纵深弹药专线（🆕 2026-08-24）→ 产出走 A层（直接出口播，不过闸门）
  定位：「老外书里的英语」选题富矿 + learn in public 人设强化（35岁零基础读原版书）
  选书三标准：①中译本为主+AI翻译兜底读得下去 ②有「老外怎么表达/怎么想」富矿
              ③能出可截图句子卡（每本 ≥5 条 A层选题钩子）
  每本读完 → 独立文件夹 + 钩子库 ≥5 条；引用原句 AI 核对，不虚构
  首本：待康哥点名，或 weread-skills 按书架推荐 3 本供挑

【支线】随心读（广度，随时插入）→ 产出默认 C层（存视频号/小红书弹药库，抖音不发）
  心情不畅 → 心理学/哲学；好奇 → 历史/科学；想读啥从书架挑
```

> 分层出口规则：读什么都可以，出口播走哪条路由 `02-知识库/01-机制与路线/2026-08-24-读书选题分层桥接规则.md` 定（A层英语纵深直出 / B层桥接英语动作 / C层存外拓储备）。
