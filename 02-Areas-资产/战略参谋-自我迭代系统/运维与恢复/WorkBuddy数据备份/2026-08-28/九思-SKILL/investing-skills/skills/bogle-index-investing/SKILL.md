# 博格指数投资（Bogle Index Investing）

> 来源：约翰·博格《The Little Book of Common Sense Investing》
> 一句话：**拥有一切，成本为零，长期持有，什么都不做。**

## 免责声明

本 skill 不构成投资建议、不荐股、不预测涨跌、不做买卖决策。只提供分析框架和决策参考，最终判断由使用者自己做。所有金额/回报率数字均来自原书，不保证当前适用。

## 核心理念（判断任何基金问题前先记住这 5 条）

1. **投资者整体就是市场**：全部投资者作为一个整体必然获得市场平均回报，扣除成本后，战胜市场是负和游戏。你的回报 = 市场回报 − 你支付的费用。
2. **投资回报 vs 投机回报**：股市回报 = 企业回报（股息+盈利增长，长期可预期）+ 投机回报（市盈率变化，不可预测）。长期看企业基本面决定一切。
3. **成本是不败的敌人**：50 年投资期，年成本 2% 的主动基金吃掉 61% 潜在财富。
4. **均值回归**：过去 5 年最好的基金只有 13%-15% 能保持前 20%；最差的会跃升。追明星基金是徒劳。
5. **简约与节俭**：90% 主动基金跑输基准。

## Workflow

### Step 1: 判断这是不是"指数投资适用"的问题

适用：长期（5 年+）资金、想跑赢通胀、不想花时间研究个股。
不适用：3 年内要用的钱、追求短期暴利、想战胜市场（那是投机）。

### Step 2: 资产配置（股债比例）

```
债券比例 ≈ 年龄
股票比例 = 100 − 债券比例
```

| 年龄 | 股票% | 债券% |
|---|---|---|
| 35 | 65 | 35 |
| 40 | 60 | 40 |
| 50 | 50 | 50 |

### Step 3: 选基金（量化阈值，全不满足则排除）

- [ ] 指数基金（被动跟踪，非主动管理）
- [ ] 费用率：股票指数基金 < 0.15%，债券指数基金 < 0.25%
- [ ] 宽基优先（沪深300 / 中证500 / 债券指数），避免单一行业/主题
- [ ] 免佣金、低换手率

### Step 4: 执行（定投 + 持有）

1. 每月固定日期、固定金额自动扣款
2. 红利再投资
3. 不择时、不预测、不折腾

### Step 5: 年度再平衡

股债比例偏离目标 > 5% 时，卖出多的、买入少的（自动实现低买高卖）。

### Step 6: 输出模板

```
【标的评估】
- 是否指数基金：是/否
- 费用率：___%（阈值 <0.15% 股 / <0.25% 债）
- 是否宽基：是/否
- 结论：符合/不符合博格原则

【组合建议】
- 股债比例：___ / ___
- 建议标的：沪深300 + 中证500 + 债券指数
- 再平衡触发线：偏离 >5%
```

## 四大陷阱（识别并警告）

1. ❌ Smart Beta 因子基金 → 高成本伪指数
2. ❌ 频繁交易 ETF → 投机而非投资
3. ❌ 追逐明星基金经理 → 均值回归牺牲品
4. ❌ 找理财顾问选基金 → 顾问平均回报 2.9% vs 自己 6.6%

## Important Notes

- 波动是费用不是罚款——不要因短期波动改变长期计划。
- 定投不需要等"最低点"，按节奏慢慢买。
- 所有历史收益数据来自原书，A 股适用性需自行判断（费用率阈值可放宽到 A 股现实水平，但逻辑不变）。
