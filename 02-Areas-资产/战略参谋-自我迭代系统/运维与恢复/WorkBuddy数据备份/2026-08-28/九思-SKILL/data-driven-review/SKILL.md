# data-driven-review — 数据驱动复盘

> 纲领一句话：**每个判断都要用后台真实数据佐证「目的到底达成没」，好的延续、坏的优化、机制有问题就修正；目的只有一个——不断优化，冲向 1 万粉。**
> 本 skill 不抓数据（交给 `douyin-data-extract`）、不判外拓（交给 `account-strategy-gate`），只干一件事：**把「数据 → 判断 → 动作」这条复盘闭环跑标准，绝不凭印象、绝不用个案归因改口。**

## 闭环图

```
[发完作品 / 复盘某条 / 查粉丝]
        │
        ▼ ① 拉真实数据（douyin-data-extract 兜底，不靠记忆）
[播放 / 赞 / 评 / 藏 / 享 / 吸粉 / 藏播比 / 粉丝数]
        │
        ▼ ② 用数据判定「达成没」（对照三条定论，不看完播率）
[爆款三要素齐吗？收藏涨没？吸粉效率够吗？]
        │
        ▼ ③ 三动作复盘（纲领原文：延续/优化/修机制）
[好的延续成模板 · 坏的精确定位根因 · 机制 bug 改机制文件]
        │
        ▼ ④ 更新粉丝看板 + 写复盘结论
[6743 → 1 万：差 3257 · 月度里程碑达没到]
```

## ② 数据判定（三条定论，别再改口）

### 定论 A：收藏是播放引擎，完播率几乎无关
- 全量 109 条相关系数：收藏 **0.945**、点赞 0.943、分享 0.823、吸粉 0.867、评论 0.805、**完播率仅 0.057**。
- 爆款完播 3.24% vs 扑街 2.85%——**完播率无区分度**。
- 铁律：**盯收藏量 + 藏播比，不看完播率**。2-4% 完播是英语干货内容的正常基线，不是问题、不是瓶颈。

### 定论 B：爆款 = 反常识 × 高频动作 × 可收藏干货，三缺一即扑
- 反常识（钩子拉播放）× 大众高频动作（精准用户）× 可收藏干货（收藏燃料）。
- 动笔前先写清「反常识点 / 高频动作 / 收藏抓手」三行，**写不出不立项**。

### 定论 C：涨粉靠结果承诺，不靠播放
- 播放引擎（收藏·反常识否定）≠ 涨粉引擎（结果承诺）。
- 案例：「千万别瞎学」60.3万播放才 18.9 粉/万；「14天流利说」13.3万播放 58.1粉/万。
- 爆款要**双层设计**：开头反常识否定钩播放 + 结尾结果承诺钩关注。

### 定论 D（2026-08-25 新增）：纯认知升格杀完播、不杀收藏；反常识角度定收藏下限
- 110「问对一个问题」原稿版实测打脸「爆/扑」二分法——它是中间态：角度对（收藏 51、赞播 3.37%）但升格段拖完播（1.66% 全场最低）。
- **把「纯认知必扑」从铁律降级为「升格段杀留存」**：两个引擎正交，别混成一条因果。
  - 播放引擎 = 收藏量（角度对不对）↔ 留存引擎 = 完播率（升格段杀不杀）。
- **判定弃二分法，用三档**：收藏 ≥50 → 角度成立可继续做；收藏 ≥200 → 进收藏引擎；吸粉 ≥10 → 结果承诺起效。

## ③ 三动作复盘（纲领核心，每次固定跑）

| 动作 | 触发条件 | 做什么 |
|:--|:--|:--|
| **好的延续** | 指标超预测线（如收藏/吸粉超预期） | 把可乘法提炼成模板，写进选题库/脚本 SOP，下一条直接复用 |
| **坏的优化** | 指标低于预测线 | 精确到根因（是钩子没反常识？是缺可收藏干货？是中段没短钩？），给一条具体改法，不许"再努力点" |
| **机制修正** | 判断/流程/选题机制本身有 bug | 改机制文件本身（选题卡选品规则、脚本审稿标准、数据口径），不靠下一次"注意点" |

**坏的优化——根因定位速查表（对应已踩坑）：**
- 收藏低 → 没有「可收藏干货」，缺收藏抓手（解法：把干货做成可截图保存的清单/公式）。
- 吸粉低（粉万比 < 15）→ 缺「结果承诺」结尾钩（解法：加"多久/几步/达成什么"的确定结果句）。
- 完播崩（中段流失）→ 深度没"拆碎了喂"，42~142 秒连续讲道理无钩（解法：每 15 秒一个短钩/反问/停顿）。
- 不进池 → 纯认知内容，抖音识别不出目标用户（解法：认知只做「场景锚定」，别脱离英语场景）。

## 铁律

1. **先拉数据再下结论**——没数据就说"待采集"，不凭印象、不用单条个案改口。
2. **判定只看四条定论**（收藏引擎 / 爆款三要素 / 结果承诺涨粉 / 升格杀完播不杀收藏），完播率不作为播放决策依据。
3. **三动作缺一不可**——每次都跑「延续 / 优化 / 修机制」，修机制要落到文件不落嘴。
4. **口径不混**：藏播比 = 藏÷播；收藏率 = 藏÷赞（健康值 >60%）；完播 2-4% 是基线不是问题。
5. **粉丝看板是活文件**——复盘一次更新一次，冲到 1 万前不看板不准收工。
