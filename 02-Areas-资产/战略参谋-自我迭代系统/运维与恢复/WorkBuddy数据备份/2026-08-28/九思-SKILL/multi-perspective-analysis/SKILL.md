# Multi-perspective Analysis 多视角分析

> 来源：《Claude Thinking Bible》拆解 · Thinking Skills Library #6/27

## 能力定位

用多个立场的最强版本审视问题，压制偏见。

## 适用场景

有争议的判断；你已有倾向、担心自己片面时；重大决策前的压力测试。

## 核心思想

强制列反方最强版本（steelman）；区分"想要的结论"与"证据支持的结论"。

## 输入要求

你的初步立场/结论。

## 执行流程

1. 写出你当前的立场。
2. 让 AI 构建**反方的最强论证**（steelman，不是稻草人）。
3. 再引入 2–3 个不同利益相关者的视角。
4. 对比各视角，找出你原立场的薄弱处。
5. 输出修正后的、更稳健的立场。

## 输出结果

各视角最强论证对比 + 你原立场的薄弱点 + 修正后立场。

## 质量检查 Checklist

- [ ] 反方是最强版本而非稻草人？
- [ ] 找到了你原立场至少一个真实薄弱点？
- [ ] 修正后的立场吸收了反方的有效部分？

## 常见错误

把反方写成容易反驳的稻草人；只找支持自己的视角。

## 最佳实践

明确要求："假设你要说服一个聪明人相信我错了，你会怎么论证？"

## 可组合 Skills

→ Decision Making、→ Self-Review、→ Anti-Sycophancy。

## 通用 Prompt 模板

    我的立场：【立场】。
    请做三件事：(1) 构建反对我的最强论证——假设你要说服一个聪明人相信我错了；(2) 给出 2–3 个不同利益相关者会怎么看；(3) 指出我原立场最薄弱的地方，并给出吸收了反方有效部分后、更稳健的修正立场。不要写容易反驳的稻草人版本。
