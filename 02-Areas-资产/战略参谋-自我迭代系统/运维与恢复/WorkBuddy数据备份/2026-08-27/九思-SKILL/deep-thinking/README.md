# 深度思考 Skill

适用于工作与人生中的重要决策、复杂问题分析、观点检验，以及“我需要把这件事真正想清楚”的问题。

它不是把一串思维模型全部套上去，而是采用：

> 固定底座 + 场景路由 + 覆盖检查

先识别真正的问题和关键未知，再选择必要的分析工具，最后检查是否遗漏了会改变结论的视角。

## 能做什么

- 拆出事实、解释、隐含假设和未知信息
- 在需要时只问一个真正会改变结论的问题
- 对重要决策做双向钢人、机会成本、二阶影响、逆向思考等分析
- 对复杂问题做因果拆解，避免把表面症状当成根因
- 识别目标、行动与现实约束之间的矛盾，但不进行羞辱式审问
- 用红队检验攻击初步结论，找出脆弱假设与失败条件
- 信息足够时给出明确判断；信息不足时给出条件化判断和下一步验证动作

## 使用方式

直接提出问题即可，例如：

```text
帮我想清楚：我是否应该接受一份薪资更高、但需要长期异地的升职机会？
```

```text
不要顺着管理层的解释。请分析团队连续三个季度业绩下降，真正原因最可能在哪里。
```

```text
我已经倾向做这个决定。请挑战我的假设，给出最强的反方论证和明确判断。
```

## 工作方式

1. 建立底座：重述真正问题，区分事实、解释、假设和未知。
2. 自动路由：按问题结构调用决策工具或分析工具。
3. 覆盖检查：只补充可能实质性改变结论的视角，不堆砌模型。
4. 收束答案：说明判断、依据、风险或反转条件，以及一个最有杠杆的下一步行动。

当信息不足以支持 A 或 B 时，明确判断可以是“现在不应锁定任何选项”，然后设计对称验证或可逆试验；不会为了回应“直接告诉我”而编造截止时间或强行选边。

## 边界

- 明确要求多专家或多学科角色分析时，应使用“顶级智囊团”等对应 Skill。
- 明确要求由多本书回答、推荐书籍或书籍视角时，应使用 `answer-with-books`。
- 不展示完整内部思维过程。
- 不使用虚构权威身份、伪精确概率或羞辱式表达。
- 医疗、法律、财务、安全以及最新事实问题，仍需要可靠资料或专业意见。

## 文件结构

```text
SKILL.md
agents/
  openai.yaml
references/
  analysis-tools.md
  decision-tools.md
```

`SKILL.md` 负责触发条件、固定底座、路由、覆盖检查和输出契约；两份参考文件分别提供决策与分析工具的细节。

## 安装

下载本仓库中的 Skill 文件，保持上面的目录结构不变，并确保目标 Skill 文件夹的根目录直接包含 `SKILL.md`。

仓库同时提供 `deep-thinking.zip` 时，可直接使用该 ZIP；压缩包根目录同样直接包含 `SKILL.md`。
