# Self-Media Compliance Review（自媒体合规审核）

## 核心规则

在自媒体视频、剪辑、封面、标题、字幕、配音、商品链接或发布文案被视作最终版本之前，运行合规审核。审核是风险控制，不是法律建议。

默认输出语言：中文。

## 审核工作流

### 1. 盘点公开面
列出所有用户可见/可听元素：
- 画面、封面、首帧、标题
- 字幕、配音、BGM
- 贴纸、评论区引导、私信引导
- 商品卡、外链、二维码
- 账号简介

视频需采样：开头 0-5s、主要场景切换、产品/CTA段落、敏感画面、结尾

### 2. 识别内容意图
判断内容类型：教育/娱乐/新闻/产品营销/医疗健康/金融/法律/情感/未成年/动物/暴力/性/公益事件

标记受监管领域：医疗健康、金融投资、法律服务、众筹、彩票博彩、宠物/车辆交易、药品/医疗器械、保健食品、特医食品

### 3. 通用风险检查

| 类别 | 检查项 |
|---|---|
| **权利** | 版权、搬运/二创、第三方水印、肖像/名誉/隐私、商标/专利 |
| **低俗色情** | 裸露、身体聚焦、性暗示、性声音/文字、性笑话 |
| **暴力不适** | 血腥、伤亡、手术、虐待、霸凌、恐怖、排泄物、密集孔洞 |
| **违法有害** | 赌博、传销、管制商品、非法金融、诈骗、危险动作 |
| **营销** | 夸大宣传、无据数据、绝对化用语、虚假权威、价格不一致、非官方渠道 |
| **虚假信息** | 过时事件当新闻、假采访、匿名情感故事、明星谣言、AI生成事故/战争无标注、伪科学 |
| **诱导引流** | 强迫点赞/评论/关注/分享、诅咒/胁迫、虚假福利、未完结剧集、站外引流 |
| **公序良俗** | 歧视、侮辱、扰乱公共秩序、异常关系炒作、家庭暴力、不良婚俗 |
| **制作品质** | 字幕不可读/错位、错误画面比例、黑屏、画面变形、音频断档、音画不同步 |

### 4. 电商扩展检查（带货/挂车/千川时启用）

| 检查项 | 内容 |
|---|---|
| 商品一致性 | 视频展示 vs 详情页：品牌/款式/颜色/形状一致？ |
| 规格一致性 | 配音规格 vs SKU规格：数量/重量/体积/尺寸一致？ |
| 价格一致性 | 配音价格 vs 链接商品价格一致？ |
| 赠品/红包/优惠券 | 条件完整准确？ |
| 功效声明 | 有资质或证据支持？ |
| 素材授权 | 视频/BGM/图片/字体/肖像/品牌资产有授权？ |
| 千川低质素材 | 商品堆砌、卖惨/演戏、图片轮播/大字报、黑边/水印/模糊、主体不清 |
| 受监管品类 | 食品/化妆品/医疗器械/药品/母婴/宠物/金融/教育 — 需资质 |

### 5. 平台引用
按目标平台加载对应规则：
- 抖音：抖音社区自律公约 + 电商规则
- 视频号：微信视频号运营规范
- 小红书：小红书社区规范
- 快手/B站/TikTok：对应平台规则

### 6. 输出格式

```
## 合规审核报告

**审核对象**：[视频/脚本/封面/全包]
**目标平台**：[抖音/视频号/小红书/...]
**审核时间**：[时间]

### 风险汇总
| 风险等级 | 数量 | 说明 |
|---|---|---|
| 🔴 阻断 | N | 必须修改才能发布 |
| 🟡 高风险 | N | 建议修改，有较大违规风险 |
| 🟢 低风险 | N | 可优化，非必须 |

### 详细问题
[逐条列出问题 + 时间戳/位置 + 风险等级 + 修改建议]

### 合规通过项
[列出已检查且无问题的项目]

### 待核验项
[列出因缺少信息无法判断的项目]
```

## 铁律

1. 不猜测平台行为，只基于规则判断
2. 缺证据标记"待核验"，不假定通过
3. 不提供法律建议
4. 审核结论必须可追溯到具体规则条款

## 九思适配说明

此 Skill 融入现有审稿系统，作为 **32+1 维审稿的第 #34 维度（合规检查）**。在 04-内容创作 的审稿流程中，发布前必须跑一遍合规审核。

**融入位置**：04-内容创作 → 审稿流程新增 #34 合规检查
**触发方式**：发布前自动调用；用户说"帮我审核这条"时手动调用
**依赖**：纯文本规则，无需外部 API，可离线使用
