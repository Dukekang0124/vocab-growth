# 链接深度学习与沉淀（Content Deep Dive）

> 康哥连续投喂链接（公众号/小红书/知乎/视频）要求深度学习时的标准工作流。
> 已实战验证 4 次：小红书（张咋啦）、公众号（歪歪小姐）、公众号（Paseo）、选题交接。

## 触发条件

康哥丢来一个链接，说"深度学习""学习下""沉淀""帮我看看"——立即走本流程。
（判断标准：链接 + 学习类动词 = 触发）

## 执行流程（6 步）

### 第 0 步：接活先确认验收标准（Loop 前置，必做）
> 源自 Agent 开发循环（Loop Engineering）：Agent 写完要循环检查、人只掌舵不划桨——前提是**任务布置时就把验收标准写清楚**。九思任何接活都先过这步，不跳过。

接到任意任务（不限链接类），**动手前先对齐"这件事做没做对，看哪几条"**——通用 5 问模板：

1. **交付物**是什么？（文件 / 结论 / 动作 / 不产出）
2. **完成度**做到什么程度算完？（含什么、不含什么）
3. **红线**哪些不能碰？（不改某目录 / 不删 / 不联网 / 不公开等）
4. **裁判**验收由谁判？（康哥拍板 / 客观标准 / 双视角复盘）
5. **沉淀**要不要固化 / 记日志 / 更新索引？

- 简单任务（如改标题）→ 九思直接列 1-2 条验收标准再动手；
- 复杂任务（多步骤）→ 先出计划/清单，康哥确认后再执行。
- 这是"先查后做"与"收尾四查"之间的骨架：**前置定标准 → 执行 → 循环自查 → 交付对照**。

### 第 1 步：先查后做
- 查 `02-知识库/AI学习库/` 是否已沉淀过同类内容，避免重复。

### 第 2 步：抓取完整内容
- WebFetch 链接，提取：标题/作者/公众号/发布时间/全文/核心论点/分节/清单/Prompt原文/表格。
- 若正文抓不全（如小红书视频笔记只有大纲）→ 诚实标注"待补"，不假装完整。

### 第 3 步：深度提炼（核心！深度到极限）
笔记正文按此结构：
1. **核心论点**（一句话版本，先给结论）
2. **内容提炼**（分节结构，关键原文摘录——Prompt/清单/金句原文必须保留）
3. **延伸思考**（结合康哥真实场景：求职/自媒体/英语/产品化/九思OS；有自己的观点，不中立罗列）
4. **行动清单**（可勾选）
5. **待补/风险**（诚实标注抓取缺口、第三方风险）

### 第 4 步：沉淀到 OB
- 落点：`08-九思搭档知识库/02-知识库/`，**按分类落库**（规范见 `02-知识库/00-索引.md`）：
  - 学习笔记（AI/自媒体方法论）→ `AI学习库/` 或 `自媒体学习库/`
  - 机制/路线 → `01-机制与路线/`
  - 工具/资源清单 → `02-工具与资源/`
  - 运维记录 → `03-运维与恢复/`
  - 选题卡 → `04-选题库/`
- 命名：`YYYY-MM-DD-主题-作者.md`
- frontmatter 模板（中文 key，固定结构）：
```yaml
---
标题: <文章标题>
作者: <作者>
公众号: <公众号/平台>
来源: 微信公众号/小红书/知乎...
链接: <原文链接>
采集日期: <YYYY-MM-DD>
形式: 图文文章/视频笔记...
标签: [主题1, 主题2, ...]
---
```

### 第 5 步：开源能力评估落地（可选）
- 文章若介绍开源工具/Skill/MCP → 按 `proactive-solution-finder` 走：工具评估三问（踩中什么麻烦/解决不了什么/适合谁）+ 6 维度评估 → 装/不装明确结论。
- 落地 skill 到 `04-SKILL/`（git clone + 清 .git + 安全审查 P2 确认）。

### 第 6 步：收尾四查 + 展示
- 四查清单：①沉淀了吗 ②固化了吗 ③合并了吗 ④最后一环了吗（present_files）。
- 工作日志追加：`C:\Users\Admin\WorkBuddy\<workspace>\.workbuddy\memory\YYYY-MM-DD.md`。

## 关键原则

1. **深度到极限**：一次打透，不等康哥反问；先给结论再解释。
2. **结合康哥场景**：延伸思考必须落到他的 5 条线（自媒体/求职/英语/投资/产品化），不做空泛总结。
3. **诚实标注**：抓不全就说抓不全（如视频口播），不假装完整。
4. **复用优先**：沉淀不是终点，能固化成机制/skill/选题的都要走"最后一环"。
5. **说人话**：不用"综上所述"，直接给判断和理由。
