# 达尔文进化论投资（Darwin Investing）

> 来源：普拉克·普拉萨德《我从达尔文那里学到的投资知识》（纳兰达资本）
> 三步投资法：**规避重大风险 → 合理价格买入高质量企业 → 永久持有**

## 免责声明

本 skill 不构成投资建议、不荐股、不预测。只提供风险规避与企业质量筛选框架，历史回报数据来自原书，不代表未来。最终判断由使用者自己做。

## 三步投资法

### 第一步：规避重大风险（先学会不亏钱）

进化论基础：动物宁可饿死也不冒险（致命风险优先避免）。

**六类规避清单（命中即排除）**：
- 🚫 骗子经营的企业
- 🚫 困境反转企业（成功概率极低）
- 🚫 高杠杆企业（债务 = 战略灵活性杀手）
- 🚫 并购成瘾的企业（70-90% 并购失败）
- 🚫 快速变化行业的企业
- 🚫 所有者利益不一致的企业

### 第二步：以合理价格买入高质量企业

- [ ] 历史资本回报率（ROCE）> 20%
- [ ] 多层稳健性：长期高 ROCE、分散客户群、零负债+超额现金、深厚壁垒、供应商分散、管理层稳定、行业变化缓慢

**累赘原理（信号识别）**：
- ❌ 虚假信号（成本低）：新闻稿、管理层采访、路演、盈利指引
- ✅ 诚实信号（成本高）：历史财务数据、传闻调研（客户/供应商/竞争对手/前员工）

### 第三步：永久持有

- **间断平衡策略**：平时不动 → 恐慌时大举买入
- 仅三种情况卖出：治理下滑 / 资本配置错误 / 不可逆损害
- 复利两个意外：早期几乎看不到效果；90% 收益来自仅 2% 的交易日——卖出 = 错失一切

## Workflow

### Step 1: 六类风险排查（命中即排除）
### Step 2: ROCE 质量筛选（<20% 排除）
### Step 3: 累赘原理信号甄别（只看诚实信号）
### Step 4: 输出模板

```
【企业评估：___】
□ 六类风险：命中哪条？___
□ ROCE：___%（阈值 >20%）
□ 多层稳健性：满足几条？___
结论：符合/不符合达尔文标准

【持有纪律】
- 平时不动，恐慌时（如 VIX>25）才大举买入
- 卖出只在：治理下滑 / 资本配置错误 / 不可逆损害
```

## Important Notes

- 关键数据（原书）：纳兰达年化回报 20.3%（扣除费用），跑赢印度 Sensex 指数 10.9 个百分点；组合企业 ROCE 中位数 ~42%；买入时往绩市盈率中位数 14.9 倍。
- 与巴菲特价值投资的核心差异：达尔文更强调"永久持有、几乎不卖"，且用历史 ROCE 而非未来 DCF 做筛选。
- 恐慌时买入 = 价值投资者的机会，但需先确认公司基本面没坏（区别于"抄底烂公司"）。
