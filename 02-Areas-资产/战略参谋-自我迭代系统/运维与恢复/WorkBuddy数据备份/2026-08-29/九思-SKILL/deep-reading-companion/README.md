# 深度阅读伙伴 · 快速上手指南

> 你的对话式陪读伙伴。不替你思考，只帮你挖深。

## 一句话启动

任何时候说：
- **"我要读这本书"**
- **"帮我消化这段"**
- **"深度阅读"**
- **"我读了一章，跟你聊聊"**

九思自动进入深度阅读伙伴模式，陪你走完 5 步对话流。

## 5 步对话流（你只需回应，九思带节奏）

```
Step 0 预读激活      → 九思问："你对这主题的已有认知是什么？想解决什么问题？"
Step 1 复述确认      → 九思复述你的理解，等你点头
Step 2 苏格拉底追问  → 四层追问（前提→逻辑→证据→反方）+ 思考钩子 3 问
Step 3 认知偏差扫描  → 九思指出你可能没注意到的思维盲区（不贴标签）
Step 4 多元视角挑战  → 反方最强论证 + 跨领域连接
Step 5 观点成型      → 帮你打磨成平衡判断 + 强制 1 个立即行动
```

## 深度调节（随时喊）

| 你说 | 九思做 |
|---|---|
| "深一点" | 追问更底层假设 |
| "浅一点" | 聚焦核心，跳过细节 |
| "换个角度" | 引入新视角 |
| "过" | 跳过当前问题 |
| "回" | 回到上一步 |
| "结束" / "够了" | 收尾，生成笔记，自动沉淀 OB |

## 产物自动沉淀

每次对话结束，九思自动生成：
- **三栏对照表**（我的理解 / 作者论证逻辑 / 我的个人见解）
- **结构化笔记**（核心论点 / 论据漏洞 / 我的立场 / 跨领域连接 / 立即行动）
- **口播选题钩子**（可选，1-3 条）

自动写入：`02-Areas-资产/九思-记忆库/深度阅读/`

## 底层能力

深度阅读伙伴内部调用 6 个批判性思维 skill：
- `socratic-questioner`（苏格拉底追问）
- `cognition-barriers`（认知障碍扫描）
- `fallacy-spotter`（谬误识别）
- `evidence-evaluator`（证据评价）
- `multi-perspective-analysis`（多元视角）
- `judgment-former`（观点成型）

你无感知它们的存在，只感知九思在跟你对话。

## 不适合什么时候用

- 要快速答案/摘要 → 不用启动，直接问
- 纯情感倾诉 → 先共情，不追问
- 明确说"不用深度阅读模式"
