# WorkBuddy 积分获取与省积分清单

> 康哥专用 · 阿Q整理 · 2026-08-21

## 核心认知（先记住这条）

- 积分是「领」和「赚」出来的，不是「用」出来的——用得越狠，积分越少，不会反过来涨。
- 白嫖能做到「日常深度使用」，但做不到「无限重度使用」。

---

## 一、每日 / 每周 / 每月例行（薅积分）

### 每日
- [ ] 打开客户端 → 左下角头像 → 领取「今日礼包」（签到）

### 每周
- [ ] 连续签到第 7 天，额外领大奖

### 每月
- [ ] 每月 1 号自动发放基础额度（体验版 500 永久积分，自动到账）

### ⭐ 社区发文完整攻略（2026-08-22 查实，多来源交叉验证）

**唯一渠道**：腾讯云开发者社区 `cloud.tencent.com/developer`（右上角"写文章"）。
⚠️ **关键前提**：登录用的微信/手机号必须和 WorkBuddy 客户端**同一个账号**，否则审核过了积分也打不到账。

**奖励标准**：

| 内容类型 | 基础奖励 | 精选额外 | 单篇最高 |
|---|---|---|---|
| 使用心得 / 踩坑记录 | +500 | 无 | 500 |
| 完整实操教程 | +1000 | +2000 | 3000 |
| 水文 / 纯 AI 生成 | 0（审核拒） | — | 0 |

- 月上限 48,000 积分/月（≈16 篇精选教程）；签到另有：前 6 天 100/天、第 7 天 1000，7 天一循环，月约 3000+。

**过审 + 冲精选要点**（编辑判断核心：能不能帮到其他想用 WorkBuddy 的人）：
1. 标题含 **WorkBuddy**，打标签 **#WorkBuddy**（必须有），分类选「人工智能」或「办公效率」
2. 配 **2~5 张真实操作截图**（教程类至少 3 张带界面标识的）
3. 全文 **≥800 字**，基于真实使用场景
4. **不留微信/二维码/外链导流**（会被拒）
5. 最容易过审的三种选题：①完整实操教程（有触发→步骤→截图→结果→踩坑）②踩坑记录（报错截图+排查路径+解法，转化率极高）③效率对比（用前 vs 用后的真实数据表）

## 三、省积分技巧（关键，比薅更重要）

1. **锁 Flash，关 Auto**（最狠的一招）：点击输入栏右下角的模型名（如「Auto ▾」）→ 弹出模型选择面板 → 手动选 **DeepSeek-V4-Flash（x0.06，全平台最低倍率）** → 确认顶部 **Max 模式开关没开**（Max 更强更贵，同任务费用翻近 3 倍）。别用 Auto 默认（它"效果优先"不是"成本优先"，简单问题也可能调 Pro 烧积分）。2026-08-22 查实内置模型倍率：Hy3 限免 / **DeepSeek-V4-Flash x0.06** / DeepSeek-V4-Pro x0.16 / MiniMax-M3 x0.25 / Kimi-K2.6 x0.52 / GLM-5.1 x0.79 / Kimi-K3 x1.62。
   - ⚠️ **Hy3 限免的坑（2026-08-22 实测踩坑）**：Hy3"限时免费"不是无限用——**每人每天有固定免费额度**，撞墙即报 **429（错误码 6004 = 请求频率受限）**，提示"使用量超出频率限制，将于 X 时重置"，等重置窗口自动恢复（康哥 8/22 实测：撞墙后要到 8/23 09:30 才恢复，近一天用不了）。规避：①Hy3 当"限免甜点"用，别死磕单模型，撞墙立刻切 Flash 兜底；②官方建议**每晚 23:00～次日 8:00 错峰**用（资源宽松、额度不易撞）；③高消耗任务分批发，别连续高频猛调（QPS 上限约 10）。免费期到 8/31。
   - **实战数据验证（2026-08-22 真实账单分析）**：129 条请求中 Pro 占 91.9%（2527/2751 积分），Flash 只占 6.5%；Pro 单次均次 31.21 积分，Flash 单次均次 11.90 积分（**Pro 是 Flash 的 2.6 倍**）。切 Flash 直接省 62%。
2. 需求一次说清楚，减少来回追问（追问最烧积分）。
3. 纯查询用 Ask 模式（只读、不动文件，消耗更低）。
4. 优先花快过期的积分（新人礼包 90 天有效期）。
5. 有独显 / 会配环境 → 接本地模型，零积分消耗。

日常办公、写东西、知识管理，这套基本够用不花钱。

## 五、重要提醒

- 以上数字来自社区用户经验帖，非官方承诺，规则会动态调整。
- 最准入口：客户端左下角头像 →「积分中心 / 今日礼包」，以实时规则为准。
- 别照旧帖数字做长期计划；真到重度使用（天天跑视频生成、海量长文档），再考虑标准版 70 元/月。
