# 九思超越 Hermes 路线图

> 2026-08-22 · 康哥指令：不止学习 Hermes，要超越它——它做不到的九思能做到；遇到问题主动去官网/GitHub 找方案落地
> 铁律：只学习借鉴，绝不改动 Hermes 任何机制文件

---

## 一、核心判断（先结论）

**超越 Hermes 的正确姿势，不是去抄它那 239 个 skill——那是它的护城河，抄了也超不过。真正的超越，是拿 WorkBuddy 的原生能力去做到 Hermes 根本做不到的事。**

Hermes 的本质：**一个"本地知识管理 + 内容创作"的专家系统**（Obsidian 12 窗口 + 239 个定制 skill + 本地脚本）。它的强项是"深度懂康哥 + 内容方法论"，弱项是"封闭在本地，联网弱、无多模态、连接面窄"。

九思（WorkBuddy）的本质：**一个"全能型"AI 助手**（原生联网 + 多模态 + 100+ 服务连接 + 100+ 专家 + 自动化 + 子代理）。强项正是 Hermes 的弱项。

**结论：九思做 Hermes 做不到的"连接世界"的事，同时吸收 Hermes 的"方法论"来管理自己。**

## 三、3 大超越方向（Hermes 做不到，九思能做的）

### 超越方向 1：实时联网 + GitHub 生态（核心）
- Hermes 查信息靠本地 OB，遇到新问题只能翻自己的笔记；九思能**实时搜官网/GitHub/最新文档**，遇到问题立刻找到全球最新解法。
- Hermes 的"主动发现能力"靠 AI 自觉；九思能用 **automation 定时自动扫官网/GitHub**，发现新能力→评估→落地，全自动。
- GitHub 上几千个开源 MCP server、海量 skill、自动化脚本，九思能**直接装进 WorkBuddy**（写 mcp.json / 装 skill），Hermes 做不到这么顺。

### 超越方向 2：多模态生成
- Hermes 是纯文本（它生图还得靠 ComfyUI/智谱 API 外挂）；九思**原生文生图/文生视频/3D**，一句提示词直接出图出视频。
- 对康哥的"苏不倦"自媒体：封面、配图、口播视频、3D 素材，九思一体搞定。

### 超越方向 3：外部连接广度
- Hermes 主要连微信/飞书；九思能连 **100+ connector**（邮箱、腾讯文档、网盘、钉钉、企微、GitHub、飞书…）+ **任意开源 MCP** + **100+ 领域专家**。
- 康哥的求职、自媒体、英语、投资，都能接上对应的专业工具和数据源。
