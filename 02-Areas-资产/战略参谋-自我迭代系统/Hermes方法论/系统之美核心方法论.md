# 系统之美 — 系统思考

> 作者：德内拉·梅多斯 | Skill：`systems-thinking-beauty`

## 基础概念

| 概念 | 含义 |
|------|------|
| 存量 | 系统中积累的东西（钱、人、知识） |
| 流量 | 流入和流出（收入/支出、入职/离职） |
| 增强回路(R) | 越强越强，正反馈（复利、口碑传播） |
| 调节回路(B) | 自动纠正，负反馈（恒温器、预算控制） |

## 八大系统陷阱

| 陷阱 | 运营场景 |
|------|------|
| 政策阻力 | 推行新制度，各部门阳奉阴违 |
| 公地悲剧 | 所有人都在薅同一批用户的羊毛 |
| 目标侵蚀 | 「反正也做不到了，下调KPI吧」 |
| 竞争升级 | 价格战、补贴战，两败俱伤 |
| 富者愈富 | 大客户拿走所有资源，小客户被忽视 |
| 转嫁负担 | 用促销维持增长，掩盖产品问题 |
| 规避规则 | 上有政策下有对策 |
| 目标错位 | KPI 实现了，但用户跑了 |

## 十二大杠杆点

**性价比最高的**是 #6 — 信息流结构：让隐藏的信息可见，问题自然解决。

## 一句话

**不要责怪系统中的人，要改变系统本身。**
