# 用数据讲故事 — 数据表达

> 作者：Cole Nussbaumer Knaflic | Skill：`data-storytelling`

## 三要素

每次展示数据前问：对象是谁？想让他们做什么？用什么形式？

## 图表选择速查

| 你要表达什么 | 用什么图 |
|------|------|
| 一个数字 | 大字突出 |
| 精确对比 | 表格 |
| 趋势 | 折线图 |
| 排名 | 水平条形图 |
| 占比 | ❌ 不要饼图 |

## 三步叙事法

```
设定（现状）→ 冲突（变化）→ 解决（建议）
```

## 面试直接用

「上季度我们通过 XX 手段（设定），发现用户留存下降了 15%（冲突），于是我做了 YY 调整，留存恢复到 85%（解决）」
