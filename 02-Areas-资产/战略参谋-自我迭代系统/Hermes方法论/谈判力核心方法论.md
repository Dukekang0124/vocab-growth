# 谈判力 — 原则式谈判

> 作者：罗杰·费希尔、威廉·尤里 | Skill：`principled-negotiation`

## 四要素

| 要素 | 一句话 |
|------|------|
| 人和事分开 | 对事不对人 |
| 利益而非立场 | 问「你为什么想要这个」而非「你要什么」 |
| 创造选择方案 | 不只一个方案，而是多个 |
| 客观标准 | 用数据说话，不靠意志力对决 |

## BATNA — 谈判中最重要的概念

**Best Alternative To a Negotiated Agreement**
如果谈不成，你的最佳备选方案是什么？

BATNA 越强，谈判底气越足。面试前先想好：如果这家不给，你手里还有什么？

## 薪资谈判流程

| 步骤 | 做什么 |
|:--:|------|
| 1 | 算好自己的 BATNA（另一个 offer / 继续找） |
| 2 | 查行业薪资数据（客观标准） |
| 3 | 先让对方出价（不要先亮牌） |
| 4 | 基于数据而非感情谈 |
| 5 | 不只要薪资——培训/假期/职级也是筹码 |
