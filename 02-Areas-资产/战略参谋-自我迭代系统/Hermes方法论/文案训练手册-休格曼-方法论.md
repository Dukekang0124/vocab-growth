# 休格曼文案写作体系

## 一句话总结

**让读者像坐滑梯一样，从第一个字读到最后一个字，然后掏钱。**

这不是文案技巧，是人性洞察。

---

## 核心理念：滑梯效应

```
标题 → 副标题 → 第一句话 → 第二句话 → …… → 掏钱
  ↓        ↓          ↓           ↓              ↓
 抓住     进一步     极短       保持惯性      读者已经在
 注意力   勾引      必须读      无法停止      你的"商店"里
```

- 每一个元素只为一个目的：让读者读下一句
- 读到全文25%，读者就大概率全读完
- 不要在开头谈产品——先让人滑下去

---

## 15条公理

### 关于写作本质
1. **文案写作是一段精神旅程** — 你的全部经历、知识、能力凝结成文字
2. **所有元素只为一个目的：让读者读第一句话** — 标题、图片、副标题，全部服务于这一个目标

### 关于开头
3. **第一句话只为让读者读第二句话** — 开头不卖货，只制造阅读惯性
4. **开头必须创造购买环境** — 像布置一个让他愿意掏钱的房间
5. **让读者不断说"是"** — 前面几句必须是无可反驳的事实

### 关于阅读体验
6. **读者应情不自禁读完全文** — 滑梯效应
7. **打破思维定式** — 别给自己设限，别预设"这不可能"
8. **用好奇心让文案趣味横生** — 种下"好奇的种子"

### 关于销售策略
9. **推销概念，而非产品** — 卖牛排的嗞嗞声，不是卖牛排
10. **酝酿过程决定创意质量** — 写完放一放，让潜意识工作
11. **文案长度 = 足够讲完故事** — 没有太长，只有太无聊
12. **每次沟通都是个人化沟通** — 用"我"和"你"，像写信给朋友
13. **预测并回答用户问题** — 按面对面推销的逻辑顺序排列
14. **用最少文字精确表达** — 初稿都是垃圾，修改才是魔法
15. **卖治愈性产品，不卖预防性** — "解决已有痛苦" ≫ "预防未来问题"

## 写作7步法

1. **成为产品专家** — 深入研究，好创意来自深度了解
2. **了解目标客户** — 谁在买？情感需求是什么？
3. **写标题和副标题** — 标题要短，要有"好奇心缺口"；副标题~20字
4. **自由倾泻初稿** — 不管语法，把所有想法倒出来
5. **编辑精雕** — 删40%字数，保持情感不变
6. **酝酿** — 放一放，散步/做别的事，隔天再看
7. **最后审视** — 总会发现还有要改的

## 三个核心文案模板

### 模板A：抖音口播脚本（60秒）

```
[0-3秒] 钩子
    一句话制造好奇心缺口
    例："学了10年英语还开不了口？问题不在你。"

[3-10秒] 共鸣
    让观众点头说"是我"
    "你是不是买过一堆课、背过几百天单词……还是哑巴英语"

[10-30秒] 故事
    不要讲道理，讲故事
    "我有一个学员叫小芳，英语四级都没过。她用了一个方法……"

[30-45秒] 方案
    概念式推销，不是产品
    "核心就一个：把英语当成工具用，不是知识学"

[45-55秒] 行动号召 + 紧迫感
    "这个方法我整理成课程了。今天前50个下单送……"

[55-60秒] 下次预告
    "下一条我讲具体怎么操作，关注别错过"
```

### 模板B：课程销售长文案

```
标题：制造好奇心缺口（必须让人想点进来）
副标题：20-30字，具体数字，进一步勾引

第一句：极短，5-10字
    "这不对劲。"
    "我被骗了3年。"

第1段：个人故事 → 建立信任和共鸣
第2段：痛点挖掘 → 让读者频频点头"是"
第3段：探索过程 → 怎么找到方案的（制造悬念）
第4段：方案揭秘 → 核心方法论（概念式推销）
第5段：为什么有效 → 技术解释，建立权威
第6段：你能得到什么 → 参与感，想象拥有
第7段：谁在用 → 案例、数字、证言
第8段：为什么现在要买 → 紧迫感+价值证明
第9段：零风险承诺 → 超出预期的保证
结尾：清晰行动指令
```

### 模板C：带货文案（商品卡/详情页/短视频）

```
痛点场景（1句）→ 产品出场 → 
3个核心卖点（数字+场景）→ 
竞品对比 → 价格锚定（原价vs现价）→ 
紧迫感 + 行动号召
```

## 5条编辑铁律

1. **删"那个"** — 删掉所有不必要的连接词
2. **长短句交替** — 制造节奏。短句有力量。像这样。
3. **组合句子** — 两个短句合成一个
4. **删废话** — "非常"、"真的"、"一个"……90%可删
5. **重新排顺序** — 前后对调，效果有时翻倍

> **目标：编辑后减少40%字数，但保持同样的情感和意思。**

## 常见错误

| 错误 | 正确 |
|------|------|
| 开头介绍产品特性 | 开头只做一件事：让人读下去 |
| 长篇大论讲道理 | **讲故事，不讲道理** |
| 一个广告推多个产品 | 一次一个。测试：1款 vs 9款 → 3倍销量差 |
| 初稿当终稿 | 初稿一定是垃圾。修改才是真正的写作 |
| 用理性卖货 | **用情感卖货，用理性让购买合理化** |
| 隐瞒产品缺点 | 主动暴露小缺点 → 信任 → 大卖 |
| 自己觉得烦了就换 | 用数据！销量下滑才换 |
| 用大词显专业 | 用简单词。每个人懂的词影响力最大 |
| 预防性定位 | 定位成"治愈已有痛苦" |
| 结尾没紧迫感 | 必须给"现在就要买"的理由 |

## 英语内容带货实战指南

### 概念式推销对照

| 不要卖 | 要卖 |
|--------|------|
| 英语课程 | "开口说英语的自信" |
| 词汇量/语法 | "30天听懂美剧的自由" |
| 学习方法 | "不背单词也能流利说的秘密" |
| 课程大纲 | "从哑巴英语到能用英语吵架" |

### 治愈性定位公式

- ❌ "学好英语能帮你找到好工作" ← 预防性，无效
- ✅ "学了10年还是哑巴英语？" ← 治愈已有痛苦，有效

### 口播开头（休格曼式短句）

- "英语学不好，不是你的错。"
- "我被骗了5年。"
- "一个反常识的英语学习方法。"
- "你的英语老师不会告诉你这个。"

### 好奇的种子（每段结尾）

- "但真正让我开窍的，是这个反常识的发现……"
- "接下来我要说的，会颠覆你的认知。"
- "这个方法我只在学员群里分享过。"
- "答案很简单，但你绝对想不到。"

### 具体数字

- "347个学员，平均21天开口说" ≫ "很多学员都说好"
- "每天只需17分钟" ≫ "每天花点时间"
- "92%的学员在30天内完成了第一次英语对话"

## 快速检查清单

写完后逐条对照：

- [ ] 标题制造了好奇心吗？读者不可能不点进来？
- [ ] 第一句话 ≤ 15字？
- [ ] 开头3句能让读者点头"是"吗？
- [ ] 用"我"和"你"了吗？像在跟一个朋友聊天？
- [ ] 每一段结尾有"必须继续读"的理由吗？
- [ ] 卖的是概念而不是产品吗？
- [ ] 数字具体吗？
- [ ] 主动暴露了一个小缺点吗？
- [ ] 结尾有"现在就要买"的理由吗？
- [ ] 删掉40%的废话后，意思和情感还在吗？

## 一句话测试

> **把你的标题/开头念给一个朋友听。如果他第一反应是"然后呢？"——你就成功了。如果他问"这说的啥？"——重写。**
