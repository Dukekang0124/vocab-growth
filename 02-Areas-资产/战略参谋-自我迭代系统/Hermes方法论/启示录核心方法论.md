# 启示录 — 产品方法论

> 作者：马蒂·卡根 | Skill：`inspired-product-methodology`

## 好产品的三角

```
价值 ── 用户愿意用
可行性 ── 技术上能做
可用性 ── 用户能用得起来
```

## 产品经理的职责边界

| 不是 | 是 |
|------|------|
| 不是项目经理 | 定义产品方向 |
| 不是设计师 | 确保产品有价值 |
| 不是工程师 | 理解技术可行性 |

## 四条核心原则

1. 产品成功靠团队，不靠个人
2. 技术驱动，而非需求文档驱动
3. 高保真原型比需求文档有效 100 倍
4. 尽早频繁验证，而不是最后验收

## 传教士 vs 雇佣兵

- 雇佣兵：完成任务，领工资
- 传教士：对产品有信念，想把事情做好

## 作为 AI 产品运营

你的位置是产品和用户之间的桥梁。运营来自产品，产品为运营铺路。理解了产品经理怎么想，你才知道怎么跟产品团队配合。
