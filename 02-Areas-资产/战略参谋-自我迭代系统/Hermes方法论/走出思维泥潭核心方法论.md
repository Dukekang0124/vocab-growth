# 走出思维泥潭 — 创新思维训练

> Skill：`breaking-thinking-mud`

## PIG In MuD 六步创新法

| 步骤 | 做什么 |
|:--:|------|
| **P**hrase | 把模糊困扰变成可操作的问题 |
| **I**dentify | 识别并跳出你的认知框架 |
| **G**enerate | 用类比/反转/重组产生新想法 |
| **I**ncubate | 放松，让潜意识工作 |
| **M**eld | 用证伪思维验证方案 |
| **D**isseminate | 用引爆点法则传播 |

## 5 种认知偏见

情境偏见 → 锚定偏见 → 固着偏见 → 预期偏见 → 后视偏见

每个都有对应的克服方法。
