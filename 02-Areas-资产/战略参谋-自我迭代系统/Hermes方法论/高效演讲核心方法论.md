# 高效演讲 — 斯坦福沟通课

> Skill：`effective-presentation`

## 三大支柱

| 支柱 | 占比 | 说明 |
|------|:--:|------|
| 内容 | 7% | 说什么是次要的 |
| 风格 | 38% | 声音、肢体、节奏 |
| 状态 | 55% | 你的能量和信念感 |

## 面试自我介绍（1-3 分钟）

```
坡道 30s → 我是谁 + 一句话抓住注意力
发现 3点 → 用 STAR 法讲 3 个关键经历
甜点 30s → 总结 + 表达对岗位的热情
```

## 职场汇报结构

1. 结论先行（高层没耐心听推导）
2. 三个要点（不超过 3 个）
3. 每个要点 = 数据 + 故事
4. 结尾：下一步行动
