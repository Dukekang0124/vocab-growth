# 新书速查 — 第6批

## 写作法宝（William Zinsser）
- 简洁 = 剥掉杂物；写作就是改写
- 括号法砍赘语、朗读法找不顺
- 你的短视频脚本直接受益

## 深度说服（梁秋阳）
- 1-3-5 法则：1个核心观点 → 3个支撑理由 → 5个具体例子
- 拉波波特法则：复述对方观点 → 列出同意之处 → 再批判
- 受身法化解质疑

## 情绪价值（蔡钰）
- 产品价值 = 功能价值 + 情绪价值 + 资产价值
- 安全感/新鲜感/价值感三板斧
- 内容创作的新维度

## 一人企业（保罗·贾维斯）
- 定义「足够」而非「更大」
- 找到小众群体 → MVP 先推出 → 建立 SOP 系统
- 你走的就是这条路
