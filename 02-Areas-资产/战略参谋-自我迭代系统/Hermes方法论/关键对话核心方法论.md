# 关键对话 — 高压沟通

> Skill：`crucial-conversations`

## 什么是关键对话

三个特征同时出现时：
- 高风险 🎯
- 不同意见 💬
- 强烈情绪 🔥

## STATE 法（表达自己）

| 步骤 | 做什么 |
|:--:|------|
| **S**hare | 分享事实（不说故事） |
| **T**ell | 说出你的想法 |
| **A**sk | 征求对方看法 |
| **T**entative | 试探性表达，不绝对 |
| **E**ncourage | 鼓励对方说真话 |

## AMPP 法（倾听对方）

| 步骤 | 做什么 |
|:--:|------|
| **A**sk | 主动询问 |
| **M**irror | 复述对方的话 |
| **P**araphrase | 用自己的话重新说 |
| **P**rime | 替对方说出他们可能没说出口的 |

## 面试直接套用

**薪资谈判：** 先分享行业数据（事实），再说期望（想法），问对方看法，不把话说死

**被问缺点：** 说一个真实缺点 → 你在怎么改进 → 问面试官怎么看

**沉默或暴力信号：** 一旦发现气氛不对，立刻拉回「安全氛围」——道歉或对比法
