# 精益创业2.0 — 核心方法论

> 作者：埃里克·莱斯 | Skill：`lean-startup-2-0`

## 核心循环

```
构建 → 测量 → 学习 → 再构建（循环迭代）
```

不做完美的产品，用最快速度做出能测试的东西，看数据，学经验，再决定继续还是转向。

## MVP 六种类型（非技术人员也能做）

| 类型 | 怎么做 | 适合场景 |
|------|------|------|
| 纸板原型 | 手绘界面，让人点击 | 验证产品概念 |
| 人工服务 | 自己手动完成「自动化」 | 测试需求是否存在 |
| 着陆页 | 一个介绍页面 + 注册按钮 | 测市场兴趣 |
| 视频演示 | 录一段产品介绍视频 | 预售验证 |
| 推销式 | 面对面跟潜在用户聊 | 深度用户研究 |
| 模拟体验 | 用现有工具拼出一个体验 | 快速方案验证 |

## 三大增长引擎

| 引擎 | 公式 | 关键指标 |
|------|------|------|
| 黏性引擎 | 留存 > 流失 | 次日/7日/30日留存率 |
| 付费引擎 | LTV > CAC | 获客成本 vs 用户终身价值 |
| 病毒引擎 | 使用 = 传播 | 病毒系数 > 1 |

## 关键决策：转型 vs 坚守

定期开「转型/坚守会议」，用数据判断：现在这条路是对的，还是需要换方向？
