# 噪声 — 决策的隐形杀手

> 作者：丹尼尔·卡尼曼等 | Skill：`noise-reduction`

## 偏误 vs 噪声

| | 偏误 | 噪声 |
|------|------|------|
| 方向 | 系统性地歪向一边 | 随机分散 |
| 可见性 | 容易被发现 | 隐藏的，难察觉 |
| 谁更严重 | 在某些情况下 | 大多数情况下噪声 > 偏误 |

## 三种噪声

| 类型 | 一句话 |
|------|------|
| 水平噪声 | 不同人判断标准不同（某法官严，某法官松） |
| 模式噪声 | 同一人对不同案例反应模式不同 |
| 情境噪声 | 同一人不同时间判断不同（心情/天气影响） |

## 核心公式

```
总误差 = 偏误² + 噪声²
```

## 决策卫生六原则

1. **准确性 > 个性** — 标准化胜过直觉
2. **外部视角** — 先看基准数据，再看具体
3. **结构化分解** — 把复杂判断拆成独立维度
4. **延迟直觉** — 先收集信息，最后才做整体判断
5. **独立汇总** — 多人独立判断后汇总
6. **相对量表** — 用比较而非绝对打分
