# 人月神话 — 项目管理经典

> 作者：弗雷德里克·布鲁克斯 | Skill：`mythical-man-month`

## 核心悖论

**向延误的软件项目加人，只会让它更延误。**

原因：新人需要培训（时间）+ 沟通成本指数增长 n(n-1)/2

## 关键概念

| 概念 | 一句话 |
|------|------|
| 第二系统效应 | 第二个版本最危险——你什么都想加进去 |
| 概念完整性 | 一个产品只能有一个人说了算 |
| 没有银弹 | 不存在能一夜解决所有问题的技术 |

## 时间分配法则

```
1/3 规划 → 1/6 编码 → 1/4 测试 → 1/4 系统测试
```

大多数项目把 90% 时间花在编码上，这是错的。

## 对你（AI 项目经理方向）

面试时如果有人问你「项目延期怎么办」，别答「加班」，答「Brooks 法则——加人会因为沟通成本让项目更慢。我会先诊断根因，然后重新排优先级。」
