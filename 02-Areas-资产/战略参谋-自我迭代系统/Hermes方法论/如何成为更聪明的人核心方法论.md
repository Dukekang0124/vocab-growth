# 如何成为更聪明的人 — 敏捷思维

> 作者：布莱恩·格里瑟姆 | Skill：`agile-thinking`

## 敏捷思维三阶段

| 阶段 | 做什么 |
|:--:|------|
| 1. 概念思考 | 分析概念 → 化整为零 → 揭示模式 → 重新整合 → 创造新概念 |
| 2. 创新思考 | 结构化提问、多视角分析、因果分析、类比法、四大突破策略 |
| 3. 做出决定 | 七步决策法、成本收益分析、风险评估、表格分析、捉对比较 |

## 与思考快与慢的互补

| 思考快与慢 | 如何成为更聪明的人 |
|------|------|
| 识别偏误 | 教你怎么破局 |
| 系统1/系统2 | 元认知 + 反直觉思考 |
| 知道哪里会错 | 知道怎么做得更好 |

## 核心洞见

**独立思考的本质不是批判别人，而是创造新的概念。**
