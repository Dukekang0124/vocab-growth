# 好战略，坏战略 — 核心方法论

> 作者：理查德·鲁梅尔特 | Skill：`good-strategy-bad-strategy`

## 好战略的三要素

1. **诊断** — 找到真正的问题是什么（不是表面症状）
2. **指导方针** — 处理问题的整体思路（不写成具体动作）
3. **连贯行动** — 彼此支撑、互不矛盾的一组动作

## 坏战略的四个标志

| 标志 | 例子 |
|------|------|
| 空话 | 「我们要成为行业领导者」 |
| 回避挑战 | 不敢说真正的问题在哪 |
| 目标当战略 | 把「营收翻倍」当战略 |
| 糟糕的战略目标 | 列一堆不相关的 KPI |

## 症结框架

> 在众多挑战中，找到**既极其重要又可解决**的那个，集中所有资源攻克。

收集 → 分类 → 筛选 → 聚焦 → 攻克

## 一句话

**战略不是你要做什么，而是你决定不做什么。**
