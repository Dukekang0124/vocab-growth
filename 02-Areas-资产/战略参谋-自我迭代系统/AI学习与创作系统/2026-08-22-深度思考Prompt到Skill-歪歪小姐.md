# 深度思考 Prompt → Skill：先判断问题类型，再选择思考工具

> 来源：公众号「歪歪小姐的Ai进化岛」2026-08-18。
> 核心：把「双向钢人」等一批深度思考 Prompt，做成了一个**先判断问题结构、再自动选择思考工具**的三层 Skill。
> 本文 = 文章深度提炼 + 关键 Prompt 原文 + 九思延伸思考 + 落地记录（已装进九思地盘）。

## 一、文章核心论点（一句话）

> **先判断这是什么问题，再决定应该怎么想。**

AI 给错一个事实，我们还有机会发现；但如果 AI 接受了一个**错误前提**，再沿着它给出一份逻辑完整、表达专业、又很符合你期待的答案，反而更危险——尤其是在重要决策时。

我们需要的，不是永远赞同自己的 AI，也不是为了显示独立而处处反驳的 AI，而是一个**先停一下、检查问题、挑战假设、寻找反证，最后仍愿意给出明确判断**的 AI。

## 二、起点：卡兹克的「双向钢人」Prompt

### 背景逻辑

- **稻草人谬误（straw man）**：把对方观点扭曲成更蠢、更极端、更容易攻击的版本。例：你说"这手机有点贵"，对方回"懂了，你就是看不起国产手机"。
- **钢人论证（steelman）**：反过来，先把一个观点补充到最完整、最合理、最难反驳的状态，再开始判断。
- **双向钢人**：不只强化你的观点，还强化反对你的观点。双方都不能靠歪曲对方取胜时，真正的分歧才会露出来。

### 关键 Prompt 原文（可直接复用）

```
先别急着回答，也别默认我已经把问题想清楚。
请先对这个问题做一次详细思考的"双向钢人论证"：

1. 用最完整、最有力的方式，重述我真正想解决的问题。
2. 使用钢人论证法分别给出支持我当前想法、以及反对它的最强论证。
3. 找出双方真正的分歧，以及最可能改变结论的关键变量。
4. 只问我一个最关键的问题。等我回答后，再给出明确判断、理由和下一步行动。

我的问题是：[粘贴你的问题]
```

### 为什么「先让 AI 不要回答」这么关键

不是让 AI 故意拖延，而是阻止它**在检查问题之前，就已经开始替你证明你的判断**。

典型场景：你问"团队业绩下滑，是不是员工执行力出了问题？"AI 可能马上开始设计考核方案，却没先检查问题到底出在员工、产品、市场、渠道，还是管理层自己的判断。

## 三、从「一段 Prompt」到「三层 Skill」

作者发现：光有双向钢人不够。不同问题需要不同工具——

| 场景 | 适合的工具 |
|------|-----------|
| 已有明显立场的二选一 | 双向钢人 |
| 问"为什么会这样" | 因果拆解 |
| 攻击一个看似正确的结论 | 红队检验 |
| 比较不同方案的代价和后果 | 决策透镜 |

真正麻烦的是：面对具体问题，我们往往**不知道该用哪一种**。所以作者不追求更长更全的万能 Prompt，而是做了一个**先判断问题结构、再自动选工具**的 Skill。

### 三层架构

**① 固定底座（无论问什么都要先做）**
- 区分事实 / 解释 / 假设 / 未知信息
- 重新界定真正要解决的问题
- 找出最可能改变结论的变量
- 只有某个缺失信息真的会改变方向时，才追问，且**一次只问一个最关键的问题**

**② 场景路由（按问题结构选工具）**
| 问题结构 | 调用工具 |
|----------|---------|
| 在多个选项中做选择 | 双向钢人 + 决策透镜 |
| 问"为什么会发生" | 假设澄清 + 因果拆解 |
| 已形成一个结论 | 红队检验，主动找推翻结论的证据 |
| 需要寻找策略 | 多路径探索，不被 A/B 两选项困住 |
| 目标与投入明显不一致 | 现实校准（但不用羞辱式话术） |

**③ 覆盖检查（形成初步判断后）**
- 有没有遗漏会推翻问题定义的假设？
- 有没有更强的反方或第三条路径？
- 有没有把表面症状误认为真正原因？
- 有没有忽略机会成本、二阶影响、不可逆风险？

> 自动路由不是每次把所有方法都用上，恰恰相反——**是为了减少无效思考，只保留真正可能改变结论的部分**。

## 四、三个 Skill 的边界（别做成大杂烩）

作者明确拒绝把「深度思考 / 世界大师智囊团 / 以书作答」三个 Skill 合成一个万能 Skill：

| Skill | 定位 | 一句话 |
|-------|------|--------|
| **深度思考** | 处理具体决策、判断、复杂问题 | 把一个**问题钻深** |
| **世界大师智囊团** | 从不同专家、学科、立场观察同一问题 | 把一个**问题看宽** |
| **以书作答** | 人生/工作/关系/价值观困境 | 让问题进入**更长的思想脉络** |

它们可以组合，但不应互相吞掉。合在一起会变成"看起来什么都有"的大杂烩，用户真正的问题反而被埋掉。

## 五、经典案例：同样是辞职，问题并不相同

| 提问者 | 真实问题类型 | 正确工具 |
|--------|-------------|---------|
| 第一个人："工作稳定但没成长，新机会收入高但风险大，留还是走？" | **选择问题** | 双向钢人 + 机会成本 + 可逆性 |
| 第二个人："我总想辞职，但认真想又觉得没那么糟，为什么反复？" | **因果问题** | 因果拆解（念头的时间/触发/模式） |
| 第三个人："我已决定辞职，帮我查查还有哪些风险。" | **观点检验** | 红队检验（高估新机会？现金够？离职能否解决？） |

> 如果只用一段固定 Prompt，AI 很可能对三个问题都输出一份看似全面的"辞职利弊分析"。
> 真正有用的深度思考，不是把每个问题都分析得更长，而是**先识别：用户现在要回答的问题，真的是最该解决的问题吗？**

## 六、九思的延伸思考（对接康哥场景）

### 1. 这个 Skill 对康哥的 4 个真实用途

| 康哥场景 | 怎么用 deep-thinking |
|----------|---------------------|
| **求职决策** | "要不要接这份 8-13K 远程岗？" → 双向钢人比较，找出反转变量（是不是又用"稳定"掩盖了"不敢冒险"） |
| **自媒体选题** | "苏不倦下一个口播做哪个方向？" → 多路径探索，别被"做 or 不做"困住 |
| **英语产品化** | "四阶段课程阶梯，先推哪个价位？" → 决策透镜（机会成本 + 二阶影响 + 激励） |
| **九思OS机制设计** | "要不要新建某个机制？" → 红队检验，主动找这个机制会失败的理由 |

### 2. 它和康哥「先查后做」铁律是同一件事

康哥给九思定的铁律是「接任务第 0 步先查后做，能复用绝不重造」。这个 Skill 的「固定底座」本质一模一样：**先别急着给答案，先搞清楚这是不是真问题、已知什么、未知什么**。区别在于，康哥的铁律管"做事"，这个 Skill 管"想事"——两条合起来才是完整的"先判断、再行动"。

### 3. 它正中康哥「讨厌和稀泥」的偏好

康哥明确反感"各有利弊""视情况而定"这种模棱两可。这个 Skill 的「形成答案」环节要求：**信息够就给明确判断 + 反转条件 + 下一步；信息不够就明说"暂不锁定选项"，给出拿证据的动作**。既不一刀切，也不和稀泥——完全对味。

### 4. 边界意识：三个 Skill 别混

文章提醒：**别把这些揉成一个万能 skill**。各自独立、按需调用，才不烂成一锅。九思现已落地完整三件套：`deep-thinking`（钻深）+ `multi-perspective-analysis`（看宽）+ `answer-with-books`（进脉络），另有 `weread-skills`（微信读书，可作为 answer-with-books 的素材源）。

## 七、落地记录（已完成 · 三件套齐）

### 已落地三个思维 Skill（均位于 `08-九思搭档知识库/04-SKILL/`）

| Skill | 目录 | 定位 | 安全审查 |
|-------|------|------|---------|
| deep-thinking | `deep-thinking/` | **钻深**：具体决策/判断/复杂问题 | P2 通过 |
| multi-perspective-analysis | `multi-perspective-analysis/` | **看宽**：多立场最强版本审视（≈世界大师智囊团） | P2 通过 |
| answer-with-books | `answer-with-books/` | **进脉络**：2-3 本互补书回答人生/价值/关系问题 | P2 通过 |

### deep-thinking（钻深）
- 结构：`SKILL.md` + `agents/openai.yaml` + `references/{analysis-tools,decision-tools}.md`
- 用法：直接提问即可，例如——
  - "帮我想清楚：我是否应该接受一份薪资更高、但需要长期异地的升职机会？"
  - "不要顺着管理层的解释。请分析团队连续三个季度业绩下降，真正原因最可能在哪里。"
  - "我已经倾向做这个决定。请挑战我的假设，给出最强的反方论证和明确判断。"

### multi-perspective-analysis（看宽 · 世界大师智囊团的替代）
- 结构：单文件 `SKILL.md`
- 说明：作者**未公开独立的「世界大师智囊团」仓库**，本 skill 是其功能最接近的替代（多立场最强版本 + 2-3 个利益相关者视角）。
- 用法：给出你的立场，它构建反方最强论证 + 利益相关者视角，找出你原立场的薄弱处，输出修正后立场。

### answer-with-books（进脉络 · 以书作答）
- 结构：`SKILL.md` + `agents/openai.yaml` + `references/{distillation-method,output-contract,situation-mode}.md`
- 用法：讲一段具体困扰或人生问题，它推荐 2-3 本互补书分别回答，不强行调和分歧。

### 三件套边界
- 明确要"多专家/多学科/多视角" → 用 multi-perspective-analysis
- 明确要"书籍视角/以书作答" → 用 answer-with-books
- 医疗/法律/财务/安全 → 三个 skill 都要求先核验事实，分析不替代专业意见。
