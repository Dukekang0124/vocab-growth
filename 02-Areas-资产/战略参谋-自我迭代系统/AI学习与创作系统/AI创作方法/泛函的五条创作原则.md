# 泛函的五条创作原则

## 五条原则

| 原则 | 说明 |
|---|---|
| 1. 直奔主题 | 每句话都有 take-away，从第一句到最后一句话 |
| 2. 读者是聪明人 | 不反复强调同一观点，不啰嗦 |
| 3. 帮读者做决策 | 内容价值 = 背景信息 + 新选项 + 评估收益与代价。知识不改命，决策累加才改命 |
| 4. 情绪是调味料 | 不是主食材。干货优先，情绪辅助吸收。深度内容传播力天然弱于情感化表达——但这不是放弃干货的理由，是找到两者的配比 |
| 5. 信息效率第一 | 假设读者随时离开。标题=核心，第一段=精华，最有价值的东西永远前置 |

## 跟 AI 的关系

泛函把这些原则写进了常用 AI 产品的 reply rules——用 AI 固化创作标准。
