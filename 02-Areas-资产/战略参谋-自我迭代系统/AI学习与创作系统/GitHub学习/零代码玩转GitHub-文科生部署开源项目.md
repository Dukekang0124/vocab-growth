# 零代码玩转 GitHub：文科生部署开源项目

## 核心方法

> 全程不记代码命令，AI 生成指令 → 复制粘贴执行。你只需要做「指令搬运工」+「截图反馈者」。

## 实操 SOP

| 步骤 | 做什么 |
|---|---|
| 1 | GitHub 搜索目标仓库，截图发给 AI |
| 2 | 告诉 AI「选择指定方案，一步步教我」 |
| 3 | AI 输出一步 → 你做一步 → 截图反馈 → AI 输出下一步 |
| 4 | 遇到报错直接截图给 AI，不自己排查 |
| 5 | AI 输出多步时，说「只告诉我下一步」拆解任务 |

## 核心原则

- **截图是通用语言**：看不懂就截图，AI 通过图片理解你的当前状态
- **不跳步不猜**：每一步做完再要下一步，不自己发挥
- **账号缺失直接说**：没有 Claude Code？直接告诉 AI，它会给你替代方案

## GitHub 基础认知

### 核心界面（新手只需这6个）

| 模块 | 作用 | 一句话 |
|---|---|---|
| Repository | 项目存储容器 | 每个链接是一个独立项目 |
| README | 项目说明书 | 新手了解项目的第一入口 |
| Star | 收藏+人气指标 | 越高越靠谱：1000+成熟，10000+标杆 |
| Issue | 公开评论区 | 搜报错、看踩坑、找官方回复 |
| Fork | 一键拷贝 | 复制到自己的仓库随意改 |
| Watch | 订阅通知 | 开启后接收项目更新提醒 |

### 四种找项目方法

| 方法 | 怎么做 |
|---|---|
| 英文关键词 | AI 翻译需求→搜英文→按 Most Stars 排序 |
| Explore 板块 | GitHub 每日热门榜 |
| Trending 榜单 | 实时热门项目 |
| AI 替你找 | 「帮我找热门的 XXX GitHub 项目并附链接」 |

### 筛选标准

- ⭐ 1000 以下 = 小众早期 / 1000-10000 = 成熟靠谱 / 10000+ = 行业标杆
- 🕐 最近更新超过 1 年 → 大概率已死
- 💬 Issue 区作者回复积极 → 后续遇到问题有保障
- 📖 README 逻辑清晰 → 项目质量不会差

### Fork + AI：从用工具到做产品

> Fork（复制）目标项目到自己账号 → 把项目链接发给 AI → AI 基于现有框架给出精准修改方案。比让 AI 从零写代码，改动精准度大幅提升、出错率显著降低。
