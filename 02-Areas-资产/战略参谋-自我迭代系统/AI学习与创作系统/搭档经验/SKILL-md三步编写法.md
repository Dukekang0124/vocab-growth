# SKILL.md 三步编写法

## Skill 是什么

> Skill = 给 AI 的「专属工作手册」。AI 自动识别触发时机，按手册完成多步推理和跨工具调用。

## 零代码生成思路

> 不上手写 SKILL.md 也可以：通过互动选择题引导用户梳理需求 → AI 自动生成全套 Skill 文件 + 测试用例验证效果。以后做新 Skill 先给你一套选择题，确定需求再动笔。

| 步骤 | 做什么 | 关键 |
|---|---|---|
| **1. 头部元信息** | `description` 字段尽可能详细——描述越丰富，AI 匹配越准 | 不要只写短句定义 |
| **2. 核心规则正文** | 用自然语言定义角色、输出格式、语气、内容禁忌 | 不需要代码，纯描述 |
| **3. 示例引导** | 给 1 组「输入→输出」样例 | 文字规则容易偏差，样例最直观 |

## 跟已有笔记的关系（2026-07-18 验证）

7 个自建 Skill 全部遵循三步编写法：

| 步骤 | 落地 | 状态 |
|---|---|---|
| 1. 头部元信息 | 所有 Skill description 详细描述触发场景+维度 | ✅ |
| 2. 核心规则正文 | 自然语言定义角色/输出格式/禁忌 | ✅ |
| 3. 示例引导 | oral-script-review 有输出示例，其余以规则+表格替代 | 🟡 部分 |

> 零代码生成思路（互动选择题→自动生成）还没跑过。下次做新 Skill 先用这个方式试。
