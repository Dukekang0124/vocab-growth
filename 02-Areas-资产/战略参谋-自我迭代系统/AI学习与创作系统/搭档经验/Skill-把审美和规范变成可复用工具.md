# Skill = 把审美和规范变成可复用的工具

## 核心观点

你觉得什么是对的、好的，不要只停留在感觉——**把它变成可复用、可传递的东西。**

张咋啦的原话：每个 Skill 都是一个观点。Follow Builders Skills 背后的观点就是「Follow Builders, not Influencers」。

## 苏不倦已有的 Skill（2026-07-18 更新）

| Skill | 形式 | 对应观点 |
|---|---|---|
| 口播审稿 | oral-script-review（双层体系）| 好的脚本要结构化审视，不是凭感觉 |
| 排版 SOP | publish-script | 排版是格式转换，原文字不改 |
| 发布流水线 | Hermes + 墨问 CLI | 多平台发布不该重复劳动 |
| 竞品分析 | competitor-analysis | 拆解对手找到差异化机会 |
| 选题判断 | topic-selection | 数据驱动的方向选择，不凭直觉 |
| 数据复盘 | data-review | 用数据说话：继续/调整/停止 |
| 内容筛选 | ai-content-curation | 四维扫描，判断比执行更重要 |

> 「下一步」里提到的竞品分析/选题判断/数据复盘——三个全做了。从 3 个 Skill 到 7 个。
