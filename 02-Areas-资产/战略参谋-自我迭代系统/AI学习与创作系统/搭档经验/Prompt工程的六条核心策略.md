# Prompt 工程的六条核心策略

## 六条策略

| 策略 | 怎么做 | 例子 |
|---|---|---|
| 1. 写清楚指令 | 说清要什么、什么格式、多长、什么语气 | 「用 200 字总结，分三点，口语化」 |
| 2. 提供参考文本 | 给范例比空口描述准得多 | 「按这个审稿清单的格式来分析下面这篇脚本」 |
| 3. 拆成简单步骤 | 复杂任务别一个 prompt 全塞进去 | 先拆选题 → 再写大纲 → 再出脚本，三步分开 |
| 4. 给模型思考时间 | 要求「一步步推理」比直接要答案质量高 | 「先列出利弊再给结论，不要跳过」 |
| 5. 用外部工具 | 搜索、代码执行、计算交给专门工具 | 需要最新数据时开搜索，别让模型硬猜 |
| 6. 系统化测试 | 改 prompt 要对比效果，靠数据不靠感觉 | 同一个任务用两版 prompt，对比输出质量 |

### 吴恩达 Prompt 进阶 🆕

| 技巧 | 怎么做 |
|---|---|
| **共情式** | 把 AI 当成高智商但不了解你背景的新人——主动喂上下文 |
| **规避顺从性** | 不在提问中暗示偏好，给客观评分标准——防止 AI 刻意迎合 |
| **渐进式生成** | 写作：先大纲→迭代→段落要点→终稿。杜绝 AI slop |
| **预判可信度** | 理解 AI 知识截止时间、不同领域数据分布，对低可信领域主动补充 |

> 原笔记写的「还没系统做」的 4 和 6，现在都在跑了。

## 一句话

> 好的 Prompt 不是一句话，是一套策略组合。给指令、给范例、给时间、给工具、给反馈。
