# Token 高效使用的 10 个方法

## 核心观点

Agent 时代，Token 不只是成本——**怎么用 Token 决定了 AI 工具是成本还是资产。**

## 关键策略摘要

| 策略 | 说明 |
|---|---|
| 精简上下文 | 只给必要的背景信息，不堆砌 |
| 复用会话 | 长任务在一个会话里完成，不重复初始化 |
| 分步执行 | 复杂任务拆开，每步只消耗必要的 token |
| 善用 Skill | 把重复流程封装，每次调用比重新描述省 token |
| 定期清理 | 上下文过长时 /compress 或 /reset |
