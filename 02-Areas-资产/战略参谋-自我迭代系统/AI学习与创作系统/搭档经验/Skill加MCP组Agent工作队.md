# Skill + MCP = Agent 工作队

## 核心类比

> **Agent 是人，Skill 是手艺，MCP 是工具箱。**

| 组件 | 做什么 | 什么时候用 |
|---|---|---|
| Skill | 按固定方法完成一件事 | 「每周要重做、有自己做法、结果可检查」 |
| MCP | 连接外部世界拿东西或做动作 | 需要读写文件、查数据库、调外部 API 时 |

## 关键原则

1. **不要从「万能 Skill」开始。** 从最小可行的开始——输入输出明确、每周至少重做一次。
2. **Skill 不是「一句提示词」。** 是完整文件夹：SKILL.md + reference/ + assets/ + scripts/。
3. **多 Skill 工作流的关键不是多，是上下游说同一种话。** 统一的输入输出格式才能自动化。
4. **让 AI 自己证明自己正确 = 最大翻车点。** 必须加质量检查 Skill。

## 普通人 7 天落地路线

| 天 | 做 |
|---|---|
| 1 | 找一个你每周至少做一次的任务 |
| 2 | 写出输入/输出是什么 |
| 3 | 做第一个最简 Skill |
| 4 | 跑一遍，看哪里卡 |
| 5 | 补一个质量检查步骤 |
| 6 | 如果需要外部数据，加 MCP |
| 7 | 串联成完整工作流 |
