# 智能体 = 模型 + 工具 + 循环

## 核心公式

Agent 的本质极其简单：

> **智能体 = 模型 + 工具 + 循环**

用户提需求 → 模型自主调用工具 → 获取结果 → 判断要不要继续调工具 → 不需要了就输出最终答案。**全程流程节点无人工预设。**

## 三层形态区分（面试重点）

| 形态 | 运行逻辑 | 是不是 Agent |
|---|---|---|
| **单轮调用** | 用户输入 → 模型输出 → 结束 | ❌ |
| **工作流** | 人预设好全部步骤，模型只是其中一环 | ❌ |
| **智能体** | 模型自主循环调用工具，自己决定什么时候停 | ✅ |

面试时能说出这三层区分，直接证明你不是「会用AI」而是「理解AI」。

## Harness 工程的再确认

不同 Agent 的差异不是循环逻辑（都一样），而是：
- 提示词配置
- 场景专属工具
- 上下文管理 + 工具调度

**这就是 Harness 工程。** 跟 [[02-Areas-资产/战略参谋-自我迭代系统/AI学习与创作系统/Builder思维/Agent四件套-Tool-MCP-Skill-Plugin]] 互补——那篇讲四个组件，这篇讲为什么「循环逻辑都一样，差异在 Harness」。
