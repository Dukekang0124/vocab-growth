# Software 3.0 - Karpathy在Sequoia Ascent 2026的完整框架

## 核心洞察

Karpathy在2026年Sequoia AI Ascent上完整阐述了"Software 3.0"概念：编程不再是手写代码（Software 1.0）或训练神经网络（Software 2.0），而是**通过prompts、上下文、agents、工具、记忆和验证来"编程"智能体**。核心转折点：人类的判断力(taste)、品味和系统理解成为最稀缺的资源。

## 四大框架

### 1. Software 3.0：上下文窗口成为编程界面
- Software 1.0：人与代码 → 精确指令
- Software 2.0：人与数据 → 训练模型
- Software 3.0：人与上下文 → 给AI方向，它自己执行
- 安装OpenClaw的例子：传统是写bash脚本适配各种环境，现在是给Agent一段文字让它自己看环境、跑命令、修bug

### 2. Agentic Engineering > Vibe Coding
- Vibe coding = 写小脚本，AI帮忙，能跑就行
- Agentic engineering = 架构级思维：安全、多Agent编排、系统设计、质量管控
- "过去两个月编程的变化比过去两年都大"

### 3. Jagged Intelligence（锯齿智能）
- AI在某些维度超神、某些维度弱智
- CEO的类比：CEO不需要自己写代码，但需要有判断力决定什么值得做
- 面试时：不需要你会写每一行代码，但需要你知道什么时候AI在胡说

### 4. Verifiability（可验证性）
- 决定AI先替代什么工作的核心指标是"结果好不好验证"
- 容易验证结果的 → 先被自动化
- 难验证的（创意、策略、判断） → 人的价值还在

## MenuGen故事（最重要的警示）

Karpathy做了一个App：拍照菜单→OCR→提取菜品→生成菜品图→重建菜单→UI展示。然后他发现：直接拿照片给Gemini，让它叠加食物图片到菜单上，一步完成。

**启示：很多AI App只是模型能力的临时补丁。模型本身能力提升后，这些App就消失了。**
