# Agent 长期运行的四大架构

## 核心突破

Agent 的关键瓶颈：**20 分钟就开始跑偏，上下文漂移、任务失控。**

四大架构逐层解决：

| 架构 | 做什么 |
|---|---|
| **Ralph Loop** | 专属循环工作流，让 Agent 长时间不中断 |
| **Agent Teams** | 复杂任务拆解给多个 Agent，各司其职 |
| **Generator-Evaluator** | 一个生成、一个审核——输出前拦截低质量结果 |
| **Harness** | 测试→评估→反馈闭环，Agent 自我优化 |

## 关键数据

- 早期：Agent 稳定运行 ~20 分钟
- 现在：连续工作 12 小时不丢上下文
- 成本：200 美元 + 6 小时从零构建可玩游戏

## 跟苏不倦的关系

你的 cronjob 每 2 天自动扫描 = Agent 长期运行的简化版。理解四大架构，面试时能聊 Agent 的工程挑战和解决方案。
