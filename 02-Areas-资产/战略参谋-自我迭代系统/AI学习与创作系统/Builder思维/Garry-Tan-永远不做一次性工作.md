# Garry Tan：永远不要做一次性工作

> YC掌门人Garry Tan 2026年7月演讲核心方法论

## 📌 核心

AI时代的效能差距不在模型本身，而在**如何重新编织工作流**。把每次成功输出变成可复用的流程（skillify），把组织知识沉淀为可检索的「企业大脑」——这就是AI原生公司的运转法则。

## 🔥 五个关键概念

### 1. 400倍效能：杠杆在流程，不在模型

- Garry Tan 2013年每天写14行有效代码，2026年效率约400倍——用的是同一个Claude
- YC W25：1/4公司95%代码由AI生成，这批公司是YC历史增长最快
- **关键差异**：增长最快的创始人没把AI当代码补全工具，而是当生产力劳动力

### 2. 新物理法则：Skill=员工，解析器表=组织架构

| 旧组织概念 | AI原生等价物 |
|:--|:--|
| 一名员工 | 一个Skill（技能手册） |
| 组织架构图 | 解析器表（分配任务给对应Skill） |
| 内部业务流程 | 归档规则 |
| 绩效考核 | 触发评估 |

案例：Emergence → 8个月9位数ARR，15人时$15M ARR。

### 3. 「skillify it」——永远不要做一次性工作 🔥🔥🔥

核心铁律：
- **如果你重复交代同一件事两次，你的管理就失败了**
- 每次Agent产出满意→立刻skillify→可复用流程
- 不skillify=每天醒来失忆；skillify=每天变更聪明
- Garry Tan在X上发了「skillify it」博文，可直接搜索加载

### 4. 企业大脑 = 图书馆 + 图书管理员

- 1 Agent = 1M Token ≈ 3本《哈利·波特》，但你公司是一座图书馆
- 核心不是检索（RAG），是**谁决定桌上该翻开哪三本书**
- Garry Tan自己的G-Brain：22万页内容，MIT开源
- 助手vs同事的区别：「同事知道你之前干了什么」

### 5. 双空间计算：潜空间 vs 确定性空间

- 审美/直觉/意图 → LLM潜空间
- 规则/代码/数据 → 确定性空间（TypeScript等）
- 大多数AI工程bug：两者错位

## 💡 跟苏不倦的关系

- 「skillify」就是你已经在做的事——11窗口、Skill体系、cron任务。Garry Tan给了它理论命名
- 求职话术：「我把重复性工作skillify成可复用流程——YC掌门人说这是AI原生公司的核心能力」
- 自媒体选题：「AI时代正在淘汰一种人：做一次性工作的人」
- 系统优化方向：参照「企业大脑」概念，把11窗口产出统一归档为可检索的知识库
