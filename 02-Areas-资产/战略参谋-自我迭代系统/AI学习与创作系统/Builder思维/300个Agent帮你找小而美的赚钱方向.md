# 300 个 Agent 帮你找小而美的赚钱方向

## 核心案例

用 Kimi 的 300 个并行 Agent，从 3800 万条网站数据中筛选出 167 个低竞争高变现的建站方向。

最反常识的发现：**「教室排座位工具」月营收 500-5000 美元。** 极简场景、零技术壁垒、稳定付费。

## 筛选逻辑

| 步骤 | 做什么 |
|---|---|
| 1. 海量采集 | Agent 自动爬取 3800 万条排名数据，清洗入库 |
| 2. AI 生成指南 | 5 个虚拟研究员并行，输出小白建站指南 |
| 3. 批量深度调研 | 6 批 Agent 集群，167 个站点逐一拆解 |

## 关键洞察

> 不是靠海量关键词堆流量——靠**精准长尾词 + 高转化率**。流量/关键词比值 > 20 的小站点最值得参考。

**300 个 Agent = 30 个虚拟员工。** 一个人完成了过去团队级的调研任务。

## 跟苏不倦的关系

- 不是做「英语学习大平台」→ 做「零基础成年人用 AI 学英语的 7 天计划」
- 精准人群 × 刚性小需求 × 稳定付费
