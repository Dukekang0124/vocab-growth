# 管理未知项：用好顶尖AI模型的关键不是Prompt，是消除盲区

> ✅ 已验证：Club Code内部工程师笔记，新浪财经2026-07-05转载，300万+浏览。知乎有独立讨论。

## 核心洞察

**顶级模型的能力越强，你的产出上限越不由模型决定——由你消除未知项的能力决定。**

Fable5这类顶尖模型在执行复杂任务时，跑偏的原因不是「模型不够聪明」，而是你给它的「地图」（提示词/上下文）和它实际面对的「疆域」（代码逻辑/现实约束）之间存在大量未被标注的信息差——这些就是未知项。

**一条万能指令**：「帮我找找这个事情的盲区，我有哪些地方没有想的很周到的。」这句话比写100条复杂Prompt值钱。

## 四类未知项（Rumsfeld矩阵 × AI协作）

| 类型 | 定义 | 你的场景 |
|:--|:--|:--|
| **已知的已知** | 你完全清楚的内容 | 审稿清单里已经固化的15个维度 |
| **已知的未知** | 你知道自己没搞清楚 | 「这个选题会不会扑？我不确定，让AI帮我分析」 |
| **未知的已知** | 你习以为常但无法描述 | 「这个脚本读起来不顺」但说不出哪里不顺 |
| **未知的未知** | 你完全没意识到的坑 | 发布后才发现违禁词、算法不喜欢某类内容 |

## 三阶段消除法

### 任务启动前（5步）

1. **盲点扫描**：「帮我找找这个事情的盲区，我有哪些地方没有想的很周到的」
2. **原型验证**：需求模糊时，让AI快速生成多版初稿，对比锚定真实需求
3. **采访模式**：让AI主动向你提问，聚焦你认知模糊的环节 → 对应你的 `socratic-interview` Skill
4. **参考物锚定**：感性需求（审美/语气）不要用文字描述，直接给截图/样例
5. **前置计划审核**：让AI把不确定环节放最前面，你先确认再继续

### 任务执行中（1规则）

让AI自动记录每次偏离计划的决策，遇到分叉点选最保守路径，事后统一复盘。不停下来问你。

### 任务完成后（2步）

1. **第三方评审**：把产出物整理成文档，给外部视角检查
2. **AI自测校验**：让AI基于最终产出出题考你 → 对应昨天入库的「3问题深度学习法」第3问

## 跟苏不倦系统的映射

```
你的审稿流程 = 盲点扫描（让我逐条查）
socratic-interview = 采访模式（让我问你问题）
3问题深度学习法第3问 = AI自测校验（让AI出题考你）
脚本先写再改 = 原型验证（先出稿再瞄定）
```

## 你今天就能用的

每次发脚本/选题/决策给我之前，先加一句：

> 「先帮我找找这个事情的盲区，我有哪些地方没有想的很周到的。」

这句指令的价值远超任何复杂Prompt。它调用的不是我的知识——是**我的提问能力**。而提问比回答更能发现你不知道的东西。
