# Agent 自进化：真进化 vs 伪进化

## 核心判断标准

只看一点：**「学习适应」环节是否真正闭环。**

| 类型 | 本质 | 代表 |
|---|---|---|
| 伪进化 | 检索过往成功案例重放 = 记忆复用 | GenericAgent |
| 局部优化 | 自动触发但产出未经验证 | Hermes Skill、EvoAgentX |
| 真进化 | 全自动闭环 + 经验验证 + 规则固化 | Evolver（GVP 架构） |

## Evolver 的 GVP 四步闭环

```
Scan（提取可复用行为模式）
  → Validate（控制变量验证，排除幻觉）
    → Mutate（泛化变异，单场景→通用规则）
      → Solidify（验证有效性后固化为 Capsule）
```

**目前唯一实现全自动闭环的方案。**

## Hermes 的定位

| 优势 | 短板 |
|---|---|
| 动态 Skill 生成，10 轮无新 Skill 主动触发整理 | Skill 无验证环节，存在幻觉风险 |
| RL 训练闭环可蒸馏大模型能力到小模型 | RL 训练为离线人工驱动，非全自动 |

## Hermes 自主进化架构（2026-07-20 补充）

### 自主技能生成

> 超过 10 步任务未生成技能 → 后台异步启动子 Agent → 审查工作流 → 识别需沉淀的复杂任务 → 自主生成/修补/删除 Skill。配套 `skill guard` 安全扫描，正则校验拦截风险内容。

### 双异步记忆审查

| 触发条件 | 行为 |
|---|---|
| 每 10 轮对话 | 自动触发记忆审查子 Agent → 提取偏好/习惯 → 更新 user.md + memory.md（≤4000 字符） |
| 每 10 步任务 | 自动触发技能审查 → 沉淀可复用领域知识 |

### 四层记忆架构

```
热记忆（user.md + memory.md 常驻提示词）
  → 温记忆（按需加载的技能库）
    → 冷记忆（本地 SQLite 全量可搜索对话历史）
      → 语义记忆层（可接入 MEM0 等第三方）
```

> 你在用但未必完全理解——自主技能生成+双异步审查+四层记忆，这就是 Hermes 越用越聪明的底层。

## 终局预判

> 群体遗传式进化：Capsule 行为资产像开源包一样被任意 Agent 拉取继承——AI Agent 物种将首次实现群体层面能力迭代。
