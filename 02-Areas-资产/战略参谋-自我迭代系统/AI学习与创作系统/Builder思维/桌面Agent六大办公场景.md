# 桌面 Agent 能干什么：六大办公场景

## 核心认知

桌面 Agent（如 KimiWork）已经能覆盖主流办公场景，零基础可用：

| 类型 | 场景 | 例子 |
|---|---|---|
| 分析类 | 市场调研、数据分析 | 自动搜集竞品信息，生成报告 |
| 报告类 | 工作汇报撰写 | Q2 季度汇报一键生成 |
| 协作类 | 客户跟进、事项提醒 | 自动发跟进邮件、到期提醒 |
| 管理类 | 预算审核 | 自动比对数据、标异常 |
| 同步类 | 团队进度对齐 | 多部门进度汇总 |
| 可视化 | 数据看板、日程排布 | 自动生成图表、排好日历 |

## 跟苏不倦的关系

你不用 KimiWork（用的是 Hermes），但关键是**理解 Agent 的能力边界**——面试时能聊：

> 「桌面 Agent 可以覆盖分析、报告、协作、管理、同步、可视化六大场景。我自己用 Hermes 实现了脚本审稿和排版发布的自动化。」
