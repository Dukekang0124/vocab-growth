# YouTube = 免费 AI 大学

## 核心观点

对于非技术背景学习者，YouTube 正在替代传统书本——创作者本身就是 AI 行业亲历者，内容时效性远超出版书籍。**可视化讲解 + 一线从业者 = 最低门槛的 AI 学习路径。**

## 适配苏不倦的频道清单

| 类别 | 频道/内容 | 适合你的原因 |
|---|---|---|
| 视频播客 | Lex Podcast、Every 播客 | AI 创始人深度访谈，信息密度极高 |
| 行业大会 | YC AI Startup School、AI Engineer World Fair | 顶级从业者原版演讲，免费获取 |
| 官方频道 | OpenAI、Anthropic 官方 | 新模型首发 + 核心团队亲自讲解 |
| 实操教程 | Claude Code + Obsidian 联动教程 | 零代码搭建个人 AI 助理 |
| 专属人物 | Andrej Karpathy | 唯一兼具 Builder + Influencer 双重身份 |

## 四个习惯

| 习惯 | 怎么做 |
|---|---|
| 长视频替代碎片 | 完整看完高价值长视频，不跳 |
| YouTube = 大学 | 按频道系统性学习，不随机刷 |
| AI 当辅导老师 | 遇到术语就问 AI，用大白话解释 |
| 走出舒适区 | 主动看超出当前认知的内容 |

## 跟苏不倦的关系

- 学习方法：不是不读书——是优先看 YouTube 上一线从业者的内容，时效性远超出版书籍
- 求职面试：「我主要通过 Andrej Karpathy 和 No Priors 等一手渠道学习 AI」→ 比「我看公众号」高一个量级
