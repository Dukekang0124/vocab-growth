# Agent Skill 是 AI 时代的核心能力

## 核心观点

不管走技术路线还是非技术路线，**理解 Agent、会构建和调优 Skill** 是 AI 时代的通用能力。

泛函提出的路径是技术向的（Codex + Vibe Coding + 全栈开发），但其中关于 Skill 的部分对非技术岗位同样适用：

| 层次 | 内容 |
|---|---|
| 会用 | 掌握 Agent 基本用法 |
| 会建 | 自己构建 Agent Skill |
| 会调 | 根据实际场景反馈调优，做出能用在生产中的 Skill |

## 跟苏不倦的关系

你已经在前两层：

| 已有的 Skill | 层次 |
|---|---|
| 口播脚本审稿清单 | 会建 |
| 排版 SOP | 会建 |
| 发布流水线 | 会建 |
| 根据用户反馈持续迭代 | 会调 |

**下一步：** 继续把运营/内容经验变成更多可复用的 Skill——这是你跟其他纯运营求职者的分水岭。

## 一句话

> 泛函的路径是给开发者的，但他的核心理念——Skill 能力是 AI 时代的基本功——对任何岗位都成立。
