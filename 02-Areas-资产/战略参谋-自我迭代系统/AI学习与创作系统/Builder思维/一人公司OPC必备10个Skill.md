# 一人公司 OPC 必备的 10 个 Skill

## 核心框架

从 Sahil Lavingia（Pinterest 联合创始人，从 400 人缩减到 1 人）的极简创业理念提炼的 10 个 Skill，构成完整创业路径：

```
找社群 → 验证想法 → 做 MVP → 流程化 → 首批 100 客户
→ 定价 → 营销 → 稳健增长 → 公司价值观 → 极简复盘
```

## 五个关键 Skill

| Skill | 解决问题 | 核心金句 |
|---|---|---|
| /validate-idea | 这个想法值不值得做？ | 「别问酷不酷，问有人付钱吗？」 |
| /mvp | 产品该做多少？ | 「只做一件事，能用交付的才做」 |
| /first-customers | 产品好了没人买 | 「100 个客户前别搞发布会，从亲友一圈圈往外卖」 |
| /pricing | 该收多少钱？ | 「从第一天就收费，免费是毒药」 |
| /minimalist-review | 任何决策犹豫不决 | 「八个问题筛完，答案就清楚了」 |
