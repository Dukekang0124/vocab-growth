# 张咋啦的 4 个 AI 绝活

## 四个明天就能用的 AI-native 工作方式

| 绝活 | 怎么做 | 核心理念 |
|---|---|---|
| 1. 所有会议默认录制 | 飞书妙记自动生成纪要 → Codex 推送个性化任务 | 会议不是讨论，是 AI 的生产原料 |
| 2. 团队共用的 Agent | Agent 在群里协作，员工在工作现场学会用 | **✅ 已验证**：泛函实践——云端部署 Codex，全团队+客户共用一个 Agent，共享记忆和 Skill |
| 3. 给上下游做 Skill | 一个人端到端负责，Agent 补齐非原生能力 | 组织低效源于人与人之间的依赖，Agent 消解它 |
| 4. 审美也是生产力 | 把设计规范做成 Skill，Agent 直接生成符合规范的 html | 审美不是玄学，是可以封装的约束条件 |

## AI Builder 的三个素质

张咋啦给 AI Builder 的定义：
- **Agency**（主观能动性）——不等指令，自己找事做
- **Taste**（品味/判断力）——对用户和产品有洞察。核心是做减法：删功能比加功能难十倍
- **Distribution**（分发能力）——会讲故事，能打动人。不只对外营销，对内也要让团队用起来

### AI 时代产品三阶段权重迁移

| 阶段 | 传统权重 | AI 时代权重 | 变化 |
|---|---|---|---|
| 决策做什么 | 中 | **极高** | ↑ 用户宁可自己用 AI 解决，你必须精准击中痛点 |
| 开发实现 | **最高** | 低 | ↓ coding agent 一句话生成产品 |
| 推广触达 | 中 | **极高** | ↑ 用户被 AI 产品轰炸，90% 落地页无法唤起兴趣 |

> 「过去纠结要不要学编程，现在完全放弃了——全部精力投入决策和分发。」——张咋啦

你的定位恰好站在这三个能力的黄金交叉点上。

### 企业 AI 应用三段位

| 段位 | 特征 | 现状 |
|---|---|---|
| Level 1 | 纯人际协作，无 AI | 已淘汰 |
| Level 2 | 员工个人用私有 AI | 90% 企业在这里 |
| Level 3 | Agent 无缝融入人际协作 | 🏆 极少数前沿公司达到 |

> 推荐论文：《为什么新技术普及了，效率却没提升？》——解释技术革命与组织变革的错配问题。

### 团队 Agent 六步搭建

1. 部署到云端（解决断连+隐私）
2. Bridge 接入飞书（群聊机器人形态）
3. 设定角色+职责+沟通风格
4. 导入会议逐字稿+群聊+文档作为 Context
5. 配置每日自动学习新信息
6. 拉入协作群，全员 @ 使用

### 产品设计铁律

> **人天生懒、健忘、注意力分散。** 产品不是功能好就有人用——必须适配已有高频习惯。Agent 的最佳入口是飞书——让 Agent 主动找人，不让人去找 Agent。

### 防 AI Slop 设计四招 🆕

| 招 | 怎么做 |
|---|---|
| 设计系统替代模板 | 用 `design doc MD` 定义色彩/字体/风格 Token，不用硬模板 |
| 动态反垃圾 | 追踪当下流行 AI 设计套路，Prompt 里明确禁止 |
| Playground 探索 | 让 AI 生成多套字体/配色/动效对比页，像菜单一样选 |
| SVG 复用 | Quiver AI 生成风格统一矢量插画，提升设计独特性 |

### Build in Public 飞轮

> **真正的壁垒不是单个创意，是持续运转的创新飞轮。** 「是骡子是马拉出来遛遛」——对手能抄一个点，抄不了一条线。

```
想法 → 产品 → 发布 → 反馈 → 洞察 → 新想法
```

你的口播就是在跑这个飞轮：脚本→发布→评论反馈→选题调整→新脚本。

**OpenAI 验证**：Codex 负责人在 X 上直接回用户，征集痛点推文 4000+ 留言，次日发布修复版本。Build in Public 不是口号——是全球顶级 AI 团队的标准工作方式。

## 时代判断：Code is cheap, show me the talk

传统信条「Talk is cheap, show me the code」被 AI 彻底反转：

| 旧 | 新 |
|---|---|
| 代码稀缺，做出来就是壁垒 | **代码变便宜了，注意力变贵了** |
| Talk is cheap | Code is cheap, show me the talk |
| 核心竞争力 = 开发能力 | 核心竞争力 = 注意力捕获 + 真实人格 |

五大趋势：
1. 代码 10 分钟落地，营销推广成最大卡点
2. AI 内容越多，活人感越稀缺
3. Builder 必须自己代言 = Influencer
4. AI slop 的根源不是表达问题，是没灵魂
5. 代码是自我表达的媒介——做有观点的产品，不做万能工具

### 增量 Loop：五步长期跟踪

> 不是抓一次就完。像投研一样长期跟踪 Builder：

```
抓取新材料 → 与已有命题对比 → 判定增量类型
→ 更新档案+证据日志 → 核验后推进断点
```

增量类型：细化/强化/新分支/修正/进入行动。
