# AI 内容生产线：12 个 Skill 全链路

## 核心框架

把自媒体内容生产拆成 12 个标准化环节，每个由 AI Skill 承接：

```
趋势捕捉 → 选题验证 → 资料调研 → 初稿生成
→ 内容提纯 → 风格校准 → 图文排版 → 素材生产
→ 动态制作 → 合规校验 → 卡点定位 → 复盘优化
```

## 苏不倦的对应

| 环节 | 你有吗 | 状态 |
|---|---|---|
| 🆕 前置积累 | ✅ | 日常素材储备+选题库前置=功夫在诗外。张咋啦：内容产出效率来自创作之外的长期积累 |
| 趋势捕捉 | ❌ | 没有自动化——靠手动刷 |
| 选题验证 | 🟡 | topic-selection Skill 已建，待实战 |
| 资料调研 | 🟡 | AI 扫描 cronjob，但不是定向调研 |
| 初稿生成 | ✅ | 你自己写脚本，不改 |
| 内容提纯 | ✅ | 审稿闭环 = AI 建议→你改→对比差异 |
| 风格校准 | ✅ | oral-script-review Skill + 正面清单 |
| 图文排版 | ✅ | publish-script + 墨问 |
| 素材生产 | ❌ | 没做封面/轮播图自动化 |
| 动态制作 | ❌ | 拍摄是人工的 |
| 合规校验 | 🟡 | 审稿 Skill 里有合规检查，但没独立环节 |
| 卡点定位 | ✅ | 复盘系统 |
| 复盘优化 | ✅ | data-review Skill |

## 核心红线

> 选题方向、价值判断、发布操作——永远是人决定，AI 只辅助。
