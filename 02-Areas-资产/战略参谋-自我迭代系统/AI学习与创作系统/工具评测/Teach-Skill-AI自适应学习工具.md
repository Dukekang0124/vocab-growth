# Teach Skill —— AI 驱动的自适应学习工具

## 核心能力

硅谷开源工具。输入任意学习目标，自动完成：
- 资料整理 → 互动课程 → 实操任务 → 知识检测 → 进度适配

形成完整的自适应学习闭环。

## 关键概念：Loop Engineering

本次演示中提及的 AI 前沿概念——**循环工程**。

核心思想：把重复性任务的执行→检查→修正流程做成可自动化循环运行的工程管线。跟智能体的「模型+工具+循环」公式一脉相承。

## 苏不倦适用判断

🟡 **理念值得借鉴，工具暂不适用。**

| 可取 | 暂不可用 |
|---|---|
| 自适应学习闭环理念 | 需要 Codex/Claude Code 等 coding agent 部署 |
| Loop Engineering 概念 | Hermes 生态暂不兼容 |
| 「学习目标→实操检验」的设计 | 技术部署门槛较高 |

## 可借鉴到自我迭代系统

Teach Skill 的闭环设计可以简化应用到你的学习流程：
`设定目标 → 找资料 → 做笔记 → 实操输出 → 检验理解 → 调整方向`

你已经在做的「一章一输出」就是这个逻辑的简化版。
