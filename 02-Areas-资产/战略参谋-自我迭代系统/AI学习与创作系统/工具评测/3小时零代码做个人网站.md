# 3 小时零代码做个人简历网站

## 6 步 SOP

| 步骤 | 做什么 | 工具 |
|---|---|---|
| 1 | 明确网站结构（要放哪些模块） | 脑子 |
| 2 | 确定风格（收集参考图/参考网站） | Gemini |
| 3 | 生成交互代码（描述想要的效果） | Gemini/GPT |
| 4 | 图片本地化（占位符→GitHub图片文件夹） | GitHub |
| 5 | 迭代调整（文本类直接改本地代码） | 编辑器 |
| 6 | GitHub 部署上线 | GitHub Pages |

总花费：0 元。总耗时：3 小时。零代码基础可操作。

## 苏不倦适用性

🟢 周末个人网站 = 这套 SOP + Open Lovable。

参考模块：首屏→自我评价→个人技能→工作经历→项目经历→作品集→联系方式。

## 避坑

- 图片名不能含中文和空格
- 图片引用用相对路径 `./images/xxx.png`
- 文本修改直接本地改，别让 AI 重生成全部代码
