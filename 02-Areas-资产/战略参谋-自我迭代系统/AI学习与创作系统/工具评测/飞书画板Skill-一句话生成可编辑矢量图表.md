# 飞书画板Skill：一句话生成可编辑矢量图表

> ✅ 已验证：飞书CLI `github.com/larksuite/cli`，MIT协议，10000+Star，v1.0.39。lark-whiteboard 为其26个Skill之一。

## 核心洞察

飞书画板Skill不是又一个「AI帮你画个图」的工具。它的关键差异在于：**生成的是SVG矢量节点，不是死图片——所有元素双击可改，支持飞书画板原生多人协同。**

一句话让Claude Code在飞书文档里生成思维导图、流程图、泳道图、架构图、CheatSheet、甚至PPT——全部可编辑、可协作、可沉淀进知识库。

## 安装（一行命令）

```bash
npx @larksuite/cli@latest install
```

自动安装CLI + 26个Skills到 `~/.claude/skills/`，扫码绑定飞书账号即可。
