## 学习策略（你的方式，不是学校的方式）

### 原则

1. **干中学，不先学后用** —— 不「先学完理论再动手」，直接开干，遇到问题查
2. **输出驱动输入** —— 每学一个东西，当场产出公开内容（LinkedIn帖/Fiverr Gig/作品集页面）
3. **AI辅助全程** —— 用 AI 写英文帖、做关键词研究、翻译 JD，不手搓
4. **低门槛启动** —— 不买课不报班，全用免费资源+AI+实战

### 三线并行

```
英语实战线 ──→ Fiverr接单 + LinkedIn发帖 + 每天跟老外聊
增长知识线 ──→ 生姜Iris出海课 + 竞品研究 + AARRR
工具线    ──→ Ahrefs/GA/SQL + 视频号研究
```

## 关键判断

泛函：**「AI 公司看重作品，不是学历。花 1-2 个月和 AI 做出作品→找创始人社媒→私聊。无需许可，不受限制。」**

这对你意味着：
- 不是「先学会再投」→ 是「边学边投，学的过程中就有产出」
- 苏不倦 + 九思系统 + 作品集网站 = 你的作品
- 你不需要再学一个新技能才开始——你已经拥有 AI Agent 实操经验（这是大多数应聘者没有的）
- 补的不是「从零开始」，是「给已有能力加一层英文和海外包装」
