## 轮换规则

- 每天三件事：📖阅读 + 🎧听力跟读 + 🗣️开口
- 阅读轮换：牛津书虫 → 跟美国学生同步练阅读（交替）
- 听力轮换：Extra English → Let's Talk in English（交替）
- 开口：每天15分钟+（多邻国/语伴/跟Hermes全英文聊）
- 每天主动发起40-50次英语对话练习

## 系统机制

- 早8:00 cron「每日英语学习提醒」→ 只推送提醒（不写日志）
- 晚21:00 cron「英语学习晚间回顾提醒」→ 提醒回顾（不写日志）
- **学习日志 = 证据驱动**：用户发词/汇报学习 → 搭档判断教学 → 沉淀进当日日志
- 日志只记录**真实发生的学习**，不记录「计划/待完成」空表格

## 与高维进化系统的互联（2026-08-04接通）

⑪号是进化系统的一环，按五步闭环运转：

| 进化环节 | ⑪号怎么做 | 去向 |
|:--|:--|:--|
| ② 沉淀 | 验证过的方法 → 03-方法论/；踩的坑 → 观察池②失败模式 | 本目录 + skill-factory-观察池.md |
| ③ 进化 | 可复用流程 → 观察池①重复工作流 → 提炼Skill | skill-factory-观察池.md |
| ④ 固化 | 成熟方法论（使用≥3次+3月无改动）→ 07-Hermes | 07-Hermes/ |
| ⑤ 释放 | 改共享资源（cron/路径/Skill）→ 登记变更台账 | 变更台账.md |
| 跨窗口 | 重要操作 → 状态日志（18:30自动广播给所有窗口） | 状态日志.md |

**触发规则**：遇到高耗时问题（≥30min）/反复坑（第2次）/配置变更/用户纠正 → 解决后立即沉淀，不等提醒。

## 核心工作流（词汇生长系统 v3）

```
你发词 → 判定高频 → 语块教学（带发音）
  → 沉淀（日志+词汇库+说法库）
  → 触发复习（随机抽5/你发词识别新旧）
  → 自由报词 → 分层抢救 → 造句 → 纠正+老外版本 → 当天用掉
```
