# candidates · 反例提取（Counter-example）

> 阶段1 产物 · 《超越感觉》第8版 · 2026-08-22
> 候选反例/失败模式单元：书中警告的思维错误（未验证）

## 基本问题（第八章）
| # | 反例 | 一句话 |
|:--|:--|:--|
| X1 | 自我中心 | 聚焦/集中在自己身上，把自己的想法当最好的 |
| X2 | 族群中心 | 过度集中于自己族群，他者想法天然低一等 |

## 立场错误（第九章）
| # | 反例 | 一句话 |
|:--|:--|:--|
| X3 | 视角匮乏 | 狭窄而不宽广的视角，思维贫乏的主要特征 |
| X4 | 无根据的假定 | 把未经验证的假设当事实 |
| X5 | 要么/要么 | 把复杂问题压成二选一 |
| X6 | 盲目遵从 | 因从众/权威而放弃独立判断 |
| X7 | 绝对主义 | 准则一旦确立，拒绝任何例外 |
| X8 | 相对主义 | 认为道德/价值纯主观，拒绝评价优劣（自相矛盾） |
| X9 | 支持或反对变化的偏见 | 无条件拥抱/拒绝变化，不看具体内容 |

## 程序错误（第十章）
| # | 反例 | 一句话 |
|:--|:--|:--|
| X10 | 有偏见的证据考量 | 只寻求支持自己偏见的证据，回避反方 |
| X11 | 双重标准 | 对自己/他人用不同标准 |
| X12 | 草率的结论 | 证据不足就下结论 |
| X13 | 过度概括和刻板成见 | 把个案推广到全体 |
| X14 | 过度简单化 | 忽略复杂性，把问题简化成单一原因 |
| X15 | 事后归因谬误 | 先发生=原因（"因为A在先，所以A导致B"） |

## 表达错误（第十一章）
| # | 反例 | 一句话 |
|:--|:--|:--|
| X16 | 自相矛盾 | 论述前后冲突 |
| X17 | 循环论证 | 用结论证明前提 |
| X18 | 无意义的陈述 | 说了一堆等于没说 |
| X19 | 误用权威 | 引权威压人，而非用论证 |
| X20 | 错误类比 | 两事物相似处不足以支撑结论 |
| X21 | 非理性的诉求 | 诉诸情感/传统/适度/权威/共同信念/宽容，而非理性 |

## 反应错误（第十二章）

| X24 | 转移举证责任 | 要对方证明自己错，而非自己证明 |
