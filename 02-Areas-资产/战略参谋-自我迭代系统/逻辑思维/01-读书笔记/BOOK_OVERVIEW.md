## 一、结构（Structural）

### 类型
方法论教科书 / 批判性思考训练指南（面向普通读者的思维技能教材）。

### 主旨（一句话）
教人**超越感觉**（自发的主观反应与外部操纵），通过系统化的批判性思考——先理解背景概念、再识别思维谬误、最后应用问题解决策略——做出明智的判断与决策。

### 核心问题
人们普遍只会"感觉"不会"思考"（被广告、大众文化、心理操纵牵着走），学校从不教思考——**如何让普通人系统掌握批判性思考？**

### 骨架（3 个一级论点，递进关系）

```
第一篇 背景（1-7章）—— 掌握工具和规则
  7 大概念：个性→思考→真理→知识→观点→证据→论证
第二篇 易犯的错误（8-13章）—— 认识并避免思维病
  5 类谬误：基本问题"我的更好"→立场错误→程序错误→表达错误→反应错误
第三篇 策略（14-19章）—— 解决问题与议题
  6 步：知道你自己→敏锐观察→选议题（少即是多）→探究→形成判断→说服他人
```

## 二、解释（Interpretive）

### 关键术语（作者用法）

| 术语 | 作者用法 |
|:--|:--|
| 感觉 | 情感/情绪/欲望的主观反应，自发生成；极不可靠，需要检验 |
| 思考 | 解决问题、作决定、取得理解而进行的有意识精神过程 |
| 批判性思考 | **评价**——检验各种主张和论据、判定优劣的探究过程；本质是提问探索性问题 |
| 真理 | 是**发现**的，不是创造的；受感知/记忆/信息缺陷干扰 |
| 认知 | 有充分证据支撑的理解；有障碍（感知、记忆、信息、智能、语言） |
| 观点 | 可能出错；须区分"有见识"与"无见识"的观点 |
| 证据 | 11 种：个人经验/传说/报道/目击/名人/专家/实验/统计/调查/观察/研究评述 |
| 论证 | 前提 + 结论；须评价前提真伪与推理有效性 |
| 谬误 | 思维错误的四类：立场/程序/表达/反应 |
| 详细目录 | 第十四章自我评估工具：用批判性思考标准盘点自身弱项 |

### 核心命题（提炼）

1. 感觉和思考互补：感觉是结论的绝佳开端，思考是确认最佳感觉的方法；但感觉从不适合替代思考。
2. **批判性思考的本质是评价**，是探究，最重要的技巧是提问探索性问题。
3. 人不是孤立个体：时间地点、大众文化、操纵的学问、心理学共同塑造了你的"你"。
4. 真理是发现的不是创造的——即使最明智的人也会出错。
5. 认知是困难的：感知不完善、记忆不可靠、信息有缺陷、语言有陷阱。
6. 观点可能出错，甚至专家也出错；形成正确观点需要证据与推理。
7. 充分证据有构成要件，评价证据须区分证据种类与可信度。
8. 思维谬误可系统分类（立场/程序/表达/反应），识别它们是防错第一步。
9. "我的更好"（自我中心 + 族群中心）是思维错误的根源。
10. 解决问题有策略：自我评估→观察→限定议题→探究→形成平衡判断→有效说服。

## 三、批判（Critical）★

1. **时代局限**：1975 初版，第 8 版虽更新，但第十七章"到何处寻找信息"仍偏前互联网时代（图书/数据库/因特网早期）；示例（如 2006 齐达内）已显旧。
2. **文化盲点**：美国大学教材视角 + 西方理性主义传统，对"直觉/情感在判断中的合理作用"处理过简（第二章直觉仅一节带过），可能低估情绪智能的价值。
3. **未证明的假设**：假设"批判性思考可教、且教了就会用"；对"真理是发现的"采取实在论立场，未回应建构主义/后现代对真理的挑战。
4. **最强反方意见**：批判性思考训练的效果（迁移到真实决策）实证证据有限；过度强调理性评估可能导致"分析瘫痪"或误伤快速直觉决策。

- 大量应用练习（作例子用）

- skill 数：8-10 个
- 优先级：谬误速查器 > 提问检查法 > 证据评价器 > 形成判断程序 > 批判性思考自查 > 说服原则
