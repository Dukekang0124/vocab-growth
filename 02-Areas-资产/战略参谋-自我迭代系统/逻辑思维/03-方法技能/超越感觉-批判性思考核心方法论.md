# 超越感觉 — 批判性思考核心方法论

> 作者：鲁吉罗 | Skill：`fallacy-spotter` / `socratic-questioner` 等 9 件套（见 `../01-读书笔记/skills/`）

## 核心模型：批判性思考 = 评价 = 提问

```
思考（有意识精神过程）
  └─ 批判性思考（评价：检验主张和论据优劣）
       └─ 本质活动：提问探索性问题
            ├─ 前提层：藏着什么假设？
            ├─ 逻辑层：中间跳步了吗？
            ├─ 证据层：数据/经验/感觉？
            └─ 反方层：最强反对意见是什么？
```

## 速查表：4 类 25 谬误

| 类 | 谬误 |
|:--|:--|
| 立场 | 视角匮乏 / 无根据假定 / 要么要么 / 盲目遵从 / 绝对主义 / 相对主义 / 变化偏见 |
| 程序 | 偏见证据 / 双重标准 / 草率结论 / 过度概括 / 过度简单化 / 事后归因 |
| 表达 | 自相矛盾 / 循环论证 / 无意义陈述 / 误用权威 / 错误类比 / 非理性诉求 |
| 反应 | 自动拒绝 / 转换话题 / 转移举证责任 / 稻草人 / 攻击批评者 |

## 速查表：形成判断六步

```
平衡观点 → 处理可能性 → 主语具体 → 谓语准确 → 加限定语 → 避免夸大
```

## 可操作清单（7 问决策自查）

做重要判断前问自己：
1. 我在用感觉还是思考？感觉检验过了吗？
2. 我的结论藏着什么假设？验证过吗？
3. 从前提能推出结论吗？跳步了吗？
4. 支撑的是数据、经验还是感觉？区分了吗？
5. 还有别的解释吗？（替代解释排查）
6. 我是不是只看了支持自己的证据？
7. 如果换个说法/换个角度，结论还成立吗？
