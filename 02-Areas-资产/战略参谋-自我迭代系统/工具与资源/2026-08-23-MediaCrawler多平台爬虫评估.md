# MediaCrawler 多平台爬虫 — 深度学习与评估

## 一、核心论点（先给结论）

**工具本身**：6.1 万 Star 的 GitHub 顶流爬虫，用 Playwright + CDP 复用你本地 Chrome 登录态，按关键词批量抓取小红书/抖音/快手/B站/微博/贴吧/知乎的**帖子和评论**，无需逆向 JS、无需复杂环境。

**九思的判断**：
- ✅ **值得「学会」**——成本极低，技术路线（Playwright 复用浏览器登录态）和康哥已有的 `douyin-transcript` 完全一致，半小时能跑通。
- ⚠️ **「运用」必须划红线**——文章免责声明写的是"仅供学习研究，禁止商业用途"，平台条款明确禁爬。康哥做自媒体是商业行为，大规模爬取变现=高风险。**小批量、研究性、不碰 Pro 版、不违反平台条款**才安全。

## 二、内容提炼

### 01 支持平台（覆盖很全）
- 小红书：笔记、评论
- 抖音：视频、评论
- 快手：视频、评论
- B站：视频、评论
- 微博：帖子、评论
- 百度贴吧：帖子、评论
- 知乎：问答、文章、评论

数据可存 CSV / JSON / JSONL / Excel，也可直写 SQLite / MySQL。

### 02 工作原理（关键）
- 核心思路：**复用浏览器登录态**。传统爬虫要逆向平台加密算法生成签名，门槛高、平台一变就重写。
- MediaCrawler 走另一条路：用 Playwright 启动浏览器，连接你已有的 Chrome 实例（**CDP 模式**），直接复用你平时登录过的账号和 Cookie。
- 平台风控主要针对自动化脚本；用真实浏览器 + 真实登录态，风险低很多。
- 遇验证码会自动截图，等你手动处理。

### 03 安装（三步）
```bash
# 装 uv（Python 包管理器）
curl -LsSf https://astral.sh/uv/install.sh | sh
# 克隆 + 装依赖
git clone https://github.com/NanmiCoder/MediaCrawler.git
cd MediaCrawler
uv sync
# 装浏览器驱动（CDP 模式其实不需要）
playwright install
```
然后配 `config/base_config.py`（关键词、平台、存储方式），跑起来即可。

### 04 额外功能
- **HomeFeed 首页信息流**：抓各平台首页推荐，做趋势分析。
- **AI Agent Skill**：已适配 OpenClaw / Claude Code / Cursor，让 Agent 直接调用爬虫能力；基于评论分析的 AI Agent 开发中。
- **自媒体视频下载器**：桌面端工具，适合学全栈。
- **Pro 版**：功能更多、架构更好，付费订阅（开源版免费）。

### 05 注意事项（原文）
- 免责声明：仅供学习研究，**禁止商业用途**。
- 爬虫违法违规案件不少，用前自判风险；遵守平台服务条款，别大规模爬取或非法使用。
- CDP 模式需本地 Chrome 在跑，且账号不能封禁。

| 工具 | 输入 | 输出 | 定位 | 是否已有 |

## 四、对康哥 5 条线的价值（结合真实场景）

- **自媒体（苏不倦，最大价值）**：
  - 选题从"猜用户要什么"→"看评论区用户在问什么"（评论抓取是核心稀缺能力）。
  - 竞品雷达：批量扫英语赛道对标账号/话题，看他们在发什么、火什么。
  - 趋势分析：HomeFeed 首页信息流，看平台在推什么。
- **求职 / 英语 / 投资 / 产品化**：边际价值，可小用（如批量看某话题讨论），非主战场。
