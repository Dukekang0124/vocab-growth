# 国内外免费大模型 API 清单

> 康哥专用 · 阿Q整理 · 2026-08-21

## 核心认知（先看这个）

免费 API 分三类，别混为一谈：

1. **限流免费层**：长期免费但有速率/次数限制（Gemini、Groq、智谱 Flash）。
2. **一次性试用额度**：注册送几千万 token，用完即止（阿里百炼、硅基流动）。
3. **开源自部署**：模型免费下载，自己出硬件/电费（Ollama 跑 Qwen/DeepSeek）。

**WorkBuddy 接入前提**（2026-08-22 更新，纠正旧结论）：这些 API 多为 OpenAI 兼容格式（`base_url + api_key`）。**旧版写「WorkBuddy 暂未开放填第三方 API key 入口」已过时**——实测 `C:\Users\Admin\.workbuddy\models.json` 已支持自定义模型（标准 OpenAI 兼容格式：`url` + `apiKey` + 能力标志），当前已配 `agnes-2.0-flash` 和 `GLM-4-Flash` 两个自定义模型。**所以这些免费 API 现在能直接配进 WorkBuddy 作为底层模型使用**，配置方法见 `2026-08-22-免费开源大模型评估与对比.md`。

## 三、实用建议（怎么选）

- **日常兜底**：智谱 `GLM-4-Flash`（永久免费）+ 阿里百炼（额度大），够个人用 1~2 年。
- **要速度 / 额度**：Groq、Cerebras（国外，注意网络）。
- **一个 key 走天下**：硅基流动（国内）、OpenRouter（国外），聚合平台最省事。
- **数据不出门**：Ollama 本地跑 Qwen / DeepSeek，零 API 成本（需硬件）。
