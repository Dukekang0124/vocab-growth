# 🧭 认知重塑计划

> 创建：2026-08-05 | 重构：2026-08-05（主题类型分类）
> 归属：⑧号窗口（战略参谋-自我迭代系统）
> 目的：重建认知系统 + **不被困在自己**——主攻逻辑/心理/哲学/历史/科学/商业认知等一切拓宽认知的书
> 铁律：**所有阅读交流、思考积累、经验技能，全部沉淀、全部复用。分类清晰，不乱放。**

## 🎯 灵魂：运用优先（2026-08-09 用户确立）

> **读书的终点是用，不是藏。** 基于自身目前的情况 → 读最有用的书中最有价值的章节 → 深度内化 → 运用。
> 知识不是用来藏灰的——沉淀 → 碰撞 → 创造 → 优化，反哺自媒体/英语/商业/求职。

```
① 当前情况（缺什么）→ ② 最有用的书 → ③ 最有价值的章节 → ④ 深度内化 → ⑤ 运用（终点）
```

**藏灰检查**：书读完一周内没有「用」的动作 = 这次阅读失败。


## 📌 主题分类规则（2026-08-05 用户定义）

**用户发「我打算读XX书」时：**

1. **我判断这本书是什么类型**（逻辑思维/心理学/哲学/历史/科学/传记/文学…）
2. **认知重塑计划下有没有这个类型的文件夹？**
   - 没有 → **立即建**这个类型（带4个功能子文件夹），书归进去
   - 有 → 正常归类进已有文件夹
3. **书的沉淀**：读书笔记 → `主题/01-读书笔记/`；思考 → `02-思考积累/`；方法论 → `03-方法技能/`；讨论 → `04-交流沉淀/`

## 使用提示

- 想到什么先丢进对应主题的 `02-思考积累/`，成型后再归类
- 读完一本书，笔记放对应主题的 `01-读书笔记/`
- 方法技能成熟，提炼进 `03-方法技能/` → 最终进 Hermes方法论
- 跟九思的讨论有价值的部分，存 `04-交流沉淀/`
- **没有主题文件夹就新建，有就归入——不新建不存在的功能层**
