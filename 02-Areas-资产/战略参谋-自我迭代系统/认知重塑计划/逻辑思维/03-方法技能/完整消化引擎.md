# 完整消化引擎（教学/自学的标配）

> 来源：2026-08-05 用户升级要求 + knowledge-digestion-method Skill
> 铁律：**每次教学/自学必须走完整引擎，概念只是第1层，禁止停在「讲清楚概念」就收工。**

## 十层消化

```
【输入层】
① 是什么——一句话说清概念
② 不是什么——常见误区（防止理解偏）

【应用层】
③ 怎么用——操作步骤
④ 用在哪——至少3个跨领域场景（英语/求职/投资/生活/创作…）
⑤ 什么时候用——触发信号 + 什么时候不该用（边界）

【效果层】
⑥ 用了会怎样——预期效果
⑦ 不用会怎样——反面案例（知道代价）

【验证层】
⑧ 考题——跨领域考题 ≥3题，覆盖不同领域
⑨ 用户自举——用户能举出第4个新场景 = 真懂
⑩ 落地——变成 Skill/笔记/行动
```

## 由浅入深五铁律

1. **先直觉后术语**——大白话+生活例子先讲「大概是这么回事」，最后才给学名
2. **比喻桥**——新知挂在旧知上（音标=英语的拼音、归纳=收网、演绎=开锁）
3. **例子分层**——同一个概念给3个例子：小孩版→生活版→专业版
4. **小孩能懂的标准**——只能用术语解释=还没想透
5. **反例教学**——讲「什么不是」有时比「是什么」更有用

## 前进门槛铁律

**当前知识点的验证题未通过前，禁止提出「继续下一章/下一节」。**
教学进程的推进只由「消化完成」驱动，不由「翻页进度」驱动。

## 跨领域内容获取规则

- 优先：用户已知领域（求职/自媒体/投资/英语/生活）
- 主动：web_search 找真实案例、方法论、他人实践
- 不局限：用户知识库没有的从外部找，找不到就构造场景（标注「构造示例」）
- 考题多样化：至少1题来自非英语领域
