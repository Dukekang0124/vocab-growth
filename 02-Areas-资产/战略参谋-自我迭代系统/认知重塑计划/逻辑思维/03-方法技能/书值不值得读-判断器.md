> 来源：2026-08-05 ⑧号窗口整合（《如何阅读一本书》检视阅读 + 樊登TIPS原则 + 豆瓣书评洞察 + 用户定制）

> 关联：认知重塑计划分类规则（判断完→按类型建/归文件夹）

## 三关模型（先快后慢，层层筛选）

```
第一关：10分钟速判（值不值得碰？）
    ↓ 通过
第二关：深度标准（值不值得深读？）
    ↓ 通过
第三关：你匹配（值不值得现在读？）
    ↓ 通过 → 进认知重塑计划，完整消化
```

---

## 第一关：10分钟速判（《如何阅读一本书》检视阅读法）

拿到书先做系统性略读（10分钟摸清底细）：

| 步骤 | 看什么 | 判断什么 |
|:--|:--|:--|
| ① 书名+副标题 | 主题是什么 | 是不是要的方向 |
| ② 序言/前言 | 作者为什么写？解决什么问题？ | 有没有戳中 |
| ③ 目录 | 找3个关心的章节 | 有没有干货 |
| ④ 索引/关键词 | 翻到关心的词，看有没有具体方法 | 实操还是空谈 |
| ⑤ 随便翻3页 | 重点章节开头结尾 | 语言风格适不适合 |

**速判结论**：
- 序言讲不清解决什么问题 → 大概率空谈
- 目录找不到感兴趣章节 → 不适合现在
- 随便翻3页读不下去 → 风格不合

**通过标准**：至少1个章节让你想「这就是我想知道的」→ 进第二关

## 第二关：深度标准（樊登TIPS原则 + 补充）

| 标准 | 问自己 | 通过 |
|:--|:--|:--|
| T 工具性 | 能带走可操作的方法吗？ | 有具体方法 |
| I 新理念 | 有改变认知的新观点吗？ | 有反常识/新视角 |
| P 实用性 | 能用在求职/自媒体/生活里吗？ | 有直接场景 |
| S 科学性 | 有依据吗？不是鸡汤/玄学？ | 有案例/数据/逻辑 |
| 建设性 | 读完后更乐观/更有行动力吗？ | 不是让你更焦虑 |

**判断**：4项以上通过 → 值得深度读
**好书标准**（豆瓣书评洞察）：**「能与你的心智一起成长」——初读超过你，重读仍超过你。** 一遍到底的书不是好书，只是信息。

---

## 第三关：你匹配（定制部分——判断「现在的你」）

| 维度 | 问自己 | 例子 |
|:--|:--|:--|
| 心情匹配 | 现在心态适合读它吗？ | 心情不畅读《反脆弱》可能更焦虑，读心理学更合适 |
| 主线匹配 | 主线书还是支线书？ | 主线（逻辑表达）持续推进；支线（随心读）随时插入 |
| 优先级匹配 | 比手头的事更重要吗？ | 求职冲刺期读《超预测》>《人类简史》 |
| 重复检查 | 已读过类似的吗？ | 已有Skill覆盖的不重复读 |

**核心原则（用户定义）**：不被困在自己——支线书不需要「有用」才读（打开视野）；主线书必须「有用」才读。

## 输出格式（⑧号每次评估时用）

```
📊 书评：《XXX》
第一关（速判）：✅/❌ —— 序言说清/目录有关注章节/风格匹配
第二关（深度）：X/5 —— 工具/理念/实用/科学/建设性
第三关（匹配）：✅/❌ —— 心情/主线支线/优先级/不重复
结论：🟢值得深度读 / 🟡可浅读 / 🔴不值得 / ⏳现在不合适
```

## 分工铁律

- **⑧号跑三关**：提供信息+框架（查豆瓣评分、搜书评、对照已有体系）
- **用户拍板**：最终决定权在用户（AI筛掉80%，用户判断剩下20%）
- **心情匹配必须问用户**：只有用户知道自己现在想读什么，不猜
- **沉淀不停**：判断完 → 不管读不读，评估结果进认知重塑计划对应主题的 `04-交流沉淀/` 或 `00-阅读计划/候选池`

## 优先级铁律 🆕（2026-08-09 用户确立：「运用优先」）

> 用户原话：「基于自身目前的情况去读对我最有用的书中最有价值的章节，然后去深度内化，之后就是去运用，而不是把所学知识藏在积灰」「当前想做的事情太多了，但认知、深度思考、判断能力、逻辑表达、商业洞察远远不够，需要借助读书——最低成本的事情——提升自己，突破自己」

### 选书五步优先级（判断器输出的扩展）

```
① 当前情况：我现在最缺什么？（认知/判断/表达/商业洞察…）
    ↓
② 最有用的书：哪本书直接解决这个缺口？（不一定是「经典」，是「对症」）
    ↓
③ 最有价值的章节：读哪几章就够了？不是全书！（判断器必须输出章节）
    ↓
④ 深度内化：完整消化引擎（十层）走完
    ↓
⑤ 运用：变成内容/决策/行动/Skill——终点，不是藏灰
```

### 判断器输出格式扩展（每次评估必须含）

```
📊 书评：《XXX》
第一关（速判）：✅/❌
第二关（深度）：X/5
第三关（匹配）：✅/❌
📌 解决你当前哪个痛点：＿＿＿＿＿＿＿＿
📌 值得读的章节：第X章、第Y章（不是全书）
📌 读完怎么用：＿＿＿＿＿＿＿＿（内容/决策/行动）
结论：🟢值得深度读 / 🟡可浅读 / 🔴不值得 / ⏳现在不合适
```

### 藏灰检查（读完一本书后必问）

- 这本书的知识我用了吗？（做成内容/决策/行动/Skill）
- 还是读完了就放那了？（=藏灰=白读）
- 判断标准：**书读完一周内没有「用」的动作 = 这次阅读失败**
