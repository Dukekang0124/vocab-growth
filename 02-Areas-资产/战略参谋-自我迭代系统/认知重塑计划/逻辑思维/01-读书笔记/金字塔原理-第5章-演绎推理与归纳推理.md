# 金字塔原理 核心方法论（第5章 演绎推理与归纳推理）

## 一句话核心

**归纳是攒例子让观众自己得出结论，演绎是给结论让观众服气。单条视频是演绎，系列才是归纳——信任是归纳出来的。**

---

## 一、归纳（特殊 → 一般）

```
例子1：跟读一年的小明 → 不会自己说
例子2：跟读一年的小红 → 不会自己说
例子3：跟读一年的小刚 → 不会自己说
──────────────────────────────
结论：跟读不会让你开口说
```

- **方向**：从下往上，具体 → 一般
- **特点**：结论是「发现」出来的，可能错（例子不够时），但能产生新认知
- **关系**：第一点 = 第二点的概括；第二点 = 第一点的因素
- **用法**：有 3+ 个真实案例/经历时用，例子是护城河

## 二、演绎（一般 → 特殊）

```
大前提：所有只动嘴不动脑的方法都没用
小前提：跟读就是只动嘴不动脑          ← 不是重复，是「应用」
──────────────────────────────
结论：跟读没用
```

- **方向**：从上往下，一般 → 具体
- **特点**：结论是「必然」的——前提对则结论一定对。说服力强，但不产生新认知
- **关系**：第一点 = 整体；第二点 = 特例（包含关系，不是赘述）
- **用法**：讲「道理」时用，逻辑链条严密

## 三、对比表

| | 归纳 | 演绎 |
|:--|:--|:--|
| 第一点 vs 第二点 | 概括 vs 因素 | 整体 vs 特例 |
| 方向 | 从散到聚（上） | 从整到例（下） |
| 收网 vs 开锁 | 收网 | 开锁 |
| 风险 | 例子不够 → 被反驳 | 前提被推翻 → 全盘崩塌 |

## 四、苏不倦内容应用

| 视频类型 | 默认结构 | 理由 |
|:--|:--|:--|
| 方法纠正类（千万别系列） | **演绎** | 钩子是「你错了」——先给结论制造冲突，再用例子撑住 |
| 故事分享类（老外聊天实录） | **归纳** | 钩子是「经历」——先堆例子让观众自己悟出道理 |
| 资源推荐类 | 演绎 | 先给结论「这个有用」，再给理由 |
| 心态建设类 | 看选题 | 争议观点→演绎；共鸣故事→归纳 |

## 五、元认知收获（今天最深的点）

**单次教学是演绎，整个教学过程是归纳。** 通过多次互动「发现」用户学会了 = 归纳。这解释了为什么「系列才是归纳」——信任是靠多条实录沉淀出来的，不是一条视频证明出来的。

---

## 学习过程记录（三问消化法）

- **误区**：把归纳演绎当「考试概念」——能分对题，但没变成创作开关
- **为什么**：学校教的是逻辑题（答案唯一），真实世界是选择（看效果）
- **做法**：变成选题/审稿筛子——每条脚本前问「这条该演绎还是归纳？」
