## 二、核心公式（纲领）

```
收入增长 ≠ 更努力
收入增长 = 选择更大的环境 × 选择有结构性收益的机会
```

底层逻辑：**选择的杠杆 > 努力**。在错误的公司/行业，大部分努力都是白费的。

## 四、方法论分层

### 层1：选择两法则（视频1）

| 法则 | 内容 | 案例 |
|:--|:--|:--|
| 选更大的环境 | 上升大周期里环境拖着你走 | 放弃H1B进湾区大厂 |
| 选结构性收益 | 看能否带到下一量级，不看短期 | 选AI工程师而非数据工程师；拒绝20万/年顾问（时间换收入陷阱）|

### 层2：选行业三原则（视频2）

| 原则 | 判断标准 | 案例 |
|:--|:--|:--|
| ① 规模效应 | 增长指数型 + 边际成本递减 | 机器视觉线性标注成本→转天然标注数据方向；Meta广告边际成本趋零 vs 早餐店/北美中餐 |
| ② 付费验证PMF | 有人用真金白银付钱=需求为真 | 2024年Claude优化写代码场景=企业强付费动力 |
| ③ 上升期行业+增长中公司 | 裁员多发生在增长停滞公司 | 红海电商控成本裁人 vs 增长公司要人多 |

补充：**敢冒险**——稳定但慢性杀死career的机会比有风险但相信的机会更危险。

### 层3：消费观（视频3）

| 原则 | 内容 |
|:--|:--|
| Buy the Minimum | 买满足真实需求的最基础款，但考虑长期价值（健康/心理/时间）|
| 车=100%负债 | 有钱人停丰田马自达，维修便宜Liability小 |
| 自住房（贵地）=消费非投资 | 流动性/回报不如股权，只有税收+低利率房贷好处 |
| Frugal是好习惯 | 收入爆炸后漂浮→只买真正需要的 |
| Give维度 | 美国儿童理财书四层：Save/Spend/Invest/Give——中国教育缺Give层 |

### 层4：人生两阶段（视频4）

```
第一阶段：加法技能专场（产出=单价×时间）→ 攒本金+信用
   ├─ 人力杠杆：标准化/系统化 → 用别人的时间scale up
   └─ 金钱杠杆：用本金/别人的钱scale up portfolio
第二阶段：乘法技能（产出=收益率×本金）→ 本金增值
```

关键认知：
- 加法技能有天花板（工程师年薪$100万≈720万人民币，扣税后要15-20年才财务自由）
- 乘法技能学习曲线长（他练3年才收益略高于市场）→ **越早开始越好**
- 早期用小钱学大教训（2015年亏40%≈生活费7万；生命周期理论：年轻人财富大头是人力资本，亏损对总财富影响小；后期亏40%才是真40%）

### 层5：伴侣选择（视频5，爆款）

**伴侣=人生中最重要的职业决定**（巴菲特/Sandberg/华盛顿大学4000人追踪）

选人三标准：
1. 情绪稳定——情绪不稳定的伴侣=全天候精力抽水机
2. 分清轻重缓急——大多数吵架是鸡毛蒜皮
3. 三观匹配——没有对错，只看匹配（上进的人找躺平的伴侣走不下去）

金句：你身边最近五个人的均值——伴侣是权重最大的那个。
