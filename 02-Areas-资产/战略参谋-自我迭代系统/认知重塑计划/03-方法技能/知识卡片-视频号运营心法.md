# 📇 知识卡片：视频号运营心法

> 来源：《视频号运营攻略》（萧大业 艾乐）
> 卡片编号：007 | 创建：2026-08-14

## 是什么
视频号运营的核心：社交推荐+个性化推荐双螺旋机制；冷启动4法；引流私域6秘技；变现路径=视频号→公众号→个人号→社群→成交。

## 原理
- 视频号推荐=社交+个性化双螺旋：**朋友的喜好决定推给你的内容**
- 点赞=公众号文章的转发（更轻的裂变）——社交推荐是核心
- 私域撬动公域：前期靠社交推荐拿数据，数据好进官方推荐池

## 怎么用
1. **冷启动4法**：自己点赞+朋友圈 / 公众号文章推广 / 高质量社群点赞群（前期）——私聊推广不推荐
2. **引流私域6秘技**：评论区引流 / 简介引流（可放微信）/ 扩展链接（公众号）/ 私信引流（每天30限）/ 直播间引流
3. **引导4法**：手势向下指引 / 文案区引导（文字+表情）/ 地理位置提醒 / 文章标题引导
4. **变现路径**：视频号→公众号→个人号→社群→朋友圈→成交（人设统一，信任成交）

## 苏不倦映射
- 预冷启动=验证（发前给朋友点赞=社交推荐机制）
- 评论区引流=双置顶评论（已做）
- 公众号导流45%=已验证（视频号→公众号）
- **缺：个人号环节**（公众号→个人微信没打通）
- 点赞群：可试（前期助推），不依赖

## 反例
- 依赖点赞群不做内容（僵尸粉，算法不再推荐）
- 私聊频繁推广（消耗社交关系，被拉黑）
- 求关注不求内容（点赞群流量虚，早晚取关）

## 边界
- 适合微信生态运营（视频号/公众号/私域）
- 社交推荐需要真实好友关系链
- 冷启动期≈1个月，后期靠内容

## 我的理解（苏不倦视角）
我的预冷启动不是玄学是算法设计。评论区引流=双置顶评论已验证。下一步补「个人号」环节：视频号→公众号→个人微信→带货成交。
