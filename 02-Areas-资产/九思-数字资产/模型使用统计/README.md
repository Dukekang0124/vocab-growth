# 模型使用统计工具 · 使用说明

> 位置：`02-Areas-资产/九思-数字资产/模型使用统计/`
> 创建：2026-08-26

## 文件清单

| 文件 | 用途 |
|---|---|
| `usage_data.json` | 数据文件，所有调用记录 |
| `usage_tracker.py` | 记录+生成看板的Python脚本 |
| `模型使用统计看板.html` | 可视化看板（浏览器打开） |

## 九思自动记录规则

每次执行任务后，九思自动调用以下命令记录：

```bash
cd "D:\写作工具\知识管理\02-Areas-资产\九思-数字资产\模型使用统计"
python usage_tracker.py log --model "模型名" --category "环节" --task "任务描述" --cost high/low/free
```

**算力类型：**
- `high`：高算力（Pro深度思考、办公任务/Agent、视频生成）→ 消耗额度
- `low`：普通（Turbo聊天、简单文案）→ 不消耗高算力额度
- `free`：免费模型（智谱GLM-4-Flash等）→ 完全免费

**环节分类：**
日常对话 / 内容创作 / 代码开发 / 信息检索 / 数据分析 / 图片生成 / 视频生成 / 办公任务/Agent / 翻译/英语 / 其他

## 生成看板

```bash
python usage_tracker.py report
```

生成/更新 `模型使用统计看板.html`，浏览器直接打开。

## 检查预警

```bash
python usage_tracker.py check
```

## 看板功能

- 总览卡片：总调用、今日、5小时窗口、高算力、预警数
- 模型占比饼图
- 环节分布柱状图
- 7天趋势折线图
- 算力类型占比
- 模型×环节交叉表
- 阈值预警面板（接近/达到上限红色预警）
- 最近记录表格（支持按模型/环节/算力/日期筛选）

## 阈值设置（免费版参考）

| 模型/环节 | 每日上限 | 5小时滚动 |
|---|---|---|
| 豆包2.1 Pro（深度思考） | ~3次 | ~5次 |
| 办公任务/Agent | ~3次 | ~5次 |
| 图片生成（高清） | ~5张 | - |
| 视频生成 | ~10条(5秒) | - |
| Turbo普通聊天 | 无限 | 无限 |
| 智谱GLM-4-Flash | 免费 | 免费 |

阈值可在 `usage_data.json` 的 `thresholds` 字段修改。
