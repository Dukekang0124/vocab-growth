## 二、作品完整拆解

### 1. 反常识点：戳破「人人都该用AI代劳」这个当下最流行共识

- **矛头**：现在很多人拍短视频，让 AI 抓热点 → 抓选题 → 生成文档 → 生成逐字稿 → 照着念——「这里边你有思考吗」。
- **反常识落点**：AI 用得越多，思考能力越退化。AI 时代真正稀缺的恰恰是**思考能力、判断力、从 0 到 1 的建模能力**。
- **致命机制（说透为什么）**：像玩游戏一样有即时反馈——你能力不强时，AI 做的东西通常比你好，你会「觉得自己越来越强」，其实越陷越深。这是「正向反馈陷阱」。

### 2. 钩子：双钩叠加

- **反常识断语钩**：「AI 会让我们越来越笨，而不是越来越聪明」——一句话站到主流对面。
- **身份悬念钩**：「那你（在这个AI时代）的不可替代性在哪？」——把话题从「工具」拽到「你自己」，制造焦虑+好奇。

### 3. 金句（可转发资产）

- 「你的生态位不取决于你会不会飞，而是取决于你的不可替代性。」
- 「AI 时代最重要的是思考能力、判断力、从0到1的建模能力。」
- 「我不是把全部交给 AI，我是让 AI 帮我不断完善。」
- 「用AI的人多了，想事的人少了，那就是你的竞争力。」（题眼）
- 「能力不强时 AI 做的比你好，你会越来越觉得自己强，其实陷进去。」

## 三、四步法（这条作品的方法论本体 = 收藏抓手）

姜胡说演示自己怎么做自媒体，四步（这是全片最值钱、最该抄的部分）：

```
① 建模（人自己从0到1，AI不代劳）
   刻意五问：拍给谁？传达什么思想？当下问题是什么？用什么结构论证（故事 or 论证）？最后落点什么？
   → 这是完全用大脑的「从0到1建模」阶段，绝不让 AI 生成文档。

② 录音口述 → 扔给AI纠偏
   不管严谨性，先对着录音把完整想法梳理一遍（结构好不好看不重要）。
   再扔给 AI：找关键点、找哪里不对、哪里能补、给多角度（"我没想到这个…这个可以补"）。
   → AI 是「对撞激荡」，不是「代笔」。

③ 对着镜头复述（费曼验证）
   "我不是拍短视频的，我是把这个观点重新复述给你"——复述本身是重新梳理、重新验证的过程。
   每个知识点、方法都重过一遍，输出即加深理解，不是拍完就扔。

④ 发布后看评论/收藏 → 校准
   拍之前有预判（讲给谁/什么问题/什么方案），拍完看评论、看收藏，验判「我对市场的判断对不对」，
   拿回来重新校准、修正。
```

**四步串起来 = 大脑一条完整的「构建 → 对撞 → 复述 → 校准」闭环**。收藏理由极强：这是可以一张图带走的完整工作流。

## 六、对康哥的可复用资产（能抄什么）

1. **「五问建模」进选题立项前置**
   姜胡说①步五问：拍给谁 / 传达什么思想 / 问题是什么 / 用什么结构 / 最后落点什么。
   康哥已有 Step1「拍给谁」（成年人想自学），但缺后四问。把五问做成选题立项的固定前置——这条能直接坐实「写脚本动笔前先写三行」的升级版。

2. **「拍摄=费曼复述，不是照念」进审稿卡**
   康哥分工是「康哥初稿 + 九思审稿」，有个隐形风险：康哥拍摄时可能照念九思审稿版——这恰恰是姜胡说③步批评的「让AI生成稿子照着念」。补一条铁律：**拍摄口播时，对照审稿意见自己复述一遍，不逐字照念**，才是「输出即学习」。

3. **「看评论/收藏校准」内嵌进人机共创卡**
   康哥的「数据驱动复盘」是外挂动作（事后跑三动作）。姜胡说的④步把它内建成内容生产的最后一环。把这一步补进人机共创卡，让「发布 → 看数据 → 校准」成为闭环的一部分，不是事后补救。

4. **「自我开源」可做一个选题方向（但必须锚回英语）**
   姜胡说把「我怎么用AI做内容」当内容 show 出来。康哥同理可以 show「一个专科生怎么用AI（九思）搭出自己的英语开口系统」。但注意：锚是「英语开口」这个结果，不是「用AI」本身——别做成纯工具分享脱锚。

### 不能抄的（会翻车）
