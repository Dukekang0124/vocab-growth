# 18-单作品系统分析 SOP

> 九思 2026-08-23 · 发作品地址 → 四层拆解 → 标准诊断报告
> 定位：把散落的分析能力串成一条统一流水线，康哥发任何平台作品地址都能套用

---

## 一句话定义

给一条作品地址 → 跑四层拆解（数据归因 + 内容拆解 + 结构裂解 + 可选合规）→ 出统一格式诊断报告（🔴致命 / 🟡关注 / 🟢积极 + 下周行动）。

---

## 一、输入前置（两类输入）

分析一条作品，缺两类输入都拆不准，先向康哥要齐：

| 输入 | 谁提供 | 说明 |
|:--|:--|:--|
| **作品链接** | 康哥发 | 九思抓内容：抖音/公众号正文可 WebFetch；视频号/小红书可能抓不全 |
| **后台数据** | 康哥补截图 | 官方后台是唯一精准数据源（见 [17-数据采集分层方案](../05-学习与工具/17-数据采集分层方案.md)） |

**能力边界（必须明确，不许装懂）**：九思能抓「内容」，抓不到「官方后台数据」。数据类指标（播放/完播/涨粉/收藏比）必须康哥补后台截图，九思只负责归因，不负责编数据。

---

## 二、输入路由（两种模式）

| 康哥说 | 走哪条 | 分析重点 |
|:--|:--|:--|
| "这条分析下""这周的作品帮我复盘" | **复盘向**（分析自己作品） | 四维归因 + 下周行动 |
| "拆下这条对标""这条为什么火" | **拆解向**（分析对标作品） | 结构裂解 + 可迁移点 |

两种模式共用同一套四层拆解，只是侧重点不同；复盘向偏「归因+行动」，拆解向偏「结构+可迁移」。

---

## 三、四层拆解流水线

> 每层不重写方法，用「关联」指向原文档，避免双写。

### ① 数据层（归因）

- **判标**：对照核心指标健康值（引用 [08-数据分析](../04-数据与复盘/08-数据分析.md) 的指标体系：收藏率>60% / 完播>40% / 2秒跳出<40% / 赞播比>1% / 评论条均>5）
- **归因**：用四维复盘法——浏览量→选题对不对 / 涨粉→价值够不够 / 完播→结构好不好 / 评论→新选题在哪
- **产出**：每条数据落到「哪个环节出问题」

### ② 内容层（拆解）

- 开头钩子类型识别（反常识/数字冲击/悬念/痛点直击/结果前置）
- 逐句触发标注（钩子句→翻车句→认知句→反驳句→金句→站队句）
- 结尾收获（认知/行动/情绪）
- 爆款四要素对照（信息价值/调性/反常识/情绪）
- 苏不倦风格清单核对（正面用没用上、壁垒词有没有踩）
- 引用 [04-内容创作](../01-系统方法论/04-内容创作.md)

### ③ 结构层（裂解）

- crack 四维钩子：视觉钩（封面/首帧）× 文字钩（标题/字幕）× 口播钩（第一句/金句）× 剧情钩（情绪曲线/反转）
- 骨架模板：开头（场景/痛点）→ 转折（反常识）→ 方法（步骤）→ 结尾（CTA/金句）
- 封面公式 + 标签策略
- 引用 [social-account-doctor](../../04-SKILL/social-account-doctor/SKILL.md)

### ④ 合规层（可选，仅发布后被限流怀疑时启用）

- 违禁词/敏感画面/带货一致性/引流诱导
- 引用 [self-media-compliance-review](../../04-SKILL/self-media-compliance-review/SKILL.md)

## 四、跨平台分析差异表

| 平台 | 重点指标 | 拆解侧重点 |
|:--|:--|:--|
| 抖音 | 完播率、2秒跳出率、赞播比、收藏率 | 开头钩子 + 逐句节奏 + 收藏驱动 |
| 视频号 | 观看时长、挂车转化 | 中段留存 + 挂车时机（短视频挂车） |
| 小红书 | 笔记收藏、评论 | 封面大字 + 图文价值密度 |
| 公众号 | 阅读、在看、留言 | 标题打开率 + 长文价值 + 留言互动 |

## 五、标准报告模板（统一输出格式）

```markdown
## 单作品分析报告

**作品**：[标题 / 链接] · 平台：[抖音/视频号/小红书/公众号]
**分析模式**：[复盘向 / 拆解向]

### 数据快照（需康哥补后台截图）
播放 / 完播率 / 2秒跳出 / 赞播比 / 收藏比 / 涨粉 / 评论

### ① 数据层归因
[四维复盘：哪个环节出问题 + 数据证据]

### ② 内容层拆解
[开头钩子类型 / 逐句触发 / 结尾收获 / 爆款四要素 / 风格清单核对]

### ③ 结构层裂解
[四维钩子 / 骨架 / 封面 / 标签]（拆解向：额外标「可迁移点」）

### ④ 合规层（可选）
[违禁/合规风险]

### 诊断结论
🔴 致命问题 / 🟡 需要关注 / 🟢 积极信号（分级列出）

### 下周行动
[按优先级排列的具体动作]
```
