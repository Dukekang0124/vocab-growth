## 内容生产标准流程

```
1. 先查后做
   ├─ 搜OB：选题库/方法论/历史脚本/复盘记录
   ├─ 搜历史：同类内容之前写过没有
   └─ 确认不重复 → 进入创作

2. 创作
   ├─ 调用对应Skill（newmedia-writing / multiplatform-rewrite等）
   ├─ 文案风格对标苏不倦（活人感、口语化、不端着）
   └─ 口播脚本结构：钩子→痛点→干货→行动召唤

3. 去AI味
   ├─ 强制调用 doubao-human-signal
   └─ 参照OB活人感规则：07-Hermes/03-数据资产/活人感规则.md（只读参考）

4. 合规检查
   └─ 发布前调用 marketing-material-review

5. 沉淀OB
   ├─ 成品写入对应目录（见路径表）
   ├─ 工作日志记录本次产出
   └─ 可复用经验提炼成方法论/工作流，写入苏不倦方法论目录

6. 四查
   ├─ 查全：需求全覆盖？
   ├─ 查准：事实/数据/路径准确？
   ├─ 查沉淀：已写入OB？经验已固化？
   └─ 查风格：去AI味？苏不倦风格？结论明确？
```

## 苏不倦风格红线

- 定位：「自学者给自学者发地图」，不做「英语老师」人设
- 语气：35岁痛定思痛型普通人，真实、不装、有翻车经历
- 文案：口语化、短句、有情绪起伏、不说教
- 禁用：「综上所述」「经过分析」「让我们来看看」等AI腔
- 学习观：早开口比先输入重要，「想说的欲望和敢说的勇气」> 知识积累

## 模型策略

- 文案创作：豆包2.1 Pro（中文创意最强）
- 批量改写/标题生成：豆包2.1 Turbo（快、省、效果比肩Pro）
- 自动化任务：免费模型里选最强的（智谱GLM-4-Flash等）
- 白嫖优先于付费

## 经验资产化规则

每次内容生产后，问自己三个问题：
1. 这次有没有产生可复用的写作模式/钩子模板/结构公式？→ 提炼成方法论
2. 有没有踩坑/翻车/被否定？→ 写进复盘记录和负反馈池
3. 同类任务下次能不能更快？→ 能则固化成工作流或Skill

**下次遇到同类问题还需重新摸索 = 这次没沉淀。**
