## 一、口播正文（逐字稿，约 420 字 / 90 秒）

学英语最坑人的四个字，叫「固定搭配」。我问你，contain 和 include 有什么区别？老师跟你说：固定搭配，背就完了。我跟你说啊，这四个字，毁了多少人。

我零基础学英语那两年，就被这四个字坑惨了。contain、include，背了忘、忘了背。我问为什么奶茶只能说 contains milk，不能说 includes milk？老师说，固定搭配。我问为什么套餐里include薯条？还是固定搭配。我当时以为，是我记性差。

后来我刷到一个视频，就一句话，我豁然开朗了——**拿出来试试**。把 contain 里面的东西拿出来，东西还是那个东西：杯子里的奶茶倒掉，杯子还是杯子。把 include 里面的东西拿出来，整体就塌了：套餐抽掉薯条，就不叫这个套餐了。

看清楚了吗？你缺的从来不是记性，是一个**能判断的标准**。「固定搭配」翻译过来就一句话：我也讲不清。讲不清不丢人，丢人的是拿四个字把你打发了。

现在任何"包含类"近义词，我十秒钟自己判断：第一步，找整体；第二步，把里面的东西拿出来；第三步，看它变不变。就这么三步，不用背。

这张近义词判断卡，现在截图存下来。评论区扣「判断」，下期我拿这个标准，给你拆 have got 和 have 的区别——评论区老有人问，我看到了。

## 四、近义词判断卡（置顶评论区图 · 待制作）

```
┌─────────────────────────────────┐
│   近义词判断卡 · 苏不倦           │
│                                 │
│  一个问题：拿出来，它变不变？      │
│                                 │
│  ① 找整体（谁是那个"东西"）       │
│  ② 拿出来（把里面的抽走）         │
│  ③ 看变不变                      │
│                                 │
│  不变 → contain（装着）          │
│  变了 → include（组成部分）       │
│                                 │
│  例：奶茶倒掉，杯子还是杯子        │
│      → the cup contains milk     │
│  例：抽掉薯条，套餐不叫套餐        │
│      → the combo includes fries  │
│                                 │
│  ── 拿不出来判断的，才叫固定搭配   │
└─────────────────────────────────┘
```

- 视觉：白底或浅色卡纸质感，黑/深灰大字，「变不变」用橙色标，结论条用高亮底色
- 尺寸：竖版 3:4，方便截图存相册
- 底部署名：苏不倦｜自学者给自学者发地图
