这是一条超级干货的视频，对吧？我猜你们猜到了——我是怎么做短视频的，我是怎么构建我的系统的。

在直播的时候，我跟大家讲说，你们把录音录下来，录完了以后，把我的录音直接扔给你们的系统，然后让它直接根据我的情况，根据我讲的这个，直接构建你们的拍摄短视频的系统管线。结果呢——就不知道我说了啥了。我这个人喜欢说脏话，结果被警告了，所以没有录像。

那这样，我专门录一条视频。这条视频呢，你们拿去用。一个是你们看一下我是怎么做短视频的，另外一个就是这条视频，你们回头把它生成文字，告诉你们的AI，然后让它生成系统。对吧？看过直播的老伙计，你懂的，是吧？你懂的。你们遇到过像我这么好的人吗？

开始啊，正式开始。

首先呢，拍摄短视频最重要的是什么？其实是选题。为什么是选题？我举个小例子啊，比如说我昨天晚上写的一篇文章，刚发出去很短，就十个评论。我上个礼拜写的一篇文章，到现在为止才五个评论。为什么？是上个礼拜的文章写的不好吗？我告诉你，不是。因为我上个礼拜的文章是告诉你，你赚够了一百万之后该怎么花——比喻啊，比喻啊——其实很多人是没赚够一百万的，这个文章和他没关系。

但是我昨天那个文章讲什么呢？怎么搭建你的最简单的智能系统。很多老伙计是特别特别需要的。

所以你看，很重要的——什么是命中用户的需求？就是用户关心什么呀？你看我讲的视频，有的时候天然会带流量的，为什么？就是你想听的，你想要的。我是怎么获得，我是怎么选题的。所以选题非常重要。

你看我讲的很多选题，就是怎么赚钱，怎么获取财富啊，怎么创业啊，怎么拍自媒体啊，怎么学习啊，怎么自我成长幸福啊——你说是不是你想要的？我之前看过有个人评论说："我懂了，讲怎么赚钱肯定有流量。"对啊，没错的。关键问题是你能讲啊。这扯的有点远了，记住——选题很重要，对不对？

选题怎么来？我们很多人的选题是这么来的：在网上找爆款，看谁的是爆款，从头到尾让AI给你分解，分解完以后把它抄过来。是不是这样的？很快你就没选题了，而且这种内容对你来说没有什么帮助的。

我跟大家讲，我是怎么做选题的。就是很多老伙计会问我问题，尤其我们社群的很多老伙计会问我问题，然后我会认认真真地回答。我会对这个问题进行统计——人们最近问的最多的问题是什么，这个问题有多少人问，那个问题有多少人问，那个问题有多少人问。我脑袋马上就会有一个痛点，有一个问题库。对吧？就是这么长时间以后，老伙计们问的最多的问题是排行榜——有多少人问，多少多少多少。所以我的选题从这里面直接拿就可以了，不是吗？

那很多人说，我没人问我问题——你可以看别人的评论区呀！尤其你像我的评论区的很多人问的问题，其实就是选题嘛。所以评论区就是选题。你很多人没有记需求的习惯，我跟你们讲，所有付费的问问题的地方，全都是好选题。统计一下，统计一下——他是不是就有选题了？

有了选题之后该怎么拍？你看选题有了吧？是不是短视频的流程，最基本的流程？这就是为什么我的短视频我不用太关注——你看你们拍那个视频，钩子钩子钩子钩子全是钩子，广告里面插播电视剧你们。但是你会发现，我根本就不太关注这个东西。为什么？就是选题。好吧，废话了。

下一步，该怎么拍？你们会发现，我拍视频永远有一个习惯，就是我的结构永远基本上是这个样子：我今天给大家分享一个方法，然后呢，比如说怎么拍短视频，我教你们一个很简单的赚点小钱的方法，我教你们怎么去学习。对吧？

你是不是有一个痛点？你是不是拍了视频没有播放量，播放量永远停留在五百？注意哦，这个是讲的稍微有点远，讲到哪说到哪。怎么营销？我告诉你，这不是一个好选题，这根本就不是问题。你看"怎么营销"是不是很大？对不对？但是你说"我的播放量卡在五百，一直卡在五百，怎么办？"说明什么？说明这个人是不是行动了？是不是正在行动，就卡在那了——这才是真正的痛点啊！卡着了。

所以你会发现，我一上来就痛点——你是不是有这个问题？然后我告诉你方案，我告诉你解决方案，我是怎么做的，一二三四五。你看，问题→解决方案，问题→解决方案。你看我的视频，所有的问题都放了，都是问题→解决方案，问题→解决方案。然后给你讲讲道理，原因是什么。

其实我跟你讲，我如果不讲道理，我的播放量会更高。我讲了道理以后，播放量就会低，因为没人愿意听你废话。但是我为什么还要讲道理呢？过滤。实话说，过滤——就是我要牺牲播放量，然后我来瞄准，就是真正过滤掉一些不是我的用户。

很多人说你不是神经病吗？不是神经病。昨天我拍视频的时候，很多人还问"遇到白嫖了怎么办？"你把他过滤出去呀！对吧？没有信心、没有耐心听完的，连内容都没耐心听完的，他一定不是你的用户。是不是？省事嘛，是不是？

你可以像我一样——问题背后的原因，然后解决方案，最后一句话总结。当然了，你如果要想要播放量的话，把那个解释原因那个地方去掉，没人想听原因的，直接解决方案。

那你会发现，我的这种短视频拍起来是不是特别容易？你看我今天这个视频是不是特别容易？不用去想钩子，不费事。对吧？问题→解决方案。那这种视频出来以后有个缺点，就是平台不一定会推你，流量没那么多。但是这种有个特别好的点是什么？有个特别好的点是——用户会搜过来。

那很多时候用户怎么搜啊？我教你们一个方法：永远不要用高大上的词，就是人们说什么你就说什么，你就这么说就好了。人们平时怎么说、怎么表达，你就怎么表达。然后短视频都会抽取文案，这种文案他在后面匹配的时候就搜出来了，特别方便。你看好多人现在直接打开短视频就直接搜的。

所以我的视频都有个特别有意思的点——就是刚开始播放量都不高，过上一段时间，播放量就几十万了、上百万了，甚至有上千万的。但是这种视频都是用户搜过来的，搜过来的用户是特别精准的用户。有些时候推的那个用户那个流量，半个月以后就没了——烟花易冷。但是你这个是资产，一直有，一直有。

所以你看我们拍短视频，你看我拍短视频——很简单吧？搜集问题，尤其是付费的问题，然后它就是能直接命中用户的痛点。人们听的就是我想要的东西。然后——你有什么问题吗？我的结构：你有什么问题吗？我告诉你几个方案，一二三四五步，然后一句话总结，就完事了。对不对？

拍短视频就这么拍。我的短视频就这么拍。你如果想像我一样做那种，真的是让人们喜欢的 IP，然后还能赚钱——你就不用到处找，因为你能解决问题，你的每一条视频都是试用装。挣钱肯定赚，你不用想挣钱的问题，钱一定挣了。我证明。

我刚才不是讲还怎么做 AI 的吗？把这条视频转化成文字，然后扔给你的智能体。智能体可不是——我不点名了，点名了也会封我了。我推荐你们用 Codex，Claude Code，Hermes 不行，WorkBuddy 也行。然后呢，你直接跟他说，说"这是我喜欢的一个博主，他告诉我怎么构建自己的系统"，然后你把录音扔给他，然后你告诉他说"先不要直接执行，你把他的整个构建智能体的方法帮我梳理出来，然后根据我的情况来进行调整，给我一个拍摄短视频的管线的一个基本方案，然后我们再一步一步的调整你拍摄短视频的系统"。第一个系统就这么出来了。

我真是个好人。

## 核心要点提炼

### 1. 选题方法论
- ❌ 抄爆款 → 很快没选题，对创作者本人无帮助
- ✅ 看评论区 + 付费问答 → 统计高频问题 → 排出痛点排行榜 → 选题就有了
- 金句：「评论区就是选题」「所有付费的问问题的地方，全都是好选题」

### 2. 内容结构公式
```
问题（痛点）→ 解决方案（12345步）→ 原因（可选，用于过滤用户）→ 一句话总结
```

### 3. 搜索流量 > 推荐流量
- 推荐流量半个月就没了（烟花易冷）
- 搜索流量是资产，一直有
- 标题用大白话，人们怎么搜就怎么写

### 4. 每一条视频都是试用装
- 你能解决问题 → 用户自然会找你 → 钱一定挣了

### 5. AI工具推荐（姜胡说原话）
- Codex / Claude Code / WorkBuddy
- 把视频转文字 → 扔给AI → 让AI梳理方法论 → 根据自己情况调整 → 生成系统管线

## 转录技术说明

- 音频获取：Playwright 拦截抖音 `/aweme/v1/web/aweme/detail/` API → 提取 `bit_rate_audio` 独立音频URL
- 音频参数：AAC HE v2 / 44100Hz / 2声道 / 13MB / 554秒
- ASR引擎：faster-whisper small 模型（CPU int8）
- 后处理：人工修正专有名词（Codex、Claude Code、Hermes、WorkBuddy 等）
- 转写耗时：约700秒
