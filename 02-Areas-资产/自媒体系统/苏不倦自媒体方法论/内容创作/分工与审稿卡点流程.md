# 分工与审稿卡点流程

> 2026-08-26 · 九思 · 康哥定「你先写、我优化」的模式后落地
> 用途：把「谁写初稿、谁审稿、审稿过什么关」一次性钉死，避免风格打架和内耗。
> 一句话：**初稿康哥（或 Hermes）出 → 九思只做「卡点检查 + 精准改」，一人一岗，不抢笔。**

---

## 一、为什么这么分（先说清楚根子）

之前的问题不是「写得不够好」，是**两个 AI 都下场写，风格不统一、来回改、内耗**。

- Hermes 写一版，九思写一版，康哥在中间挑——挑的不是好坏，是**两种画风**。
- 九思优化又忍不住重写整篇，等于把康哥的「活人感」和「他自己的话」给替掉了。

**分工原则三句：**
1. **初稿的「人味」只能来自写的人**——康哥/Hermes 出初稿，保住「困境里的我」这个不可替代的叙事。
2. **审稿的「标准」只能来自数据定论**——九思只对照红线卡和卡点清单，做「查漏+精准改」，不重写。
3. **一条稿只经过一次「审」**——九思审完给出「改哪里、为什么改」，康哥改完就可以拍，不再往返第三轮。

---

## 二、分工边界（谁干什么，钉死）

| 环节 | 谁做 | 干什么 | 交付物 |
|:--|:--|:--|:--|
| ① 选题 | 康哥/Hermes 提，九思查 | 拿出一个候选题，九思拿它过「选题红线卡」 | 过卡/打回 |
| ② 写初稿 | **康哥 或 Hermes** | 按叙事驱动写完整口播脚本（困境里的我） | 一版有毛边的初稿 |
| ③ 审稿 | **九思** | 对照「审稿卡点清单」逐项勾，只给「改哪+为什么」，不重写 | 一页审稿意见 |
| ④ 改稿 | 康哥 | 按九思意见改（默认保留细节，不砍） | 定稿 |
| ⑤ 排版/发布/复盘 | 九思 | 排好版待发 → 发布 → 数据复盘反哺红线卡 | 待发布稿 + 复盘 |

**三个铁规矩：**

1. **九思不写初稿，只审**。除非康哥明确说「这条你直接写」，否则九思不动笔写正文，避免又变回两家打架。
2. **九思给意见默认「保留」，不默认「砍」**。犹豫该不该删一段 → 保留（苏不倦自改版每次都加细节/情绪/场景，从不砍）。
3. **拍摄口播 = 费曼复述，不逐字照念**（姜胡说四步法③）：康哥拍摄时对照审稿意见自己复述一遍；照念 = 把思考外包给稿子，脑子退化。拍不出来说明这稿还没吃透，回去再想。

## 三、交叉触发词（康哥说了哪个词就启动哪个动作）

| 触发词 | 动作 |
|:--|:--|
| 「我写好了 / Hermes写好了 / 审稿」 | 九思启动③审稿，输出一页审稿意见 |
| 「你直接写这条」 | 九思破例写初稿，写完仍走③自审 |
| 「改好了 / 可以拍了」 | 结束审稿，进入⑤排版→待拍 |
| 「拍摄了 / 已拍摄」 | 脚本移入「待发布（文章）」 |
| 「我发布XXX / 发布XXX」 | 九思按公众号排版格式排版 →「排好版待发」 |
| 「发完了」 | 移入归档库，按去向加前缀 |

> 触发词与「脚本流转机制」一致，不另建新仓，沿用 `短视频创作脚本/` 三子文件夹。

## 四、审稿卡点清单（九思审稿时逐项过）

> 这是把散落在「02-理论纲领 / 04-内容创作 / 内容创作机制速查 / 25号定论」里的审稿标准收敛成一页，替代已丢失的 `oral-script-review` Skill。分三档：**A 红线（不过=打回重写）、B 必改（改完才算过）、C 加分（能加就加）。**

### A 档 · 红线（一条不过，直接打回，不救）

| # | 卡点 | 判断标准 | 依据 |
|:--|:--|:--|:--|
| A1 | 三要素齐全 | 反常识点 + 高频动作 + 收藏抓手，三行都写得出；写不出=选题不立项 | 25号铁律② |
| A2 | 标题兑现 | 标题承诺的东西，正文给了；不能标题「300词开口」正文没给清单 | 审稿核心维度 |
| A3 | 有收藏抓手 | 必须有可截图保存的清单/步骤/路径；纯观点没步骤=打回 | 25号铁律① |
| A4 | 认知挂英语场景 | 纯泛认知（不进英语场景）→ 打回，认知只做场景锚定 | 25号铁律④ |
| A5 | 开头不铺垫 | 前3秒直接进冲突，删「今天跟大家聊」这种清嗓子 | 表达逻辑链 |

### B 档 · 必改（改完才算过，九思给具体改法）

| # | 卡点 | 判断标准 | 依据 |
|:--|:--|:--|:--|
| B1 | 黑粉测试 | 逻辑有没有硬伤会被喷；「高级≠好」这类对立要自洽 | 逻辑一致性 |
| B2 | 争论点 | 观众看完会不会想评论/反驳；没争论点=曝光潜力低 | 扩大曝光战略 |
| B3 | 节奏密度 | 每 15 秒一个钩子/反问/停顿，不连续 20 秒纯讲道理 | 109教训 |
| B4 | 深度拆碎喂 | 第3层深度压成 1-2 句金句砸出，不铺 100 秒 | 109教训 |
| B5 | 金句 | 每条一句可截图转发的话 | 内容机制速查 |
| B6 | AI味词=0 | 首先/其次/综上所述/赋能…黑名单全清 | AI味检查 |
| B7 | 活人感5条 | 语气词/口语动词/情绪重复/成果具体/场景具体，缺哪补哪 | 写后验证 |
| B8 | 双置顶评论 | ①橱窗引流 + ②争议钩子，两条都写 | 写后验证 |
| B9 | 差异化 | 去掉「翻车史」，这条还剩什么独特视角 | 护城河 |
| B10 | 挂商品 | 挂什么教材、挂不挂车，明确（千万别系列不挂车） | 变现路径 |

### C 档 · 加分（能加就加，不影响过关）

| # | 卡点 | 说明 |
|:--|:--|:--|
| C1 | 结果承诺钩 | 结尾加「结果向」承诺钩关注（14天流利说/300词开口），涨粉引擎 |
| C2 | 金句打磨 | 把金句磨到「绕不过去」 |
| C3 | 差异化强化 | 补「只有过来人才踩过的坑」细节 |
| C4 | 站队钩子 | 口播结尾放站队，让观众选边 |

## 五、审稿输出格式（九思固定这样回）

```
【审稿结论】过 / 打回（A档未过）
【A档红线】✅全过 / ❌第X条没过 → 具体打回原因
【B档必改】逐条给「改哪 + 为什么 + 改成什么样」
【C档建议】可选，康哥自己定
【一句话】这次改完，这条能到什么水平
```

**原则重申：先分析为什么不好，再给修改建议；不直接塞改好的全文（那是重写，不是审）。**

---

## 六、这条流程的验收标准

康哥说了「你写 / 审稿」，九思做完必须能这样自查：
1. 没有自己下场重写初稿（除非康哥明说「你直接写」）。
2. 审稿意见按「A红/B必改/C加分」三档输出，每条带「为什么」。
3. 三要素（反常识/高频动作/收藏抓手）任一条没写出来，这条不敢放行。
4. 改完的稿子，收藏抓手是「可截图的清单/步骤」，不是一句观点。
