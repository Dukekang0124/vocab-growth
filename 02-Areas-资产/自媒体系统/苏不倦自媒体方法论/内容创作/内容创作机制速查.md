# 🎬 内容创作机制速查（2026-08-22 建立）

> 用途：内容创作全流程「做什么 + 做到什么程度」一页速查。覆盖**三种内容形态**：①短视频口播（苏不倦）②播客（今日进化）③公众号（九思对外输出）。
> 定位：不是"教方法"，是"展示困境里的我"——方法只是赠品，踩坑时的感受才是主角。
> 判断标准本质：AI能写公式/步骤=叙事不够；AI写不出你的具体困境+真实情绪=才算到位。

---

# 第一部分：短视频口播（苏不倦·主战场）

## 内容创作闭环（7环节，缺一环影响最终数据）

① 选题 → ② 写脚本前（查证）→ ③ 写脚本（叙事）→ ④ 写完后（验证）→ ⑤ 审稿 → ⑥ 发布 → ⑦ 复盘

---

## ① 选题环节

**做什么**：评论区/私信挖需求（不是自己想）；先查选题系统确认没拍过；用争点理论（共同事实+不同解释+待判问题）加争议性。

**做到什么程度**：
- 至少命中2个黄金维度（笑点/热点/共鸣点/冲突点/知识点/槽点）
- 流量天花板 = **共情面 × 信息价值**（共情面窄=锁死）
- 认知纠错选题**必须挂靠英语场景**（纯泛认知→观众困惑"英语还是情感"）
- 判断：这选题"让多少人想看/想评论/想反驳？"——没人想反驳=曝光潜力低

## ② 写脚本前（强制查证）

**做什么**：动笔前**必须输出📋查证清单**给用户看，逐条写。没输出=没查=违抗。

```
📋 写脚本前查证：
① 查思考模式库——用「XX」思考模式
② 查活人感规则——融入「XX」活人感
③ 查负反馈池——避免「XX」判断错
④ 查作品问题库——规避「XX」问题
⑤ 3问：选题覆盖够大？开头2秒有冲突？认知配干货？（逐条✅/❌）
```

**做到什么程度**：
- **3问必过**：①选题覆盖够大（「35岁」泛化→「成年人」）②开头2秒有冲突/爽点（不铺垫）③认知纠错配干货（收藏的是方法）
- **两句话消化**：核心观点（≤20字）+ 为什么值得讲（亲身经历验证）
- **写前6问**：写给谁/对他有什么用/什么场景看到/看完能立刻做什么/一句话概括/跟上一篇区别——**答不清别写**
- **深度到极限**：认知纠错挖到第3层"自我欺骗"，不停在"怕被笑"（完美主义=讨好；35岁挖到"你犹豫=自己信了太晚"）
- 判断标准：没输出查证清单=没查=违抗机制

## ③ 写脚本（叙事驱动·实验版总纲）

**做什么**：主角从「方法」换成「困境里的我」；选一个主表达框架（公式/故事/反转/对比/对话/场景），不固定套模板；用板书3关键词（痛点/原因/解法）；逐句标注功能（钩子句→翻车句→认知句→反驳句→金句→站队句），无废句。

**做到什么程度**：
- **狼狈时刻不是总结是还原**——重播全过程（误解→纠正→得意→再次被打懵），让观众跟你一起经历
- **金句必查**：每条必有一句可截图转发的话
- **记忆锚点**：固定开头「我是苏不倦。35岁零基础。不是老师，过来人。」（钩子位置让路）
- **不虚构**：真实经历只润色不改事实，外部知识先搜再写，不确定标"待验证"
- 判断：写完自查"这条AI能不能写出来？"——AI能写=叙事不够；AI写不出=到位

## ④ 写完后（强制验证）

**做什么**：立即**手动commit**一次（标记"九思写的版本"，让diff学习有清晰分界）+ 反向验证 + 活人感自查 + 双置顶评论。

**做到什么程度**：
- **反向验证3问**：①开头2秒有冲突吗②认知配干货吗③选题覆盖够大吗——没规避就改
- **活人感5条自查**（主动用，不是等用户改）：①语气词（啊/呢/咱）②口语化动词（算是/可以/就）③关键情绪重复④成果具体化（"学起来了"→"能跟老外日常交流"）⑤场景具体化——缺哪条补哪条
- **双置顶评论**（每条必带，别漏）：①橱窗引流（对应教材）+②引发评论（有争议钩子，不是"二选一"没争议）
- 判断：没有双置顶评论=脚本没写完

## ⑤ 审稿环节

**做什么**：黑粉视角自审 + 36+2维质量评估。

**做到什么程度**：
- **简化版=不合格**：狼狈时刻一句话带过/每点2句讲完/无正面清单词 → 都是"简化版信号"，必须改完整版（场景/感受/身体反应+每误区3-4句+解法每步2句+至少2个口头禅）
- **改稿默认保留**：犹豫该不该删一段→默认保留（苏不倦自改版每次都是加细节/加情绪/加场景，从不砍）
- **精简≠去活人感**：精简服务于活人感，不是反过来

## ⑥ 发布环节

**做什么**：按平台差异化 + 挂商品规则。

**做到什么程度**：
- **内容矩阵节奏**：周一方法纠正 / 周三争议观点(G类) / 周五老外聊天 / 周日可选碎碎念（系列寿命3-6个月，之后必疲软）
- **资源推荐类**：App/工具名**放评论区不放正文**（不触发导流审核+评论算互动+只给真有兴趣的）
- **挂商品**：抖音/小红书评论区挂橱窗+引导话术；视频号纯话术引导「点头像进橱窗」
- **带货教材匹配**：音标→赖世雄音标 / 语法→赖世雄美语 / 阅读→牛津书虫 / 口语→走遍美国

## ⑦ 复盘环节

**做什么**：分析数据 → 发现问题 → 反哺作品问题库。

**做到什么程度**：
- **先看发布时间**：<4h=泛流量不下结论；24h初步；48h才可下结论
- **五层漏斗逐层诊断**：曝光→点击→3秒→完播→互动（不平均用力，假设驱动）
- **数据不好三原则**：不删/不隐藏，看后台，**肯定是内容问题不是别人的原因**
- **问题反哺**：发现问题模式（选题窄/开头平/认知没干货）→ 记入作品问题库 → 下次写脚本前查库规避
- 判断：分析完发现问题没记库=下次还犯

---

## 内容创作核心铁律

1. **叙事驱动**：主角是「困境里的我」不是「方法」——AI时代方法论不值钱（AI一问就有），真实困境+活人观点才值钱（个人轶事22倍留存率）
2. **深度到极限**：认知纠错挖到第3层"自我欺骗"，不停在表面情绪
3. **扩大曝光**：曝光>一切，选题要有争议点（争议=推流引擎），但「争议开头+高价值内核」才是完整打法
4. **共情面决定天花板**：共情=把新体验链接上旧体验，选题往上走共情面越大
5. **活人感=信任=数据**：精简服务于活人感，不是反过来
6. **不虚构**：真实经历只润色，绝不编造
7. **学了必须用出来**：学到新内容自动三问（能用在哪/下次什么时候用/用什么动作用）

# 第二部分：播客制作（九思·「今日进化」）

> 形式：对话式（苏不倦真人声 + 九思AI声）。品牌「今日进化」，主播「九思同学」。平台：小宇宙主阵地 + 公众号/视频号/喜马拉雅/网易云/QQ + 海外Firstory。

## 制作流程（6步闭环）

① 选题（成长类，可用06-Wiki概念）→ ② 写对话剧本 → ③ 用户录音（苏不倦真人）→ ④ 九思TTS配音 → ⑤ FFmpeg合成（对话交替+BGM）→ ⑥ 发布（小宇宙+多平台）。

## 做到什么程度（关键标准）

| 环节 | 标准 |
|:--|:--|
| **剧本打磨** | 开场钩子15秒抓耳（真实扎心提问，不说「今天跟你说个事」）→ 才是「欢迎来到」正式开场 → 每点=抛问题→拆解→追问→分享 → 金句收尾 → 行动号召+评论钩子 |
| **录音工作流** | 逐条数出真人台词生成清单（第1期17条）→ 逐句录（自然聊天不播音，有停顿/笑真实）→ 降噪（**只降底噪保人声，不消音**）→ 每段收尾金句/行动 |
| **AI生成合规** | 发布必须开「本音频为AI生成」开关（九思台词=合成音有AI部分就必须标）；ShowNotes 自然标注「九思同学=AI」 |
| **TTS选型** | 选拟人方案（CosyVoice/ChatTTS，支持[laugh]笑声/[uv_break]停顿）；**Edge不够拟人（用户否定）**；九思女声固定=候选1（音色ID存.pt，不漂移） |
| **配乐** | 用**真实音乐**（落雪API拿网易云FLAC），**不用FFmpeg合成**（用户否定）；开头前奏15s+结尾收尾20s固定同一首（品牌识别）|
| **时长** | 第1期6.2分钟太短；**第2期起15-20分钟**（小红书要求≥10分钟）|
| **ShowNotes** | 5段结构：引子/精确时间轴（wave读时长，**不估算**）/核心金句/本期行动+互动钩子/播客介绍 |

## 坑（实测踩过）

- FFmpeg 读中文路径列表会断（只拼出前几秒假成品）→ 先标准化ASCII临时文件再concat
- ChatTTS 数字不读→改中文数字；重复→只留一句；<3字短句生成残缺→改自然长表达
- 合成后只有几十秒=concat断了，完整版时长≈素材总时长

# 第三部分：公众号写作（九思·对外输出）

> 定位：九思对外输出，小白能懂的AI文章。品牌「今日进化」。AI写+排版，**用户手动发布**（自动发布=红线）。

## 写作原则（红线）

1. **不说教**——「你可以试试」不是「你应该」
2. **跟小白站一起**——不装专家，是「同路人」（身份=用AI的人）
3. **真实痛点开头**——不是「今天我们讲AI」，是「你是不是也收藏了100个AI工具一个没用上？」
4. **600-900字**（深度升级后1500-2000字）——小白读得完
5. **一篇一题**——不贪多讲透一个
6. **有观点**——独立思考不中立打太极
7. **可验证**——读者看完能立刻试

## 写前6问（答不清别写）

写给谁（具体到阶段）→ 对他有什么用 → 什么场景用 → 怎么用（看完能立刻做什么）→ 一句话概括（≤20字）→ 跟上一篇区别在哪。

## 开头钩子（前3秒）

- **删清嗓子**——「今天跟大家聊」「这篇文章讲」=浪费开头=划走
- **直接进冲突/痛点**——「你是不是也收藏了几百个工具，一个没用上？」
- **狼狈时刻**——「我第一次用AI问问题，它回我一堆废话，我差点卸载」（感受还原不是总结）

## 完成标准（写完必过）

- [ ] **AI味词=0**（首先/其次/综上所述/赋能…完整黑名单见 ai-wei-check）
- [ ] 口语词≥2个（我跟你说/说句实在的/你还别说）
- [ ] 开头直接进冲突没清嗓子
- [ ] 有真实经历/狼狈时刻，不是干讲道理
- [ ] 术语解释了（「提示词→跟AI说的话」）
- [ ] 标题兑现
- [ ] **有金句**（一句可截图转发的话）
- [ ] **有互动钩子**（文末提问引评论——补评论短板）
- [ ] **有收获**（方法/对比表/步骤/清单）
- [ ] 600-900字

## 排版规范（公众号）

字号15px（长文16）/标题20+16px加粗/行距1.75/页边距8-12px/正文#3f3f3f深灰/强调**品牌橙#FF8C42**（全文≤3色）；段落总分总（总结论→分3-4要点→总升华）；头部Slogan+引导关注，尾部4块（互动留言/往期精选/引导关注/点赞在看）+话题卡文末。**Markdown无色**——加粗能复制，颜色要标注 `【品牌橙】` 让用户手动套。

## 数据策略（公众号=搜一搜是唯一流量通道）

- 新号推荐0%冷启动，**用户主动搜索能搜到你**→ 选题必带「用户会搜的词」
- **标题=搜索词**（用户搜什么标题含什么）；连续同主题成「内容集群」
- 配封面图（搜一搜结果=标题+封面，有图点击率高）
- **数据心态**：周复盘4问（发几篇/哪篇最好为什么/最差为什么/下周改什么），不被单篇涨跌绑架
- **一次只改一个点**，爆款后复制不解释

# 三形态共性铁律

1. **最小可验证**：先发最小版本拿真实反馈，不闷头做到完美再发（≥1个用户看过/用过=有效验证）
2. **数据是进化燃料**：没有数据反馈=没验证的表达，分析数据才能优化
3. **用户手动发布**：AI写+排版+封面，**用户负责发布**（自动发帖=红线）
4. **设计产出放D盘**：封面/海报等放D盘，不放桌面/C盘
5. **发布后主动收集反馈**，不在「完美」再发，用市场反馈决定继续/调整/停
