# 🧲 内容注意力法则（Dan Koe 说服性沟通）

> 2026-08-12 消化沉淀。来源：Dan Koe（火山译）。
> 核心："人们不记得你说了什么，记得你让他们感受到了什么。"
> 用途：苏不倦内容创作（抖音/文章/播客）的标题/开头/选题底层逻辑。

## 捕获注意力10法则（标题/开头/选题用）

| # | 法则 | 说明 | 苏不倦例子 |
|:--|:--|:--|:--|
| 1 | **具体数字** | 数字越具体越抓人 | "学了3年英语，开不了口" |
| 2 | **模式中断** | 打破浏览节奏 | 突然的转折/反常 |
| 3 | **负面偏见** | 人脑关注负面 | "千万别跟读"（已验证）|
| 4 | **群体呼唤** | 呼唤特定人群选边 | "零基础学英语的人" |
| 5 | **问题呼唤** | 描述痛苦引发共鸣 | "为什么收藏了却改变不了" |
| 6 | **潜在利益** | 痛苦和收益切换 | "这样练，30天敢开口" |
| 7 | **社会证明** | 展示成果不炫耀 | "我这样找到第一个老外" |
| 8 | **信心与信念** ⭐ | **最重要** | "说真话，不卖焦虑" |
| 9 | **主动语态** | 暗示有故事 | "我踩过的坑" |
| 10 | **警告忠告** | 帮人避坑 | "这三个坑别踩" |

## 信心与信念（最重要的一条）
```
✅ 人们上社交媒体=被自信地告诉该做什么
✅ 消除不确定性词：也许/可能/有些人 → 确定的表述
✅ 绝对语气+夸大观点增加能量（"地球上每个人发展技能至关重要"）
✅ 领导者不在观点周围跳舞——苏不倦说真话人设=信心
```

## 留住注意力（2个关键）
```
✅ 故事结构：短行/换行/破折号（不是长段落——口播"一行一意"已验证）
✅ 新颖视角：从书/播客获取想法（不是社交媒体）——我们读书→内容链路正确
   隐喻+个人经验+创造新概念=新颖性三件套
```

## 制造参与（3种感受）
```
✅ 教育（学到东西→多巴胺）
✅ 灵感（帮人连接点→"自己想出答案"的感觉）
✅ 娱乐（笑话/梗/有趣观点）
→ 能同时做到2个，内容就炸
```

## 落地到九思OS
```
✅ ①号内容创作：选题/标题/开头 → 检查是否用足10法则（至少3条）
✅ 口播审稿（oral-script-review）→ 加"注意力法则"检查项
✅ 播客：开场钩子/结构 → 对齐
✅ 核心人设：信心与信念（说真话/不卖焦虑）→ 保持
```

## 触发
- 写标题/开头/选题时 → 检查10法则
- 审稿时 → 注意力检查（够不够抓人）
- 内容数据不好 → 先查"注意力"（是不是没捕获）
