# 扩大曝光战略与表达逻辑链（完整版）

> 2026-08-16 建立。整合：用户6铁律 + 外网STEPPS/情绪触发 + 李守洲爆款四要素 + 口播万能模板。
> 核心：**每一句都有功能，环环相扣**——开头引爆→中间传价值→结尾让人收获。

---

## 一、扩大曝光战略（6铁律）

| # | 铁律 | 含义 |
|:--|:--|:--|
| 1 | 选题覆盖面要大 | 哪怕吸引黑粉/不同意见也没关系 |
| 2 | 审稿判断曝光潜力 | 看「能引发多少讨论」，不只质量 |
| 3 | 脚本要有争议点 | 让用户忍不住评论，哪怕是开骂反驳 |
| 4 | 反驳同行为核心 | 同行讲过的，就以反驳他为核心 |
| 5 | 不局限选题思维 | 拓展面越大越好，英语只是起点 |
| 6 | 新瓶装旧酒可以 | 旧观点新包装=获取流量的手段 |

**平衡铁律**：争议打开入口，价值留住人。收藏比60-72%优势不能丢。

## 三、爆款四要素（李守洲）

| 要素 | 操作 |
|:--|:--|
| 信息价值 | 信息预期 + 比观众强的描述概括能力 |
| 调性高级 | 考虑受众词汇范围，不装逼 |

| **情绪价值** | ①认同观众本身 ②认同观众认可的人事物 ③**否定观众否定的事物** |

## 四、表达逻辑链（核心·逐句都有功能）

### 开头：3秒引爆（制造「知识缺口」）

**钩子三步公式**（外网 Postiz）：
```
context lean（语境前倾）→ scroll-stop interjection（停顿插入）→ contrarian snapback（反转回击）
```

**五种开头钩子**：
| 类型 | 模板 |
|:--|:--|
| 反常识 | 「99%的人都以为X，其实Y」 |
| 数字冲击 | 「学了3年英语，开口只会3个词」 |
| 悬念 | 「这个坑，我踩了3年才明白」 |
| 痛点直击 | 「你是不是也…（具体场景）」 |
| 结果前置 | 「我从哑巴英语到跟老外聊天，就靠这1件事」 |

**开头铁律**：前3秒必须让观众「自我选择」——是目标人群就留下，不是就划走（不要骗非目标人群看，会伤完播）。

### 中间：逐句触发（每一句都有一个功能）

**五大心理机制 → 对应动作**（外网+中文整合）：
| 心理机制 | 触发方式 | 让观众做什么 |
|:--|:--|:--|
| 好奇心 | 悬念/大揭秘/反转 | 想看完 |
| 情感共鸣 | 背后故事/后果反思 | 想点赞 |
| **社交需求** | 归属感/互动/**争议辩论** | **想评论** |
| 实用价值 | 技巧/列表/对比 | 想收藏 |
| 娱乐刺激 | 幽默/挑战/反差 | 想转发 |

**每5秒一个新信息点**（抖音），每个论点：结论→解释→例子（≤15秒）。

**逐句触发设计**（写脚本时逐句标注功能）：
```
钩子句（共鸣：说的就是我）
↓
翻车句（情绪：心疼/好笑）
↓
认知句（思考：原来如此）
↓
反驳句（开骂：你凭什么这么说）
↓
金句（截图：这话我得存）
↓
站队句（评论：我站哪边）
```

### 结尾：三种收获（让人有「得到」）

| 收获类型 | 设计 | 触发 |
|:--|:--|:--|
| 认知收获 | 金句可截图转发 | 转发 |
| 行动收获 | 方法可落地（3步） | 收藏 |
| 情绪收获 | 站队/共鸣/被理解 | 评论 |

## 五、外网补充（STEPPS框架 · 疯传6要素）

> Jonah Berger《疯传》（Contagious）——内容被疯传的6要素：

| 要素 | 含义 | 苏不倦应用 |
|:--|:--|:--|
| S社交货币 | 分享后显得自己厉害/有趣 | 分享「认知」显得自己懂 |
| T触发物 | 内容挂钩日常场景 | 「周一早晨」「刷手机」「学英语」 |
| E情绪 | 情绪够强才分享（不一定要正面） | 愤怒/共鸣/破防 |
| P公开性 | 行为可见才被模仿 | 评论区站队可见 |
| P实用价值 | 有用才收藏 | 3步方法/教材 |
| S故事 | 故事承载信息 | 翻车史 |

**情绪分享触发7种**（外网）：惊喜/娱乐/怀旧/**认同**/好奇/敬畏/**愤怒**——信息必须裹在情绪里，纯信息不会疯传。

**关键洞察**：「信息需要裹在情绪里」——你讲的「听得懂70%说不出」是信息，但裹上「你不是学了是看了」的愤怒/破防，才会被疯传。

| 杀手锏 | 案例 |

## 七、完整闭环（心法）

```
争议（曝光入口）→ 共识（留人磁铁）→ 情绪（互动推流）
   ↓                    ↓                    ↓
 开头引爆           中间传价值            结尾让人收获
  （钩子）          （逐句触发）          （三种收获）
```

**一句话**：先用争议把门打开，再用共识把人留住，最后用情绪价值让人站队——每一句都在这条链上有位置，环环相扣。
