## 一、内容 DNA 诊断

### 标题公式
```
颠覆认知 + 痛点直击 + 解决方案暗示
```

| 爆款案例 | 拆解 |
|---------|------|
| 零基础学英语，千万别一上来就瞎学 | 人群锚定 + 否定常识 + 暗示有正解 |
| 刷美剧听播客根本没用！正确方法在这里 | 否定流行做法 + 直接给方案 |
| 靠美剧学英语，基本都是白费劲 | 否定常见行为 |
| 学不好英语，根本不是缺方法 | 反转归因 |

### 人设语言库
- **口头禅**：说句大实话、说句实在的、我跟你说、别杠
- **叙事视角**：第一人称（我自己试过、我当初也这样）
- **分寸感**：有攻击性但留余地（"不是XXX不好，而是..."）
- **节奏**：中速偏快，短句为主，每句不超过25字

### 核心资源矩阵（高频推荐，保持一致性）

| 水平 | 资源 | 用途 |
|------|------|------|
| 零基础 | 赖世雄美语音标 | 发音入门 |
| 零基础 | Yakka Dee / WOW English | 启蒙听感 |
| 入门 | Let's Learn English (VOA) | 日常口语 |
| 入门 | 华尔街英语 | 场景对话 |
| 进阶 | Oxford Spoken English | 地道表达 |

## 二、核心结构模板

```
┌─────────────────────────────┐
│  痛点锚定（5秒）            │ ← "你是不是也这样..."
├─────────────────────────────┤
│  常见错误（15-20秒）        │ ← 列举2-3个流行错误做法
├─────────────────────────────┤
│  我的方法（20-30秒）        │ ← 核心观点，"你知道我是怎么做的吗？"
├─────────────────────────────┤
│  具体步骤（40-90秒）        │ ← 3-5步 + 资源推荐
├─────────────────────────────┤
│  行动号召（5-10秒）         │ ← "今天就去试试"
└─────────────────────────────┘
```

### 模板骨架（可直接复制填空）

```markdown
## 标题
[颠覆认知] + [痛点直击] + [解决方案暗示]

## 开场（5秒）
[口语化切入，制造共鸣]
"我就这么跟你说吧..."
"你是不是也这样..."
"每次听到有人说...说实话我都觉得..."

## 痛点锚定（15秒）
[描述用户正在经历的困境]
"每次...说实话我都觉得..."
"相信很多人和我一样..."

## 常见错误（20秒）
[列举2-3个流行的错误做法]
"大多数人都是这么做的：...但结果呢？"
"第一个坑：...第二个坑：...第三个坑：..."

## 我的方法（30秒）
[核心观点，娓娓道来]
"后来我才算想明白..."
"你知道我是怎么做的吗？"

## 具体步骤（40-60秒）
[3-5步，带资源推荐]
"第一步：..."
"第二步：..."
"推荐你用..."

## 结尾行动号召（10秒）
"今天就去试试。"
"收藏这条，慢慢跟着练。"
"评论区告诉我你卡在哪一步。"
```

## 三、5 步 SOP

### Step 1：选题决策（5分钟）

**⚠️ 第一步硬动作：锁「人群」，不是锁「话题」——先想清帮谁，再选讲什么**

选题前，先答这四问，答清楚才能往下走（顺序钉死：先帮对人 → 再谈钩子和结构）：

| 四问 | 苏不倦的固定答案 |
|:--|:--|
| **拍给谁？（锁人群）** | 爱学习、对现状不满、想上进的中年人 |
| **从哪切入？（锁场景）** | 英语——学不会、不敢开口、方法用错 |
| **给什么价值？** | 「学不会不是你的问题，是方法的问题」共识 + 可落地方法 |
| **我的方法是什么？** | 真实翻车史 + 认知纠错 + 干货解法 |

> 人群是根（爱上进的人，能顺着 英语→认知→成长 多线走），英语是当前主切入场景、不丢。四问答完，钩子／结构是最后一步（进 Step 2）。**先扎根（帮对人），再用争议放大（扩大触达）。**

**输入源：** [选题总库](../../选题系统/选题总库.md) + 评论区最新动态 + 搜索热点

**四维评分矩阵：**

| 维度 | 权重 | 判断标准 |
|------|------|---------|
| 搜索量 | ⭐⭐⭐ | "零基础学英语"等关键词在抖音搜索热度 |
| 评论区需求 | ⭐⭐⭐ | 最近30天评论/私信高频问题 |
| 差异化 | ⭐⭐ | 这个话题别人讲得少或讲得不好 |
| 可操作性 | ⭐⭐ | 能给出具体步骤，不只是观点 |

**操作：** 从选题库按优先级挑1个 → 对照评论区确认时效性 → 确定

### Step 2：脚本生成（AI 辅助）

**前置环节：选题聊天（5分钟）🆕**

拿到选题 → 先跟我聊 5 分钟，不写稿，纯聊天。你说你的想法，我问你问题。

目的：把脑子里的碎片说出来 → 表达欲被激发 → 写脚本更顺畅。

聊完你再自己写。卡壳了再回来聊。

**流程：**
```
选题 → 聊5分钟激发表达欲 → 自己写脚本 → 发我审稿
```

**流程：**
```
选题 → 填模板骨架 → 扔给AI生成初稿 → 人工做口语化调整 → 终稿
```

**AI Prompt 模板：**
```
你是英语学习博主"苏不倦"，风格特点：
- 口语化、直接、第一人称
- 口头禅：说句大实话、我跟你说、别杠
- 有攻击性但有分寸："不是XXX不好，而是..."
- 短句为主，每句不超过25字

请按以下结构生成口播脚本：
1. 痛点锚定（1-2句，制造共鸣）
2. 常见错误（列举2-3个坑）
3. 我的方法（核心观点）
4. 具体步骤（3-5步，含资源推荐）
5. 行动号召（1句收尾）

选题：[填入选题]
时长目标：[1分半/3分钟/4分钟]
```

**人工润色清单：**
- [ ] 加入口头禅（说句大实话、说句实在的、我跟你说）
- [ ] 确认资源推荐准确（不要推荐没用过的）
- [ ] 控制字数（1分半≈300字，3分钟≈600字，4分钟≈800字）
- [ ] 每句话读一遍，不顺口的改掉

### Step 3：口播录制（固定流程）

| 项目 | 标准 |
|------|------|
| **时长参考** | A/D类：1-2分钟 / B/E类：2-4分钟 / C类：1-2分钟 / F类：1-3分钟 |
| 语速 | 中速偏快，有节奏感，关键句停顿 |
| 表情 | 真诚直接，可以有无奈/认真/调侃的表情变化 |
| 眼神 | 看镜头，像在跟一个人聊天 |
| 背景 | 简洁干净，不要分散注意力 |
| 字幕 | 关键句加大加粗，步骤编号清晰 |

## 四、姜胡说方法论映射

| 姜胡说方法论 | 你（苏不倦） | 优化方向 |
|-------------|------------|---------|
| 选题从评论区来 | ✅ 已经在做 | 系统化：每周统计高频问题 |
| 问题→方案→原因→总结 | ✅ 结构吻合 | 保持，可尝试在 B/D 类加「原因」段 |
| 标题用大白话 | ✅ 天然优势 | 每标题埋搜索关键词 |
| 搜索流量是资产 | ✅ 零基础英语=高频词 | 保持定位，不追娱乐热点 |
| 每一条视频是试用装 | ✅ 每条解决具体痛点 | 结尾加引导关注/私信 |
| 讲道理=过滤用户 | ⚠️ 你很少讲道理 | **可尝试：** 在 B 类「方法纠正」视频中加 15 秒「原因解释」，过滤非目标用户 |
| 牺牲播放量换精准用户 | 待验证 | 选一条 B 类视频做 A/B 测试 |

## 五、爆款三大法宝（来自博主六年数据复盘）

### 法宝 1：内容稀缺性

让你拍比让其他人拍更有说服力的东西：

| 你的稀缺性 | 怎么强化 |
|-----------|---------|
| 从哑巴到流利的真实经历 | 每条视频至少讲一个「我当初也这样」的细节 |
| 渔夫帽视觉符号 | 不变 |
| 干中学理念 | 每个方法都配上自己的故事 |

### 法宝 2：内容利他性

你已经验证了实用价值（60%+ 收藏率）。可以补情绪价值：

- **冲突前置**：开头前 3 秒加一个对比冲击——像「看了 100 部电影听力还是烂」「14 天流利」这种
- **感官冲突**：你的否定式标题已经在做，可以更极致

### 法宝 3：信息高密度表达

你已经做到：短句节奏 + 分点结构。可再加：

| 方法 | 怎么用 |
|------|--------|
| 加快口播节奏 | 每句不超过 25 字（已在做） |
| POV 改造 | 把「我推荐你看 X」改成「我当时怎么发现 X 的」 |
| 未完成式钩子 | 开头说「有一种方法我试了 3 次才敢说有用」，不说是啥 |

## 七、正面清单 + 壁垒清单（持续积累）

每次审稿闭环后更新：

### 正面清单（苏不倦会用的表达）
- 「说句大实话」「我跟你说」「说句实在的」
- 「你还别说」「干脆」「反正就是」
- 短句为主，每句不超过 25 字
- 开场即钩子：第一句直接进痛点/反常识，价值前置，不做自我介绍
- 朋友视角：用「我当年 / 我后来才发现 / 我现在」第一人称叙事，别切到「你该懂的道理」说教视角

### 壁垒清单（苏不倦不会用的表达）
- 「每天分享」「保证见效」「7 天流利」
- 绝对化用语（「最好」「第一」「100%」）
- 结尾 CTA 引导语（不喊收藏点赞关注）
- 开场自我介绍（「我是苏不倦 / 35岁 / 零基础 / 不是老师过来人」）——观众不在乎你是谁，只在乎对自己有没有用（实用 + 情绪价值）
- 说教腔：命令式（「你该 / 别再 / 先别管」）、下结论金句（「才是真本事」「是遮羞布」）、点破句式（「你以为…其实」）——把「我教你」换成「我当年踩坑跟你吐槽」，争议用「我当年」包、不用「你该」下命令

> 每次审稿发现新的「会用/不会用」表达，追加到此清单。
