## 二、账号健康度诊断

### 核心指标基准

| 指标 | 健康线 | 警戒线 |
|:--|:--|:--|
| 推荐播放占比 | >50% | <30%主要靠私域 |
| 完播率(≤30s) | >50% | — |
| 完播率(≥5min) | >15% | — |
| 3秒留存率 | >65% | 前3秒跳出>35%⚠️ |
| 关注转化率 | >1% | <0.3%定位偏差 |
| 内容垂直度 | >80% | 低于80%方向漂移 |

### 四大诊断信号

| 信号 | 根因 | 动作 |
|:--|:--|:--|
| 播放涨但推荐占比低 | 私域撑，公域未破 | 优化完播+互动 |
| 完播高但不涨粉 | 好看但与定位偏差 | 强化人设+关注引导 |
| 新增≫净增 | 取关严重/方向漂移 | 核查近期内容一致性 |
| 互动率低于同类 | 竞争力弱 | 后台看百分位对比 |

### 稳定性评估

- 近7天频次稳定（误差≤1天）
- 垂直领域占比 >80%
- 无违规/低质搬运

## 三、单条视频诊断

### 指标含义对照

| 指标 | 含义 | 权重 |
|:--|:--|:--|
| 爱心赞 | 情绪共鸣 | 低 |
| 评论 | 引发讨论→延长推荐 | 中 |
| 收藏 | 用户觉得有用 | **高** |
| 分享 | 社交货币→公域起点 | **高** |
| 关注 | 人设匹配 | **最高** |

> 互动权重：收藏 > 复访 > 铁粉互动 > 互动 > 5秒留存 > 完播

### 诊断SOP

1. 近30天播放Top3 → 提炼正面共性（选题/钩子/节奏/CTA）
2. 近30天垫底3条 → 提炼反面共性
3. 看观看留存曲线 → 逐秒流失图，陡降点=内容短板
4. 形成「复用清单」+「避坑清单」

### 流量来源诊断

| 来源 | 高→说明 | 低→说明 |
|:--|:--|:--|
| 推荐 | 公域传播力好 | 加大钩子+完播 |
| 朋友圈 | 社交裂变强 | 公域渗透不足 |
| 好友点赞 | 私域→公域通畅 | 社交背书效率低 |
| 搜一搜 | SEO长尾价值 | 关键词布局弱 |

## 五、视频号独家机制 🆕

**社交推荐+算法推荐双引擎**：好友点赞→私域曝光→数据达标→公域推荐池。

**预冷启动**：发视频前先发给符合粉丝画像的微信朋友→她们点赞→进入「朋友赞过」流→帮你找到精准受众。

## 八、常见误区 🆕

| 误区 | 真相 |
|:--|:--|
| 播放破千=被推荐 | 可能全是朋友点赞，推荐占比0% |
| 完播越高越好 | 跨时长对比无意义，30s完播50%≠5min完播15% |
| 只看总粉丝数 | 100万泛粉<1万精准粉 |
| 每天盯数据 | 前72h波动最大，建议24h/72h/7d各看一次 |
| 只看播放量 | 关注转化率(>1%)比播放量更关键 |
| 忽略私密赞 | 爱心赞(公开)≠私密赞，含义不同需分开看 |

## 封面缩略图规则（《微信视频号》2026-08-14吸收）🆕

**问题**：视频号分享到微信自动生成缩略图，**会裁掉封面上下部分**——标题靠边缘=分享出去显示不全，影响推荐流量（最高50%）。

**规则**：
1. 视频封面标题/内容**尽量往中间靠拢**（上下留出裁剪安全区）
2. 首帧画面=封面（分享缩略图取首帧）
3. 分析作品时检查：封面标题是否在中间安全区？不在→提醒重做

## 视频号直播规划（《微信视频号》+《视频号运营攻略》2026-08-14）🆕

**为什么直播**：视频号生态关键环节（信任+带货），社交信任背书（朋友看过=信任）。
**准备**：
1. 预热：朋友圈+社群提前预约（服务通知触达率高）
2. 流程：有脚本有节奏（不让用户被带偏）
3. 人设统一：直播人设=视频内容人设
4. 引流：直播间引导加微信/进群（私域沉淀）

**触发**：粉丝稳定增长后开播（当前6,000+已够），先从「答疑型」直播试水（回答评论问题，轻量）。
