# 🌐 多平台合规采集指南（不装自动爬虫的合规方式）

> 2026-08-21 建立。吸收 MediaCrawler 思路（CDP复用登录态/覆盖多平台），但**不装自动爬虫**——用合规方式覆盖多平台数据采集。
> 核心：用户手动登录 + 我CDP提取当前可见内容，不自动爬全站/不碰敏感Cookie/不违反平台条款。

---

## 一、合规采集三原则（红线，绝不破）

```
① 用户手动登录：我用 CDP 连接「已登录的 Chrome」，只提取当前可见内容——绝不自动登录/自动翻页爬全站
② Cookie 不自动化：小红书等平台，绝不碰自动 Cookie；数据源一定是「用户手动登录态」
③ 不违反平台条款：只做「用户本人能看到」的数据分析，不做大规模爬取/商业扫描
```

**为什么不用 MediaCrawler**：它自动爬全站+支持小红书（踩我们「小红书自动化/Cookie绝不碰」红线）+「禁止商业用途」（我们商业变现）——合规风险高，不装。

## 三、核心方法（跟抖音同款，扩展多平台）

```
① 用户手动打开目标平台并登录（浏览器登录态）
② 我 Playwright connect_over_cdp('http://localhost:9222') 连登录态Chrome
③ 导航到目标页面（用户作品列表/数据分析页/评论区）
④ extract 当前可见内容（innerText）→ 结构化 → 分析
```

**跟 MediaCrawler 的区别**：它是「自动爬全站」（违规），我们是「用户手动登录+提取当前可见」（合规）。技术路线一样（CDP），但「操作尺度」完全不同。

## 四、铁律

| 铁律 | 说明 |
|:--|:--|
| 只提取用户能看到 | 不做「用户权限外」的爬取 |
| 数据用完即删 | 分析完源数据即删（我们既有铁律） |
| 不碰平台Cookie自动化 | 小红书等，只用用户手动登录态 |
| 分析什么平台就合规采集什么 | 不越界采集无关数据 |
