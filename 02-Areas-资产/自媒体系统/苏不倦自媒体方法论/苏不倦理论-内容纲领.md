# 苏不倦理论（内容纲领）

> 2026-08-13 建立。把散落方法论串成完整理论，作为所有内容的纲领。
> 一句话：**英语学不会不是你的问题，是方法的问题。**

---

## 一、底层信条（整个理论的地基）

```
英语学不会，不是你不努力，是你被带错了路。
学校教了你12年考试，没教你开口。
你不是笨，你是被方法坑了。
```

**所有内容的立场**：不是教你怎么学，是告诉你别再用错的方法。你学不会是正常的，因为方法本来就是错的。

## 五、内容方法论（怎么写）

### 写前（两句话消化+写前6问）
- 讲了什么（≤20字）？为什么值得讲（跟我啥关系）？
- 写给谁/有什么用/什么场景/看完能做什么/一句话概括/跟上一篇区别

### 写中（苏不倦风格）
- **翻车细节**（I go shopping yesterday 老外愣了一下）——差异化核心
- **认知拆解**（钱是成本时间是本金/存电话号码比喻）——收藏驱动力
- **争点**（共同事实+不同解释+待判）——推流引擎
- **金句**（可截图转发的话）——记忆点
- **松弛感**（「我算了算我这几年」分享口吻，不说教）
- **正面清单**（我跟你说/说句实在的/你还别说/反正就是）

### 写后（32+1维审稿）
- #25逻辑一致性（黑粉测试）
- #27标题兑现
- #31争论点（观众会不会评论）
- #32差异化（去掉翻车还有啥）
- #33挂商品（挂什么教材+挂不挂车）

## 十一、人群垂直战略（2026-08-23 确立，重大战略升级）

> 核心转向：**苏不倦不是「英语博主」，是「35岁爱学习、上进、逆袭的人」的博主。英语是抓手，不是全部。**

### 为什么（外网印证：Katie Steckly「Big creators don't have niches」）

```
❌ 内容垂直：只做「英语」→ 观众倦怠 + 创作者burnout + 话题做尽就没了
✅ 人群垂直：围绕「35岁爱学习上进的人」→ 内容跨话题但始终围绕「人」
   → 观众因为「你这个人」关注你，不是因为「英语」这个话题
```

### 人群画像

**35岁左右，爱学习、上进、不甘现状、想逆袭的人**——英语只是他们「想学的东西之一」，还想学AI、想转行、想自我提升。

### 五阶段成长路径（按「人的成长」分，不是按「话题」分）

| 阶段 | 人群的问题 | 内容方向 | 苏不倦对应 |
|:--|:--|:--|:--|
| ① 敢不敢开始 | 「35岁还来得及吗」 | 中年重启 | 35岁学英语疯了 |
| ② 学什么 | 「我该学英语还是AI」 | 抓手（英语→AI） | 千万别系列 |
| ③ 怎么学好 | 「为什么学了没进步」 | 学习方法 | 问对一个问题 |
| ④ 卡住了 | 「我是不是不行」 | 认知纠错 | 换个脑子 |
| ⑤ 学了怎么用 | 「学会了我怎么改变现状」 | 从学到用/变现 | **缺口（待做）** |

### 战略配比（英语是抓手，其他是增长盘）

```
现状（失衡）：英语 90% + 其他 10%
目标：英语 40%（抓手，持续建立信任）
     + 认知成长 20% + 学习方法 15% + 中年重启 15% + AI/变现 10%（增长盘）
```

### 关键认知

```
英语 = 抓手（入口）：用「35岁零基础学英语」建立「过来人+真实逆袭」的信任
信任建立后 → 认知/AI/学习方法/中年重启 = 更大的盘子
   「这个35岁逆袭的人，他怎么学习、怎么面对焦虑、怎么学AI、怎么改变现状」
```

**⑤「学了怎么用/变现」是当前最大缺口**——「学习」不是人群的终极目的，「改变现状/赚钱」才是。这个「结果」没讲，是人群垂直的下一步重点。

### ⑤ 学了怎么用/变现 内容方向（2026-08-23 补）

| 选题思路 | 核心 | 对应机制 |
|:--|:--|:--|
| 「35岁学英语，不是为了考试，是用起来改变现状」 | 从学到用 | 变现倒着做 |
