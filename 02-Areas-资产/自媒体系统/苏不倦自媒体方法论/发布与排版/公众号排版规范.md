# 公众号文章排版规范（苏不倦定制版）

> 2026-08-13 建立。基于优秀公众号排版方法论+苏不倦品牌调性。
> 适用于：公众号「苏康说」（主号）+ 知乎/头条统一使用。

---

## 一、基础参数（排版好不好看70%看这里）

| 参数 | 推荐值 | 说明 |
|:--|:--|:--|
| 正文字号 | **15px** | 深度长文用16px |
| 一级标题 | **20px 加粗** | 品牌色 |
| 二级标题 | **16px 加粗** | 辅助色 |
| 注释/来源 | **12px** | 浅灰色 |
| 行距 | **1.75倍** | 最舒适区间（1.5-2.0） |
| 段距 | **空一行** | 替代首行缩进 |
| 字间距 | **0.5-1px** | 微调提升舒适度 |
| 页边距 | **8-12px** | 舒适气泡 |

## 二、配色（3色原则：克制才高级）

| 用途 | 颜色 | 说明 |
|:--|:--|:--|
| 正文 | **#3f3f3f** | 深灰，不用纯黑#000（刺眼） |
| 强调/标题 | **#FF8C42（品牌橙）** | 苏不倦品牌色=能量+温暖+过来人 |
| 辅助/引用 | **#e5e5e5 浅灰** | 分割线/引用块边框 |

**配色公式**：深灰正文 + 品牌橙强调 + 浅灰辅助 = 永远不出错

## 三、结构（让版面呼吸）

1. **每段3-4行**——不堆大段文字
2. **段落之间空一行**
3. **长文每800-1000字插入一张图或分割线**
4. **重要内容加粗**（少用颜色，重点文字加粗即可）
5. **金句用引用块**（可截图转发的句子单独成块）

## 四、正文重点加粗配色（优秀案例验证 🆕）

> 来源：优秀公众号案例——「重点标注：用加粗+主题色突出关键内容（别用斜体/下划线）」「金句：单独成段、加粗」

**规则**：
| 内容类型 | 排版方式 |
|:--|:--|
| 核心观点/结论 | **品牌橙加粗**（#FF8C42） |
| 高价值点/方法步骤 | **黑色加粗**（或品牌色，控制总量） |
| 金句 | **单独成段 + 品牌橙加粗**（可截图转发） |
| 反例/警告 | 加粗（不用颜色） |

**克制原则**：
- 全文加粗内容 ≤ 5处（太多=没有重点）
- 金句全篇 1-3句（单独成段+品牌橙）
- 品牌色只在「最核心的1-2句」用，其余用黑色加粗
- 不用斜体/下划线（显得乱）

**⚠️ 品牌橙标注（2026-08-13发现）**：
- **Markdown不含颜色**——加粗（`**`）能复制到公众号编辑器，颜色不能（颜色是OB主题样式，不是文本）
- **解法**：排版文件里在需要上色的文字后加 `` `【品牌橙】` `` 标注 → 用户在编辑器里手动选中该文字→套品牌色 → 粘贴后删掉标注
- 标注示例：`**零基础学语法，千万别一上来就啃书。** 【品牌橙】`

**段落总分总结构（优秀案例 🆕）**：
```
【总】开头给结论（金句/核心观点先亮出来）
【分】中间展开（3-4个要点，每个要点小标题+解释）
【总】结尾总结（回扣开头+升华+行动）
```
- 每小节可有一句收束，单独成段或加粗
- 总分总让读者「先知道结论→看论证→再被总结击中」

## 五、头部引导（正文前）

```
[Slogan] 英语学不会不是你的问题，是方法的问题。
[引导关注] 点击上方蓝字「苏康说」关注我，一起用正确的方法学英语。
```

- Slogan=公众号价值一句话（「英语学不会不是你的问题，是方法的问题」）
- 引导关注=给读者关注理由（干货诱饵）

## 六、话题卡片（公众号支持，选题驱动 🆕）

> 2026-08-13 用户确认：公众号文章支持话题卡片，根据选题和正文判断加什么话题。

**话题卡片作用**：
1. **内容聚合**——同话题文章串联成集群（搜一个话题看到多篇）
2. **蹭热门流量**——选择有搜索量的话题（搜一搜命中）
3. **涨粉**——话题页引流（读者看话题→看到你的文章→关注）

**加话题规则**：
| 话题类型 | 怎么选 | 示例 |
|:--|:--|:--|
| 核心话题（必加） | 文章主题词 | #零基础学英语# |
| 精准话题 | 内容细分词 | #英语语法# |
| 系列话题 | 自有系列名（沉淀） | #千万别系列# |
| 蹭热话题（可选） | 高搜索量词 | #学英语# #英语口语# |

**话题数量**：2-4个（太多显乱，太少聚合弱）
**位置**：**文末**（尾部引导之后，最后一行）——用户2026-08-13确认话题卡放末尾，不放开头

**判断方法**：读选题+正文 → 提取主题词（核心/精准/系列/热门各选1个）→ 生成话题卡片行

## 七、尾部引导（4块，看完文章的最后临门一脚）

```
┌─────────────────────────────┐
│ 💬 互动留言                    │
│ 「你学英语这几年，花得最多的是钱还是时间？评论区聊聊」 │
│                              │
│ 📚 往期精选                    │
│ 《把音标学透再学英语，可能是你走过最长的弯路》   │
│ 《英语学完就忘？不是你的问题，是这个方法坑了你》  │
│ 《别等词汇量够了！300词就能开口说英语》       │
│                              │
│ ⭐ 引导关注                    │
│ 「关注我——我35岁零基础，把踩过的坑都绘成了地图。│
│   你学英语的路，我帮你避开这些坑。」           │
│                              │
│ 👍 点赞/分享/在看                │
│ 「觉得有用，点个「在看」让更多需要的人看到」     │
└─────────────────────────────┘
```

**尾部引导四要素**：
1. **互动留言**——跟正文有关、最有表达欲的问题（评论区钩子）
2. **往期精选**——3篇数据最好的文章（把单次阅读价值放大）
3. **引导关注**——传递公众号价值（我是谁+我对你有什么用）
4. **点赞/分享/在看**——提醒动作（读者可能忘记）

## 八、排版执行

用户说「发布XXX」时，排版文件按此规范组织：
1. 标题（20px加粗品牌橙）
2. 头部引导（Slogan+关注）
3. 正文（15px/1.75行距/3-4行一段/空一行）
4. 金句引用块
5. 尾部引导（互动/精选/关注/点赞）
6. 其他平台（知乎/头条）统一使用此规范（字号可保持，平台自动适配）

## 九、验证

- 排版文件生成后，按此规范逐项检查（字号/行距/配色/结构/头部/尾部）
- 用户确认「可以」= 排版完成
