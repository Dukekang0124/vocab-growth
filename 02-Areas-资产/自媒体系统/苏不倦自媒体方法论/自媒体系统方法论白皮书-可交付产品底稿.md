## 二、每个子系统的可交付内容

### ① 选题系统（如何找到爆款选题）

**方法**：
1. **评论区挖掘**——爆款视频评论区=免费选题库（高赞评论→选题）
2. **争点理论**——共同事实+不同解释+待判问题
3. **选题8分制**——搜索需求/竞争空白/差异化/安全性/合集匹配
4. **六大维度**——笑点/热点/共鸣点/冲突点/知识点/槽点（至少2个）
5. **反驳同行**——同行说什么，你反驳什么（争议=推流）

**可交付**：选题方法论文档+选题评估清单+博主监控模板

### ② 写稿系统（如何写出高收藏脚本）

**方法**：
1. **两句话消化法**——讲了什么/为什么值得讲（写完再动笔）
2. **写前6问**——写给谁/有什么用/什么场景/看完做什么/一句话概括/跟上一篇区别
3. **认知拆解SOP**——观众原来怎么想/错在哪/真相是什么
4. **苏不倦结构**——钩子→翻车→认知拆解→方法→金句→互动钩子
5. **金句必查**——每条有可截图转发的话

**可交付**：写稿SOP+脚本结构模板+金句案例库

### ③ 审稿系统（如何保证质量+曝光）

**方法**：
1. **32+1维审稿**——逻辑一致性/标题兑现/争论点/差异化/挂商品
2. **三级分类**——🔴致命（不过不发）/🟡重要/🔲优化
3. **双置顶评论**——橱窗话术+互动钩子（每条必备）
4. **扩大曝光判断**——观众会忍不住评论/反驳吗

**可交付**：审稿清单+双置顶评论模板

### ④ 发布系统（如何分发）

**方法**：
1. **平台矩阵**——深耕（抖音+视频号）/同步（B站/小红书/百家号）/停投（支付宝/头条）
2. **内容×平台匹配**——千万别→抖音视频号/资源→小红书/共鸣→全通
3. **排版规范**——正文15px/品牌橙/总分总/话题卡文末
4. **封面流水线**——IP形象+标题合成+平台尺寸适配

**可交付**：平台矩阵文档+排版规范+封面制作流程

### ⑤ 分析系统（如何复盘）

**方法**：
1. **三平台分析策略**——抖音/视频号/小红书各有指标体系
2. **全平台引擎**——发链接自动分析（数据/评论区/双置顶）
3. **双置顶评论检查**——数据好但没置顶=流量红利浪费
4. **四维复盘**——浏览量=选题/涨粉=价值/完播=结构/评论区=新选题

**可交付**：分析模板+复盘SOP+评论区挖掘流程

### ⑥ 变现系统（如何赚钱）

**方法**：
1. **带货教材**——自己真实在用的（音标→赖世雄/阅读→书虫/口语→走遍美国）
2. **挂法**——抖音/小红书=评论区橱窗、视频号=点头像进橱窗
3. **产品阶梯**——免费PDF→¥9.9→¥97→¥297（发疯姥子/姜胡说验证）
4. **种草逻辑**——帮向往的生活找到方案（不是推销）

**可交付**：带货选品池+挂法手册+产品阶梯规划

### ⑦ 理论纲领（苏不倦理论）

**核心**：英语学不会不是你的问题，是方法的问题。
**五大支柱**：千万别（方法纠错）/集体共鸣/老外聊天/碎碎念/换个脑子（认知纠错）

**🟡 半复制**：理论框架可复制（五大支柱+争点理论），但「翻车史」不可复制——这是苏不倦的护城河。

### ⑧ 知识卡片（如何内化）

**方法**：姜胡说四步内化（复述→重建→迁移→实操）+知识卡片格式
**可交付**：知识卡片模板+8张方法论示例

## 三、可复制 vs 不可复制（产品化关键判断）

| 层 | 可复制性 | 产品化方式 |
|:--|:--|:--|
| **方法论**（8子系统流程） | 🟢 可复制 | 可打包成文档/课程/Skill |
| **模板**（审稿清单/脚本结构） | 🟢 可复制 | 可打包成工具包 |
| **案例**（88条踩坑/数据反馈） | 🟡 部分 | 脱敏后可作案例库 |
| **人设**（苏不倦翻车史） | 🔴 不可复制 | 不能产品化（但可教别人建自己的人设） |

**结论**：方法论+模板=可产品化；人设=不可复制但可「教学」（教别人怎么建自己的人设）。

## 四、推广验证路径（最小可验证）

**目标**：哪怕现在是90%，先推广出去，拿真实反馈验证。

**阶段1：免费验证（1个月）**
- 选1个「同类困境的人」（想做知识博主但没方向的）免费辅导
- 用这套系统带TA从选题到发布走一遍
- 拿到真实反馈：哪些方法有用/哪些不适用/哪里卡住

**阶段2：低价产品（验证后）**
- 如果阶段1反馈好 → 打包成¥99-199的《知识博主系统化起号指南》（PDF/Skill）
- 在墨问/小红书/公众号发布

**阶段3：迭代**
- 用反馈迭代方法论 → 升级2.0 → 再验证

**推广渠道**（结合平台矩阵）：
- 公众号/知乎：发「方法论拆解」文章（搜索流量）
- 小红书：发「方法卡片」图文（种草）
- 抖音/视频号：发「系统起号」系列（扩大曝光）

## 五、风险与边界（诚实）

1. **90%不是100%**——还没验证「离开苏不倦」能用，这是最大不确定性
2. **人设不可复制**——卖方法论可以，卖「苏不倦」不行
3. **竞争**——知识博主方法论已有同类（姜胡说/发疯姥子都在讲），差异化=「系统化+AI辅助+最小可验证」
4. **合规**——AI辅助生成内容需标注；不承诺效果
