# 视频号封面检查清单

> 2026-08-14 落地。基于《微信视频号》「封面缩略图」规则。
> 视频号分享到微信=自动生成缩略图，会裁掉封面上下部分——标题靠边缘=显示不全=影响推荐流量（最高50%）。

---

## 封面安全区规则

```
┌─────────────────────┐
│    （上裁剪区·别放内容）    │
│                       │
│      【标题·放这里】      │  ← 中间安全区（标题/人物/关键信息）
│                       │
│    （下裁剪区·别放内容）    │
└─────────────────────┘
```

**规则**：
1. 标题/人物/关键信息 → 放封面**中间60%**区域
2. 上下各20% = 裁剪安全区（不放重要内容）
3. 首帧=封面（分享缩略图取首帧）——首帧就要有标题
4. 封面标题 ≥ 大字（缩略图小，字太小看不清）

## 发布前自查（每条视频）

- [ ] 标题在中间安全区？（不在→重新构图）
- [ ] 标题字够大？（缩略图下能看清）
- [ ] 首帧画面=有标题的封面？
- [ ] 上下边缘无关键信息？

## 参考

- 抖音封面：900×1200 竖版，标题上方（抖音不裁边）
- 视频号封面：**竖版但分享缩略图会裁上下**——标题必须居中
- 视频号/抖音封面不能直接用同一版（裁切规则不同）
