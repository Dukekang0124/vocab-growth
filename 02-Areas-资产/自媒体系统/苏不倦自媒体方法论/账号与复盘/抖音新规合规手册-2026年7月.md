## 算法底层机制（新增）

### 双塔召回模型

| 塔 | 存储内容 |
|----|---------|
| **内容塔** | 视频时长、视觉元素、主题属性等所有内容维度特征 |
| **用户塔** | 所在地、历史点击、收藏、复访等所有用户行为数据 |

**规则：** 内容特征越清晰 → 算法定位精准受众越快。你的「零基础学英语+音标」= 特征极其清晰。

### 升级后的深度学习模型

可达几十层隐藏网络推理。用户在某条视频多停留几秒 → 算法推导出用户自己都没意识到的隐藏需求。

**新作品发布后分秒级完成「推送→验证→调整」全流程，不再依赖概率。**

### 新号红利

新号、零粉博主、小众垂类获平等曝光机会。优质内容无需依赖历史账号权重也能跑出好数据。

## 二、合规自查清单（每次发布前）

### 🔴 必查（违规后果严重）

- [ ] **AI 标注**：如果 AI 写了 >50% 的文案内容 → 发布时勾选 AI 标识。如果自己写→AI 改→自己念 → 不需标注（人为主导）
- [ ] **私域导流**：评论区/主页/私信不留微信号、手机号、二维码。推荐资源用公开名称（"B站搜XXX"）
- [ ] **绝对化用语**：标题和正文不出现「最好」「第一」「100%」「绝对」「保证」
- [ ] **不贬低同行**：你的「不是XXX不好，而是...」句式是安全的。「XXX是垃圾」不行

### 🟡 建议查（降低风险）

- [ ] **虚假宣传**：不说「7天流利」「看完就会」「包教包会」。保持「个人经验分享」定位
- [ ] **未经证实的结论**：不虚构数据（如「90%的人学英语失败」），如果有统计数据，加「根据我的观察」
- [ ] **App/工具提及** 🆕：口播中能不出现具体App名称就不出现。用「一个听力App」「看视频学英语的工具」代替。机器审核不区分「主观分享」和「商业推广」——名字出现即触发「引导至第三方App」

### 🟢 不涉及（你当前不受限）

- 电商挂车 / 直播带货 → 你暂不做
- 医疗/珠宝/金融类目 → 你不涉及
- 憋单 / 儿童带货 → 不相关

## 四、算法策略微调建议

### 优化标题和结尾，强化「收藏」和「复访」

**标题优化：**
```
旧：零基础学英语，千万别一上来就瞎学
新：零基础学英语，千万别一上来就瞎学（建议收藏）
                     ↑ 加收藏引导不算标题党，是算法友好
```

**结尾优化：**
```
旧：今天就去试试。
新：这条值得收藏，下次不知道学什么的时候翻出来看。
    ↑ 暗示复访价值，匹配「复访率」权重
```

### 视频内加「收藏理由」

在内容中间自然加入暗示收藏价值的句子：
- 「这5步你可能一次记不住，建议先收藏」
- 「后面推荐的资源清单，截个图或者收藏方便找」

### 段落前置小钩子 🆕

在每个内容模块前，用一句话告诉用户这部分的价值：

```
「先告诉你为什么音标重要——后面3个坑你基本全踩过」
「接下来是具体怎么做，就3步」
「最后给你推荐一个资源，零基础直接用」
```

> 不让用户猜这段在讲什么，持续勾住注意力，拉长停留时长。

### 8. 三类高压线 🆕

**低质重复类：** 搬运抄袭、模板批量生产、机器人念稿、夸张标题骗点击 → 停止推流

**营销违规类：** 极端夸大词、站外联系方式、刷单虚假测评 → 严查

**细节疏漏类：**
- [ ] 画面中出现他人隐私信息未打码
- [ ] 引战/脏话等负能量
- [ ] 生硬套路化诱导（「不点赞就怎样」）
- [ ] **频繁删除已发布作品**
- [ ] 单日发布大量低质视频
- [ ] **内容跨度过大打乱账号定位** ⚠️ 如果突然插全英文或读书类，需过渡自然

### 9. 搜推联动做法 🆕

不只标题埋词，口播中也要自然植入关键词：

```
标题：「零基础学英语，每天1小时就够了」
口播自然地提到：「零基础学英语」「音标」「自学英语」
字幕中保留这些关键词
```

> 用户搜索这些词时，你的视频出现在搜索结果中 → 持续被动流量。
