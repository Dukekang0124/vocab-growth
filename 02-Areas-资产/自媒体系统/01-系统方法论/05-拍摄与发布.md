## 5步 SOP

```
Step 1: 选题决策（5分钟）
  → Step 2: 脚本生成（AI辅助）
  → Step 3: 口播录制
  → Step 4: 剪辑发布
  → Step 5: 数据复盘
```

---

## Step 1: 选题决策（5分钟）

**输入源**：选题总库 + 评论区最新动态 + 搜索热点

**四维评分矩阵**：

| 维度 | 权重 | 判断标准 |
|:--|:--|:--|
| 搜索量 | ⭐⭐⭐ | 关键词在抖音搜索热度 |
| 评论区需求 | ⭐⭐⭐ | 最近30天评论/私信高频问题 |
| 差异化 | ⭐⭐ | 这个话题别人讲得少或讲得不好 |
| 可操作性 | ⭐⭐ | 能给出具体步骤，不只是观点 |

---

## Step 2: 脚本生成（AI辅助）

### 前置环节：选题聊天（5分钟）

拿到选题 → 先聊5分钟，不写稿，纯聊天。把脑子里的碎片说出来 → 表达欲被激发 → 写脚本更顺畅。卡壳了再回来聊。

### AI Prompt 模板

```
你是英语学习博主"苏不倦"，风格特点：
- 口语化、直接、第一人称
- 口头禅：说句大实话、我跟你说、别杠
- 有攻击性但有分寸："不是XXX不好，而是..."
- 短句为主，每句不超过25字

请按以下结构生成口播脚本：
1. 痛点锚定（1-2句，制造共鸣）
2. 常见错误（列举2-3个坑）
3. 我的方法（核心观点）
4. 具体步骤（3-5步，含资源推荐）
5. 行动号召（1句收尾）

选题：[填入选题]
时长目标：[1分半/3分钟/4分钟]
```

### 人工润色清单
- 加入口头禅（说句大实话、说句实在的、我跟你说）
- 确认资源推荐准确（不要推荐没用过的）
- 控制字数（1分半≈300字，3分钟≈600字，4分钟≈800字）
- 每句话读一遍，不顺口的改掉

## 核心结构模板（可直接填空）

```
┌─────────────────────────────┐
│  痛点锚定（5秒）            │ ← "你是不是也这样..."
├─────────────────────────────┤
│  常见错误（15-20秒）        │ ← 列举2-3个流行错误做法
├─────────────────────────────┤
│  我的方法（20-30秒）        │ ← 核心观点
├─────────────────────────────┤
│  具体步骤（40-90秒）        │ ← 3-5步 + 资源推荐
├─────────────────────────────┤
│  行动号召（5-10秒）         │ ← "今天就去试试"
└─────────────────────────────┘
```

### 标题公式
```
颠覆认知 + 痛点直击 + 解决方案暗示
```

## 人设语言库

| 维度 | 规范 |
|:--|:--|
| 口头禅 | 说句大实话、说句实在的、我跟你说、别杠 |
| 叙事视角 | 第一人称（我自己试过、我当初也这样） |
| 分寸感 | 有攻击性但留余地（"不是XXX不好，而是..."） |
| 节奏 | 中速偏快，短句为主，每句不超过25字 |

---

## Step 3: 口播录制

| 项目 | 标准 |
|:--|:--|
| 时长参考 | A/D类：1-2分钟 / B/E类：2-4分钟 / C类：1-2分钟 / F类：1-3分钟 |
| 语速 | 中速偏快，有节奏感，关键句停顿 |
| 表情 | 真诚直接，可以有无奈/认真/调侃的表情变化 |
| 眼神 | 看镜头，像在跟一个人聊天 |
| 背景 | 简洁干净，不要分散注意力 |
| 字幕 | 关键句加大加粗，步骤编号清晰 |

## Step 4: 剪辑发布

### 发布清单
- 标题：大白话 + 含搜索关键词
- 话题标签：3-5个精准标签
- 封面：关键句截屏或统一模板
- 评论区置顶：补充资源链接或引导互动问题

### 推荐标签池
```
主标签（必选2-3个）：
#从零开始学英语 #零基础学英语 #英语学习

副标签（按内容选1-2个）：
#英语口语 #英语学习方法 #成年人学英语 
#英语听力 #英语入门 #学英语
```

## 三平台发布规范

### 抖音
- 深耕平台，千万别系列主场
- 评论区挂橱窗，不挂车（保内容流量池）
- 标题用大白话，埋搜索关键词

### 视频号
- 最健康平台，社交推荐+个性化双螺旋
- 可挂商品（图书佣金40-60%）
- 封面缩略图规则：标题居中

### 公众号
- 排版规范：正文15px/品牌橙/总分总/话题卡文末
- 引流路径：公众号→个人微信

## 爆款三大法宝（博主六年数据复盘）

### 法宝1：内容稀缺性
让你拍比让其他人拍更有说服力的东西——真实经历+渔夫帽视觉符号+干中学理念

### 法宝2：内容利他性
已验证实用价值（60%+收藏率），可补情绪价值：冲突前置+感官冲突

### 法宝3：信息高密度表达
加快口播节奏+POV改造（「我推荐你看X」→「我当时怎么发现X的」）+未完成式钩子
