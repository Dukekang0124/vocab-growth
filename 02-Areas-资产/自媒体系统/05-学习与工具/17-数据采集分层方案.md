## 一、核心结论（v2）

4. **MediaCrawler 彻底不用装了**——Hermes 脚本是同类（CDP）且更贴合你。

## 二、Hermes CDP 抓取机制（已学透）

### 是什么
CDP = Chrome DevTools Protocol。Hermes 用一个「已登录你抖音账号的 Chrome」（`hermes-chrome-profile`），通过调试端口 9222 发指令自动化抓取网页数据。原理跟你手动打开创作者中心看数据一样，只是脚本代劳了。

### 脚本清单（`07-Hermes/scripts/`）

| 脚本 | 抓什么 |
|:--|:--|
| `cdp_extract.py` | 单条视频内容 + 截图封面（CDP 自愈提取器 v2.0，自动重启 Chrome） |
| `weekly_extract.py` | 创作者中心→作品列表全量解析：**播放/平均播放时长/封面点击率/点赞/评论/分享/收藏/弹幕** + 日期/标题/标签 |
| `weekly_comments.py` | 创作者中心→互动管理→评论页 |
| `weekly_report_cdp.py` | 周报生成（编排上面脚本） |
| `weekly_stats.py` | 统计汇总 |

### 关键能力
- ✅ **平均播放时长（完播相关）、封面点击率（CTR）**——九思之前补不到、要你截图的指标，Hermes 脚本能自动抓
- ✅ 完整作品列表 + 账号粉丝数
- ✅ 评论抓取

### 环境适配注意（要跑通需先改）
- 脚本硬编码 `PROFILE = C:/Users/11/hermes-chrome-profile`，但你的 Windows 用户是 `Admin`，需改成 `C:/Users/Admin/...`（历史遗留，之前在用户「11」下写）
- 依赖：Python + websockets + asyncio + 已登录抖音的 Chrome
- 启动时需带 `--remote-debugging-port=9222`
