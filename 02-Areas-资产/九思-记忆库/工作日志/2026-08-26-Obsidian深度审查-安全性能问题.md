# Obsidian 深度审查 · 安全/性能问题清单 · 2026-08-26

> 审查范围:`.obsidian` 配置、插件、vault 数据质量、git 版本控制、运行时产物、安全
> 核心结论:主要隐患集中在 **git 版本控制污染**——运行时产物(浏览器登录态、WorkBuddy 检查点、模型、媒体)被 obsidian-git 纳入 .git,导致 .git 膨胀 3.4G 且账号凭据进历史。**当前无远程仓库,未外泄**,但属高风险待整改。

## 问题清单(按重要性)

| # | 级别 | 问题 | 证据 |
|---|---|---|---|
| 1 | 🔴 P0 安全 | 抖音登录凭据被 git 追踪 | `douyin-transcript/chrome-profile` 下 `Login Data`/`Network/Cookies`/`Web Data` 等 4551 文件入 git;当前无远程未外泄,一旦配远程 push 即泄漏账号 |
| 2 | 🔴 P0 安全 | WorkBuddy 会话检查点入 git | `08-工作空间/.zcode/v2/checkpoints/*.tar.gz.enc`(2 个共 ~2GB)被提交进历史 |
| 3 | 🟡 P1 性能 | .git 膨胀 3.4G(占 vault 45%)且未 gc | 两个 pack(2.7G)+ 单个 764MB loose object;历史含 onnx 模型(228MB)、视频(97/88MB) |
| 4 | 🟡 P1 架构 | .gitignore 缺漏是根因 | 未忽略 `08-工作空间/`、`chrome-profile/`、`*.mp4/*.png`、`models/*.onnx`,运行时产物全被版本控制 |
| 5 | 🟡 P1 架构 | 运行时产物混入知识库 | douyin-transcript 的 chrome-profile(437MB)+ model.onnx(228MB)+ output 视频混在 `03-Resources/九思-SKILL` |
| 6 | 🟡 P1 历史 | git 历史残留旧路径 | 大量 blob 指向已改名/删除的 `08-九思搭档知识库/`,历史无法靠删工作区文件瘦身 |
| 7 | 🟢 P2 数据 | 零散残留 | `().md` 0字节(删被护栏拦)、`附件/` 空目录(配置空转)、chrome-profile 大量 LOCK/LOG 空文件 |

## 修复建议(待康哥确认后执行,均有备份)

1. **立即止血**:`git rm -r --cached` 移除 chrome-profile、08-工作空间、模型、媒体(仅移除追踪,不删工作区文件)
2. **补 .gitignore**:加入 `08-九思-工作空间/`、`**/chrome-profile/`、`**/models/`、`**/output/`、`*.mp4`、`*.png` 等
3. **历史瘦身**:`git gc --aggressive` + `git prune`,或 BFG/filter-repo 清历史大 blob(需谨慎,先备份 .git)
4. **chrome-profile 迁出**:从 SKILL 库移到 D 盘独立目录(如 `D:\douyin-chrome-profile`),skill 内用绝对路径引用
5. **清零散残留**:`().md`、空 `附件/`、LOCK/LOG(回收站可用后)
