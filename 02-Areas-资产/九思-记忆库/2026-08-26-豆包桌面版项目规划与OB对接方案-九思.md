### 1.2 核心判断

**Hermes体系擅长的（豆包不碰）：**
- Skill开发、系统运维、OB库管理、索引更新
- 自动化脚本、定时任务、数据采集（Python）
- 知识库维护、读书消化（仓颉skill）
- 投资系统（已有完整体系+段永平skill）

**豆包擅长且Hermes体系缺的（豆包主战场）：**
1. **多模态生成**：图片（封面/海报/头像）、视频（AI片段）、音频（TTS/音效）
2. **媒资处理**：音频降噪/分离/合成、视频剪辑/字幕、图片编辑
3. **中文内容创作**：口播文案/公众号/小红书，去AI味，多平台改写
4. **网页应用快速原型**：app-builder比手写HTML快10倍
5. **正式交付物**：飞书文档/PPT/Excel
6. **数据可视化升级**：现有Python+HTML看板可以用豆包可视化能力增强

## 二、豆包项目规划（4个核心项目）

### 项目1：苏不倦-内容工厂

| 项 | 说明 |
|---|---|
| **定位** | 苏不倦IP的文字内容生产中心 |
| **对接OB目录** | 读：自媒体系统/02-选题、苏不倦自媒体方法论、04-数据与复盘；写：自媒体系统/苏不倦方法论、OPC/九思对外输出/01-文章草稿 |
| **核心技能** | `doubao-newmedia-writing`（口播/公众号/小红书）、`doubao-multiplatform-rewrite`（一稿多发）、`doubao-headlines-calendar`（标题A/B+内容日历）、`doubao-human-signal`（去AI味）、`doubao-marketing-material-review`（合规审核） |
| **典型任务** | 口播脚本撰写、公众号文章、小红书笔记、标题打磨、选题排期、文案去AI味、多平台改写 |
| **产出格式** | Markdown文件（直接写OB）、飞书文档 |
| **不做什么** | 不做图片/视频（归视觉工坊）、不做数据采集（归Hermes） |

### 项目2：今日进化-播客与视觉工坊

| 项 | 说明 |
|---|---|
| **定位** | 播客制作+全IP视觉资产+AI音视频生成 |
| **对接OB目录** | 读：播客创作/01-剧本、00-通用资产；写：播客创作/02-音频、设计资产、02-Areas/九思-数字资产/设计资产、自媒体系统/06-设计资产 |
| **核心技能** | `doubao-creative-design`（封面/海报/头像/KV）、`seed-audio`/`text_to_audio`（TTS/音效/配乐）、`byted-mediakit-audio`（降噪/人声分离/音频合成）、`byted-mediakit-editing`（剪辑/拼接/字幕压制/淡入淡出）、`byted-mediakit-video`（视频字幕/画质增强/抠像）、`doubao-creative-video`+`seedance-25`（AI视频生成）、`doubao-video-extract`（视频转写/提取）、`byted-mediakit-image`（图片增强/擦除/抠图） |

## 五、豆包与Hermes协作边界

```
┌─────────────────────────────────────────────────┐
│                  康哥的AI协作体系                  │
├──────────────────────┬──────────────────────────┤
│      Hermes/九思      │      豆包桌面版/九思       │
├──────────────────────┼──────────────────────────┤
│ 系统运维/Skill开发    │ 内容生产（文字+多模态）     │
│ 数据采集/Python脚本   │ 媒资处理（音视频剪辑合成）  │
│ 知识库管理/索引       │ 视觉生成（封面/海报/头像）  │
│ 读书消化/方法论沉淀   │ 网页原型（app-builder）    │
│ 自动化/定时任务       │ 正式交付物（飞书/PPT/PDF） │
│ 投资系统运营          │ 求职弹药库                 │
│ 长期记忆/会话归档     │ 跨会话读OB记忆文件          │
├──────────────────────┴──────────────────────────┤
│          共享：OB知识库（读写各自目录）             │
│          铁律：豆包不碰07-Hermes和九思-SKILL       │
└─────────────────────────────────────────────────┘
```

**数据流：**
- 豆包产出 → 直接写入OB对应目录（md/图片/音视频/html）
- Hermes产出 → 已在OB中
- 豆包读OB → 获取方法论、历史数据、上下文
- 记忆文件 → `02-Areas/九思-记忆库/2026-08-26-康哥长期记忆与交互约定-九思.md`
