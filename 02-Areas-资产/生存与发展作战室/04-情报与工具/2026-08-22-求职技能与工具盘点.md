## 一、求职 Agent Skills（SKILL.md 格式，可直接装）

### 🥇 offer-toolkit-skill — yanliudesign/offer-toolkit-skill

**319★ · v1.2.0 · 2026-08-22 当天还在更新 · MIT · 中英双语**

六个子技能一条龙，每个可单独用，路由自动分发：

| 子技能 | 干什么 |
|:--|:--|
| job-hunt-skill | 喂简历+方向+种子JD → 搜公开渠道 → 去重 → 生成可筛选的 HTML 岗位清单（只发现分析，不代投） |
| job-description-skill | JD+简历 → HTML 报告：值不值得投、匹配度、差距、可能被问什么、薪资是否合理、六周行动建议 |
| resume-skill | 润色/从 LinkedIn 拉取/对话式从零建简历 → **11 套打印级模板**（含 Classic-ATS 等）→ PDF+可编辑 HTML 双输出 |
| bq-skill | 行为面试：挖真实经历建 STAR/CAR 故事库，中英双语打标签；读 JD 预测该公司 20 个可能问题并陪练 |
| offer-compare-skill | 多 offer 对比：四年总包/成长/AI 接触度/风险/晋升/生活/简历价值 → HTML 决策报告+明确建议 |
| salary-negotiation-skill | 诊断薪资筹码 → 谈判策略+电话/邮件话术 → 模拟 HR 反扑 → 明确 sign/walk/stop 三条线 |

四条共享原则（质量信号）：绝不编造经历数字；只问影响答案的问题；先定结构再渲染；**永不代用户投递**。数据全程本地。
兼容性：官方标注 Claude Code / Codex / OpenCode / OpenClaw / Hermes 通用。
用法：整个文件夹丢进 skills 目录即用；30 秒试用：「这个岗位我该投吗」+贴 JD。
