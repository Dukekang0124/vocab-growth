# MediaCrawler 评估 — 多平台爬虫工具

> 2026-08-23 · 来源：掘金公众号文章（微信 mp.weixin.qq.com/s/GWeWfrvVDvwcXFcZdE-HIQ）
> 仓库：github.com/NanmiCoder/MediaCrawler · 6.1 万 Star · 开源版免费（MIT 类），另有付费 Pro

## 是什么

一个工具抓全网主流平台：小红书（笔记+评论）、抖音/快手/B站（视频+评论）、微博/贴吧（帖子+评论）、知乎（问答+文章+评论）。

**核心思路：不逆向，复用浏览器登录态。** 用 Playwright 连接本机已登录的 Chrome（CDP 模式），真实浏览器+真实 Cookie，风控风险远低于脚本；遇验证码自动截图等人工处理。数据存 CSV/JSON/JSONL/Excel，或直写 SQLite/MySQL。

安装三步：uv（Python 包管理器）→ git clone + `uv sync` → 配置 `config/base_config.py`（关键词/平台/存储方式）→ 跑。

额外功能：HomeFeed 首页信息流抓取（做趋势分析）；**AI Agent Skill**（已适配 OpenClaw/Claude Code/Cursor，Agent 可直接调用）；桌面端视频下载器。

## 康哥场景评估（结论：值得用，摆对位置）

| 场景 | 判断 | 用法 |
|---|:--:|---|
| 苏不倦竞品+选题 | ✅ 直接命中 | 抓对标账号爆款笔记+评论区 → 评论区=用户痛点富矿 → 喂选题库（02-投递作战/04-选题库链路） |
| 求职作品集 | ✅ 高价值 | 「爬评论→AI 痛点分析→选题报告」= AI 求职五步法第 4 步的真实项目，投 AI 内容运营岗的开路作品 |
| 技术门槛 | 🟡 可被 AI 代劳 | uv+配置文件级操作，康哥出需求，九思/千问办公执行安装与运行 |
| 法律红线 | ⚠️ 先划清 | 项目免责声明：**仅供学习研究，禁止商业用途**。小规模竞品研究/自身选题分析=低风险；大规模爬取/卖数据/商用=红线；抓取数据不得直接进付费课程素材 |
| 优先级 | 🟡 中 | 排 Bridge 投递、出海课之后；它是弹药工具不是主线，先有具体任务再跑 |

## 落地备忘

- 环境：Windows + 本机 Chrome（保持目标平台已登录、账号无封禁）
- GitHub 下载通道注意：本机 git clone github.com 会被墙重置；备用方案=raw 逐文件（见千问办公记忆的 GitHub 获取通道）或镜像站
- 首选试点任务：苏不倦对标账号近 30 天爆款笔记+评论 → AI 分析「英语自学者高频痛点」→ 产出选题包（一次跑通同时验证工具价值+攒作品案例）
