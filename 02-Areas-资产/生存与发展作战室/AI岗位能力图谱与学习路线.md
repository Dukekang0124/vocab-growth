## 🆕 FDE / 企业AI落地方向（新增，潜在最高价值定位）

> 来源：泛函人物故事《FDE 中的顶尖强者，都是在江湖里杀出来的》——刘今朝（HRBP→企业AI落地）

### 这个方向为什么适合你

| 刘今朝的路径 | 你的对应物 |
|:--|:--|
| HRBP（懂组织）→ FDE | 运营（懂业务）→ 企业AI落地 |
| 编排人类员工 → 编排Agent | 九思系统 = 你已编排12个Agent |
| 技术选型判断力 | 你选工具很准（DeepSeek/智谱/ComfyUI） |
| 结果导向（对使用率/效率负责） | IPTV从0到1年收千万 = 结果导向 |

### FDE核心能力（对照你的现状）

| # | 能力 | 刘今朝怎么做的 | 你现在 | 怎么补 |
|:--:|:--|:--|:--|:--|
| 1 | **看懂业务系统找破局点** | 先判断哪个场景值得先做、最容易被组织看见 | 🟡 有业务sense | 多读企业AI落地案例 |
| 2 | **先小胜换信任** | 多个项目里选最容易交付可见结果的 | ✅ IPTV从0到1 | 保持 |

### 你的隐藏优势
- 九思系统 = 12Agent编排的活体证据（面试直接展示）
- 运营背景 = 懂业务为什么需要AI、组织为什么抗拒
- 省钱机制 = "每个Token花在刀刃上"的选型判断力（不是省小钱，是战略能力）

### 学习路径（2-4周）
```
Week 1-2: 读刘今朝完整案例 + 研究3个企业AI落地案例（名创优品/华为/飞书CLI）
Week 2-3: 把九思系统整理成"企业AI落地案例文档"（可对决策者讲）
Week 3-4: 学Agent评估方法（盲测/一致性测试）→ 应用到九思系统验证
```

### 投递方向
- 企业AI落地负责人 / AI FDE / 数字化转型运营（十五五方向）
- 求职时定位："用AI放大组织生产力的落地者" 而非 "会用AI工具的运营"

## 学习路线（4周速通版）

### Week 1：海外基建
```
Mon: 注册LinkedIn → 完善英文Profile → 发第一条post
Tue: 注册X (Twitter) → 关注AI/增长领域KOL → 互动
Wed: 注册Reddit → 加入r/ArtificialIntelligence、r/SaaS → 潜水学习
Thu: Google Analytics安装到作品集网站
Fri: 研究Bridge官网 → 理解其产品和增长策略
Sat: 生姜Iris出海课 第一课（五大致命误区）
Sun: 本周复盘 → 整理学到的东西发一条LinkedIn帖子
```

### Week 2：增长体系
```
Mon: 生姜Iris出海课 第三课（增长基本流程）
Tue: 学习AARRR模型（Acquisition-Activation-Retention-Revenue-Referral）
Wed: 研究3个AI Agent产品的增长案例
Thu: 生姜Iris出海课 竞品调研篇
Fri: Google Analytics进阶——设目标+转化追踪
Sat: Fiverr发布第一个Gig
Sun: 本周复盘
```

### Week 3：SEO+数据分析
```
Mon: Ahrefs入门 → 关键词研究基础
Tue: On-page SEO → 优化你作品集网站的SEO
Wed: Google Analytics + PostHog基础
Thu: SQL基础（SELECT/WHERE/JOIN）→ W3Schools教程
Fri: 研究Saparo.ai官网 → 分析其海外策略
Sat: Fiverr优化Gig → 看数据调整
Sun: 本周复盘
```

### Week 4：视频号+直播+投递
```
Mon: 下载视频号 → 关注方比比+同赛道TOP10 → 分析内容结构
Tue: 看方比比直播 → 记录场控/话术/节奏
Wed: 用OBS模拟一次直播 → 练习基础操作
Thu: 写Bridge投递邮件 → 附作品集
Fri: 写方比比团队投递邮件 → 附苏不倦账号
Sat: Fiverr数据分析 → 调整策略
Sun: 月度复盘 → 更新能力差距表
```
