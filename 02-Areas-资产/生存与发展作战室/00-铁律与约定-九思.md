# 00 · 铁律与约定

> 建立：2026-08-22 · 康哥亲授 · 最高优先级，覆盖本文件夹所有操作

## 铁律一：实时沉淀，结构化分类

凡是交流的内容、形成的方法论、形成的 skill 等，**都要存在本文件夹下**，按结构化分类规则归档：

| 内容类型 | 落点 | 命名 |
|:--|:--|:--|
| 对话结论、会话记录、决策 | `05-记忆库/` | `YYYY-MM-DD-主题.md` |
| 方法论、专题研究、笔记 | 主题分类文件夹（`01-战略与方法论` 至 `04-情报与工具`） | 同上 |
| 脚本、模板、图表、可复用产出 | `06-数字资产/` | `主题-类型-版本` |
| Skill（技能） | `07-SKILL/`（D 盘正本）+ 系统目录注册副本 | `skill名/SKILL.md` |
| 长期约定、规则 | 本文件 `00-铁律与约定.md` | — |

- 每次交流后**实时写、不遗漏**，不等提醒。
- 新增文件必须**顺手更新 `README.md` 索引**。
- 机制建了要真执行，沉淀要可验证。

## 铁律二：D 盘为家，三位一体

所有内容尽可能都存放在 D 盘本文件夹，使其成为**记忆库 + 知识库 + 数字资产库**三位一体的核心载体：

- **记忆库**：跨会话可查的对话沉淀与决策记录（05-记忆库）
- **知识库**：方法论与专题知识的结构化体系（01-战略与方法论 至 04-情报与工具 + 后续扩展）
- **数字资产库**：可复用、可直接交付的产出物（06-数字资产）
- 不往 C 盘写非必要内容；系统正常运行必需部件（程序/配置/技能注册副本）除外。
- 千问办公侧已同步存有 vault 路径与关键情报的记忆，双保险。

## 边界（继承 08 区既有约定）

- 本文件夹在 Hermes vault 内，逻辑独立分区；**不改动** Hermes 的任何机制与其他目录。
- 与九思（WorkBuddy）的关系：同一地盘的两个协作者，先到先得不动对方文件，冲突时康哥裁决。
