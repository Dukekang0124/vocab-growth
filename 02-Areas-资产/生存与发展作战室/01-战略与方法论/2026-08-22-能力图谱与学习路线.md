## 4 周速通学习路线

### Week 1：海外基建
```
Mon: 注册LinkedIn → 完善英文Profile → 发第一条post
Tue: 注册X → 关注AI/增长KOL → 互动
Wed: 注册Reddit → 加入r/ArtificialIntelligence、r/SaaS → 潜水
Thu: Google Analytics安装到作品集网站
Fri: 研究Bridge官网 → 理解产品和增长策略
Sat: 生姜Iris出海课 第一课（五大致命误区）
Sun: 复盘 → 发一条LinkedIn帖子
```

### Week 2：增长体系
```
Mon: 生姜Iris 第三课（增长基本流程）
Tue: AARRR模型（Acquisition-Activation-Retention-Revenue-Referral）
Wed: 研究3个AI Agent产品增长案例
Thu: 出海课竞品调研篇
Fri: Google Analytics进阶——目标+转化追踪
Sat: Fiverr发布第一个Gig
Sun: 复盘
```

### Week 3：SEO+数据分析
```
Mon: Ahrefs入门 → 关键词研究基础
Tue: On-page SEO → 优化作品集网站
Wed: Google Analytics + PostHog基础
Thu: SQL基础（SELECT/WHERE/JOIN）→ W3Schools
Fri: 研究Saparo.ai官网 → 分析海外策略
Sat: Fiverr优化Gig看数据
Sun: 复盘
```

### Week 4：视频号+直播+投递
```
Mon: 视频号 → 关注方比比+同赛道TOP10 → 分析内容结构
Tue: 看方比比直播 → 记录场控/话术/节奏
Wed: OBS模拟一次直播
Thu: 写Bridge投递邮件 → 附作品集
Fri: 写方比比团队投递邮件 → 附苏不倦账号
Sat: Fiverr数据分析调整策略
Sun: 月度复盘 → 更新能力差距表
```
