## 一句话定位

## 核心方法论：行业 → 公司 → 岗位

源于泛函（AI猎头）：不要先盯岗位名，先看哪个行业在涨，再找行业里的公司，最后看你能在那些公司里做什么。

### 战略铁律

```
❌ 盲目搜岗位名 → 海投 → 石沉大海
✅ 行业筛选 → 公司锁定 → 岗位匹配 → 精准投递
```
