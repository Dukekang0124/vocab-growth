## 一分钟结论（康哥当前个人发展全局）

1. **战略**：自媒体（苏不倦）是主战场，求职是保底供氧线，不是 all in 求高薪。
2. **求职定位**：帮传统行业/企业落地 AI 的运营；潜力最高方向 = FDE/企业AI落地（运营背景 + 九思系统 = 活体证据）。
3. **投递方法**：行业→公司→岗位，精投不海投，6 条主线里运营商数智化和出海增长是双主攻。
4. **能力策略**：缺什么补什么——Tier 1 五项（英语书面/海外社媒/增长方法论/SEO/B2B认知）按 4 周路线补齐。
5. **硬性铁律**：pass 就是 pass 不翻盘；非 AI 岗不推荐；学历卡本科直接跳；<8K 不投。
6. **当前最优先动作**：Bridge 投递邮件（见 02-投递作战，待康哥审定发送）。
